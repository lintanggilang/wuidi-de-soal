  • B. Create a KMS multi-region key: replicate the primary key from us-east-1 to eu-west-1 as a replica key. Configure S3 CRR to use the replica key in the destination region. S3 CRR with KMS encryption requires destination-region key configuration: Option 1 — Multi-Region Keys (MRK): Create MRK in us-east-1 (primary key). Replicate to eu-west-1 (replica key).
