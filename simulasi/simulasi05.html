Skill 1.1.1
A data engineer is designing a real-time analytics pipeline using Amazon Kinesis Data Streams. The stream receives 5,000 records per second with an average record size of 50 KB. The engineer needs to determine the number of shards required. What is the MINIMUM number of shards needed to handle this throughput?
  • A. 5 shards
  • B. 50 shards
  • C. 250 shards
  • D. 500 shards
Jawaban Benar: C
Setiap shard Kinesis mendukung hingga 1 MB/detik atau 1.000 records/detik untuk write. Berdasarkan throughput data: 5.000 records × 50 KB = 250.000 KB/detik = ~244 MB/detik. Berdasarkan volume: 244 MB / 1 MB per shard = 244 shards (dibulatkan ke 250). Berdasarkan jumlah records: 5.000 / 1.000 = 5 shards. Bottleneck ada pada throughput data (MB/s), sehingga minimal 250 shards diperlukan. Opsi A dan B terlalu sedikit. Opsi D berlebihan.

A data platform team wants to publish a curated "customer_360" dataset as a data product in Amazon DataZone. The underlying data comes from three sources: S3 (raw data), Redshift (aggregated metrics), and a Glue table (transformed features). They want consumers to access a unified view without knowing the underlying sources. Which DataZone publishing approach achieves this?
  • A. Publish each source (S3, Redshift, Glue) as separate assets and let consumers subscribe to all three individually
  • B. Create a Glue ETL job that consolidates all three sources into a single curated table, register this table as a data asset in the DataZone catalog with comprehensive metadata (description, schema, quality metrics, lineage), and publish it as a single data product from the producer project
  • C. Create a DataZone "composite asset" that virtually joins the three sources at query time
  • D. Export all data to a single S3 bucket and share the bucket ARN through DataZone
Jawaban Benar: B
Best practice untuk data products adalah menyediakan curated, ready-to-consume datasets. Consolidating three sources ke single curated table (via Glue ETL) kemudian publishing sebagai single asset memberikan: (1) clean consumer experience — satu subscription, satu table, (2) abstraction — consumers tidak perlu tahu tentang underlying 3 sources, (3) quality control — producer ensures data quality sebelum publishing, (4) rich metadata — description, schema documentation, data quality scores, lineage showing where data came from. Opsi A — three separate subscriptions creates friction dan exposes implementation details ke consumers. Opsi C — DataZone tidak memiliki "composite asset" feature yang auto-joins sources. Opsi D — sharing raw bucket ARN bypasses catalog governance dan metadata enrichment.

A company is building a data governance framework and needs to define data classification levels with corresponding handling requirements. They have four levels: Public, Internal, Confidential, and Restricted. Which classification-to-control mapping represents best practices for an AWS data platform?
  • A. All levels receive the same encryption and access controls to simplify management
  • B. Public: no encryption needed, open access | Internal: SSE-S3, authenticated users | Confidential: SSE-KMS with CMK, role-based access, audit logging | Restricted: SSE-KMS with CMK + CloudHSM key store, MFA-required access, real-time monitoring, DLP scanning, data masking for non-privileged users
  • C. Public: SSE-S3 | Internal: SSE-S3 | Confidential: SSE-S3 | Restricted: SSE-KMS — only encryption level changes between classifications
  • D. Classification levels only affect who can view data in the catalog; actual security controls are the same regardless of classification
Jawaban Benar: B
Data classification framework yang efektif menerapkan controls proportional to sensitivity level. Progressive security controls: Public — minimal controls karena data bisa diakses siapa saja. Internal — basic encryption (SSE-S3 managed) dan authentication required. Confidential — stronger encryption (customer-managed CMK memberikan key rotation control dan access audit), role-based access (least privilege), dan audit logging wajib. Restricted — maximum controls: CMK dengan CloudHSM key store (FIPS 140-2 Level 3), MFA required untuk decrypt operations, real-time monitoring (GuardDuty, Macie), DLP scanning, dan dynamic data masking. Opsi A — uniform controls wastes resources untuk low-sensitivity data atau under-protects high-sensitivity. Opsi C — encryption alone tidak sufficient; access control, monitoring, dan other controls harus juga progressive. Opsi D — classification tanpa corresponding controls tidak meaningful.
