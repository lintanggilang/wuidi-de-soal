A data engineer is designing a real-time analytics pipeline using Amazon Kinesis Data Streams. The stream receives 5,000 records per second with an average record size of 50 KB. The engineer needs to determine the number of shards required. What is the MINIMUM number of shards needed to handle this throughput?
  • A. 250 shards
  • B. 5 shards
  • C. 245 shards
  • D. 500 shards

Berdasarkan volume: 244 MB / 1 MB per shard = 244 shards (dibulatkan ke 250). Berdasarkan jumlah records: 5.000 / 1.000 = 5 shards. Opsi A: BENAR.
Opsi B: SALAH. Dan B terlalu sedikit.
Opsi C: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi D: SALAH. Berlebihan.
