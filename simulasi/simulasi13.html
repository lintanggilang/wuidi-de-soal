Cross-account copy with different KMS keys requires dual key permissions: Process during S3 CopyObject: (1) S3 reads source object → needs kms:Decrypt on SOURCE key (Account A's CMK). (2) S3 prepares to write to destination → needs kms:GenerateDataKey on DESTINATION key (Account B's CMK). (3) In memory: source decrypted → immediately re-encrypted with new data key from destination CMK. (4) Re-encrypted object written to destination bucket.
