Organization trails that is created from management account automatically is applied to all akun anggota in entire region. Member accounts cannot memodifikasi or deletes organization trail — only management account that has kontrol full. This provides audit trail terpusat and tamper-resistant.

A Brazilian healthcare company must comply with LGPD (Lei Geral de Proteção de Dados) which requires patient data to be stored in Brazil. They use AWS KMS for encryption. The security architect argues that KMS keys used to encrypt patient data must also be in the same region as the data. Why is this important for data sovereignty, and what happens if the KMS key is in a different region?
  • A. KMS keys automatically replicate to the region where data is stored, so there's no sovereignty concern, satisfying all of the stated requirements with minimal effort and protecting the data both in transit and at rest and satisfying strict compliance and audit requirements
  • B. Key location only matters for performance (latency), not for sovereignty compliance, handling the described workload reliably at scale and satisfying all of the stated requirements with minimal effort and satisfying strict compliance and audit requirements and enforcing encryption and fine-grained access control
  • C. KMS keys are global and can be used from any region, so key location doesn't matter for sovereignty with a key in us-east-1, protecting the data both in transit and at rest and integrating natively with the rest of the pipeline
  • D. KMS keys are regional. If data is in sa-east-1 but encrypted with a key in us-east-1, decryption requests must reach us-east-1, creating a technical dependency on a foreign jurisdiction and potentially violating sovereignty requirements if the foreign region becomes inaccessible
Correct Answer: D
KMS keys bersifat REGIONAL — key that is created in us-east-1 only can is used in us-east-1. This menciptakan: (1) dependency jurisdiksi asing — if US government issues order related key in us-east-1, this can affects access to data Brasil, (2) availability risk — if connection to us-east-1 terputus, data in sa-east-1 cannot didekripsi. For sovereignty, key MUST berada in region that same with data.

Option A: INCORRECT. Incorrect — KMS keys not auto-replicate (multi-Region keys there is but must explicitly configured).
Option B: INCORRECT. Besides performance, sovereignty and jurisdictional control is concern main.
Option C: INCORRECT. Incorrect — KMS keys not global — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
