Skill 3.2.1: Visualize data (QuickSight)

QuickSightDataBrewvisualization

Summary

Skill this including in Domain 3: Operations & Support (Task 3.2: Analyze data by using AWS services), with fokus on visualize data (quicksight). Materi berikut merangkum service AWS that relevan along with concept important that needs kamu kuasai for topik this.

Key Services & Concepts

AWS Glue DataBrew
Persiapan data visual (no-code) for membersihkan and menormalkan data.
Amazon QuickSight
BI/visualisasi managed with engine SPICE for dashboard interaktif.

Key Points

  • SPICE is in-memory calculation engine milik QuickSight that stores data in a local so that interaksi dashboard very fast without needing query ulang to source data. SPICE supports miliaran rows and provides sub-second response time for filter and drill-down.
  • QuickSight embedded analytics enables penyematan dashboard to application or portal web external. By anonymous embedding, user does not need akun AWS or QuickSight, quite accesses via URL that in-embed. This most cost-effective for ratusan user external because dikenakan cost per session, not per user.
  • DataBrew profile jobs automatically menganalisis all column and produces statistics komprehensif including null rate, distribution value, korelasi between column, duplikat, and outlier without needing writes code. This is way tercepat for gets overview kualitas data.
  • Row-Level Security (RLS) in QuickSight enables creation one dataset and one dashboard that automatically filters data based on user/group. Permissions dataset contains mapping between username/group and value department_id that boleh dilihat. This is solution most scalable and maintainable.
  • Amazon QuickSight has feature ML Insights bawaan that mencakup anomaly detection (detects outlier without threshold manual uses Random Cut Forest) and forecasting (prediksi tren uses built-in ML models). Keduanya can enabled directly on visual without needing ML expertise.
  • QuickSight SPICE supports incremental refresh that only retrieves data new/changes based on column date/timestamp. For RDS that changes harian, incremental refresh saves time and SPICE capacity. For S3 CSV that only update bulanan, full refresh bulanan already quite.
  • For authenticated embedding with SSO, QuickSight supports SAML federation. Setelah user terdaftar via SAML (Okta as IdP), application backend calls GetDashboardEmbedUrl API with identity type QUICKSIGHT for gets signed URL that in-embed. This provides SSO seamless.
  • DataBrew profile jobs can is configured with number node (max workers) that larger for increases paralelisme and reduces time eksekusi. Increases node allocation is way directly for speeds up profile job on dataset large.
  • Amazon Athena in a native terintegrasi with AWS Glue Data Catalog and can directly query data Parquet in S3 without infrastructure additional (serverless). QuickSight has native connector to Athena, so that can directly memvisualisasikan data from data lake.
  • Amazon EventBridge captures event from QuickSight including dataset refresh success/failure in real-time. Event rule can is configured for filters only failure events and mengirimkannya to SNS topic for notifikasi email/SMS. This is approach event-driven that most operationally efficient.
