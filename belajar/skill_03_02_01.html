Skill 3.2.1: Visualize data (QuickSight)

QuickSightDataBrewvisualization

Ringkasan

Skill ini termasuk dalam Domain 3: Operations & Support (Task 3.2: Analyze data by using AWS services), dengan fokus pada visualize data (quicksight). Materi berikut merangkum layanan AWS yang relevan beserta konsep penting yang perlu kamu kuasai untuk topik ini.

Layanan & Konsep Utama

AWS Glue DataBrew
Persiapan data visual (no-code) untuk membersihkan dan menormalkan data.
Amazon QuickSight
BI/visualisasi terkelola dengan engine SPICE untuk dashboard interaktif.

Poin-Poin Kunci

  • SPICE adalah in-memory calculation engine milik QuickSight yang menyimpan data secara lokal sehingga interaksi dashboard sangat cepat tanpa perlu query ulang ke sumber data. SPICE mendukung miliaran baris dan menyediakan sub-second response time untuk filter dan drill-down.
  • QuickSight embedded analytics memungkinkan penyematan dashboard ke aplikasi atau portal web eksternal. Dengan anonymous embedding, pengguna tidak perlu akun AWS atau QuickSight, cukup mengakses via URL yang di-embed. Ini paling cost-effective untuk ratusan pengguna eksternal karena dikenakan biaya per session, bukan per user.
  • DataBrew profile jobs secara otomatis menganalisis semua kolom dan menghasilkan statistik komprehensif termasuk null rate, distribusi nilai, korelasi antar kolom, duplikat, dan outlier tanpa perlu menulis kode. Ini adalah cara tercepat untuk mendapatkan overview kualitas data.
  • Row-Level Security (RLS) di QuickSight memungkinkan pembuatan satu dataset dan satu dashboard yang secara otomatis memfilter data berdasarkan user/group. Permissions dataset berisi mapping antara username/group dan nilai department_id yang boleh dilihat. Ini adalah solusi paling scalable dan maintainable.
  • Amazon QuickSight memiliki fitur ML Insights bawaan yang mencakup anomaly detection (mendeteksi outlier tanpa threshold manual menggunakan Random Cut Forest) dan forecasting (prediksi tren menggunakan built-in ML models). Keduanya bisa diaktifkan langsung pada visual tanpa perlu ML expertise.
  • QuickSight SPICE mendukung incremental refresh yang hanya mengambil data baru/berubah berdasarkan kolom date/timestamp. Untuk RDS yang berubah harian, incremental refresh menghemat waktu dan SPICE capacity. Untuk S3 CSV yang hanya update bulanan, full refresh bulanan sudah cukup.
  • Untuk authenticated embedding dengan SSO, QuickSight mendukung SAML federation. Setelah user terdaftar via SAML (Okta sebagai IdP), aplikasi backend memanggil GetDashboardEmbedUrl API dengan identity type QUICKSIGHT untuk mendapatkan signed URL yang di-embed. Ini memberikan SSO seamless.
  • DataBrew profile jobs dapat dikonfigurasi dengan jumlah node (max workers) yang lebih besar untuk meningkatkan paralelisme dan mengurangi waktu eksekusi. Meningkatkan node allocation adalah cara langsung untuk mempercepat profile job pada dataset besar.
  • Amazon Athena secara native terintegrasi dengan AWS Glue Data Catalog dan bisa langsung query data Parquet di S3 tanpa infrastruktur tambahan (serverless). QuickSight memiliki native connector ke Athena, sehingga bisa langsung memvisualisasikan data dari data lake.
  • Amazon EventBridge menangkap event dari QuickSight termasuk dataset refresh success/failure secara real-time. Event rule dapat dikonfigurasi untuk memfilter hanya failure events dan mengirimkannya ke SNS topic untuk notifikasi email/SMS. Ini adalah pendekatan event-driven yang paling operasionally efisien.

  • Memerlukan coding dan maintenance.

  • Memerlukan banyak dataset duplikat.
  • Menyembunyikan kolom, bukan memfilter baris.

  • Terlalu kompleks untuk kebutuhan ini.
  • Memerlukan pengembangan dan maintenance custom solution.
