Key Points

  • For workload that predictable, consistent, and runs each days sepanjang years, Reserved Instances provides diskon up to 72% dibanding On-Demand pricing. EMR on EC2 with RI ideal for sustained utilization pattern. EMR Serverless mengenakan premium for convenience and more cost-effective for sporadic/unpredictable workloads.
  • Redshift Serverless automatically scales compute resources based on workload demand. On days without query, cost mendekati nol (only storage). On days sibuk, resources scale up appropriate requirements. RPU base capacity enables warm state for response fast.
  • For spikes that diketahui previously (game launches scheduled), scheduled scaling on provisioned capacity is choice most cost-effective. Table in-scale up before launch and scale down after traffic returns normal.
  • Keuntungan main serverless (Glue) is eliminasi operational overhead. Tim does not need manages cluster lifecycle (start/stop/resize), OS patching, security updates, or capacity planning. For team with limited DevOps, this very significant.
  • Amazon EMR on EC2 with long-running Spark Structured Streaming application always active and ready to process data without cold start. Application terus polling source data and processes in micro-batches (can serendah 100ms trigger interval). Zero cold start because cluster always running.
  • Arsitektur hybrid provides optimization best: Redshift Serverless handles complex analytical queries with performa high and auto-scales based on demand (hemat when volume low). Athena handles simple ad-hoc queries with cost per-scan that minimal. This provides cost-effectiveness because second service only charge when is used.
  • Amazon EMR on EC2 provides fleksibilitas maksimum: supports all framework Hadoop ecosystem (Spark, Hive, Presto, HBase), enables custom AMIs, bootstrap actions for configuration specific, and kontrol full above versi framework. This most similar with on-premises Hadoop.
  • AWS serverless data services (Glue, Athena, Redshift Serverless, EMR Serverless) semuanya supports VPC deployment, KMS customer-managed keys, and CloudTrail logging. Keamanan not lagi differentiator main between provisioned and serverless.
  • EMR Serverless pre-initialized capacity (pre-warmed workers) maintains pool of initialized workers that ready to execute, eliminates cold start time. Workers still warm and can directly starts processing. Biaya pre-initialized workers lower from running cluster but eliminates 4-5 minutes cold start.
  • TCO comparison between provisioned (RI) and serverless depends on average utilization. Provisioned RI provides fixed cost regardless of usage, so that semakin high utilization semakin cost-effective. Weighted average utilization: (8h × 80% + 4h × 40% + 12h × 5%) / 24h ≈ 37%. By RI discounts (up to 72% off on-demand), provisioned becomes cheaper in titik this dibanding serverless that charges per-RPU-hour consumed.
