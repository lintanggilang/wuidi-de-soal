Skill this including in Domain 3: Operations & Support (Task 3.1: Automate data processing), with fokus on aws service features for processing. Materi berikut merangkum service AWS that relevan beserta concept important that needs kamu kuasai for topik this.

Key Services & Concepts

AWS Glue
ETL serverless based on Spark + Data Catalog; ideal for transformation and katalogisasi data.
Amazon EMR
Cluster big data managed (Spark, Hive, Presto); supports Spot Instances for hemat cost.
Amazon Redshift
Data warehouse scale petabyte; supports COPY/UNLOAD, materialized view, and streaming ingestion.
Redshift Streaming Ingestion
Konsumsi directly from Kinesis/MSK to materialized view Redshift, latensi seconds, without staging S3.

Key Points

  • AWS Glue DynamicFrames designed khusus for handles data semi-structured with schema that not consistent. DynamicFrame has feature "choice type" that detects when field has type data different in record that different, and transform Relationalize automatically memecah nested arrays menjadi table relasional separate.
  • EMR instance fleets with allocation strategy "capacity-optimized" memilih instance types from Spot capacity pools that most available, reduces possibility interruption. By configures multiple instance types, EMR has more opsi for gets capacity Spot that stabil.
  • Materialized views in Amazon Redshift stores result query that already in-precompute and supports AUTO REFRESH that automatically updates data when table base changes. Ini menyederhanakan ETL because not requires orchestration external.
  • AWS Glue crawlers designed for automation schema discovery. By jadwal crawl and opsi "Update the table definition in the Data Catalog", crawler will detects changes schema (kolom new, type data changes) and updates Data Catalog automatically. Ini supports berbagai format file and not requires code kustom.
  • EMR auto-termination policy automatically menghentikan cluster setelah there is no job that runs during periode idle that is determined. Ini ensures cluster only active saat is required without risiko kehilangan data because termination only occurs saat idle.
  • Redshift stored procedures supports procedural logic (IF/ELSE, loops, variables) with transaction control full (BEGIN/COMMIT/ROLLBACK), enables entire ELT workflow dieksekusi sebagai atomic unit in in Redshift. This is ideal for business logic kompleks that requires konsistensi.
  • AWS Glue interactive sessions provides environment serverless on-demand for development interaktif. Engineer can runs code snippets, melihat result intermediate, and performs iterasi fast without provisioning infrastructure. Sessions dimulai in hitungan seconds and only dikenakan cost saat is used.
  • Amazon EMR Serverless eliminates requirements provisioning and management cluster sepenuhnya. Job runs on-demand with auto-scaling automatic, and perusahaan only membayar for compute resources that is used during job execution. This is ideal for workloads that not terprediksi.
  • AWS Glue supports interoperabilitas between DynamicFrames and Spark DataFrames. Uses .toDF() for konversi to DataFrame enables usage entire Spark API (UDFs, broadcast joins, window functions), while fromDF() enables konversi returns to DynamicFrame for memanfaatkan feature Glue such as bookmarks and error handling.
  • Redshift stored procedures supports exception handling (BEGIN...EXCEPTION...END blocks), conditional logic (IF/ELSE), loops, variabel, CTEs, and temporary tables — all in satu procedural unit. System tables such as STL_LOAD_ERRORS and SVL_QLOG provides detailed logging native in Redshift. Ini memenuhi all requirements without exits from Redshift.
