Key Services & Concepts

AWS Glue DataBrew
Persiapan data visual (no-code) for membersihkan and menormalkan data.
AWS Lake Formation
Tata kelola data lake: permission based on table/column/rows and LF-Tags in above Glue Catalog.
Amazon SageMaker
Platform ML end-to-end; SageMaker Catalog/Unified Studio for governance & discovery data.

Key Points

  • AWS Glue DataBrew provides visual interface no-code for data preparation with 250+ built-in transformations. Recipes can is created at all and is run berulang kali (repeatable) for each batch file new. DataBrew has built-in functions for date parsing multi-format, null handling, and string formatting.
  • DataBrew data quality rules (rulesets) enables definisi rule validation (regex patterns, range checks, null thresholds, date ranges) that diaplikasikan through profile jobs. Hasilnya indicates persentase data that pass/fail each rule, provides visibility to data quality without changes data.
  • Amazon SageMaker Data Wrangler designed khusus for ML data preparation. Ia provides visual interface for feature engineering (one-hot encoding, normalization, imputation), data exploration with built-in visualizations, and capabilities export to SageMaker Pipeline for production. This mencakup all requirements: visual exploration, ML-specific transforms, and pipeline export.
  • DataBrew recipe jobs is mekanisme production-ready for runs recipes on full datasets. Recipe jobs can is configured with output to S3 (berbagai format: CSV, Parquet, JSON), and scheduled uses built-in scheduler or EventBridge for automasi harian. DataBrew automatically handles scaling for dataset large.
  • AWS Glue ETL better suited for complex multi-table joins, conditional business logic that requires programming constructs (PySpark/Scala), and custom partitioning schemes. Glue ETL provides full control above Spark processing that is required for scenario kompleks this.
  • DataBrew provides built-in string transformations (TRIM, UPPER, LOWER, PROPER_CASE) for standarisasi format teks, and supports configuration character encoding when import dataset so that can handles berbagai encoding source. Kombinasi this solves second problem (encoding + formatting) in one tool.
  • DataBrew profile jobs automatically produces comprehensive statistics for each column: data types, unique values, missing values, distributions, percentiles, correlations, and outlier detection — without writes code apapun. Profile runs as managed job that scale automatic.
  • DataBrew supports duplicate removal based on grouping columns. By pre-standardisasi nama (UPPER, TRIM for deletes variasi formatting), exact match on nama that already distandardisasi bersama date of birth and insurance ID provides deduplication that effective.
  • Urutan that correct is: (1) Fix format first (comma → dot) so that string can diparse, (2) Cast to numeric so that operation numerik can is performed, (3) Normalize timestamps to UTC for konsistensi temporal, (4) Forward-fill missing values that requires data already in type that correct and order temporal that correct.
  • DataBrew recipes supports versioning — each publish creates versi new that immutable. IAM policies can controls who that boleh publish recipes (data stewards) vs who that boleh runs recipe jobs. CloudTrail logs all API calls including recipe modifications for audit trail lengkap. Kombinasi this provides governance built-in without tools external.
