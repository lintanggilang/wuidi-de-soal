Key Points

  • AWS Glue Data Quality enables definisi rules in a deklaratif uses Data Quality Definition Language (DQDL). Rules can dievaluasi automatically during ETL job execution and terintegrasi directly with Glue Data Catalog. Rules such as Completeness, ColumnValues range check can didefinisikan without coding.
  • Amazon Athena is solution serverless that can directly query data in S3 without loading or provisioning. Query GROUP BY with HAVING COUNT > 1 will segera indicates skala duplikasi and record specific. This most fast because zero setup.
  • Amazon Data Firehose with transformation Lambda is solution most terintegrasi for validation real-time before data enters to data lake (S3). Lambda performs validation JSON and range check, returns status Ok for valid records and ProcessingFailed for invalid records. Firehose automatically separates failed records to error prefix.
  • Jupyter Notebooks on EMR provides fleksibilitas full for eksplorasi interaktif uses PySpark and pandas. Data scientist can mencoba berbagai strategy cleaning in a iteratif, writes custom parsing logic, and directly melihat hasilnya. This most suitable for complexity format that requires logic custom.
  • AWS Glue Data Quality with EvaluateDataQuality transform enables definisi rules deklaratif for referential integrity (ReferentialIntegrity), freshness (DataFreshness), and uniqueness (Uniqueness). Rules dievaluasi inline in Glue workflow and can is configured for menghentikan job if fails. Integrasi with CloudWatch enables alerting automatic.
  • Athena CTAS (CREATE TABLE AS SELECT) is approach most cost-effective because serverless and Anda only membayar per data that in-scan. By function date_parse and CASE statements, Anda can detects format and mengkonversi to standard. Hasilnya directly available as table new in Glue Data Catalog.
  • SageMaker Data Wrangler provides built-in transforms for Handle Outliers (including Winsorization that caps values on percentile certain) and Handle Missing Values (including imputation with median, mean, or custom value). Kedua operation this available as visual transforms without coding.
  • AWS Glue Data Quality evaluation results can in-export to S3 in format that can in-catalog by Glue Crawler. By data historis in S3, QuickSight can creates dashboard interaktif that menampilkan tren quality scores per source, trend degradation, and drill-down to specific rules. This provides visualisasi most kaya and interaktif.
  • Uses Glue ETL with configuration mapping in DynamoDB is approach most maintainable. When supplier new is added, quite adds entry in table configuration without changes code ETL. DynamicFrame with ApplyMapping supports schema that flexible.
  • AWS DMS has feature data validation bawaan that automatically membandingkan data between source and target during migration task. Feature this performs row-by-row comparison, memeriksa row count, and reports mismatches. This most efficient because terintegrasi directly with process migration.
