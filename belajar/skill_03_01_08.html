Key Services & Concepts

AWS Lambda
Komputasi serverless event-driven; limit timeout 15 minutes and memory up to 10 GB.
Amazon EventBridge
Event bus serverless for routing event between service; supports schedule rule.

Key Points

  • Event source mapping maximum concurrency (feature that more new) directly limits number concurrent Lambda invocations that is triggered by SQS, provides kontrol that presisi. Batch size 10 processes more messages per invocation, speeds up processing.
  • For Kinesis event source mappings, "bisect on function error" memecah batch becomes two if occurs error, in a progresif isolates record that problematic. "Maximum retry attempts" limits how many kali record diretryi. "On-failure destination" sends failed record to SQS DLQ after retry limit is reached, enables processing melanjutkan to record berikutnya.
  • Lambda layers enables packaging shared dependencies in a separate from function code. Layers can in-share between multiple functions and in-version independently. When dependency diupdate, only layer version new that in-publish and functions uses versi new. This reduces deployment package size (function code without dependencies) and centralize management.
  • Lambda destinations (feature async invocation) enables routing result invocation — good success maupun failure — to target destinations such as Lambda function, SQS, SNS, or EventBridge. On-failure destination directly sends event payload along with error details to Lambda other for analysis. This more rich dibanding DLQ because menyertakan response payload and metadata.
  • AWS Lambda Power Tuning is open-source tool (Step Functions-based) that automatically runs function with berbagai memory configurations, mengukur execution time and cost for each, and produces visualization curve that indicates sweet spot optimal. This data-driven and comprehensive.
  • Parallelization factor (1-10) enables multiple Lambda invocations per shard, increases throughput processing without adds shard. DynamoDB Streams mempertahankan records during 24 hours, jadi data not hilang during throttle — only processing tertunda. Increasing reserved concurrency ensures function has capacity for burst.
  • Lambda supports ephemeral storage (/tmp) up to 10,240 MB (10 GB), quite for file 5 GB. Streaming processing (reads and writes file in chunks) avoids requirements memuat entire file to memory sekaligus, enables processing file large with memory that smaller.
  • AWS Step Functions provides orchestration visual with: parallel states for steps that can run concurrently, Retry policies per step (configurable intervals, max attempts, backoff rate), Catch blocks for error handling specific per step, and conditional branching (Choice state). This provides full control and visibility above multi-step pipeline.
  • Places SQS queue between S3 events and Lambda provides buffering — events not hilang because persisted in queue. Lambda SQS event source mapping with maximum concurrency setting controls how many many concurrent invocations, prevents throttling. SQS messages in-retry automatically if processing fails.
  • Lambda function URLs provides dedicated HTTPS endpoint directly for Lambda function without requires API Gateway or load balancer. By auth type NONE, endpoint becomes public. Function URLs supports request/response streaming, built-in HTTPS, and CORS configuration. This is solution most simple for simple HTTP endpoints.
