Skill this including in Domain 1: Ingestion & Transformation (Task 1.1: Perform data ingestion), with fokus on set up schedulers. Materi berikut merangkum service AWS that relevan along with concept important that needs kamu kuasai for topik this.

Key Services & Concepts

Amazon EventBridge
Event bus serverless for routing event between service; supports schedule rule.
EventBridge Scheduler
Penjadwal managed (cron/rate) scale large for triggers target AWS.
Amazon MWAA
Managed Workflows for Apache Airflow; orkestrasi pipeline based on DAG.

Key Points

  • EventBridge (penerus CloudWatch Events) supports cron expressions that can determines days in weeks. cron(0 6 ? * MON-FRI *) runs on pukul 6:00 UTC only on days Senin up to Jumat. This solution most simple and native.
  • AWS Glue Workflows designed khusus for orchestrates multiple Glue jobs with dependensi. Workflows supports triggers conditional (on job success/failure) and fan-out/fan-in patterns. For pipeline that sepenuhnya uses Glue jobs, this is solution most terintegrasi.
  • Amazon MWAA (Apache Airflow) is one-satunya solution that provides all feature: DAG visualization, cross-system orchestration (Glue, EMR, Redshift, APIs), retry policies, SLA monitoring, and alerting built-in. This designed for pipeline orchestration scale enterprise.
  • Uses EventBridge for detects S3:PutObject events and triggers crawler only when data new tiba eliminates run that does not need. Crawler only runs when there is data new.
  • Apache Airflow supports timezone-aware scheduling uses library pendulum. By determines timezone in start_date, Airflow automatically handles transisi DST. DAG will always runs on 8:00 AM Eastern terlepas from whether EST or EDT applies.
  • MWAA (Airflow) provides built-in support for retries, retry_delay, and callbacks (on_failure_callback) in one configuration DAG. This mencakup all requirements: scheduling, retry logic, interval, and notification.
  • MaxConcurrentRuns = 1 on Glue job ensures only one instance job that runs on one time. If schedule triggers run new while run previously still runs, run new will diskip or queued.
  • MWAA uses S3 bucket for DAGs (dags/ folder), plugins (plugins.zip), and dependencies (requirements.txt). Custom Python packages didaftarkan in requirements.txt and diinstall automatic when environment update. Plugins (custom operators) dipaket in plugins.zip.
  • Glue Workflow with conditional trigger is way most native and straightforward for runs crawler after job sukses. Trigger "SUCCEEDED" only triggers crawler when job complete with sukses.
  • EventBridge Scheduler supports schedule groups. By places all related schedules in one group, Anda can men-disable (or delete) entire group sekaligus. This most efficient for batch operations.
