A data engineer needs to process messages from an Amazon SQS queue using AWS Lambda. Each message contains a reference to a file in S3 that needs to be transformed. During peak hours, the queue depth reaches 100,000 messages. The Lambda function takes 30 seconds per message. The team wants to process the backlog as quickly as possible without exceeding 100 concurrent Lambda invocations. Which configuration achieves this?
  • A. Configure the SQS event source mapping with a batch size of 1 and set the Lambda function's reserved concurrency to 100
  • B. Configure the SQS event source mapping with a batch size of 10 and maximum concurrency of 100 on the event source mapping
  • C. Set the SQS visibility timeout to 30 seconds and use provisioned concurrency of 100
  • D. Configure the SQS queue with a redrive policy and set Lambda timeout to 5 minutes
Jawaban Benar: B
Event source mapping maximum concurrency (fitur yang lebih baru) langsung membatasi jumlah concurrent Lambda invocations yang dipicu oleh SQS, memberikan kontrol yang presisi. Batch size 10 memproses lebih banyak pesan per invocation, mempercepat processing. Opsi A (reserved concurrency) membatasi fungsi secara global tetapi bisa menyebabkan throttling dan message kembali ke queue jika exceeded. Opsi C (provisioned concurrency) mengurangi cold starts tetapi tidak membatasi total concurrent invocations — reserved concurrency yang membatasi. Opsi D (redrive policy + timeout) tidak mengontrol concurrency.
2
A data pipeline uses Lambda to process records from a Kinesis Data Stream. When the Lambda function encounters a malformed record, it throws an error causing the entire batch to be retried repeatedly, blocking subsequent records in the shard. Which Lambda event source mapping configuration BEST handles this poison pill scenario?
  • A. Configure bisect on function error, maximum retry attempts, and an on-failure destination (SQS dead-letter queue) on the event source mapping
  • B. Set the Kinesis stream retention period to 24 hours so failed records expire automatically
  • C. Add try/catch in the Lambda code to skip all errors silently
  • D. Configure the Lambda function's dead-letter queue (async invocation DLQ) for failed events
Jawaban Benar: A
Untuk Kinesis event source mappings, "bisect on function error" memecah batch menjadi dua jika terjadi error, secara progresif mengisolasi record yang bermasalah. "Maximum retry attempts" membatasi berapa kali record diretryi. "On-failure destination" mengirim failed record ke SQS DLQ setelah retry limit tercapai, memungkinkan processing melanjutkan ke record berikutnya. Opsi B (retention expiry) berarti menunggu 24 jam — unacceptable delay. Opsi C (skip errors) kehilangan visibility ke masalah data. Opsi D (async DLQ) tidak berlaku untuk stream-based invocations (Kinesis) yang synchronous — DLQ pada fungsi hanya untuk async invocations.
3
Multiple Lambda functions in a data pipeline share common dependencies: a custom data validation library (50 MB), pandas (80 MB), and database connection utilities. Each function is deployed independently. The team wants to reduce deployment package sizes and centralize dependency management. Which Lambda feature is MOST appropriate?
  • A. Create Lambda layers containing the shared libraries and attach them to each function, updating the layer version when dependencies change
  • B. Package all functions into a single monolithic deployment with all dependencies included
  • C. Use container images for Lambda with a shared base image containing all dependencies
  • D. Store dependencies in Amazon EFS and mount the filesystem in each Lambda function
Jawaban Benar: A
Lambda layers memungkinkan packaging shared dependencies secara terpisah dari function code. Layers dapat di-share antar multiple functions dan di-version independently. Ketika dependency diupdate, hanya layer version baru yang di-publish dan functions menggunakan versi baru. Ini mengurangi deployment package size (function code tanpa dependencies) dan centralize management. Opsi B (monolithic) menghilangkan keuntungan microservices dan memperbesar blast radius. Opsi C (container images) viable tetapi lebih overhead untuk sharing dependencies. Opsi D (EFS) menambah latency cold start karena mount operation dan biaya EFS yang lebih tinggi.
4
A data engineering team has a Lambda function that processes files uploaded to S3. The function is invoked asynchronously. When processing fails after all retries, the team needs to be notified and the failed event should be routed to a different Lambda function for error analysis. Which Lambda feature provides built-in support for this routing pattern?
  • A. Configure Lambda destinations with an on-failure destination pointing to the error analysis Lambda function
  • B. Configure a dead-letter queue (DLQ) on the Lambda function pointing to an SQS queue consumed by the error analysis function
  • C. Use CloudWatch Logs subscription filters to detect error patterns and trigger the analysis function
  • D. Wrap the function in a Step Functions state machine with a Catch block
Jawaban Benar: A
Lambda destinations (fitur async invocation) memungkinkan routing hasil invocation — baik success maupun failure — ke target destinations seperti Lambda function, SQS, SNS, atau EventBridge. On-failure destination langsung mengirim event payload beserta error details ke Lambda lain untuk analysis. Ini lebih rich dibanding DLQ karena menyertakan response payload dan metadata. Opsi B (DLQ) bisa bekerja tetapi hanya mengirim original event tanpa error context details dan memerlukan intermediate SQS queue. Opsi C (CloudWatch) kompleks dan memiliki delay. Opsi D (Step Functions) overhead yang berlebihan untuk use case ini.
5
A data engineer needs to optimize a Lambda function that processes data files. The function currently uses 128 MB memory and takes 45 seconds to complete. Increasing memory to 1024 MB reduces execution time to 8 seconds. The team wants to find the optimal memory configuration that minimizes cost while maintaining acceptable performance (under 15 seconds). Which approach provides the MOST data-driven recommendation?
  • A. Use AWS Lambda Power Tuning tool to automatically test multiple memory configurations and visualize the cost-performance tradeoff curve
  • B. Manually test 3-4 memory configurations and calculate the cost for each
  • C. Always use the maximum memory (10,240 MB) since more memory means more CPU and faster execution
  • D. Use AWS Compute Optimizer recommendations for the Lambda function
Jawaban Benar: A
AWS Lambda Power Tuning adalah open-source tool (Step Functions-based) yang secara otomatis menjalankan fungsi dengan berbagai memory configurations, mengukur execution time dan cost untuk masing-masing, dan menghasilkan visualization curve yang menunjukkan sweet spot optimal. Ini data-driven dan comprehensive. Opsi B (manual testing) viable tetapi tidak se-comprehensive dan lebih time-consuming. Opsi C (max memory) mengabaikan cost optimization — setelah titik tertentu, more memory tidak mengurangi time secara proporsional. Opsi D (Compute Optimizer) memberikan rekomendasi tetapi kurang detail dibanding Power Tuning's multi-point analysis.
6
A real-time data processing pipeline uses Lambda to consume from DynamoDB Streams. The function processes change events and updates a search index. During a bulk data migration, thousands of items are updated simultaneously, causing Lambda throttling. The team needs to ensure no events are lost and the search index eventually becomes consistent. Which configuration handles this burst scenario?
  • A. Configure the DynamoDB Streams event source mapping with parallelization factor up to 10 and increase the function's reserved concurrency to handle the expected burst
  • B. Replace DynamoDB Streams with Kinesis Data Streams for higher throughput capacity
  • C. Add an SQS queue between DynamoDB Streams and Lambda to buffer the events
  • D. Reduce the batch window to 0 seconds to process events as quickly as possible
Jawaban Benar: A
Parallelization factor (1-10) memungkinkan multiple Lambda invocations per shard, meningkatkan throughput processing tanpa menambah shard. DynamoDB Streams mempertahankan records selama 24 jam, jadi data tidak hilang selama throttle — hanya processing tertunda. Increasing reserved concurrency memastikan fungsi memiliki kapasitas untuk burst. Opsi B (Kinesis) memerlukan redesign arsitektur yang signifikan. Opsi C (SQS buffer) tidak bisa disisipkan antara DynamoDB Streams dan Lambda — streams langsung trigger Lambda. Opsi D (batch window 0) justru meningkatkan invocations per record, memperburuk throttling.
7
A data processing Lambda function needs to handle files up to 5 GB in size from S3. The function performs data validation and transformation. The standard Lambda ephemeral storage (512 MB default) is insufficient for processing these files. Which approach enables processing large files in Lambda?
  • A. Configure Lambda ephemeral storage up to 10 GB (/tmp) and use streaming read/write with S3 to process the file in chunks without loading the entire file into memory
  • B. Mount an Amazon EFS filesystem to the Lambda function and use it as temporary storage for file processing
  • C. Split the file into smaller chunks using S3 Select before invoking the Lambda function
  • D. Increase Lambda memory to 10 GB to hold the entire file in memory during processing
Jawaban Benar: A
Lambda supports ephemeral storage (/tmp) up to 10,240 MB (10 GB), cukup untuk file 5 GB. Streaming processing (membaca dan menulis file dalam chunks) menghindari kebutuhan memuat seluruh file ke memory sekaligus, memungkinkan processing file besar dengan memory yang lebih kecil. Opsi B (EFS) viable tetapi menambah cold start latency (VPC + mount), biaya lebih tinggi, dan overhead konfigurasi. Opsi C (S3 Select) hanya mendukung subset format (CSV, JSON, Parquet) dan query sederhana, bukan transformasi kompleks. Opsi D (10 GB memory) wasteful dan mahal — memory lebih mahal dari ephemeral storage.
8
A company has an event-driven data pipeline where files uploaded to S3 trigger Lambda functions for processing. The pipeline consists of 5 sequential steps: validation, enrichment, transformation, quality check, and loading. Each step has different error handling requirements and some steps can run in parallel. Which architecture provides the BEST orchestration for this multi-step Lambda pipeline?
  • A. Use AWS Step Functions to orchestrate the Lambda functions with parallel states, error handling (Retry/Catch), and conditional branching for each step
  • B. Chain Lambda functions using S3 event notifications — each step writes output to a different S3 prefix that triggers the next step
  • C. Use a single Lambda function that calls the other functions synchronously using the invoke API
  • D. Use SNS topics between each step with Lambda subscriptions
Jawaban Benar: A
AWS Step Functions menyediakan orchestration visual dengan: parallel states untuk steps yang bisa run concurrently, Retry policies per step (configurable intervals, max attempts, backoff rate), Catch blocks untuk error handling spesifik per step, dan conditional branching (Choice state). Ini memberikan full control dan visibility atas multi-step pipeline. Opsi B (S3 event chaining) sulit di-debug, tidak memiliki built-in retry, dan tidak mendukung conditional logic. Opsi C (synchronous invoke) menghadapi Lambda timeout limit dan single point of failure. Opsi D (SNS) bersifat fire-and-forget tanpa orchestration state atau error handling.
9
A data engineering team has a Lambda function triggered by S3 PUT events that processes incoming data files. They notice that when multiple small files are uploaded simultaneously (e.g., 1000 files in 1 second), the Lambda function hits the account's concurrent execution limit, causing some invocations to be throttled and events to be lost. Which solution prevents event loss while managing concurrency?
  • A. Route S3 events to an SQS queue, then configure Lambda to poll the queue with a maximum concurrency setting on the event source mapping
  • B. Increase the AWS account Lambda concurrent execution limit and add reserved concurrency to the function
  • C. Configure S3 Event Notifications with a filter to only process files matching specific prefixes
  • D. Enable Lambda provisioned concurrency to pre-warm 1000 execution environments
Jawaban Benar: A
Menempatkan SQS queue antara S3 events dan Lambda memberikan buffering — events tidak hilang karena persisted di queue. Lambda SQS event source mapping dengan maximum concurrency setting mengontrol berapa banyak concurrent invocations, mencegah throttling. SQS messages di-retry secara otomatis jika processing gagal. Opsi B (increase limit) mungkin tidak cukup untuk extreme bursts dan meningkatkan biaya. Opsi C (prefix filter) mengurangi events tetapi tidak menyelesaikan concurrency issue untuk files yang match filter. Opsi D (provisioned concurrency) mengurangi cold starts tetapi tidak mencegah throttling jika invocations melebihi reserved concurrency.
10
A data platform exposes a simple HTTP endpoint that returns processed analytics results. The endpoint needs to: accept GET requests with query parameters, return JSON responses, require no authentication (public data), and handle up to 1000 requests per second. The team wants the simplest possible deployment without API Gateway. Which Lambda feature meets this requirement?
  • A. Configure a Lambda function URL with auth type NONE and set reserved concurrency to handle the expected load
  • B. Deploy the Lambda function behind an Application Load Balancer with a target group
  • C. Use Lambda@Edge associated with a CloudFront distribution
  • D. Create an API Gateway HTTP API with no authorizer configured
Jawaban Benar: A
Lambda function URLs menyediakan dedicated HTTPS endpoint langsung untuk Lambda function tanpa memerlukan API Gateway atau load balancer. Dengan auth type NONE, endpoint menjadi public. Function URLs mendukung request/response streaming, built-in HTTPS, dan CORS configuration. Ini adalah solusi paling sederhana untuk simple HTTP endpoints. Opsi B (ALB) memerlukan provisioning dan biaya load balancer. Opsi C (Lambda@Edge) untuk content customization di edge, bukan general-purpose API. Opsi D (API Gateway) bekerja tetapi requirement spesifik menyebutkan "tanpa API Gateway" — dan function URL lebih sederhana untuk use case ini.
