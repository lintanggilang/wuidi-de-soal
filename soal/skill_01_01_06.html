1
A data engineer needs to trigger an AWS Glue ETL job whenever a new file is uploaded to a specific S3 prefix (s3://data-lake/raw/orders/). The trigger must be reliable and not miss any events. The S3 bucket receives hundreds of files per minute. Which approach is MOST reliable?
  • A. Enable Amazon EventBridge notifications on the S3 bucket and create a rule matching s3:ObjectCreated events with a prefix filter targeting the Glue StartJobRun API
  • B. Use a scheduled Lambda function to list new objects in S3 every minute
  • C. Configure S3 Event Notification to send to an SQS queue, with EventBridge polling the queue with native S3 integration and optimized data transfer
  • D. Configure S3 Event Notification to send directly to a Lambda function that starts the Glue job
Jawaban Benar: A
Amazon EventBridge integration dengan S3 adalah cara paling reliable untuk event-driven triggers. EventBridge menangkap semua S3 events dengan at-least-once delivery dan mendukung filtering berdasarkan prefix. Ini juga bisa langsung menargetkan Glue API.

Opsi A: BENAR.
Opsi B: SALAH. Tidak real-time dan bisa miss files di antara interval polling.
Opsi C: SALAH. Arsitektur-nya salah karena EventBridge tidak "poll" SQS — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Bisa kehilangan events jika Lambda throttled.
2
A company wants to trigger different processing pipelines based on the file type uploaded to S3. CSV files should go to Pipeline A, JSON files to Pipeline B, and Parquet files to Pipeline C. Which event configuration provides the cleanest routing?
  • A. Create three separate S3 prefixes with individual S3 Event Notifications for each with native S3 integration and optimized data transfer
  • B. Use S3 Object Lambda to intercept upload events and route them
  • C. Create one S3 Event Notification sending to a Lambda function that routes based on file extension
  • D. Create three EventBridge rules with content-based filtering on the S3 object key suffix (.csv, .json, .parquet)
Jawaban Benar: D
EventBridge rules mendukung content-based filtering pada event payload termasuk S3 object key. Tiga rules terpisah dengan suffix filter (.csv, .json, .parquet) memberikan routing paling bersih tanpa kode tambahan. Setiap rule menargetkan pipeline yang berbeda.

Opsi A: SALAH. Memaksa reorganisasi data berdasarkan format — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Untuk transformasi read access, bukan event routing.
Opsi C: SALAH. Menambah Lambda sebagai router yang meningkatkan kompleksitas.
Opsi D: BENAR.
3
A data pipeline is triggered by S3 Event Notifications sent to an SQS queue. The processing Lambda function occasionally fails, causing messages to return to the queue and trigger duplicate processing. How should the engineer prevent duplicate processing while ensuring no data is lost?
  • A. Delete messages from the queue immediately before processing starts
  • B. Use an SQS FIFO queue with deduplication enabled
  • C. Set the SQS visibility timeout to 24 hours to prevent reprocessing configured for optimal performance and minimal operational overhead
  • D. Configure a dead-letter queue (DLQ) for failed messages and implement idempotent processing in the Lambda function using DynamoDB to track processed files
Jawaban Benar: D
DLQ menangkap messages yang gagal diproses setelah max retries, mencegah infinite reprocessing. Idempotent processing dengan DynamoDB tracking memastikan bahwa jika message diproses ulang, hasilnya sama (tidak ada duplikasi data).

Opsi A: SALAH. Menyebabkan data loss jika processing gagal.
Opsi B: SALAH. Membatasi throughput ke 300 msg/s dan S3 events tidak guarantee deduplication ID.
Opsi C: SALAH. Menunda retry terlalu lama tanpa menyelesaikan masalah root cause — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
4
A data engineer needs to implement an event-driven pipeline where a Glue ETL job should only be triggered when ALL expected files for a given batch have arrived in S3 (e.g., 5 files with naming pattern batch_001_part_*.csv). Which architecture handles this "completeness check" pattern?
  • A. S3 events → EventBridge rule that triggers after 5 matching events
  • B. Use S3 Event Notification with suffix filter for a "_COMPLETE" marker file that the source system uploads last
  • C. S3 events → Lambda function that increments a counter in DynamoDB → When counter reaches 5, Lambda triggers the Glue job
  • D. Schedule a Glue crawler every 5 minutes to count files in the partition with suffix filter for a "_COMPLETE" marker file
Jawaban Benar: B
Marker file (sentinel file) pattern adalah solusi paling sederhana dan reliable. Source system mengupload "_COMPLETE" file setelah semua data files selesai diupload. S3 event notification hanya memicu pipeline ketika marker file muncul, menjamin semua data sudah tersedia.

Opsi A: SALAH. Tidak bisa menghitung events sebelum trigger.
Opsi B: BENAR.
Opsi C: SALAH. Bisa bekerja tapi lebih kompleks dan rentan race condition.
Opsi D: SALAH. Tidak event-driven dan memiliki latency — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
5
A data engineer set up S3 Event Notifications to trigger a Lambda function. However, when multiple files are uploaded simultaneously, some events are lost. Investigation shows the Lambda function is hitting concurrency limits. What is the BEST solution to prevent event loss?
  • A. Increase the Lambda reserved concurrency to the maximum account limit
  • B. Use S3 Batch Operations to process files instead of events
  • C. Add an SQS queue between S3 Event Notifications and Lambda as a buffer
  • D. Configure S3 Event Notifications with a retry policy and Lambda as a buffer
Jawaban Benar: C
SQS queue sebagai buffer antara S3 events dan Lambda mencegah event loss. SQS menyimpan messages hingga Lambda siap memprosesnya (retention up to 14 days). Lambda SQS event source mapping juga mengatur batch size dan concurrency secara otomatis.

Opsi A: SALAH. Membantu tapi masih bisa hit account-level limits.
Opsi B: SALAH. Bukan event-driven dan untuk operasi massal yang dijadwalkan.
Opsi C: BENAR.
Opsi D: SALAH. S3 Event Notifications tidak memiliki configurable retry policy — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
6
A company has an existing S3 bucket that already uses S3 Event Notifications to send to an SNS topic for an existing application. The data engineering team now needs to also trigger a Glue job from the same events. However, S3 allows only one event notification configuration per event type per prefix. How should this be resolved?
  • A. Replace S3 Event Notifications with EventBridge and migrate the existing application
  • B. Create a Lambda function subscribed to the SNS topic that triggers the Glue job
  • C. Enable Amazon EventBridge notifications on the S3 bucket, which provides unlimited rule targets without conflicting with existing S3 Event Notifications
  • D. Add a second subscription to the existing SNS topic that targets the Glue job with existing S3 Event Notifications
Jawaban Benar: C
Enabling EventBridge on an S3 bucket works alongside existing S3 Event Notifications tanpa konflik. EventBridge menerima semua S3 events secara independen dan Anda bisa membuat rules dengan multiple targets. Existing notification ke SNS tetap berfungsi.

Opsi A: SALAH. Membutuhkan migrasi aplikasi existing.
Opsi B: SALAH. Bisa bekerja tapi menambah overhead Lambda invocation.
Opsi C: BENAR.
Opsi D: SALAH. Memerlukan Glue memiliki SNS subscription endpoint yang tidak langsung supported — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
7
A data engineer needs to set up an event trigger that starts a Step Functions workflow whenever an AWS Glue job changes state to FAILED. The workflow should capture the job name and error message for alerting. Which implementation is correct?
  • A. CloudWatch Alarm on Glue job failure metric, with alarm action targeting Step Functions
  • B. Glue job notification trigger configured to call Step Functions API on failure with detail and message
  • C. EventBridge rule matching "Glue Job State Change" with detail.state = "FAILED", targeting Step Functions with input transformation to extract jobName and message
  • D. SNS topic subscribed to Glue job events with a Lambda subscriber that starts Step Functions
Jawaban Benar: C
EventBridge menangkap Glue Job State Change events natively. Dengan rule filtering pada state "FAILED" dan input transformation, event detail (jobName, error message) bisa diteruskan ke Step Functions sebagai input. Ini adalah pola event-driven yang paling direct.

Opsi A: SALAH. Tidak membawa detail error message.
Opsi B: SALAH. Glue tidak memiliki "notification trigger" built-in yang memanggil API langsung — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Menambah layer SNS dan Lambda yang tidak diperlukan.
8
A company receives partner data via SFTP to AWS Transfer Family. When a file is uploaded, it's stored in S3. The data engineer needs to trigger processing only for files larger than 100 MB (to batch small files separately). Which event trigger configuration supports file-size-based filtering?
  • A. S3 Event Notification with a size filter in the configuration
  • B. EventBridge rule with content filtering on the detail.object.size field using numeric matching (greater than 104857600)
  • C. S3 Intelligent-Tiering to separate large and small files automatically with content filtering on the detail
  • D. Lambda function triggered by all S3 events that checks file size using HeadObject before processing
Jawaban Benar: B
EventBridge mendukung content-based filtering termasuk numeric matching pada field seperti object size. Rule bisa memfilter events dimana detail.object.size > 104857600 (100 MB). Ini menghindari invokasi yang tidak perlu.

Opsi A: SALAH. S3 Event Notifications tidak mendukung filtering berdasarkan ukuran file.
Opsi B: BENAR.
Opsi C: SALAH. Untuk storage class management, bukan event filtering — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Bekerja tapi memicu Lambda untuk setiap file yang tidak efisien.
9
A data engineer configured an EventBridge rule to trigger a Lambda function when objects are created in S3. During testing, the engineer notices that the Lambda function receives events for both PutObject and CompleteMultipartUpload. The function should only process complete multipart uploads of large files. How should the rule be refined?
  • A. Filter in the Lambda function code to only process CompleteMultipartUpload events configured for optimal performance
  • B. Add an event pattern filter specifying detail.reason as "CompleteMultipartUpload" in the EventBridge rule
  • C. Create a separate S3 bucket for multipart uploads only
  • D. Use S3 Event Notification with the s3:ObjectCreated:CompleteMultipartUpload event type instead
Jawaban Benar: B
EventBridge S3 events include detail.reason field yang menunjukkan bagaimana object dibuat (PutObject, CompleteMultipartUpload, CopyObject, dll). Memfilter pada field ini di EventBridge rule memastikan Lambda hanya dipanggil untuk multipart uploads.

Opsi A: SALAH. Membuang invocation cost untuk events yang tidak diproses — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Mengubah arsitektur storage secara tidak perlu.
Opsi D: SALAH. Bisa bekerja tapi S3 Event Notifications kurang fleksibel dibanding EventBridge.
10
A data engineering team needs to implement a cross-account event trigger. When data is uploaded to an S3 bucket in Account A, a Glue job in Account B should be triggered. Which is the MOST secure approach?
  • A. Account A sends S3 events to its EventBridge bus → Cross-account EventBridge rule puts events on Account B's event bus → Account B rule triggers the Glue job
  • B. Account A configures S3 Event Notification directly targeting Account B's Lambda function
  • C. Account B polls Account A's S3 bucket using ListObjectsV2 every minute with native S3 integration and optimized data transfer
  • D. Account A S3 Event Notification sends to an SNS topic → Account B Lambda subscribes to the topic and starts the Glue job
Jawaban Benar: A
Cross-account EventBridge event forwarding adalah pola paling secure dan native untuk cross-account event triggers. Account A mengizinkan Account B's event bus sebagai target melalui resource-based policy. Ini menggunakan IAM untuk security dan tidak memerlukan shared credentials.

Opsi A: BENAR.
Opsi B: SALAH. Tidak supported — S3 Event Notifications tidak bisa langsung target cross-account Lambda.
Opsi C: SALAH. Tidak event-driven, lambat, dan membutuhkan cross-account S3 access — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Bekerja tapi membutuhkan subscription confirmation.
