A data engineer needs to trigger an AWS Glue ETL job whenever a new file is uploaded to a specific S3 prefix (s3://data-lake/raw/orders/). The trigger must be reliable and not miss any events. The S3 bucket receives hundreds of files per minute. Which approach is MOST reliable?
  • A. Enable Amazon EventBridge notifications on the S3 bucket and create a rule matching s3:ObjectCreated events with a prefix filter targeting the Glue StartJobRun API
  • B. Use a scheduled Lambda function to list new objects in S3 every minute, maintaining the original event sequence from end to end
  • C. Configure S3 Event Notification to send to an SQS queue, with EventBridge polling the queue with native S3 integration and optimized data transfer
  • D. Configure S3 Event Notification to send directly to a Lambda function that starts the Glue job, integrating natively with the rest of the pipeline
Correct Answer: A
Amazon EventBridge integration with S3 is way most reliable for event-driven triggers. EventBridge captures all S3 events with at-least-once delivery and supports filtering based on prefix. Ini also can directly menargetkan Glue API.

Option A: CORRECT.
Option B: INCORRECT. Not real-time and can miss files in between interval polling.
Option C: INCORRECT. Arsitektur-nya incorrect because EventBridge not "poll" SQS — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Can kehilangan events if Lambda throttled.

A company wants to trigger different processing pipelines based on the file type uploaded to S3. CSV files should go to Pipeline A, JSON files to Pipeline B, and Parquet files to Pipeline C. Which event configuration provides the cleanest routing?
  • A. Create three separate S3 prefixes with individual S3 Event Notifications for each with native S3 integration and optimized data transfer
  • B. Use S3 Object Lambda to intercept upload events and route them, handling the described workload reliably at scale
  • C. Create one S3 Event Notification sending to a Lambda function that routes based on file extension
  • D. Create three EventBridge rules with content-based filtering on the S3 object key suffix (.csv, .json, .parquet)
Correct Answer: D
EventBridge rules supports content-based filtering on event payload including S3 object key. Tiga rules separate with suffix filter (.csv, .json, .parquet) provides routing most bersih without code additional. Each rule menargetkan pipeline that different.

Option A: INCORRECT. Memaksa reorganisasi data based on format — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. For transformation read access, not event routing.
Option C: INCORRECT. Adds Lambda sebagai router that increases complexity.
Option D: CORRECT.

A data pipeline is triggered by S3 Event Notifications sent to an SQS queue. The processing Lambda function occasionally fails, causing messages to return to the queue and trigger duplicate processing. How should the engineer prevent duplicate processing while ensuring no data is lost?
  • A. Delete messages from the queue immediately before processing starts, integrating natively with the rest of the pipeline and reducing day-to-day operational effort
  • B. Use an SQS FIFO queue with deduplication enabled, integrating natively with the rest of the pipeline and handling the described workload reliably at scale
  • C. Set the SQS visibility timeout to 24 hours to prevent reprocessing configured for optimal performance and minimal operational overhead
  • D. Configure a dead-letter queue (DLQ) for failed messages and implement idempotent processing in the Lambda function using DynamoDB to track processed files
Correct Answer: D
DLQ captures messages that fails is processed setelah max retries, prevents infinite reprocessing. Idempotent processing with DynamoDB tracking ensures that if message is processed ulang, hasilnya same (there is no duplikasi data).

Option A: INCORRECT. Menyebabkan data loss if processing fails.
Option B: INCORRECT. Membatasi throughput to 300 msg/s and S3 events not guarantee deduplication ID.
Option C: INCORRECT. Menunda retry too old without solves problem root cause — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: CORRECT.

A data engineer needs to implement an event-driven pipeline where a Glue ETL job should only be triggered when ALL expected files for a given batch have arrived in S3 (e.g., 5 files with naming pattern batch_001_part_*.csv). Which architecture handles this "completeness check" pattern?
  • A. S3 events → EventBridge rule that triggers after 5 matching events, applying schema conversion and enrichment inline
  • B. Use S3 Event Notification with suffix filter for a "_COMPLETE" marker file that the source system uploads last
  • C. S3 events → Lambda function that increments a counter in DynamoDB → When counter reaches 5, Lambda triggers the Glue job
  • D. Schedule a Glue crawler every 5 minutes to count files in the partition with suffix filter for a "_COMPLETE" marker file
Correct Answer: B
Marker file (sentinel file) pattern is solution most simple and reliable. Source system mengupload "_COMPLETE" file setelah all data files complete diupload. S3 event notification only triggers pipeline when marker file muncul, guarantees all data already available.

Option A: INCORRECT. Not can calculates events before trigger.
Option B: CORRECT.
Option C: INCORRECT. Can works but more complex and rentan race condition.
Option D: INCORRECT. Not event-driven and has latency — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

A data engineer set up S3 Event Notifications to trigger a Lambda function. However, when multiple files are uploaded simultaneously, some events are lost. Investigation shows the Lambda function is hitting concurrency limits. What is the BEST solution to prevent event loss?
  • A. Increase the Lambda reserved concurrency to the maximum account limit
  • B. Use S3 Batch Operations to process files instead of events
  • C. Add an SQS queue between S3 Event Notifications and Lambda as a buffer
  • D. Configure S3 Event Notifications with a retry policy and Lambda as a buffer
Correct Answer: C
SQS queue sebagai buffer between S3 events and Lambda prevents event loss. SQS stores messages up to Lambda siap memprosesnya (retention up to 14 days). Lambda SQS event source mapping also configures batch size and concurrency automatically.

Option A: INCORRECT. Membantu but still can hit account-level limits.
Option B: INCORRECT. Not event-driven and for operasi massal that dijadwalkan.
Option C: CORRECT.
Option D: INCORRECT. S3 Event Notifications not has configurable retry policy — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

  • B. Create a Lambda function subscribed to the SNS topic that triggers the Glue job, integrating natively with the rest of the pipeline

The function should only process complete multipart uploads of large files. How should the rule be refined?

Option A: INCORRECT. Membuang invocation cost for events that not is processed — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

A data engineering team needs to implement a cross-account event trigger. When data is uploaded to an S3 bucket in Account A, a Glue job in Account B should be triggered. Which is the MOST secure approach?
  • A. Account A sends S3 events to its EventBridge bus → Cross-account EventBridge rule puts events on Account B's event bus → Account B rule triggers the Glue job
  • B. Account A configures S3 Event Notification directly targeting Account B's Lambda function, enforcing encryption and fine-grained access control and satisfying all of the stated requirements with minimal effort
  • C. Account B polls Account A's S3 bucket using ListObjectsV2 every minute with native S3 integration and optimized data transfer, satisfying strict compliance and audit requirements and minimizing end-to-end processing latency
  • D. Account A S3 Event Notification sends to an SNS topic → Account B Lambda subscribes to the topic and starts the Glue job, handling the described workload reliably at scale
Correct Answer: A
Cross-account EventBridge event forwarding is pattern most secure and native for cross-account event triggers. Account A allows Account B's event bus sebagai target through resource-based policy. Ini uses IAM for security and not requires shared credentials.

Option A: CORRECT.
Option B: INCORRECT. Not supported — S3 Event Notifications cannot directly target cross-account Lambda.
Option C: INCORRECT. Not event-driven, slow, and requires cross-account S3 access — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Bekerja but requires subscription confirmation.
