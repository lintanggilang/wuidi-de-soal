Skill 4.5.3: Implement Data Privacy Strategies to Prevent Backups or Replications to Disallowed Regions

Preventing data from being copied to unauthorized AWS Regions for data residency compliance

1
A German bank processes customer data that must remain within the EU under GDPR data residency requirements. Their AWS Organization contains accounts across eu-west-1, eu-central-1, and us-east-1. Developers have been accidentally creating resources in us-east-1. Which preventive control MOST effectively ensures no data resources can be created outside EU regions across the entire organization?
  • A. Create IAM policies in each account that deny all actions when aws:RequestedRegion is not an EU region
  • B. Apply a Service Control Policy (SCP) at the organization root that denies all actions except for global services when aws:RequestedRegion is not in the approved EU region list
  • C. Use AWS Config rules to detect resources in non-EU regions and automatically terminate them
  • D. Disable non-EU regions in the AWS Organizations account settings for all member accounts
Jawaban Benar: B
SCPs (Service Control Policies) adalah preventive controls yang berlaku untuk SEMUA principals dalam account (termasuk root user). SCP yang deny actions ketika aws:RequestedRegion tidak termasuk EU regions mencegah pembuatan resource di region yang tidak diizinkan. SCP harus mengecualikan global services (IAM, Route 53, CloudFront, dll) yang beroperasi dari us-east-1 tapi bersifat global. Opsi A (IAM policies per account) memerlukan management di setiap account dan bisa di-override oleh admin yang membuat new policies. Opsi C (Config + terminate) adalah detective control — resource sudah dibuat sebelum dihapus, menyebabkan brief data exposure. Opsi D — Anda bisa opt-in regions (yang non-default) tapi EU dan US regions adalah default regions yang tidak bisa di-disable melalui account settings.
2
A company has an S3 bucket in eu-central-1 containing regulated data. A developer attempts to configure S3 Cross-Region Replication (CRR) to a bucket in ap-southeast-1 for disaster recovery. The data governance team needs to ensure S3 replication can ONLY target buckets within approved EU regions. Which approach prevents unauthorized cross-region replication?
  • A. Apply a bucket policy on the source bucket that denies s3:PutReplicationConfiguration unless the destination ARN contains an EU region
  • B. Use an SCP that denies s3:PutReplicationConfiguration when the s3:DestinationRegion condition key is not in the approved EU region list
  • C. Configure AWS Config rule s3-bucket-replication-enabled with a parameter restricting allowed destination regions
  • D. Use S3 Object Lock in Compliance mode to prevent any replication outside the current region
Jawaban Benar: A
Bucket policy dengan condition pada destination ARN adalah pendekatan paling tepat untuk mengontrol S3 replication destinations. Policy bisa menggunakan condition StringLike pada resource ARN atau StringEquals pada spesifik region identifier dalam ARN. Contoh: Deny s3:PutReplicationConfiguration kecuali arn:aws:s3:::*eu-central-1* atau *eu-west-1*. Ini mencegah konfigurasi replication ke non-EU regions. Opsi B — tidak ada condition key s3:DestinationRegion yang valid untuk SCPs terkait S3 replication. Opsi C — Config rule s3-bucket-replication-enabled memeriksa apakah replication enabled, bukan membatasi destination — ini detective bukan preventive. Opsi D — S3 Object Lock mencegah deletion/modification objek, tidak mengontrol kemana objek bisa direplikasi.
3
An organization uses Amazon RDS for PostgreSQL in eu-west-1 for their production database containing EU customer data. The DBA team needs to create cross-region read replicas for disaster recovery but ONLY within EU regions. They also need to prevent manual snapshots from being copied to non-EU regions. Which combination of controls achieves this? (Select the approach that covers both requirements)
  • A. SCP denying rds:CreateDBInstanceReadReplica and rds:CopyDBSnapshot when aws:RequestedRegion is not in EU regions
  • B. IAM policy denying rds:CreateDBInstanceReadReplica with condition on the DestinationRegion not being in EU, plus a separate SCP denying rds:CopyDBSnapshot to non-EU regions
  • C. SCP with two statements: deny rds:CreateDBInstanceReadReplica when rds:DatabaseEngine condition is "postgres" and region is non-EU, plus deny rds:CopyDBClusterSnapshot to non-EU regions
  • D. AWS Config custom rule detecting non-EU read replicas combined with Systems Manager Automation to delete them
Jawaban Benar: A
SCP yang deny kedua actions (CreateDBInstanceReadReplica dan CopyDBSnapshot) ketika aws:RequestedRegion bukan EU region adalah solusi paling sederhana dan efektif. Untuk cross-region read replica, aws:RequestedRegion mengevaluasi region tujuan. Untuk CopyDBSnapshot cross-region, request dikirim ke destination region sehingga aws:RequestedRegion juga mencerminkan tujuan. Satu SCP mencakup kedua requirement. Opsi B — mencampur IAM dan SCP menambah complexity tanpa benefit; juga DestinationRegion bukan condition key standar untuk RDS. Opsi C — rds:DatabaseEngine condition key tidak ada; dan CopyDBClusterSnapshot berbeda dari CopyDBSnapshot (cluster vs instance). Opsi D — detective control, bukan preventive — replika sudah dibuat sebelum dihapus.
4
A company uses AWS Control Tower to manage their multi-account environment. They need to implement a guardrail that prevents any Amazon Redshift cluster snapshots from being copied to regions outside of their approved list (eu-central-1, eu-west-1, eu-west-2). Which Control Tower approach provides this preventive control?
  • A. Enable the built-in "Disallow cross-region data transfer" elective guardrail in Control Tower
  • B. Create a custom Control Tower guardrail using an SCP that denies redshift:CopyClusterSnapshot when aws:RequestedRegion is not in the approved region list
  • C. Configure the Control Tower Region deny setting to block all services in non-approved regions
  • D. Use Control Tower's detective guardrail to identify cross-region snapshots and send alerts
Jawaban Benar: B
Control Tower mendukung custom SCPs sebagai preventive guardrails. Untuk granular control pada Redshift snapshot copying, custom SCP yang deny redshift:CopyClusterSnapshot ketika region bukan approved list memberikan precisely scoped control. Ini preventive — request akan ditolak sebelum snapshot copy dimulai. Opsi A — tidak ada built-in Control Tower guardrail dengan nama persis tersebut yang specifically covers Redshift snapshot copying. Opsi C — Region deny setting memblokir SEMUA services di non-approved regions; ini mungkin terlalu broad jika ada legitimate services yang perlu berjalan di region lain. Opsi D — detective guardrail hanya mendeteksi dan alert setelah violation terjadi, snapshot sudah ter-copy.
5
A company uses AWS Backup to manage automated backups for their data infrastructure (RDS, DynamoDB, EFS) in eu-central-1. The compliance team discovers that AWS Backup has been configured to copy backups to us-east-1 as part of a cross-region backup strategy set up by a previous administrator. How should the data engineer prevent AWS Backup from creating copies in non-EU regions while maintaining the backup strategy for EU regions?
  • A. Modify the AWS Backup plan to remove the cross-region copy rule targeting us-east-1, and add copy rules only for eu-west-1
  • B. Apply an SCP that denies backup:CopyIntoRegion when the target region is not in the EU approved list
  • C. Modify the backup plan AND apply an SCP denying backup:StartCopyJob with a condition that the destination vault ARN does not contain an EU region identifier
  • D. Use AWS Backup Vault Lock to prevent any modification to backup copies and their destinations
Jawaban Benar: C
Pendekatan defense-in-depth adalah yang paling tepat: (1) Modifikasi backup plan untuk menghapus copy rule ke us-east-1 dan menambah EU destination — ini memperbaiki konfigurasi saat ini, (2) Apply SCP sebagai preventive guardrail agar tidak ada administrator yang bisa membuat cross-region copy ke non-EU di masa depan. Condition pada destination vault ARN memastikan backup copies hanya bisa dituju ke vaults di EU regions. Opsi A hanya memperbaiki konfigurasi current tapi tidak mencegah future misconfiguration. Opsi B — backup:CopyIntoRegion bukan IAM action yang valid. Opsi D — Vault Lock mencegah deletion/modification recovery points, bukan mengontrol kemana backups bisa di-copy.
6
A multinational company has data in DynamoDB Global Tables that need to replicate between eu-west-1 and eu-central-1 for EU operations. However, a developer accidentally added us-west-2 as a replica region. The compliance team needs an immediate detective control to identify when DynamoDB tables are replicated to non-approved regions. Which AWS Config approach detects this violation?
  • A. Use the managed Config rule dynamodb-table-encrypted-kms to check if tables are encrypted in approved regions only
  • B. Create a custom AWS Config rule using a Lambda function that evaluates DynamoDB table replica regions against an approved region list and marks tables with non-EU replicas as NON_COMPLIANT
  • C. Use CloudTrail to log CreateTable events and create a CloudWatch alarm for non-EU region activities
  • D. Use the managed Config rule dynamodb-autoscaling-enabled and check its regional configuration
Jawaban Benar: B
Custom AWS Config rule dengan Lambda function adalah solusi paling tepat untuk memeriksa DynamoDB Global Tables replica regions. Lambda function bisa menggunakan DynamoDB DescribeTable API untuk mendapatkan daftar replica regions, lalu membandingkan dengan approved region list. Jika ada replica di region yang tidak diizinkan, function mengembalikan NON_COMPLIANT. Config rule ini berjalan periodic atau saat configuration change terdeteksi. Opsi A — dynamodb-table-encrypted-kms memeriksa enkripsi, bukan replica regions. Opsi C — CloudTrail + CloudWatch bisa mendeteksi CreateTableReplica calls tapi tidak memberikan continuous compliance evaluation seperti Config; juga tidak memeriksa existing state. Opsi D — dynamodb-autoscaling-enabled tidak ada hubungannya dengan regional replication.
7
A healthcare organization needs to ensure their S3 data cannot be replicated OR moved to regions outside of their country (Australia - ap-southeast-2). They want to use S3 Object Lock to add an additional layer of protection. A developer suggests using S3 Object Lock Compliance mode to prevent data movement. Is this correct, and what is the proper approach?
  • A. Yes, S3 Object Lock Compliance mode prevents cross-region replication and movement of objects
  • B. No, S3 Object Lock protects against deletion/modification but does NOT prevent replication. Use SCPs to deny s3:ReplicateObject when the destination is not ap-southeast-2, combined with bucket policies restricting PutReplicationConfiguration
  • C. Yes, S3 Object Lock Legal Hold prevents any operation including replication on the objects
  • D. No, use S3 Glacier Vault Lock instead, which prevents cross-region movement of archived data
Jawaban Benar: B
S3 Object Lock (baik Compliance maupun Governance mode) melindungi objects dari DELETION dan OVERWRITE selama retention period — BUKAN dari replication atau copying. Objects yang locked tetap bisa direplikasi ke region lain jika replication rule dikonfigurasi. Untuk mencegah cross-region replication, diperlukan: (1) SCP yang deny s3:ReplicateObject di region yang tidak diizinkan, (2) Bucket policy yang mencegah PutReplicationConfiguration ke non-approved destinations. Opsi A salah — Object Lock tidak mencegah replication. Opsi C salah — Legal Hold juga hanya mencegah deletion, bukan replication. Opsi D — Glacier Vault Lock juga tentang deletion protection untuk archive, bukan cross-region movement prevention.
8
A company operates in eu-central-1 and uses IAM condition keys to restrict actions to approved regions. However, they find that some AWS services (IAM, Organizations, Route 53, CloudFront) stop working because these are global services hosted in us-east-1. How should the SCP be structured to block non-EU regions while allowing global services to function?
  • A. Create the SCP with a Deny effect and add a NotAction list containing global service actions (iam:*, organizations:*, route53:*, cloudfront:*, etc.) so these services are excluded from the region restriction
  • B. Create two SCPs: one allowing all actions in EU regions, and another explicitly allowing global services in us-east-1
  • C. Add a condition to the SCP that checks if the service is a global service before applying the region restriction
  • D. Use StringNotEquals on aws:RequestedRegion with only the non-EU regions listed in the condition, rather than allowed regions
Jawaban Benar: A
Pattern yang benar untuk region-restriction SCP adalah menggunakan NotAction (bukan Action) pada statement Deny. NotAction berisi daftar global service actions yang harus dikecualikan dari restriction. Statement menjadi: "Deny everything NOT in this list UNLESS region is in approved list." Global services yang perlu di-exclude: iam:*, sts:*, organizations:*, route53:*, cloudfront:*, support:*, budgets:*, waf:*, dll. Opsi B — SCPs are deny-only effective (Allow in SCP hanya membuka ceiling, tidak grant); dua SCP terpisah tidak akan menghasilkan efek yang diinginkan karena Deny tetap berlaku. Opsi C — tidak ada condition key yang mengidentifikasi apakah service "global" atau regional. Opsi D — pendekatan ini bisa bekerja tapi tidak menyelesaikan masalah global services karena mereka tetap di us-east-1.
9
An organization needs to implement a comprehensive data residency solution that prevents data from leaving the EU across ALL data services (S3, RDS, Redshift, DynamoDB, EBS, EFS). They are concerned about both explicit copying (replication, snapshots) and implicit data movement (Lambda processing in other regions accessing EU data). Which layered approach provides the MOST comprehensive protection?
  • A. Apply a single SCP restricting aws:RequestedRegion to EU regions for all services
  • B. SCP restricting aws:RequestedRegion to EU + VPC endpoint policies denying cross-region API calls + S3 bucket policies restricting replication destinations + AWS Config rules for continuous compliance monitoring
  • C. Use AWS Control Tower Region deny guardrail combined with detective Config rules
  • D. Enable AWS Artifact agreements for GDPR and rely on AWS's contractual guarantee that data stays in specified regions
Jawaban Benar: B
Defense-in-depth approach memerlukan multiple layers: (1) SCP sebagai organizational-wide preventive guardrail untuk region restriction, (2) VPC endpoint policies menambah network-level control — traffic ke AWS services bisa dibatasi hanya ke EU region endpoints, mencegah Lambda atau EC2 dari calling APIs di non-EU regions, (3) S3 bucket policies sebagai resource-level control spesifik untuk replication, (4) AWS Config rules sebagai detective control untuk continuous compliance verification. Setiap layer menangani attack vector berbeda. Opsi A — single SCP mencakup banyak tapi tidak menangani network-level implicit access atau resource-specific configurations. Opsi C — kurang granular dibanding opsi B karena tidak mencakup VPC endpoint policies. Opsi D — contractual agreement bukan technical control; tidak mencegah misconfiguration oleh users.
10
A data engineer discovers that an AWS Config rule has flagged an S3 bucket that has cross-region replication configured to an unauthorized region (us-west-2). The bucket contains 500 TB of data that has already been partially replicated. The Config rule needs to trigger automatic remediation to: (1) disable the replication rule, and (2) delete the objects that were already replicated to the unauthorized region. Which remediation approach is correct?
  • A. Configure AWS Config automatic remediation using SSM Automation document that calls S3 DeleteBucketReplication API and then deletes objects in the destination bucket
  • B. Configure AWS Config automatic remediation to disable the replication rule only, then use a separate scheduled Lambda to identify and delete already-replicated objects in the unauthorized region with appropriate approval workflow
  • C. Use Config manual remediation to prevent accidental deletion of 500 TB of potentially needed data
  • D. Configure EventBridge to detect the Config NON_COMPLIANT finding and trigger Step Functions that handles both remediation steps with error handling
Jawaban Benar: B
Remediation harus dilakukan secara bertahap dan dengan risk management: (1) Immediate automated remediation: disable replication rule untuk STOP ongoing data transfer ke unauthorized region — ini urgent dan low-risk. (2) Deleting 500 TB of already-replicated data memerlukan careful handling — approval workflow diperlukan karena: data mungkin masih diakses, deletion 500 TB memakan waktu, perlu confirm tidak ada dependencies. Automated deletion tanpa approval untuk data skala besar terlalu berisiko. Opsi A — automatically deleting 500 TB tanpa approval workflow terlalu dangerous. Opsi C — manual remediation untuk step 1 (disabling replication) terlalu lambat karena data terus ter-replicate selama menunggu manual action. Opsi D — bisa bekerja tapi over-engineering untuk step 1 dan tetap tidak seharusnya auto-delete tanpa approval.
