1
A financial services company stores customer data across 500 S3 buckets. The compliance team requires automated discovery of all PII (names, credit card numbers, Social Security numbers) within these buckets and needs findings categorized by severity. They also want continuous monitoring as new data arrives. Which Amazon Macie configuration provides the MOST comprehensive PII detection?
  • A. Enable Macie, configure automated sensitive data discovery for the account, and create scheduled classification jobs running daily for comprehensive coverage
  • B. Enable Macie and create a one-time classification job scanning all 500 buckets, then manually re-run monthly for the account
  • C. Use S3 event notifications to trigger a Lambda function that calls Macie's API for each new object uploaded
  • D. Enable Macie with automated sensitive data discovery only, relying on its statistical sampling approach for all detection needs
Jawaban Benar: A
Kombinasi automated sensitive data discovery dan scheduled classification jobs memberikan coverage paling komprehensif. Automated sensitive data discovery melakukan sampling berkelanjutan terhadap bucket untuk membuat overview, sementara scheduled classification jobs memastikan setiap objek baru di-scan secara sistematis setiap hari. Ini memberikan both continuous monitoring dan comprehensive deep scanning.

Opsi A: BENAR.
Opsi B: SALAH. Melewatkan data yang masuk antara scan dan memerlukan manual intervention — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Bukan cara Macie bekerja — Macie menggunakan jobs, bukan per-object API calls.
Opsi D: SALAH. Menggunakan sampling dan mungkin melewatkan beberapa objek — tidak cukup untuk compliance requirement yang memerlukan detection di semua data.
2
A healthcare company receives patient intake forms in PDF and CSV format uploaded to S3. They have specific formats for medical record numbers (MRN) that follow the pattern "MRN-XXXXXX-YY" where X is digits and Y is letters. Macie's built-in managed data identifiers do not recognize this custom format. How should the data engineer configure Macie to detect these custom identifiers?
  • A. Create an allow list in Macie containing all valid MRN patterns so Macie classifies matches as sensitive
  • B. Use AWS Glue sensitive data detection with custom PII entity types instead of Macie
  • C. Submit a request to AWS to add the MRN pattern to the managed data identifiers list with keywords ["medical record" and a maximum match distance of 50 characters
  • D. Create a custom data identifier in Macie using the regex pattern MRN-\d{6}-[A-Z]{2} with keywords ["medical record", "patient"] and a maximum match distance of 50 characters
Jawaban Benar: D
Macie custom data identifiers memungkinkan pengguna mendefinisikan regex patterns untuk format data sensitif yang unik bagi organisasi. Konfigurasi mencakup: regex pattern (MRN-\d{6}-[A-Z]{2}), keywords untuk mengurangi false positives (harus muncul dalam proximity tertentu), dan maximum match distance yang menentukan seberapa dekat keyword harus berada dari match.

Opsi A: SALAH. Allow lists digunakan untuk MENGECUALIKAN known non-sensitive matches (false positives), bukan untuk mendeteksi data sensitif baru.
Opsi B: SALAH. Glue sensitive data detection ada tapi pertanyaan spesifik tentang Macie dan custom identifiers adalah fitur built-in Macie.
Opsi C: SALAH. AWS tidak menerima request untuk menambah managed identifiers untuk format proprietary perusahaan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
3
A data engineering team receives Macie findings showing HIGH severity PII detections in an S3 bucket used by their data lake. They want to automatically restrict access to the affected objects and notify the security team when PII is detected. Which architecture provides automated remediation?
  • A. Macie → CloudWatch Alarm → Auto Scaling action to move objects to Glacier and tags objects) + SNS notification to security team
  • B. Macie → SNS → Security team email notification, then manual access restriction
  • C. Macie → AWS Config rule → Systems Manager Automation to delete affected objects
  • D. Macie → EventBridge rule (filter on HIGH severity findings) → Lambda function (adds restrictive bucket policy for affected prefix and tags objects) + SNS notification to security team
Jawaban Benar: D
Macie terintegrasi native dengan Amazon EventBridge, mengirimkan findings sebagai events. EventBridge rule dapat mem-filter berdasarkan severity (HIGH) dan trigger Lambda function untuk automated remediation — misalnya menambahkan deny policy pada bucket untuk prefix tertentu, menambahkan object tags (classification=pii), atau memindahkan ke quarantine bucket. Parallel SNS notification memberitahu security team.

Opsi A: SALAH. Macie tidak mengirim metrics ke CloudWatch Alarms secara langsung, dan Auto Scaling + Glacier bukan remediation yang tepat — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Hanya notification tanpa automation.
Opsi C: SALAH. AWS Config rules tidak directly triggered oleh Macie findings, dan menghapus objects terlalu agresif (mungkin masih diperlukan tapi perlu restricted access).
Opsi D: BENAR.
4
A company runs Macie across a multi-account AWS Organization. The security team notices that Macie is generating many false positive findings for a test bucket that contains synthetic data with realistic-looking credit card numbers. These false positives overwhelm the genuine findings. What is the MOST appropriate way to reduce these false positives without disabling Macie?
  • A. Create an allow list in Macie containing the specific synthetic credit card numbers so they are ignored in future scans
  • B. Exclude the test bucket from Macie classification jobs by adding it to the job's S3 bucket criteria exclusion
  • C. Suppress the findings using a findings filter with auto-archive action for the specific bucket
  • D. Disable the CREDIT_CARD_NUMBER managed data identifier for the entire account
Jawaban Benar: C
Suppression rules (findings filters with auto-archive) adalah cara paling tepat untuk menangani false positives dari bucket tertentu. Rule dapat dikonfigurasi untuk automatically archive findings dari bucket spesifik tersebut, sehingga tidak muncul di default findings view tapi tetap tersimpan untuk audit. Macie tetap scanning bucket tersebut (berguna jika real PII accidentally masuk ke test bucket).

Opsi A: SALAH. Memerlukan Anda memasukkan setiap synthetic number — tidak scalable jika ratusan test records.
Opsi B: SALAH. Menghentikan scanning entirely — jika real PII masuk ke test bucket, tidak akan terdeteksi.
Opsi C: BENAR.
Opsi D: SALAH. Mempengaruhi SEMUA buckets, bukan hanya test bucket — credit card detection hilang di production buckets juga.
5
A European insurance company must comply with GDPR requirements for PII identification and data protection. They use Amazon Macie for PII discovery in their S3 data lake and AWS Lake Formation for access control. When Macie identifies objects containing EU citizen PII, the objects must automatically be tagged and Lake Formation permissions must restrict access to only the Data Protection Officer (DPO) team. Which integration approach achieves this?
  • A. Macie finding → EventBridge → Lambda that: (1) adds S3 object tag "contains-eu-pii=true", (2) registers the S3 location in Lake Formation, (3) grants Lake Formation permissions only to the DPO team's IAM role
  • B. Configure Lake Formation to automatically read Macie findings and apply tag-based access control based on sensitivity levels with native S3 integration and optimized data transfer
  • C. Macie finding → SNS → SQS → Lambda that moves objects to a separate "pii-quarantine" S3 bucket managed by Lake Formation with DPO-only permissions
  • D. Use Macie's built-in Lake Formation integration to automatically restrict permissions when PII is detected
Jawaban Benar: A
Integrasi Macie-Lake Formation memerlukan orchestration melalui EventBridge dan Lambda karena tidak ada native direct integration. Lambda function melakukan: (1) tagging S3 object untuk classification tracking, (2) mendaftarkan S3 location di Lake Formation jika belum registered, (3) menggunakan Lake Formation API untuk GRANT permissions hanya ke DPO role dan REVOKE dari yang lain. Ini memenuhi GDPR requirement untuk access restriction segera setelah PII teridentifikasi.

Opsi A: BENAR.
Opsi B: SALAH. Lake Formation tidak memiliki kemampuan membaca Macie findings secara otomatis — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Menambah data movement overhead dan bisa mengganggu downstream pipelines yang referencing original path.
Opsi D: SALAH. Tidak ada built-in direct integration antara Macie dan Lake Formation.
6
A data engineer is configuring a Macie classification job for a data lake bucket containing millions of objects in various formats (CSV, JSON, Parquet, PDF, XLSX). The job needs to complete within a 4-hour maintenance window each night. Previous runs exceeded 8 hours. Which configuration changes would MOST effectively reduce job runtime while maintaining comprehensive PII detection?
  • A. Reduce the number of managed data identifiers to scan only for the most critical PII types
  • B. Split into multiple parallel jobs — one per file format — and run all simultaneously with object criteria and set a sampling depth percentage
  • C. Increase the sampling depth to scan more objects per run but limit the number of bytes scanned per object
  • D. Configure the job with object criteria to include only objects modified since the last successful run (incremental scanning) and set a sampling depth percentage
Jawaban Benar: D
Macie classification jobs mendukung object criteria filtering termasuk berdasarkan last modified date. Dengan hanya scanning objects yang berubah sejak last successful run, volume scanning berkurang drastis. Sampling depth mengontrol persentase eligible objects yang di-scan per run. Kombinasi incremental approach + appropriate sampling memastikan job selesai dalam window tanpa melewatkan data baru.

Opsi A: SALAH. Mengurangi identifiers mengurangi coverage dan bisa menyebabkan compliance gaps; runtime reduction-nya juga minimal karena bottleneck biasanya di object reading bukan pattern matching.
Opsi B: SALAH. Multiple parallel jobs tidak mempercepat karena Macie memiliki account-level concurrency limits — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Meningkatkan sampling depth memperbanyak objects yang di-scan sehingga memperlama runtime, bukan mengurangi.
Opsi D: BENAR.
7
A retail company uses Macie to scan their customer data lake. They notice Macie correctly identifies credit card numbers but assigns them as MEDIUM severity. According to their internal policy, any credit card data detection should be treated as HIGH severity and trigger immediate remediation. How can the team ensure credit card findings are escalated appropriately?
  • A. Create a custom data identifier for credit cards with a higher severity threshold setting and trigger the HIGH-priority remediation workflow
  • B. Create an EventBridge rule that matches Macie findings containing the CREDIT_CARD_NUMBER data identifier regardless of severity, and trigger the HIGH-priority remediation workflow
  • C. Modify Macie's severity scoring configuration to change CREDIT_CARD_NUMBER findings from MEDIUM to HIGH
  • D. Use AWS Security Hub to customize the severity of Macie findings before they reach EventBridge
Jawaban Benar: B
Macie severity levels ditentukan secara internal berdasarkan jumlah occurrences dan jenis data — pengguna tidak bisa mengubah severity scoring logic. Solusi yang tepat adalah membuat EventBridge rule yang memfilter berdasarkan tipe data identifier (classificationDetails.result.sensitiveData.detections.type = "CREDIT_CARD_NUMBER") tanpa memperhatikan severity field. Rule ini kemudian trigger remediation workflow yang sesuai policy internal (HIGH priority).

Opsi A: SALAH. Custom data identifiers tidak memiliki "severity threshold setting" — severity tetap dihitung oleh Macie berdasarkan volume detections — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Macie tidak menyediakan konfigurasi untuk mengubah severity scoring per identifier type.
Opsi D: SALAH. Security Hub tidak bisa memodifikasi severity findings sebelum EventBridge; findings flow ke EventBridge langsung dari Macie.
8
A multinational company needs to implement PII detection that covers California Consumer Privacy Act (CCPA) requirements. CCPA defines PII more broadly than traditional definitions, including IP addresses, browsing history, geolocation data, and inferences drawn from other data. Which Macie configuration provides the MOST complete CCPA PII coverage?
  • A. Use only custom data identifiers to create regex patterns for all CCPA-defined PII categories
  • B. Enable all Macie managed data identifiers which cover all CCPA PII categories including behavioral and inference data
  • C. Use Macie managed data identifiers for standard PII (names, emails, SSN) combined with custom data identifiers for CCPA-specific categories like geolocation coordinates and device identifiers
  • D. Deploy a third-party DLP solution since Macie cannot detect non-standard PII types required by CCPA with custom data identifiers for CCPA-specific categories like geolocation coordinates and device identifiers
Jawaban Benar: C
CCPA mendefinisikan personal information sangat luas. Macie managed data identifiers mencakup banyak standard PII (names, addresses, SSN, credit cards, emails, phone numbers) tetapi tidak mencakup semua kategori CCPA seperti geolocation coordinates, device IDs, atau browsing patterns. Solusi terbaik adalah kombinasi: managed identifiers untuk standard PII + custom data identifiers untuk format CCPA-specific yang tidak di-cover. Custom identifiers bisa mendeteksi patterns seperti koordinat GPS (regex untuk lat/long), MAC addresses, advertising IDs, dll.

Opsi A: SALAH. Menggunakan custom saja berarti membuat ulang detection yang sudah ada di managed identifiers (duplikasi effort).
Opsi B: SALAH. Managed identifiers tidak cover SEMUA kategori CCPA (terutama behavioral data).
Opsi C: BENAR.
Opsi D: SALAH. Macie bisa mendeteksi sebagian besar dengan managed + custom; third-party tidak diperlukan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

A data engineer is reviewing Macie's automated sensitive data discovery results for their organization's S3 buckets. The sensitivity score for one bucket shows 85/100 with the breakdown showing 60% of sampled objects contain PII. The bucket is used by an ETL pipeline as a staging area before data is loaded into Redshift. What action should the data engineer take based on this finding?
  • A. Move the staging bucket to a different AWS Region where Macie is not enabled
  • B. Immediately delete all objects in the staging bucket since they contain PII
  • C. Run a targeted classification job on the bucket to get complete findings, then implement data masking or tokenization in the ETL pipeline before data reaches the staging bucket
  • D. Reduce the bucket's sensitivity score by adding it to Macie's exclusion list configured for optimal performance and minimal operational overhead
Jawaban Benar: C
Automated sensitive data discovery menggunakan sampling, jadi sensitivity score adalah estimasi. Langkah proper adalah: (1) Run targeted classification job untuk mendapatkan complete picture (object-by-object detail), (2) Berdasarkan findings, implementasi data masking/tokenization/encryption di ETL pipeline SEBELUM data landing di staging — ini memastikan PII tidak ada di staging area. Pendekatan ini mengatasi root cause (PII di staging) bukan gejalanya.

Opsi A: SALAH. Memindahkan ke region tanpa Macie adalah security by obscurity yang tidak menyelesaikan PII exposure risk.
Opsi B: SALAH. Deleting data mengganggu ETL pipeline dan mungkin menghapus data yang masih diperlukan.
Opsi C: BENAR.
Opsi D: SALAH. Exclusion list menyembunyikan masalah, bukan menyelesaikan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

A company uses Macie for PII detection across 50 AWS accounts managed through AWS Organizations. The delegated Macie administrator account receives findings from all member accounts. The security team wants to generate a monthly compliance report showing: PII findings per account, remediation status, and trending data. They also want to aggregate findings with other security tools. Which architecture supports this reporting requirement?
  • A. Configure each member account to independently export findings to a centralized S3 bucket with Athena and QuickSight
  • B. Enable AWS Security Hub integration to aggregate Macie findings, then use Security Hub's export to S3 for cross-service reporting with Athena and QuickSight
  • C. Export Macie findings to the delegated administrator's S3 bucket using Macie's findings export configuration, then use Athena to query findings for the report
  • D. Use Macie's built-in reporting dashboard to generate monthly PDF compliance reports
Jawaban Benar: B
Security Hub adalah central aggregation point untuk security findings termasuk Macie. Dengan enabling Security Hub integration: (1) Macie findings dari semua member accounts otomatis flow ke Security Hub, (2) Security Hub juga menerima findings dari services lain (GuardDuty, Inspector, dll) memungkinkan cross-service reporting, (3) Security Hub findings bisa di-export ke S3 untuk querying dengan Athena dan visualization dengan QuickSight. Ini memberikan trending, per-account breakdown, dan aggregation yang diminta.

Opsi A: SALAH. Per-account configuration tidak diperlukan jika menggunakan delegated administrator model; juga menambah management overhead — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Bisa bekerja tapi hanya untuk Macie findings — tidak mengaggregasi dengan security tools lain.
Opsi D: SALAH. Macie tidak memiliki built-in PDF reporting dashboard.
