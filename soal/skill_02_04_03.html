1
A company is migrating from Oracle 19c to Amazon Aurora PostgreSQL. The Oracle database contains 200 stored procedures, 50 packages, and 30 triggers that use PL/SQL-specific features. The data engineer needs to assess the migration complexity before starting. Which AWS tool should be used FIRST?
  • A. AWS Database Migration Service (DMS) to start replication immediately
  • B. AWS Schema Conversion Tool (SCT) to generate a migration assessment report
  • C. AWS Application Discovery Service to inventory database dependencies
  • D. Amazon RDS Performance Insights to compare source and target capabilities
Jawaban Benar: B
AWS Schema Conversion Tool (SCT) harus digunakan pertama kali untuk menghasilkan Database Migration Assessment Report. Report ini menganalisis seluruh schema objects (tables, views, stored procedures, packages, triggers) dan mengklasifikasikan setiap item berdasarkan kompleksitas konversi: otomatis (green), memerlukan sedikit modifikasi (orange), atau memerlukan rewrite manual (red). Ini memberikan picture jelas tentang effort yang diperlukan. Opsi A (DMS) digunakan setelah schema sudah dikonversi untuk data migration. Opsi C (Application Discovery) untuk infrastructure migration, bukan database schema. Opsi D (Performance Insights) untuk monitoring, bukan assessment.
2
A data engineer is using AWS SCT to convert an Oracle data warehouse schema to Amazon Redshift. The assessment report shows that Oracle BITMAP indexes cannot be automatically converted. What is the CORRECT approach for handling bitmap indexes during migration to Redshift?
  • A. Manually create B-tree indexes in Redshift as a replacement
  • B. Convert bitmap indexes to Redshift interleaved sort keys for similar filtering performance
  • C. Indexes are not needed in Redshift — use appropriate sort keys and distribution keys instead for query optimization
  • D. Use Redshift Spectrum to maintain Oracle-style indexes on external tables
Jawaban Benar: C
Amazon Redshift tidak menggunakan indexes sama sekali — ini adalah perbedaan fundamental dari OLTP databases. Redshift mengoptimasi query performance melalui columnar storage, sort keys (compound atau interleaved), distribution keys, dan zone maps. Bitmap indexes dari Oracle tidak perlu "dikonversi" — perlu diidentifikasi query patterns yang menggunakan indexes tersebut dan kemudian pilih sort keys dan distribution keys yang sesuai. Opsi A salah — Redshift tidak mendukung B-tree indexes. Opsi B terlalu spesifik — interleaved sort keys bukan direct replacement untuk bitmap indexes. Opsi D (Spectrum) tidak mendukung indexes.
3
A company is migrating SQL Server to Amazon Aurora PostgreSQL. The SQL Server database uses extensively T-SQL specific features including MERGE statements, CROSS APPLY, and Common Table Expressions (CTEs) with recursion. After running AWS SCT, the assessment shows 60% automatic conversion. What does this percentage indicate?
  • A. 60% of the data can be migrated without transformation
  • B. 60% of the database schema objects and code can be automatically converted to PostgreSQL-compatible syntax
  • C. 60% of the queries will run without modification on Aurora PostgreSQL
  • D. 60% of the migration will be completed by AWS DMS automatically
Jawaban Benar: B
SCT assessment percentage menunjukkan proporsi schema objects (tables, views, stored procedures, functions, triggers) dan code yang bisa dikonversi secara otomatis ke target syntax. 60% berarti SCT bisa menghasilkan PostgreSQL-compatible DDL/code untuk 60% objects tanpa intervensi manual. Sisa 40% memerlukan modifikasi manual — misalnya, CROSS APPLY perlu diubah ke LATERAL JOIN di PostgreSQL. Opsi A salah — ini tentang schema/code, bukan data. Opsi C salah — ini tentang schema objects, bukan runtime query. Opsi D salah — DMS menangani data migration, bukan schema conversion.
4
A data engineer is migrating an Oracle database to Aurora PostgreSQL using AWS DMS Schema Conversion (serverless). Compared to the traditional AWS SCT desktop application, what is the PRIMARY advantage of DMS Schema Conversion?
  • A. DMS Schema Conversion supports more source database engines than SCT
  • B. DMS Schema Conversion is fully serverless and does not require installing or maintaining a local application
  • C. DMS Schema Conversion can convert stored procedures that SCT cannot
  • D. DMS Schema Conversion performs data migration and schema conversion simultaneously
Jawaban Benar: B
AWS DMS Schema Conversion adalah fitur serverless yang terintegrasi dalam AWS DMS console. Tidak perlu mengunduh, menginstal, atau memelihara aplikasi desktop seperti SCT tradisional. Ini mengurangi operational overhead dan memudahkan kolaborasi tim. Opsi A salah — DMS Schema Conversion sebenarnya mendukung lebih sedikit source-target combinations dibanding SCT desktop. Opsi C salah — stored procedure conversion capabilities serupa. Opsi D salah — schema conversion dan data migration tetap proses terpisah, meski keduanya tersedia di DMS console.
5
During an Oracle to PostgreSQL migration using AWS SCT, the tool flags Oracle sequences with CACHE and CYCLE options as requiring manual intervention. The data engineer needs to understand why. Which limitation causes this SCT action item?
  • A. PostgreSQL does not support sequences at all
  • B. PostgreSQL sequences support different CACHE behavior and CYCLE semantics that may need application-level verification
  • C. AWS Aurora PostgreSQL has a hard limit of 100 sequences per schema
  • D. Oracle sequences must be converted to DynamoDB atomic counters during migration
Jawaban Benar: B
PostgreSQL mendukung sequences dengan CACHE dan CYCLE, tetapi behavior-nya mungkin sedikit berbeda dari Oracle. Misalnya, Oracle CACHE menyimpan batch di SGA memory instance-wide, sementara PostgreSQL caches per-session. CYCLE behavior juga bisa memiliki perbedaan dalam gap handling. SCT menandai ini untuk verifikasi manual karena perbedaan semantik bisa mempengaruhi application logic yang bergantung pada sequence behavior. Opsi A salah — PostgreSQL mendukung sequences. Opsi C salah — tidak ada limit 100. Opsi D tidak relevan — sequences dikonversi ke PostgreSQL sequences, bukan DynamoDB.
6
A company is migrating a 10 TB Oracle data warehouse to Amazon Redshift. The AWS SCT assessment report shows three categories of action items: "Simple" (green), "Medium" (amber), and "Complex" (red). The report indicates 40 complex action items, all related to Oracle PL/SQL packages with PRAGMA directives and AUTONOMOUS_TRANSACTIONS. What should the data engineer do with these complex items?
  • A. Run SCT again with enhanced conversion mode to automatically resolve complex items
  • B. Manually rewrite the PL/SQL logic using Redshift stored procedures (PL/pgSQL) or redesign as Python UDFs or Lambda UDFs
  • C. Skip the stored procedures and rely on application-level logic instead
  • D. Use AWS DMS to migrate the stored procedures as-is to Redshift
Jawaban Benar: B
Complex (red) items memerlukan manual rewrite karena fitur Oracle yang digunakan tidak memiliki equivalent langsung di target. PRAGMA directives dan AUTONOMOUS_TRANSACTIONS adalah Oracle-specific features. Untuk Redshift, opsinya: (1) rewrite sebagai Redshift stored procedures (PL/pgSQL), (2) implementasi sebagai Python/Lambda UDFs, atau (3) pindahkan logic ke ETL layer (Glue/Step Functions). Opsi A salah — tidak ada "enhanced mode" yang bisa resolve complex items otomatis. Opsi C mungkin valid tapi tidak selalu practical. Opsi D salah — DMS migrasi data, bukan stored procedures, dan Redshift tidak bisa menjalankan PL/SQL.
7
A data engineer uses AWS SCT to convert a SQL Server schema to Aurora PostgreSQL. After applying the converted schema, they need to validate that the conversion is correct before migrating data. Which testing approach is RECOMMENDED?
  • A. Compare row counts between source and target tables
  • B. Run the application's test suite against the new Aurora PostgreSQL with the converted schema, comparing query results between source and target
  • C. Use AWS DMS validation feature to compare schemas
  • D. Verify only that CREATE TABLE statements execute without errors
Jawaban Benar: B
Validasi konversi schema yang paling komprehensif adalah menjalankan test suite aplikasi terhadap target database dan membandingkan hasil query antara source dan target. Ini memvalidasi bahwa stored procedures, views, triggers, dan constraints berperilaku sesuai ekspektasi. Opsi A (row counts) hanya memvalidasi data migration, bukan schema conversion correctness. Opsi C (DMS validation) memvalidasi data consistency setelah migration, bukan schema logic correctness. Opsi D hanya memastikan DDL syntax valid tapi tidak memvalidasi logic (stored procedures bisa syntactically correct tapi logically wrong).
8
A company migrating from Oracle to Aurora PostgreSQL encounters Oracle-specific data types: CLOB (Character Large Object), RAW, and NUMBER(38,10). AWS SCT maps these to PostgreSQL types. Which mapping is CORRECT?
  • A. CLOB → TEXT, RAW → BYTEA, NUMBER(38,10) → NUMERIC(38,10)
  • B. CLOB → VARCHAR(MAX), RAW → VARBINARY, NUMBER(38,10) → FLOAT8
  • C. CLOB → BLOB, RAW → TEXT, NUMBER(38,10) → INTEGER
  • D. CLOB → JSON, RAW → UUID, NUMBER(38,10) → BIGINT
Jawaban Benar: A
Mapping yang benar: Oracle CLOB (character large object) → PostgreSQL TEXT (unlimited length text); Oracle RAW (binary data) → PostgreSQL BYTEA (byte array); Oracle NUMBER(38,10) → PostgreSQL NUMERIC(38,10) (exact numeric dengan precision dan scale yang sama). Opsi B menggunakan tipe SQL Server (VARCHAR(MAX), VARBINARY) dan FLOAT8 kehilangan precision. Opsi C salah — BLOB bukan text type, RAW bukan text, dan INTEGER terlalu kecil untuk NUMBER(38,10). Opsi D salah — semua mapping tidak sesuai secara semantik.
9
A large enterprise is migrating 500 database schemas from SQL Server to Aurora PostgreSQL. The migration team has 5 engineers and needs to track progress, assign action items, and collaborate on manual code conversions. Which AWS SCT feature supports team collaboration for large-scale migrations?
  • A. SCT extension pack for bulk conversion automation
  • B. AWS DMS Schema Conversion with multi-user project support and action item assignment
  • C. SCT desktop application with export to CSV for project management tracking
  • D. AWS Migration Hub for database migration orchestration
Jawaban Benar: B
AWS DMS Schema Conversion (serverless version) mendukung multi-user collaboration melalui AWS DMS console. Multiple engineers bisa bekerja pada migration project yang sama, melihat assessment results, dan melacak action items. Ini lebih collaborative dibanding SCT desktop yang single-user. Opsi A (extension pack) menyediakan helper functions di target database, bukan collaboration. Opsi C (CSV export) adalah workaround manual, bukan built-in feature. Opsi D (Migration Hub) melacak overall migration progress tapi tidak memiliki schema conversion detail-level collaboration.
10
A data engineer is migrating an Oracle database to Amazon Redshift using AWS SCT. The Oracle source contains materialized views with complex refresh logic (FAST refresh using materialized view logs). SCT cannot automatically convert these. Which Redshift alternative should the data engineer implement?
  • A. Create standard Redshift views and schedule manual REFRESH using stored procedures
  • B. Use Redshift materialized views with AUTO REFRESH option for automatic incremental refresh
  • C. Replace materialized views with Redshift external tables pointing to S3
  • D. Implement the refresh logic using AWS Glue ETL jobs on a schedule
Jawaban Benar: B
Amazon Redshift mendukung materialized views dengan AUTO REFRESH yang secara otomatis melakukan incremental refresh ketika base tables berubah. Ini adalah pengganti terdekat untuk Oracle materialized views dengan FAST refresh. Redshift mendeteksi perubahan pada base tables dan melakukan refresh inkremental tanpa perlu materialized view logs. Opsi A (standard views) tidak menyimpan data secara fisik sehingga tidak memberikan performance benefit. Opsi C (external tables) memiliki performa lebih lambat dari materialized views. Opsi D (Glue ETL) menambah complexity yang tidak perlu ketika native feature tersedia.
