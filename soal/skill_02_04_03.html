A company is migrating from Oracle 19c to Amazon Aurora PostgreSQL. The Oracle database contains 200 stored procedures, 50 packages, and 30 triggers that use PL/SQL-specific features. The data engineer needs to assess the migration complexity before starting. Which AWS tool should be used FIRST?
  • A. Amazon RDS Performance Insights to compare source and target capabilities
  • B. AWS Schema Conversion Tool (SCT) to generate a migration assessment report
  • C. AWS Database Migration Service (DMS) to start replication immediately
  • D. AWS Application Discovery Service to inventory database dependencies
Jawaban Benar: B
AWS Schema Conversion Tool (SCT) harus digunakan pertama kali untuk menghasilkan Database Migration Assessment Report. Report ini menganalisis seluruh schema objects (tables, views, stored procedures, packages, triggers) dan mengklasifikasikan setiap item berdasarkan kompleksitas konversi: otomatis (green), memerlukan sedikit modifikasi (orange), atau memerlukan rewrite manual (red). Ini memberikan picture jelas tentang effort yang diperlukan.

Opsi A: SALAH. Untuk monitoring, bukan assessment.
Opsi B: BENAR.
Opsi C: SALAH. Digunakan setelah schema sudah dikonversi untuk data migration.
Opsi D: SALAH. Untuk infrastructure migration, bukan database schema.

#Redshift#SCT
A data engineer is using AWS SCT to convert an Oracle data warehouse schema to Amazon Redshift. The assessment report shows that Oracle BITMAP indexes cannot be automatically converted. What is the CORRECT approach for handling bitmap indexes during migration to Redshift?
  • A. Manually create B-tree indexes in Redshift as a replacement, handling the described workload reliably at scale
  • B. Convert bitmap indexes to Redshift interleaved sort keys for similar filtering performance, validating and cleansing each record before delivery
  • C. Indexes are not needed in Redshift — use appropriate sort keys and distribution keys instead for query optimization
  • D. Use Redshift Spectrum to maintain Oracle-style indexes on external tables and distribution keys instead for query optimization
Jawaban Benar: C
Amazon Redshift tidak menggunakan indexes sama sekali — ini adalah perbedaan fundamental dari OLTP databases. Redshift mengoptimasi query performance melalui columnar storage, sort keys (compound atau interleaved), distribution keys, dan zone maps. Bitmap indexes dari Oracle tidak perlu "dikonversi" — perlu diidentifikasi query patterns yang menggunakan indexes tersebut dan kemudian pilih sort keys dan distribution keys yang sesuai.

Opsi A: SALAH. Salah — Redshift tidak mendukung B-tree indexes.
Opsi B: SALAH. Terlalu spesifik — interleaved sort keys bukan direct replacement untuk bitmap indexes.
Opsi C: BENAR.
Opsi D: SALAH. Tidak mendukung indexes — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

A company is migrating SQL Server to Amazon Aurora PostgreSQL. The SQL Server database uses extensively T-SQL specific features including MERGE statements, CROSS APPLY, and Common Table Expressions (CTEs) with recursion. After running AWS SCT, the assessment shows 60% automatic conversion. What does this percentage indicate?
  • A. 60% of the migration will be completed by AWS DMS automatically configured for optimal performance and minimal operational overhead
  • B. 60% of the queries will run without modification on Aurora PostgreSQL, optimizing cost for the described workload
  • C. 60% of the database schema objects and code can be automatically converted to PostgreSQL-compatible syntax
  • D. 60% of the data can be migrated without transformation, handling the described workload reliably at scale
Jawaban Benar: C
SCT assessment percentage menunjukkan proporsi schema objects (tables, views, stored procedures, functions, triggers) dan code yang bisa dikonversi secara otomatis ke target syntax. 60% berarti SCT bisa menghasilkan PostgreSQL-compatible DDL/code untuk 60% objects tanpa intervensi manual. Sisa 40% memerlukan modifikasi manual — misalnya, CROSS APPLY perlu diubah ke LATERAL JOIN di PostgreSQL.

Opsi A: SALAH. Salah — DMS menangani data migration, bukan schema conversion — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Salah — ini tentang schema objects, bukan runtime query.
Opsi C: BENAR.
Opsi D: SALAH. Salah — ini tentang schema/code, bukan data.

A data engineer is migrating an Oracle database to Aurora PostgreSQL using AWS DMS Schema Conversion (serverless). Compared to the traditional AWS SCT desktop application, what is the PRIMARY advantage of DMS Schema Conversion?
  • A. DMS Schema Conversion is fully serverless and does not require installing or maintaining a local application
  • B. DMS Schema Conversion supports more source database engines than SCT with fully managed infrastructure and automatic scaling
  • C. DMS Schema Conversion can convert stored procedures that SCT cannot, requiring no servers to manage or scale manually
  • D. DMS Schema Conversion performs data migration and schema conversion simultaneously, applying schema conversion and enrichment inline
Jawaban Benar: A
AWS DMS Schema Conversion adalah fitur serverless yang terintegrasi dalam AWS DMS console. Tidak perlu mengunduh, menginstal, atau memelihara aplikasi desktop seperti SCT tradisional. Ini mengurangi operational overhead dan memudahkan kolaborasi tim.

Opsi A: BENAR.
Opsi B: SALAH. Salah — DMS Schema Conversion sebenarnya mendukung lebih sedikit source-target combinations dibanding SCT desktop — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Salah — stored procedure conversion capabilities serupa.
Opsi D: SALAH. Salah — schema conversion dan data migration tetap proses terpisah, meski keduanya tersedia di DMS console.

#DynamoDB#Aurora#SCT
During an Oracle to PostgreSQL migration using AWS SCT, the tool flags Oracle sequences with CACHE and CYCLE options as requiring manual intervention. The data engineer needs to understand why. Which limitation causes this SCT action item?
  • A. AWS Aurora PostgreSQL has a hard limit of 100 sequences per schema
  • B. PostgreSQL sequences support different CACHE behavior and CYCLE semantics that may need application-level verification
  • C. PostgreSQL does not support sequences at all configured for optimal performance and minimal operational overhead
  • D. Oracle sequences must be converted to DynamoDB atomic counters during migration
Jawaban Benar: B
PostgreSQL mendukung sequences dengan CACHE dan CYCLE, tetapi behavior-nya mungkin sedikit berbeda dari Oracle. Misalnya, Oracle CACHE menyimpan batch di SGA memory instance-wide, sementara PostgreSQL caches per-session. CYCLE behavior juga bisa memiliki perbedaan dalam gap handling. SCT menandai ini untuk verifikasi manual karena perbedaan semantik bisa mempengaruhi application logic yang bergantung pada sequence behavior.

Opsi A: SALAH. Salah — tidak ada limit 100.
Opsi B: BENAR.
Opsi C: SALAH. Salah — PostgreSQL mendukung sequences — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Tidak relevan — sequences dikonversi ke PostgreSQL sequences, bukan DynamoDB.

A company is migrating a 10 TB Oracle data warehouse to Amazon Redshift. The AWS SCT assessment report shows three categories of action items: "Simple" (green), "Medium" (amber), and "Complex" (red). The report indicates 40 complex action items, all related to Oracle PL/SQL packages with PRAGMA directives and AUTONOMOUS_TRANSACTIONS. What should the data engineer do with these complex items?
  • A. Run SCT again with enhanced conversion mode to automatically resolve complex items, integrating natively with the rest of the pipeline
  • B. Skip the stored procedures and rely on application-level logic instead configured for optimal performance and minimal operational overhead
  • C. Manually rewrite the PL/SQL logic using Redshift stored procedures (PL/pgSQL) or redesign as Python UDFs or Lambda UDFs
  • D. Use AWS DMS to migrate the stored procedures as-is to Redshift, integrating natively with the rest of the pipeline
Jawaban Benar: C
Complex (red) items memerlukan manual rewrite karena fitur Oracle yang digunakan tidak memiliki equivalent langsung di target. PRAGMA directives dan AUTONOMOUS_TRANSACTIONS adalah Oracle-specific features. Untuk Redshift, opsinya: (1) rewrite sebagai Redshift stored procedures (PL/pgSQL), (2) implementasi sebagai Python/Lambda UDFs, atau (3) pindahkan logic ke ETL layer (Glue/Step Functions).

Opsi A: SALAH. Salah — tidak ada "enhanced mode" yang bisa resolve complex items otomatis.
Opsi B: SALAH. Mungkin valid tapi tidak selalu practical — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Salah — DMS migrasi data, bukan stored procedures, dan Redshift tidak bisa menjalankan PL/SQL.

A data engineer uses AWS SCT to convert a SQL Server schema to Aurora PostgreSQL. After applying the converted schema, they need to validate that the conversion is correct before migrating data. Which testing approach is RECOMMENDED?
  • A. Verify only that CREATE TABLE statements execute without errors, applying schema conversion and enrichment inline and transforming records into the required target format
  • B. Run the application's test suite against the new Aurora PostgreSQL with the converted schema, comparing query results between source and target
  • C. Compare row counts between source and target tables, applying schema conversion and enrichment inline and handling the described workload reliably at scale
  • D. Use AWS DMS validation feature to compare schemas with the converted schema and target, meeting the latency and throughput goals of the design
Jawaban Benar: B
Validasi konversi schema yang paling komprehensif adalah menjalankan test suite aplikasi terhadap target database dan membandingkan hasil query antara source dan target. Ini memvalidasi bahwa stored procedures, views, triggers, dan constraints berperilaku sesuai ekspektasi.

Opsi A: SALAH. Hanya memastikan DDL syntax valid tapi tidak memvalidasi logic (stored procedures bisa syntactically correct tapi logically wrong).
Opsi B: BENAR.
Opsi C: SALAH. Hanya memvalidasi data migration, bukan schema conversion correctness.
Opsi D: SALAH. Memvalidasi data consistency setelah migration, bukan schema logic correctness — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

A company migrating from Oracle to Aurora PostgreSQL encounters Oracle-specific data types: CLOB (Character Large Object), RAW, and NUMBER(38,10). AWS SCT maps these to PostgreSQL types. Which mapping is CORRECT?
  • A. CLOB → TEXT, RAW → BYTEA, NUMBER(38,10) → NUMERIC(38,10)
  • B. CLOB → BLOB, RAW → TEXT, NUMBER(38,10) → INTEGER
  • C. CLOB → VARCHAR(MAX), RAW → VARBINARY, NUMBER(38,10) → FLOAT8
  • D. CLOB → JSON, RAW → UUID, NUMBER(38,10) → BIGINT
Jawaban Benar: A
Mapping yang benar: Oracle CLOB (character large object) → PostgreSQL TEXT (unlimited length text); Oracle RAW (binary data) → PostgreSQL BYTEA (byte array); Oracle NUMBER(38,10) → PostgreSQL NUMERIC(38,10) (exact numeric dengan precision dan scale yang sama).

Opsi A: BENAR.
Opsi B: SALAH. Salah — BLOB bukan text type, RAW bukan text, dan INTEGER terlalu kecil untuk NUMBER(38,10).
Opsi C: SALAH. Menggunakan tipe SQL Server (VARCHAR(MAX), VARBINARY) dan FLOAT8 kehilangan precision.
Opsi D: SALAH. Salah — semua mapping tidak sesuai secara semantik.

AWS DMS Schema Conversion (serverless version) mendukung multi-user collaboration melalui AWS DMS console. Multiple engineers bisa bekerja pada migration project yang sama, melihat assessment results, dan melacak action items. Ini lebih collaborative dibanding SCT desktop yang single-user.

Opsi A: SALAH. Melacak overall migration progress tapi tidak memiliki schema conversion detail-level collaboration — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Menyediakan helper functions di target database, bukan collaboration.
Opsi C: SALAH. Adalah workaround manual, bukan built-in feature.

A data engineer is migrating an Oracle database to Amazon Redshift using AWS SCT. The Oracle source contains materialized views with complex refresh logic (FAST refresh using materialized view logs). SCT cannot automatically convert these. Which Redshift alternative should the data engineer implement?
  • A. Replace materialized views with Redshift external tables pointing to S3
  • B. Implement the refresh logic using AWS Glue ETL jobs on a schedule with AUTO REFRESH option for automatic
  • C. Create standard Redshift views and schedule manual REFRESH using stored procedures
  • D. Use Redshift materialized views with AUTO REFRESH option for automatic incremental refresh
Jawaban Benar: D
Amazon Redshift mendukung materialized views dengan AUTO REFRESH yang secara otomatis melakukan incremental refresh ketika base tables berubah. Ini adalah pengganti terdekat untuk Oracle materialized views dengan FAST refresh. Redshift mendeteksi perubahan pada base tables dan melakukan refresh inkremental tanpa perlu materialized view logs.

Opsi A: SALAH. Memiliki performa lebih lambat dari materialized views.
Opsi B: SALAH. Menambah complexity yang tidak perlu ketika native feature tersedia — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Tidak menyimpan data secara fisik sehingga tidak memberikan performance benefit.
Opsi D: BENAR.
