Skill 4.5.6: Manage Data Access Through Amazon SageMaker Catalog Projects

Using SageMaker Catalog (DataZone) projects to control and govern data access

1
A large enterprise has 200+ data assets across multiple AWS accounts. Data scientists frequently request access to datasets but the current process involves manual Jira tickets, taking 2-3 weeks for approval. They want to implement a self-service data access platform with governance guardrails. Which Amazon DataZone (SageMaker Catalog) architecture enables this?
  • A. Create a DataZone domain, organize data assets into projects by domain ownership, enable the data catalog for discovery, configure approval workflows for subscription requests, and provision environments for approved consumers
  • B. Create an AWS Glue Data Catalog shared across accounts and use Lake Formation for access control without DataZone
  • C. Build a custom portal using Amazon API Gateway and Lambda that automates IAM role creation for data access
  • D. Use AWS Service Catalog to create pre-approved data access products that teams can self-provision
Jawaban Benar: A
Amazon DataZone (integrated as SageMaker Catalog) dirancang untuk exactly this use case: self-service data discovery dan governed access. Architecture-nya: (1) Domain — organizational container untuk governance, (2) Projects — memiliki data assets, dikategorikan per domain ownership (marketing, finance, etc), (3) Data catalog — memungkinkan data scientists search dan discover assets, (4) Subscription requests — consumers request access yang routes melalui approval workflow (owner/steward approval), (5) Environments — provisioned compute access setelah approval. Proses 2-3 minggu menjadi minutes-to-hours. Opsi B — Glue + Lake Formation menyediakan access control tapi tidak discovery portal, approval workflow, atau self-service experience. Opsi C — custom build expensive dan doesn't leverage managed governance features. Opsi D — Service Catalog untuk infrastructure provisioning, bukan data governance.
2
A data governance team is setting up Amazon DataZone projects. They need to define who can publish data products, who can subscribe to them, and who approves subscription requests. The organization has three roles: Data Producers (publish datasets), Data Consumers (use datasets), and Data Stewards (approve access). How should project membership and roles be configured?
  • A. Create one project for all users and use IAM policies to differentiate roles
  • B. Create producer projects where data teams publish assets (members have "Project Owner" or "Project Contributor" roles for publishing), create consumer projects for analytics teams (members request subscriptions), and assign Data Stewards as reviewers in the domain's approval workflow configuration
  • C. Create separate DataZone domains for producers and consumers with cross-domain sharing
  • D. Use a single project with custom Lambda authorizers to handle role-based actions
Jawaban Benar: B
DataZone project structure separates concerns: Producer projects contain teams yang own dan publish data assets — members dengan "Project Owner" role bisa publish dan manage, "Project Contributor" bisa contribute assets. Consumer projects contain teams yang subscribe ke dan use data — mereka initiate subscription requests. Data Stewards dikonfigurasi sebagai approvers di domain atau project level untuk review subscription requests. Separation of producer/consumer projects mencerminkan organizational boundaries dan responsibility. Opsi A — single project tidak mendukung proper governance separation; semua users seeing semua assets tanpa discovery process. Opsi C — separate domains terlalu extreme; domains typically represent organizations, bukan roles. Opsi D — custom Lambda authorizers bukan bagian dari DataZone architecture.
3
A data scientist discovers a dataset called "customer_transactions" in the Amazon DataZone catalog and wants to use it for a churn prediction model. The dataset is owned by the Finance team's project. What is the correct workflow for the data scientist to get access to this dataset?
  • A. Directly access the underlying S3 path of the dataset since it's visible in the catalog
  • B. Submit a subscription request through the DataZone portal specifying the dataset and purpose → Finance team's project owner/steward reviews the request → Upon approval, DataZone automatically provisions access in the data scientist's project environment
  • C. Ask the Finance team to manually share IAM credentials for the dataset's S3 bucket
  • D. Clone the dataset into the data scientist's own project using the catalog's copy feature
Jawaban Benar: B
DataZone subscription workflow adalah inti dari governed data access: (1) Consumer discovers asset di catalog, (2) Consumer submits subscription request — menyertakan use case/purpose, (3) Asset owner atau designated steward reviews request, (4) Upon approval, DataZone automatically grants access — ini bisa berupa Lake Formation permissions, Redshift datashare access, atau Glue catalog permissions tergantung underlying data source, (5) Consumer bisa query data dari their project's environment. Catalog visibility ≠ data access — Anda bisa melihat metadata tapi harus request subscription untuk actual data access. Opsi A — catalog visibility tidak berarti data access; ini adalah key governance principle. Opsi C — manual credential sharing bypasses governance. Opsi D — DataZone tidak memiliki "copy feature" yang bypass subscription.
4
A company's compliance team needs an audit trail showing: who requested access to which data assets, when requests were approved/denied, who approved them, and when access was actually used. They use Amazon DataZone for data governance. Which combination of features provides this complete audit trail?
  • A. DataZone subscription activity logs (showing requests, approvals, denials) combined with CloudTrail for API-level actions and the underlying data service logs (Athena query logs, Redshift audit logs) for actual data usage
  • B. CloudTrail alone provides all audit information for DataZone activities
  • C. DataZone's built-in compliance reporting dashboard provides all required audit data in one view
  • D. AWS Config records all DataZone configuration changes which serves as the audit trail
Jawaban Benar: A
Complete audit trail memerlukan multiple layers: (1) DataZone tracks subscription lifecycle — who requested, what was requested, purpose stated, who approved/denied, timestamps for each state change. (2) CloudTrail captures API-level actions — DataZone API calls, environment provisioning, access grant operations. (3) Underlying service logs capture actual data usage — Athena query logs show what queries ran against subscribed tables, Redshift audit logs show query history, S3 access logs show object access patterns. Kombinasi tiga layer ini memberikan full picture: request → approval → actual usage. Opsi B — CloudTrail mencatat API calls tapi tidak subscription workflow details atau actual data query activity. Opsi C — DataZone tidak memiliki built-in compliance reporting dashboard yang comprehensive. Opsi D — Config tracks resource configuration, bukan access patterns atau approval workflows.
5
A data platform team wants to publish a curated "customer_360" dataset as a data product in Amazon DataZone. The underlying data comes from three sources: S3 (raw data), Redshift (aggregated metrics), and a Glue table (transformed features). They want consumers to access a unified view without knowing the underlying sources. Which DataZone publishing approach achieves this?
  • A. Publish each source (S3, Redshift, Glue) as separate assets and let consumers subscribe to all three individually
  • B. Create a Glue ETL job that consolidates all three sources into a single curated table, register this table as a data asset in the DataZone catalog with comprehensive metadata (description, schema, quality metrics, lineage), and publish it as a single data product from the producer project
  • C. Create a DataZone "composite asset" that virtually joins the three sources at query time
  • D. Export all data to a single S3 bucket and share the bucket ARN through DataZone
Jawaban Benar: B
Best practice untuk data products adalah menyediakan curated, ready-to-consume datasets. Consolidating three sources ke single curated table (via Glue ETL) kemudian publishing sebagai single asset memberikan: (1) clean consumer experience — satu subscription, satu table, (2) abstraction — consumers tidak perlu tahu tentang underlying 3 sources, (3) quality control — producer ensures data quality sebelum publishing, (4) rich metadata — description, schema documentation, data quality scores, lineage showing where data came from. Opsi A — three separate subscriptions creates friction dan exposes implementation details ke consumers. Opsi C — DataZone tidak memiliki "composite asset" feature yang auto-joins sources. Opsi D — sharing raw bucket ARN bypasses catalog governance dan metadata enrichment.
6
A company uses Amazon DataZone with multiple projects across different AWS accounts. When a subscription is approved for a Glue table asset, DataZone needs to automatically grant the consumer project's environment access to the underlying data. What happens behind the scenes when a subscription is approved for a Glue-based asset?
  • A. DataZone copies the data to the consumer's AWS account S3 bucket
  • B. DataZone grants Lake Formation permissions on the Glue table to the consumer project's IAM role, enabling the consumer to query the data through their environment (e.g., Athena) without data movement
  • C. DataZone creates a VPN connection between producer and consumer VPCs for data transfer
  • D. DataZone sends the consumer a pre-signed URL to download the dataset
Jawaban Benar: B
Ketika subscription approved untuk Glue-based asset, DataZone secara otomatis orchestrates access grants melalui AWS Lake Formation. Proses: (1) DataZone identifies consumer project's environment IAM role, (2) Grants Lake Formation SELECT permission pada Glue table/columns ke consumer role, (3) Jika cross-account, menggunakan RAM share untuk Lake Formation resource sharing, (4) Consumer bisa langsung query menggunakan Athena atau tools lain di their environment — data tetap di location asli (zero-copy). Ini adalah key architectural principle: access granting, bukan data copying. Opsi A — no data copying terjadi; ini zero-copy access. Opsi C — VPN tidak diperlukan; access dilakukan melalui AWS service APIs. Opsi D — pre-signed URLs bukan mekanisme yang digunakan; ini would bypass governance setelah download.
7
A data governance team wants to implement time-limited data access through Amazon DataZone. When a data scientist subscribes to a sensitive dataset for a specific research project, access should automatically expire after 90 days. How can they implement this time-bound access pattern?
  • A. Configure the DataZone subscription grant with an expiration date; DataZone automatically revokes access when the subscription expires
  • B. Use an EventBridge scheduled rule that triggers a Lambda function after 90 days to call DataZone's revoke-subscription API and remove Lake Formation grants
  • C. Set the IAM role's session duration to 90 days so credentials expire
  • D. Add a DynamoDB TTL entry that triggers automatic access revocation through DynamoDB Streams
Jawaban Benar: A
Amazon DataZone mendukung subscription grants dengan expiration/time-based access. Ketika approving subscription request, approver atau policy bisa menetapkan grant duration. Setelah expiration date tercapai, DataZone secara otomatis revokes access — menghapus Lake Formation permissions, Redshift datashare access, atau access mechanism lain yang diberikan. Consumer perlu re-subscribe dan mendapat re-approval jika masih memerlukan akses setelah expiry. Ini built-in feature untuk temporary access patterns. Opsi B — custom automation bisa bekerja tapi over-engineers sesuatu yang sudah built-in. Opsi C — IAM session duration max 12 hours (for assumed roles), bukan 90 days; ini bukan mekanisme yang tepat. Opsi D — over-engineered dan fragile solution untuk built-in capability.
8
A company has both structured data (in Redshift and Glue tables) and unstructured data (documents in S3) that they want to catalog and govern through DataZone. A marketing team needs access to customer survey PDFs stored in S3 for sentiment analysis. How does DataZone handle access to unstructured S3 data assets?
  • A. DataZone only supports structured data; unstructured S3 objects cannot be cataloged or governed
  • B. Register the S3 location as a DataZone asset with appropriate metadata, publish to catalog. Upon subscription approval, DataZone grants S3 access (via IAM/bucket policies) to the consumer project's environment role, allowing them to access the S3 objects
  • C. DataZone automatically converts unstructured data to structured format before granting access
  • D. Unstructured data must be registered through a separate AWS service (Kendra) before DataZone can govern it
Jawaban Benar: B
DataZone bisa manage assets berbagai jenis termasuk S3-based unstructured data. Process: (1) Register S3 location (prefix atau specific objects) sebagai asset di DataZone, (2) Enrich dengan metadata — description, classification tags, owner information, (3) Publish ke catalog agar discoverable, (4) Consumers subscribe dan setelah approved, DataZone provisions S3 access melalui IAM role permissions atau bucket policy updates yang allow consumer role untuk GetObject pada S3 path yang registered. Consumer kemudian access files melalui their environment. Opsi A — DataZone mendukung baik structured maupun unstructured data assets. Opsi C — DataZone tidak mengkonversi format; ini governance layer bukan transformation tool. Opsi D — Kendra adalah search service; DataZone sendiri bisa register S3 assets.
9
A DataZone domain administrator needs to define different approval workflows for different sensitivity levels of data. Public datasets should be auto-approved (no manual review needed), internal datasets require manager approval, and confidential datasets require both the data steward AND the CISO's approval. How should they configure the approval workflows?
  • A. Create three separate DataZone domains — one for each sensitivity level — with different approval configurations
  • B. Configure metadata forms with a sensitivity classification field on assets, then set up subscription approval policies at the project or domain level that route approvals based on the asset's sensitivity metadata — auto-approve for "public", single approver for "internal", multi-level approval for "confidential"
  • C. Use a single auto-approve policy for all assets and rely on IAM policies to restrict access to confidential data
  • D. Implement approval workflows entirely outside DataZone using Step Functions and notify DataZone after external approval
Jawaban Benar: B
DataZone mendukung metadata-driven approval policies. Assets bisa di-classify menggunakan metadata forms (sensitivity level: public, internal, confidential). Subscription approval policies dikonfigurasi per project atau domain dan bisa reference asset metadata untuk menentukan approval flow: (1) Public — auto-approve policy, no manual intervention needed, (2) Internal — single approver (project owner/manager), (3) Confidential — multi-level approval chain. Ini memberikan governance proportional to data sensitivity tanpa over-burdening access to low-risk data. Opsi A — separate domains untuk sensitivity levels is over-architecture dan prevents cross-sensitivity discovery. Opsi C — auto-approve everything undermines governance untuk sensitive data. Opsi D — external workflow menambah complexity; DataZone memiliki built-in approval capabilities.
10
A company's data platform team is evaluating whether to use Amazon DataZone environments provisioned through "Blueprints" or to manage environments separately. A consumer project needs access to subscribed data through both Athena (for SQL queries) and SageMaker Studio (for ML experiments). What is the role of DataZone environment blueprints in this scenario?
  • A. Blueprints are templates that provision compute environments (like Athena workgroups, SageMaker Studio domains) pre-configured with access to subscribed data assets. The project can have multiple environments from different blueprints, giving users both SQL and ML access to the same governed data
  • B. Blueprints only support one tool per project — the consumer must choose either Athena or SageMaker
  • C. Blueprints are only for data producers to configure how data is stored, not for consumer access
  • D. Blueprints create separate copies of data optimized for each tool (columnar for Athena, tensor for SageMaker)
Jawaban Benar: A
DataZone environment blueprints adalah templates yang provision ready-to-use compute environments untuk project members. Sebuah project bisa memiliki MULTIPLE environments dari different blueprints: (1) "Data Lake" blueprint provisions Athena workgroup dengan IAM role yang sudah memiliki access ke subscribed Glue tables, (2) "ML" blueprint provisions SageMaker Studio domain dengan IAM role yang bisa access subscribed data. Kedua environments share same underlying data access (via Lake Formation grants) tapi menyediakan different tools. Users bisa SQL query di Athena DAN run ML experiments di SageMaker pada data yang sama, semua governed oleh subscription. Opsi B — multiple environments per project are supported. Opsi C — blueprints digunakan baik producer maupun consumer sides. Opsi D — blueprints tidak copy data; mereka provision compute access ke same underlying data.
