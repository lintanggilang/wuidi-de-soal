A machine learning team at a pharmaceutical company trains multiple models using datasets sourced from various S3 buckets and transformed through several preprocessing steps. A compliance audit requires them to prove which exact dataset version was used to train a specific model that is currently in production. Which AWS service provides the MOST comprehensive solution for this requirement?
  • A. AWS Glue Data Catalog version history to identify which table version was active during training
  • B. Amazon SageMaker ML Lineage Tracking to automatically capture relationships between datasets, processing steps, and model artifacts
  • C. AWS CloudTrail to track S3 API calls and correlate timestamps with model training jobs and model artifacts
  • D. Amazon S3 versioning combined with manual tagging of objects used in each training run
Correct Answer: B
Amazon SageMaker ML Lineage Tracking automatically logs hubungan between datasets, processing steps, training jobs, and model artifacts in bentuk grafik lineage. Ini menciptakan record end-to-end from data source up to model deployment.

Option A: INCORRECT. Only melacak changes schema, not hubungan data-to-model.
Option B: CORRECT.
Option C: INCORRECT. Only logs API calls without konteks ML pipeline — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Requires effort manual and not provides visualisasi lineage automatic.

A data engineering team manages an ETL pipeline where raw data flows from S3 through AWS Glue jobs, then to a curated data lake, and finally to Amazon Redshift. A business analyst reports incorrect values in a Redshift dashboard. The team needs to trace the data back to its origin to identify where corruption occurred. Which approach provides upstream lineage tracking for this scenario?
  • A. Use Amazon Redshift system tables (STL_LOAD_COMMIT) to identify the S3 source files loaded
  • B. Use Amazon DataZone lineage visualization to trace data flow from Redshift back to S3 sources
  • C. Enable AWS CloudTrail data events on all S3 buckets and correlate object access patterns
  • D. Query AWS Glue job run history and manually trace input/output datasets for each job
Correct Answer: B
Amazon DataZone provides visualisasi lineage that menunjukkan aliran data from source to destination in a end-to-end. Ini enables upstream tracing from Redshift returns to raw S3 data through each transformation Glue.

Option A: INCORRECT. Only menunjukkan file mana that in-load, not full transformation lineage.
Option B: CORRECT.
Option C: INCORRECT. Only menunjukkan who that accesses file, not how data ditransformasi.
Option D: INCORRECT. Requires effort manual that significant and not scalable.
3
A financial institution uses SageMaker to build credit scoring models. Regulators require the institution to demonstrate that no prohibited data (such as race or ethnicity) was used directly or indirectly in model training. The institution needs to show complete data lineage from raw data collection through feature engineering to model input. Which SageMaker ML Lineage Tracking entity type should they query to find all data sources that contributed to a specific model's training dataset?
  • A. Traverse the lineage graph upstream from the Model Artifact using Association entities
  • B. Query the Trial Component entities associated with the model's training job
  • C. Use the Context entity to find all artifacts within the same pipeline execution
  • D. Query the Experiment entity to list all datasets used across all trials
Correct Answer: A
SageMaker ML Lineage Tracking uses grafik lineage with entities (Artifacts, Contexts, Actions) that is connected by Associations. For menemukan all data sources that berkontribusi to model certain, Anda traverse upstream from Model Artifact through Associations, that will menunjukkan all processing steps and input datasets.

Option A: CORRECT.
Option B: INCORRECT. Menunjukkan steps in satu trial but not full upstream lineage.
Option C: INCORRECT. Mengelompokkan entitas but not provides directional lineage.
Option D: INCORRECT. Terlalu broad, mencakup all trials.

A data platform team wants to implement data lineage tracking across their organization's data lake that uses AWS Glue for ETL processing. They want to adopt an open standard for lineage metadata to avoid vendor lock-in and enable integration with third-party tools. Which approach should they use?
  • A. Implement custom lineage tracking by parsing AWS Glue job logs and storing metadata in DynamoDB
  • B. Configure AWS Glue Data Quality to track data transformations and output lineage reports
  • C. Use AWS Lake Formation tag-based access control as a proxy for lineage tracking
  • D. Use the OpenLineage standard with AWS Glue's native OpenLineage integration to emit lineage events
Correct Answer: D
OpenLineage is standar terbuka for lineage metadata that enables interoperabilitas between tools. AWS Glue supports integration OpenLineage that enables emisi lineage events in format standar, so that can dikonsumsi by tools pihak ketiga such as Marquez or DataHub.

Option A: INCORRECT. Requires custom development that expensive and not mengikuti standar.
Option B: INCORRECT. Fokus on quality rules not lineage.
Option C: INCORRECT. Adalah for access control, not lineage tracking.
Option D: CORRECT.

A healthcare analytics company needs to perform impact analysis before modifying a shared dataset. They want to understand which downstream reports, dashboards, and ML models would be affected if they change the schema of a specific table in their data lake. Which lineage capability addresses this requirement?
  • A. Cross-account lineage federation to identify consumers in other AWS accounts
  • B. Upstream lineage traversal to identify all source systems feeding into the table
  • C. Downstream lineage traversal to identify all consumers and derived datasets from the table
  • D. Point-in-time lineage snapshot to compare current and previous schema versions
Correct Answer: C
Impact analysis requires downstream lineage traversal — namely menelusuri to bawah from dataset that will is changed for identifies all konsumen (reports, dashboards, ML models) that depends padanya. Ini membantu team memahami blast radius from changes schema.

Option A: INCORRECT. Adalah feature specific that not menjawab requirements impact analysis in a umum.
Option B: INCORRECT. Menunjukkan source data, not konsumen.
Option C: CORRECT.
Option D: INCORRECT. Membandingkan schema but not menunjukkan who that terpengaruh.

An e-commerce company has a complex data pipeline where customer transaction data flows through 15 different transformations before reaching the analytics data warehouse. A data governance team needs to certify that specific GDPR-related transformations (anonymization, pseudonymization) were applied to personal data before it reaches any analytics system. Which lineage approach BEST supports this compliance verification?
  • A. Use AWS Config rules to verify that all Glue jobs have the anonymization code in their scripts, validating and cleansing each record before delivery
  • B. Run data quality checks on the final output to verify that PII patterns are not present with transformation metadata and analytics outputs
  • C. Use data lineage with transformation metadata to verify that required processing steps exist in the lineage path between raw PII data and analytics outputs
  • D. Implement row-level logging in each transformation job and audit the logs periodically, applying schema conversion and enrichment inline and transforming records into the required target format
Correct Answer: C
Data lineage with transformation metadata enables verifikasi that step-step processing that is required (anonymization, pseudonymization) ada in path lineage between data PII mentah and output analytics. Ini provides bukti process that can diaudit.

Option A: INCORRECT. Memeriksa configuration job but not membuktikan that job the said correct-correct dieksekusi on data certain.
Option B: INCORRECT. Adalah reactive, not preventive, and not membuktikan process that correct is run — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option C: CORRECT.
Option D: INCORRECT. Very expensive and not scalable for 15 transformation.

A data science team uses Amazon SageMaker Pipelines to automate their ML workflow. They notice that a model's prediction accuracy dropped after a recent pipeline execution. They need to compare the lineage of the current underperforming model with the previous well-performing model to identify what changed. Which SageMaker ML Lineage Tracking approach helps them identify the root cause?
  • A. Query and compare the lineage graphs of both model artifacts to identify differences in input data, processing steps, or hyperparameters
  • B. Review CloudWatch metrics for both training jobs to compare resource utilization, integrating natively with the rest of the pipeline
  • C. Compare the Model Package versions in the SageMaker Model Registry configured for optimal performance and minimal operational overhead
  • D. Use SageMaker Debugger to compare tensor outputs between the two training runs, integrating natively with the rest of the pipeline
Correct Answer: A
By membandingkan lineage graphs from kedua model artifacts, team can identifies perbedaan specific — whether input dataset changes, whether ada processing step new, or whether hyperparameters different. Ini provides root cause analysis that komprehensif.

Option A: CORRECT.
Option B: INCORRECT. Menunjukkan resource usage not data/pipeline changes.
Option C: INCORRECT. Menunjukkan versi model but not detail about what that changes in pipeline — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Membantu debug training issues but not menunjukkan changes in input data or preprocessing.

A retail company wants to implement data lineage for their AWS Glue-based ETL pipelines that process data across multiple AWS accounts (raw data account, processing account, and analytics account). They need centralized lineage visibility across all accounts. Which architecture provides the MOST effective cross-account lineage solution?
  • A. Enable AWS Glue Data Catalog replication across accounts and track lineage in each account's catalog independently
  • B. Use Amazon DataZone with cross-account enrollment to provide unified lineage visualization across all participating accounts
  • C. Use AWS RAM (Resource Access Manager) to share Glue Data Catalog resources and enable cross-account lineage queries
  • D. Consolidate all AWS Glue jobs into a single account to simplify lineage tracking with cross-account enrollment
Correct Answer: B
Amazon DataZone supports cross-account enrollment that enables visualisasi lineage terpusat across multiple AWS accounts. Ini provides single-pane-of-glass view for memahami how data mengalir lintas account boundaries.

Option A: INCORRECT. Not provides unified view.
Option B: CORRECT.
Option C: INCORRECT. Enables sharing catalog resources but not provides unified lineage visualization.
Option D: INCORRECT. Not praktis and melanggar best practices multi-account — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

They need to track lineage for each feature, including which raw data sources contribute to each feature, what transformations are applied, and which models consume each feature. They want this lineage to be automatically captured without requiring developers to manually instrument their code. Which combination of AWS services provides automatic lineage capture for this use case?
  • A. SageMaker Feature Store with SageMaker ML Lineage Tracking, using SageMaker Pipelines for feature computation
  • B. AWS Glue Data Catalog with manual lineage annotations added via custom classifiers for feature computation
  • C. Amazon Neptune to build a custom lineage graph with Lambda functions triggered by CloudTrail events
  • D. DynamoDB to store lineage metadata with streams triggering Lambda for graph construction
Correct Answer: A
SageMaker Feature Store terintegrasi with SageMaker ML Lineage Tracking, and when feature computation is run through SageMaker Pipelines, lineage automatically in-capture including input data, transformation, and output features. Not is required instrumentasi manual.

Option A: CORRECT.
Option B: INCORRECT. Requires manual annotations — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option C: INCORRECT. Dan D requires custom development that significant and not automatic — keduanya requires effort engineering for membangun and memaintain.
Option D: INCORRECT.

A media streaming company operates a data mesh architecture where different domain teams own their data products. The central data governance team needs to establish organization-wide data lineage that spans across all domain teams' pipelines. Each domain team uses different AWS services (some use Glue, others use EMR, some use Redshift). Which strategy provides the MOST scalable approach to organization-wide lineage in this architecture?
  • A. Build a custom lineage aggregation service using AWS Lambda that reads CloudTrail logs from all accounts with lineage metadata attached
  • B. Use AWS Lake Formation cross-account permissions to create a unified view of all data assets, satisfying all of the stated requirements with minimal effort
  • C. Require all domain teams to use AWS Glue exclusively so that lineage is tracked in a single Glue Data Catalog
  • D. Use Amazon SageMaker Catalog (formerly Amazon DataZone) as a centralized business catalog where each domain publishes data products with lineage metadata attached
Correct Answer: D
Amazon SageMaker Catalog (sebelumnya Amazon DataZone) designed for data mesh architecture, enables domain teams mempublikasikan data products to katalog bisnis terpusat with lineage metadata. Ini supports berbagai compute engines and provides organization-wide lineage visibility without memaksa standarisasi tools.

Option A: INCORRECT. Requires custom development and CloudTrail not provides transformation-level lineage — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Fokus on access control, not lineage tracking lintas heterogeneous tools.
Option C: INCORRECT. Not praktis because memaksa all team uses satu service.
Option D: CORRECT.
