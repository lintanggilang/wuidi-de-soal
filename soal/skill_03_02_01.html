Skill 3.2.1: Visualize Data by Using AWS Services and Tools

AWS Glue DataBrew, Amazon QuickSight for data visualization and exploratory analysis

1
A retail analytics team needs to create interactive dashboards that combine data from Amazon Redshift and Amazon S3. The dashboards must load within 3 seconds even when querying billions of rows. Users should be able to interact with filters without waiting for queries to re-execute against the source. Which Amazon QuickSight feature should the data engineer enable to meet this requirement?
  • A. Enable direct query mode to push all computations to the source databases
  • B. Import data into SPICE (Super-fast, Parallel, In-memory Calculation Engine)
  • C. Create a QuickSight dataset with custom SQL that includes pre-aggregated results
  • D. Use QuickSight Q to auto-generate optimized queries against the sources
Jawaban Benar: B
SPICE adalah in-memory calculation engine milik QuickSight yang menyimpan data secara lokal sehingga interaksi dashboard sangat cepat tanpa perlu query ulang ke sumber data. SPICE mendukung miliaran baris dan menyediakan sub-second response time untuk filter dan drill-down. Opsi A (direct query) justru akan lambat karena setiap interaksi memicu query ke source. Opsi C (custom SQL pre-aggregated) mengurangi fleksibilitas dan tidak menjamin kecepatan interaksi. Opsi D (QuickSight Q) adalah fitur NLP untuk bertanya dalam bahasa alami, bukan untuk optimasi performa.
2
A data engineer needs to share an Amazon QuickSight dashboard with 500 external business partners who do not have AWS accounts. The partners should only be able to view the dashboard without any ability to modify the analysis. The solution must minimize cost and administrative overhead. Which approach should the engineer use?
  • A. Create 500 QuickSight Reader accounts and share the dashboard with each user
  • B. Use QuickSight embedded analytics with anonymous access enabled
  • C. Export the dashboard to PDF and distribute via email on a scheduled basis
  • D. Create a QuickSight Enterprise account and federate with an external identity provider
Jawaban Benar: B
QuickSight embedded analytics memungkinkan penyematan dashboard ke aplikasi atau portal web eksternal. Dengan anonymous embedding, pengguna tidak perlu akun AWS atau QuickSight, cukup mengakses via URL yang di-embed. Ini paling cost-effective untuk ratusan pengguna eksternal karena dikenakan biaya per session, bukan per user. Opsi A memerlukan manajemen 500 akun. Opsi C kehilangan interaktivitas. Opsi D memerlukan setup IdP dan tetap membutuhkan lisensi per-user.
3
A financial services company uses AWS Glue DataBrew for data profiling. A data analyst has uploaded a dataset with 50 columns and needs to quickly identify columns with high null rates, unusual distributions, and potential data quality issues before building a transformation recipe. Which DataBrew feature provides this capability with the LEAST effort?
  • A. Create a DataBrew project and run a profile job on the dataset
  • B. Create a DataBrew recipe with validation steps for each column
  • C. Export data to Amazon QuickSight and use the auto-narrative feature
  • D. Write a custom AWS Glue ETL script to compute column-level statistics
Jawaban Benar: A
DataBrew profile jobs secara otomatis menganalisis semua kolom dan menghasilkan statistik komprehensif termasuk null rate, distribusi nilai, korelasi antar kolom, duplikat, dan outlier tanpa perlu menulis kode. Ini adalah cara tercepat untuk mendapatkan overview kualitas data. Opsi B (recipe) memerlukan definisi manual per kolom. Opsi C (QuickSight) tidak dirancang untuk profiling data mentah. Opsi D (custom script) memerlukan coding dan maintenance.
4
A healthcare organization has built an Amazon QuickSight dashboard showing patient visit metrics. Different hospital departments must only see data for their own department. The data is stored in a single Amazon Redshift table with a department_id column. How should the data engineer implement this access control in QuickSight?
  • A. Create separate QuickSight datasets with SQL filters for each department
  • B. Implement row-level security (RLS) rules in QuickSight using a permissions dataset
  • C. Create separate Redshift views for each department and map each to a different dashboard
  • D. Use QuickSight column-level security to hide department_id from unauthorized users
Jawaban Benar: B
Row-Level Security (RLS) di QuickSight memungkinkan pembuatan satu dataset dan satu dashboard yang secara otomatis memfilter data berdasarkan user/group. Permissions dataset berisi mapping antara username/group dan nilai department_id yang boleh dilihat. Ini adalah solusi paling scalable dan maintainable. Opsi A memerlukan banyak dataset duplikat. Opsi C memerlukan banyak dashboard yang sulit di-maintain. Opsi D (CLS) menyembunyikan kolom, bukan memfilter baris.
5
A marketing team wants their Amazon QuickSight dashboard to automatically detect unusual spikes in website traffic and highlight them without manual threshold configuration. The dashboard should also predict future traffic trends for the next 2 weeks. Which QuickSight capabilities should the data engineer configure?
  • A. Use QuickSight calculated fields with IF/THEN logic to flag values above historical averages
  • B. Enable ML-powered anomaly detection and forecasting insights on the relevant visuals
  • C. Connect QuickSight to Amazon SageMaker for real-time anomaly detection inference
  • D. Create a Lambda function to compute anomalies and store results in a separate table
Jawaban Benar: B
Amazon QuickSight memiliki fitur ML Insights bawaan yang mencakup anomaly detection (mendeteksi outlier tanpa threshold manual menggunakan Random Cut Forest) dan forecasting (prediksi tren menggunakan built-in ML models). Keduanya bisa diaktifkan langsung pada visual tanpa perlu ML expertise. Opsi A memerlukan threshold manual dan tidak adaptif. Opsi C terlalu kompleks untuk kebutuhan ini. Opsi D memerlukan pengembangan dan maintenance custom solution.
6
A data engineer is creating an Amazon QuickSight dataset that combines data from an Amazon RDS PostgreSQL database and a CSV file stored in Amazon S3. The combined dataset will be used for monthly sales analysis. The data in RDS changes daily while the CSV is updated monthly. What is the MOST efficient approach to configure the dataset refresh?
  • A. Use direct query mode for both sources to always get the latest data
  • B. Import both sources into SPICE with a daily full refresh schedule
  • C. Import into SPICE with incremental refresh on the RDS source and full refresh monthly for the S3 source
  • D. Import into SPICE with a weekly full refresh schedule for cost optimization
Jawaban Benar: C
QuickSight SPICE mendukung incremental refresh yang hanya mengambil data baru/berubah berdasarkan kolom date/timestamp. Untuk RDS yang berubah harian, incremental refresh menghemat waktu dan SPICE capacity. Untuk S3 CSV yang hanya update bulanan, full refresh bulanan sudah cukup. Opsi A kehilangan keuntungan performa SPICE. Opsi B membuang resource dengan full refresh setiap hari. Opsi D bisa menyebabkan data stale hingga seminggu untuk sumber RDS yang berubah harian.
7
A data team wants to embed an Amazon QuickSight dashboard into their internal React web application. The application uses SAML-based SSO with Okta for authentication. Users should see their QuickSight dashboards seamlessly without a separate login prompt. Which implementation approach is correct?
  • A. Use the QuickSight GetDashboardEmbedUrl API with the QUICKSIGHT identity type after registering users via SAML federation
  • B. Use the GenerateEmbedUrlForAnonymousUser API to avoid authentication complexity
  • C. Embed QuickSight using an iframe with the dashboard URL directly from the QuickSight console
  • D. Use QuickSight public sharing link and embed it in the React application
Jawaban Benar: A
Untuk authenticated embedding dengan SSO, QuickSight mendukung SAML federation. Setelah user terdaftar via SAML (Okta sebagai IdP), aplikasi backend memanggil GetDashboardEmbedUrl API dengan identity type QUICKSIGHT untuk mendapatkan signed URL yang di-embed. Ini memberikan SSO seamless. Opsi B (anonymous) tidak memanfaatkan SSO dan tidak mendukung RLS per-user. Opsi C (direct iframe) diblokir oleh QuickSight karena alasan keamanan. Opsi D (public link) tidak aman untuk data internal.
8
A data engineer is using AWS Glue DataBrew to profile a large dataset stored in Amazon S3. The profile job needs to analyze 500 million rows but must complete within 30 minutes to meet SLA requirements. The default profile job configuration is timing out. What should the engineer do to optimize the profile job performance?
  • A. Increase the maximum number of DataBrew nodes allocated to the profile job
  • B. Configure the profile job to use a sample of the data instead of profiling the entire dataset
  • C. Convert the data from CSV to Parquet format before profiling
  • D. Split the dataset into multiple smaller files and run parallel profile jobs
Jawaban Benar: A
DataBrew profile jobs dapat dikonfigurasi dengan jumlah node (max workers) yang lebih besar untuk meningkatkan paralelisme dan mengurangi waktu eksekusi. Meningkatkan node allocation adalah cara langsung untuk mempercepat profile job pada dataset besar. Opsi B (sampling) mengurangi akurasi profiling karena tidak memeriksa semua data. Opsi C (konversi format) membantu tapi memerlukan langkah tambahan dan tidak menjamin selesai dalam SLA. Opsi D (split + parallel) menambah kompleksitas operasional dan hasil profiling terpisah sulit digabung.
9
A company's data lake contains tables in the AWS Glue Data Catalog. A business analyst wants to use Amazon QuickSight to visualize this data without setting up any additional infrastructure. The data is stored in Parquet format in Amazon S3. Which method should the data engineer use to create a QuickSight dataset from this data?
  • A. Create a QuickSight dataset using Amazon Athena as the data source, which references the Glue Data Catalog tables
  • B. Create a QuickSight dataset using a direct S3 data source with manifest file pointing to the Parquet files
  • C. Load the data into Amazon Redshift first, then connect QuickSight to Redshift
  • D. Use AWS Glue ETL to export the data to CSV, then upload directly to QuickSight
Jawaban Benar: A
Amazon Athena secara native terintegrasi dengan AWS Glue Data Catalog dan bisa langsung query data Parquet di S3 tanpa infrastruktur tambahan (serverless). QuickSight memiliki native connector ke Athena, sehingga bisa langsung memvisualisasikan data dari data lake. Opsi B (S3 manifest) mendukung format terbatas dan lebih kompleks konfigurasinya. Opsi C (Redshift) memerlukan provisioning cluster yang tidak perlu. Opsi D (export CSV) kehilangan efisiensi Parquet dan memerlukan ETL tambahan.
10
A data engineering team has scheduled an Amazon QuickSight SPICE dataset to refresh every 6 hours. Occasionally the refresh fails because the source Amazon Redshift cluster is undergoing maintenance. The team wants to be notified immediately when a refresh failure occurs so they can take corrective action. What is the MOST operationally efficient way to implement this notification?
  • A. Create a CloudWatch alarm that monitors QuickSight SPICE refresh metrics and triggers an SNS notification
  • B. Use Amazon EventBridge to capture QuickSight dataset refresh failure events and route to an SNS topic
  • C. Write a Lambda function that polls QuickSight API every 15 minutes to check dataset refresh status
  • D. Configure QuickSight email reports to include refresh status in the report header
Jawaban Benar: B
Amazon EventBridge menangkap event dari QuickSight termasuk dataset refresh success/failure secara real-time. Event rule dapat dikonfigurasi untuk memfilter hanya failure events dan mengirimkannya ke SNS topic untuk notifikasi email/SMS. Ini adalah pendekatan event-driven yang paling operasionally efisien. Opsi A (CloudWatch alarm) tidak tersedia untuk QuickSight refresh metrics secara native. Opsi C (Lambda polling) menambah overhead dan latensi deteksi. Opsi D (email reports) tidak real-time dan tidak spesifik untuk failure.
