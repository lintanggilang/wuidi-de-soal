Skill 2.3.5: Delete Data to Meet Business and Legal Requirements

Implementing data deletion policies for compliance with GDPR, CCPA, and data retention regulations

1
A European e-commerce company stores customer data in an S3-based data lake using Apache Parquet format. A customer exercises their GDPR "right to erasure" and requests deletion of all their personal data. The data lake contains petabytes of Parquet files organized by date partitions. Which approach provides the MOST efficient way to delete specific customer records from the data lake?
  • A. Rewrite all Parquet files that contain the customer's data, excluding their records, and replace the original files
  • B. Use Apache Iceberg table format with position DELETE operations to remove specific records without rewriting entire files
  • C. Add a "deleted" flag column to the Parquet files and filter out flagged records in downstream queries
  • D. Delete the entire date partitions that contain the customer's data and rebuild them without the customer's records
Jawaban Benar: B
Apache Iceberg mendukung row-level DELETE operations yang memungkinkan penghapusan record spesifik tanpa menulis ulang seluruh file Parquet. Iceberg menggunakan delete files (position deletes atau equality deletes) untuk menandai record yang dihapus, kemudian compaction dilakukan secara async. Ini jauh lebih efisien untuk data lake skala petabyte.

Opsi A: SALAH. Memerlukan rewrite seluruh file yang sangat mahal untuk skala petabyte.
Opsi B: BENAR.
Opsi C: SALAH. Tidak memenuhi GDPR karena data masih tersimpan secara fisik — GDPR mengharuskan penghapusan aktual.
Opsi D: SALAH. Menghapus data lain yang tidak perlu dihapus.
2
A company stores critical legal documents in an S3 bucket with S3 Object Lock enabled in Compliance mode with a 7-year retention period. A court order now requires the immediate deletion of a specific document due to a legal settlement. What can the data engineer do?
  • A. Switch the Object Lock mode from Compliance to Governance, then delete with the s3:BypassGovernanceRetention permission
  • B. Use the root account to delete the object since root bypasses Object Lock
  • C. Contact AWS Support to remove the Object Lock for this specific object configured for optimal performance and minimal operational overhead
  • D. The object CANNOT be deleted until the retention period expires — no user, role, or even the root account can override Compliance mode
Jawaban Benar: D
S3 Object Lock dalam Compliance mode tidak bisa di-override oleh siapapun, termasuk root account dan AWS Support. Objek dilindungi hingga retention period berakhir. Ini dirancang untuk memenuhi regulasi seperti SEC 17a-4(f).

Opsi A: SALAH. Salah — tidak bisa mengubah dari Compliance ke Governance mode setelah ditetapkan.
Opsi B: SALAH. Salah — root account tidak bisa bypass Compliance mode.
Opsi C: SALAH. Salah — AWS Support juga tidak bisa menghapus Object Lock Compliance — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini. Perusahaan harus mempertimbangkan hal ini sebelum menggunakan Compliance mode.
Opsi D: BENAR.
3
A data engineer manages an Amazon Redshift data warehouse that contains customer purchase history. The company's data retention policy requires purging records older than 5 years. After deleting millions of rows using DELETE statements, query performance has degraded significantly. What should the data engineer do to restore performance?
  • A. Run VACUUM DELETE to reclaim disk space and re-sort the remaining rows
  • B. Run ANALYZE on the affected tables to update statistics and re-sort the remaining rows
  • C. Resize the Redshift cluster to add more nodes
  • D. Create a new table, COPY the remaining data, then swap the table names
Jawaban Benar: A
Di Redshift, DELETE hanya menandai rows sebagai deleted (soft delete) — disk space tidak langsung di-reclaim. VACUUM DELETE membersihkan rows yang di-delete dan mengembalikan space, serta memperbaiki sort order. Ini mengembalikan performa query.

Opsi A: BENAR.
Opsi B: SALAH. Hanya memperbarui statistics tapi tidak mengembalikan disk space — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Menambah biaya tanpa menyelesaikan masalah fragmentasi.
Opsi D: SALAH. Bisa bekerja tapi lebih kompleks dan memerlukan downtime — VACUUM adalah solusi standar untuk masalah ini.
4
A multinational company needs to implement a cross-service data deletion workflow that removes a customer's data from DynamoDB, S3 data lake, Amazon Redshift, and Amazon OpenSearch Service when a GDPR deletion request is received. The deletion must be atomic — either all services are cleaned or none. Which orchestration approach is MOST appropriate?
  • A. Use a single Lambda function with try-catch blocks to delete from all services sequentially
  • B. Use Amazon EventBridge to fan-out deletion events to separate Lambda functions for each service simultaneously
  • C. Use AWS Step Functions with compensating transactions pattern — execute deletion in each service and implement rollback logic for failures
  • D. Use AWS DMS to synchronize deletions across all data stores in real-time with compensating transactions pattern — execute deletion in each service
Jawaban Benar: C
AWS Step Functions dengan saga pattern (compensating transactions) adalah pendekatan terbaik untuk orchestrasi cross-service yang memerlukan consistency. Jika satu service gagal, compensating actions bisa rollback perubahan di service yang sudah berhasil. Step Functions menyediakan error handling, retry logic, dan state tracking.

Opsi A: SALAH. Berisiko timeout 15 menit dan tidak memiliki built-in state management atau retry.
Opsi B: SALAH. Tidak menyediakan mekanisme atomicity atau rollback.
Opsi C: BENAR.
Opsi D: SALAH. Tidak mendukung semua service ini dan bukan untuk deletion orchestration — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
5
A company has an S3 bucket with Object Lock in Governance mode. A legal investigation requires placing a "legal hold" on specific objects to prevent their deletion regardless of the retention period. What happens when a legal hold is placed on an object that already has a Governance mode retention period set?
  • A. The object is protected by BOTH the legal hold and the retention period independently — the object cannot be deleted until both are removed/expired
  • B. The legal hold overrides Governance mode and converts it to Compliance mode
  • C. The legal hold replaces the Governance retention period configured for optimal performance and minimal operational overhead
  • D. The legal hold only takes effect after the retention period expires
Jawaban Benar: A
Legal hold dan retention period adalah mekanisme proteksi independen. Keduanya berlaku secara bersamaan. Objek tidak bisa dihapus sampai: (1) retention period berakhir ATAU di-bypass dengan Governance permission, DAN (2) legal hold dilepas. Keduanya harus clear sebelum objek bisa dihapus.

Opsi A: BENAR.
Opsi B: SALAH. Salah — legal hold tidak mengubah retention mode.
Opsi C: SALAH. Salah — legal hold tidak menggantikan retention — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Salah — legal hold berlaku langsung saat ditetapkan.
6
A data engineer needs to delete specific items from a large DynamoDB table containing 500 million items. The deletion must remove approximately 10 million items matching a specific customer ID across various partition keys. Which approach minimizes consumed write capacity and operational impact?
  • A. Use PartiQL DELETE statement to delete all items matching the customer ID in a single operation
  • B. Drop the table and recreate it without the items to be deleted configured for optimal performance
  • C. Enable DynamoDB TTL and update the TTL attribute on target items to a time in the past
  • D. Use BatchWriteItem with DeleteRequest for batches of 25 items with exponential backoff
Jawaban Benar: C
Menggunakan TTL dengan timestamp di masa lalu adalah pendekatan paling cost-effective karena TTL deletions tidak mengonsumsi WCU. Update TTL attribute mengonsumsi WCU untuk write, tapi penghapusan aktual oleh TTL gratis. Untuk 10 juta items, ini menghemat biaya signifikan dibanding DeleteItem langsung.

Opsi A: SALAH. Tetap mengonsumsi WCU per item dan tidak bisa delete jutaan item dalam satu statement.
Opsi B: SALAH. Menghapus semua 500 juta items termasuk yang valid — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Mengonsumsi WCU penuh untuk setiap delete operation — 10 juta deletes sangat mahal.
7
A company subject to CCPA (California Consumer Privacy Act) regulations receives a "right to delete" request. Their data architecture includes customer data replicated across three AWS Regions for disaster recovery. The data engineer must ensure complete deletion across all regions. Which consideration is MOST critical?
  • A. S3 CRR does NOT replicate delete operations by default — delete markers must be explicitly configured for replication, and permanent version deletions are never replicated
  • B. Deleting data in the primary region will automatically propagate deletions to all replica regions via S3 Cross-Region Replication
  • C. Using S3 Batch Operations in one region automatically executes across all regions
  • D. AWS Organizations SCPs can enforce automatic cross-region deletion compliance and permanent version deletions are never replicated for replication
Jawaban Benar: A
Secara default, S3 Cross-Region Replication TIDAK mereplikasi delete markers. Bahkan jika delete marker replication diaktifkan, penghapusan permanen (dengan version ID) tidak pernah direplikasi. Ini berarti data engineer harus menjalankan deletion operation secara eksplisit di setiap region. Ini adalah pertimbangan kritis untuk CCPA compliance.

Opsi A: BENAR.
Opsi B: SALAH. Salah karena delete operations tidak otomatis direplikasi.
Opsi C: SALAH. Salah — Batch Operations bersifat per-region.
Opsi D: SALAH. Salah — SCPs mengontrol permission tapi tidak mengotomatiskan deletion — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
8
A data engineer needs to maintain an audit trail proving that customer data was properly deleted in compliance with GDPR Article 17. Which AWS service combination provides the MOST comprehensive audit trail for data deletion operations?
  • A. Use AWS Config rules to detect when objects are deleted and generate compliance reports
  • B. Enable Amazon CloudWatch Events to capture deletion notifications and store in CloudWatch Logs
  • C. Enable S3 Server Access Logging and DynamoDB Streams to capture all deletion events with Object Lock
  • D. Use AWS CloudTrail to log all API calls (DeleteObject, DeleteItem) and store trail logs in a separate compliance S3 bucket with Object Lock
Jawaban Benar: D
AWS CloudTrail mencatat semua API calls termasuk DeleteObject (S3) dan DeleteItem (DynamoDB) dengan detail siapa, kapan, dan apa yang dihapus. Menyimpan trail logs di bucket terpisah dengan Object Lock memastikan audit trail tidak bisa dimodifikasi atau dihapus, memberikan bukti tamper-proof untuk compliance.

Opsi A: SALAH. Mendeteksi configuration changes tapi tidak cocok untuk tracking individual data deletions.
Opsi B: SALAH. Tidak menangkap semua API calls secara detail.
Opsi C: SALAH. Kurang komprehensif dan DynamoDB Streams memiliki retention 24 jam saja — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
9
A company wants to implement S3 Object Lock in Governance mode on their data lake bucket. A junior data engineer accidentally tries to delete a protected object. What permission must a user have to override Governance mode retention and delete the object?
  • A. AdministratorAccess managed policy is sufficient with native S3 integration and optimized data transfer
  • B. s3:BypassGovernanceRetention permission and must include x-amz-bypass-governance-retention:true header in the request
  • C. s3:ObjectLockGovernanceBypass permission with root account credentials
  • D. s3:DeleteObject and s3:PutObjectRetention permissions
Jawaban Benar: B
Untuk bypass Governance mode, user memerlukan permission s3:BypassGovernanceRetention DAN harus menyertakan header x-amz-bypass-governance-retention:true dalam request. Kedua syarat harus dipenuhi.

Opsi A: SALAH. Tidak otomatis menyertakan header yang diperlukan — permission saja tidak cukup — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Salah — permission yang benar adalah s3:BypassGovernanceRetention, bukan s3:ObjectLockGovernanceBypass, dan root account bukan persyaratan.
Opsi D: SALAH. Bisa mengubah retention tapi bukan bypass.
10
A streaming analytics company stores raw event data in S3 and processed results in Amazon Redshift. Their data retention policy requires: raw data deleted after 1 year, processed data retained for 3 years, and compliance reports retained for 7 years. Which implementation strategy ensures all retention requirements are met automatically?
  • A. Use AWS Backup with different retention policies for S3 and Redshift
  • B. Use S3 lifecycle rules with different prefix-based configurations for each data type: raw/ (expire after 365 days), and use a scheduled Redshift stored procedure to DELETE and VACUUM processed data older than 3 years
  • C. Implement a single Lambda function on a daily CloudWatch Events schedule that checks timestamps and deletes data across all stores
  • D. Create one S3 lifecycle rule that deletes all objects after 7 years with different prefix-based configurations for each data type: raw/ (expire after 365 days)
Jawaban Benar: B
Strategi yang tepat menggunakan fitur native masing-masing service: S3 lifecycle rules untuk raw data (prefix-based filtering, expire after 365 days) dan scheduled procedure di Redshift untuk DELETE + VACUUM data older than 3 years. Compliance reports bisa di S3 dengan lifecycle rule 7 tahun.

Opsi A: SALAH. Mengelola backups, bukan deletion dari data asli.
Opsi B: BENAR.
Opsi C: SALAH. Menambah single point of failure dan complexity yang tidak perlu ketika native features tersedia.
Opsi D: SALAH. Menggunakan satu rule yang sama untuk semua — tidak memenuhi retention berbeda — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
