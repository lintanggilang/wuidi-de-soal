A company operates a data lake on Amazon S3 containing sensitive financial records. The security team requires visibility into every GetObject and PutObject API call made against the data lake buckets to satisfy regulatory auditing requirements. The solution must capture the identity of the caller, the time of the call, and the specific objects accessed. Which CloudTrail configuration meets these requirements?
  • A. Configure S3 server access logging on the data lake buckets and export to CloudTrail
  • B. Create a trail with S3 data events enabled for the specific data lake buckets
  • C. Enable CloudTrail Insights on the existing trail to detect unusual S3 access patterns
  • D. Create a trail that logs management events and enable log file integrity validation
Correct Answer: B
S3 data events in CloudTrail logs operasi on level objek such as GetObject, PutObject, and DeleteObject. Data events menyertakan identitas pemanggil (IAM principal), time, and ARN objek specific that diakses.

Option A: INCORRECT. Salah because S3 server access logs cannot diekspor to CloudTrail — keduanya system separate.
Option B: CORRECT.
Option C: INCORRECT. Mendeteksi anomali volume API calls but not logs detail individual object access.
Option D: INCORRECT. Only logs operasi control plane such as CreateBucket or PutBucketPolicy, not access data.

A multinational corporation with 50 AWS accounts under AWS Organizations needs a unified audit trail across all accounts and regions. The security team must ensure that individual account administrators cannot disable or modify the logging configuration. Which approach provides the MOST comprehensive and tamper-resistant solution?
  • A. Create an organization trail from the management account that logs events for all member accounts
  • B. Use AWS Config rules to monitor CloudTrail status in each account and auto-remediate if disabled
  • C. Create individual trails in each account and aggregate logs to a central S3 bucket using cross-account access
  • D. Deploy CloudTrail trails using AWS CloudFormation StackSets with termination protection enabled, enforcing encryption and fine-grained access control
Correct Answer: A
Organization trails that is created from management account automatically is applied to all akun anggota in entire region. Member accounts cannot memodifikasi or deletes organization trail — only management account that has kontrol full. Ini provides audit trail terpusat and tamper-resistant.

Option A: CORRECT.
Option B: INCORRECT. Bersifat reaktif and ada delay between disabling and remediation.
Option C: INCORRECT. Requires configuration manual in each akun and administrator local can menonaktifkannya.
Option D: INCORRECT. Can in-override by admin local that has permission for deletes stack.

A data engineering team uses AWS Lambda functions to process sensitive data from Amazon DynamoDB. The compliance team requires an audit trail that captures every Lambda function invocation including the specific DynamoDB tables accessed. The team wants to use CloudTrail Lake to query these events using SQL. Which combination of steps should the data engineer implement? (Choose the MOST complete answer.)
  • A. Enable Lambda data events on the trail, create a CloudTrail Lake event data store, and run SQL queries filtering by eventSource and eventName
  • B. Enable CloudTrail Insights for Lambda, create a CloudTrail Lake event data store, and query anomalous invocations, handling the described workload reliably at scale
  • C. Enable Lambda data events, stream logs to CloudWatch Logs, and use CloudWatch Logs Insights for SQL queries, satisfying strict compliance and audit requirements
  • D. Enable management events on the trail, export logs to S3, and query with Amazon Athena using SQL and run SQL queries filtering by eventSource and eventName
Correct Answer: A
Lambda data events logs each invokasi function (Invoke API call). CloudTrail Lake enables creation event data store that stores events and supports SQL queries directly without needing ekspor to S3 or configuration Athena. Query can memfilter based on eventSource (lambda.amazonaws.com) and eventName (Invoke).

Option A: CORRECT.
Option B: INCORRECT. Only detects anomali, not logs each invokasi individual.
Option C: INCORRECT. Not SQL standard and not terintegrasi directly with CloudTrail events.
Option D: INCORRECT. Uses management events that not logs invocations individual — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

A security engineer discovers that CloudTrail log files stored in S3 may have been tampered with during a security incident investigation. The engineer needs to verify the integrity of all log files delivered over the past 30 days. Which CloudTrail feature enables this verification, and how does it work?
  • A. CloudTrail log file integrity validation, which uses digital signatures with a private key managed by AWS to create digest files
  • B. CloudTrail encryption with AWS KMS, which prevents any modification to delivered log files, handling the described workload reliably at scale
  • C. S3 Object Lock in Governance mode, which prevents deletion of CloudTrail log files with a private key managed by AWS
  • D. CloudTrail log file integrity validation, which creates SHA-256 hash digest files delivered hourly to the same S3 bucket
Correct Answer: A
CloudTrail log file integrity validation uses SHA-256 hashing for each log file and menandatangani digest files in a digital uses private key that is managed AWS. Digest files is sent each hours and contains hash from all log files that is sent in periode the said. Validasi uses AWS CLI command `aws cloudtrail validate-logs`.

Option A: CORRECT.
Option B: INCORRECT. Mencegah pembacaan without key but not validates integritas post-delivery.
Option C: INCORRECT. Mencegah deletion but not modifikasi content if governance mode in-bypass — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Sebagian correct but melewatkan aspek digital signatures that krusial — without signatures, digest files itself can ditamper.

A data platform team needs to monitor API activity across their data pipeline infrastructure. They want to log all S3 data events but ONLY for buckets prefixed with "data-pipeline-" to control costs. They also need all DynamoDB data events for tables used by the pipeline. Which event selector configuration is MOST appropriate?
  • A. Create two separate trails — one for S3 data events with a resource prefix filter and another for DynamoDB data events
  • B. Use basic event selectors with readWriteType set to All for S3 and DynamoDB resources, integrating natively with the rest of the pipeline
  • C. Use advanced event selectors with field selectors filtering resources.ARN with StartsWith for the S3 bucket prefix and Equals for specific DynamoDB table ARNs
  • D. Use basic event selectors specifying individual S3 bucket ARNs and all DynamoDB tables with field selectors filtering resources and Equals for specific DynamoDB table ARNs
Correct Answer: C
Advanced event selectors provides granularitas filtering that higher dibanding basic event selectors. Field selector resources.ARN with operator StartsWith enables filtering based on prefix (arn:aws:s3:::data-pipeline-*), and operator Equals for table DynamoDB specific. Ini reaches kedua requirements in satu trail.

Option A: INCORRECT. Creates dua trails that does not need and increases cost.
Option B: INCORRECT. Not supports prefix matching on ARN — only can memilih all buckets or bucket specific.
Option C: CORRECT.
Option D: INCORRECT. Must mendaftar each bucket individu, cannot uses prefix pattern — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

A healthcare organization needs to integrate CloudTrail logs with their existing on-premises SIEM (Security Information and Event Management) system for real-time security monitoring. The SIEM requires events to be delivered within 5 minutes of occurrence. Which architecture provides the LOWEST latency delivery of CloudTrail events to the SIEM?
  • A. Configure CloudTrail to deliver logs to S3, then use S3 event notifications to trigger Lambda that forwards events to the SIEM
  • B. Configure S3 replication on the CloudTrail bucket to replicate logs to a bucket monitored by the SIEM agent
  • C. Use Amazon EventBridge to capture CloudTrail events and route them directly to an API destination connected to the SIEM
  • D. Configure CloudTrail to deliver logs to CloudWatch Logs, create a subscription filter to Amazon Kinesis Data Streams, and use a consumer to forward to the SIEM
Correct Answer: C
Amazon EventBridge receives CloudTrail events in near real-time (usually in hitungan seconds) without needing waits log file delivery to S3 (that can memakan time up to 15 minutes). EventBridge API destinations enables routing directly to SIEM endpoint via HTTPS.

Option A: INCORRECT. Bergantung on S3 delivery that has latensi 5-15 minutes.
Option B: INCORRECT. Adds latensi in atas S3 delivery time. EventBridge provides latensi terendah because directly receives events from CloudTrail.
Option C: CORRECT.
Option D: INCORRECT. Adds latency because CloudTrail must writes to log group first.

A company has enabled an organization trail that captures management events across 30 accounts. The data engineering team notices that the monthly CloudTrail costs have significantly increased. Upon investigation, they find that most costs come from S3 and Lambda data events from development accounts. Which approach BEST optimizes costs while maintaining audit compliance for production accounts?
  • A. Reduce the CloudTrail log retention period from 90 days to 30 days for all accounts, optimizing cost for the described workload
  • B. Disable the organization trail and create individual trails only in production accounts, protecting the data both in transit and at rest
  • C. Switch from an organization trail to CloudTrail Lake with a shorter retention period for production accounts
  • D. Use advanced event selectors to exclude data events from development account resources while keeping all events for production accounts
Correct Answer: D
Advanced event selectors enables filtering data events based on resource ARN, including filtering based on account ID in ARN. By excludes data events from development accounts (or only meng-include production account resources), cost data events berkurang significant without mengorbankan audit compliance for production.

Option A: INCORRECT. Mengacu on S3 lifecycle, not feature CloudTrail — and reduces retention can melanggar compliance.
Option B: INCORRECT. Eliminates visibility to management events in development accounts that still is required.
Option C: INCORRECT. Has pricing different that can more expensive depends volume query — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: CORRECT.

A data engineer is configuring CloudTrail for a new AWS account that will host a data analytics platform. The platform uses Amazon Redshift, AWS Glue, Amazon EMR, and Amazon Athena. The engineer needs to ensure that both control plane operations (like CreateCluster, StartJobRun) and data plane operations (like Redshift query execution) are logged. Which statement about CloudTrail event types is CORRECT?
  • A. Management events capture both control plane and data plane operations for all AWS services with native S3 integration and optimized data transfer
  • B. CloudTrail automatically logs all API calls including data plane operations without additional configuration, handling the described workload reliably at scale and minimizing end-to-end processing latency
  • C. Management events are free and data events are always charged, regardless of the number of trails, meeting the latency and throughput goals of the design
  • D. Data events must be enabled separately and are available for S3, Lambda, DynamoDB, and other supported services, but not all services support data events
Correct Answer: D
Data events must diaktifkan in a separate and only available for service certain that is supported (S3, Lambda, DynamoDB, EBS, S3 Object Lambda, dll). Not all service AWS supports data events — for example Redshift query execution not is logged sebagai data events in CloudTrail.

Option A: INCORRECT. Salah because management events only logs control plane operations — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Salah because data events requires configuration eksplisit.
Option C: INCORRECT. Sebagian incorrect — management events gratis for satu copy pertama but charged for copies additional, and pricing data events memang dikenakan cost per event.
Option D: CORRECT.

A financial institution requires that CloudTrail logs be retained for 7 years to comply with regulatory requirements. The logs must be queryable for the first 90 days and then moved to cold storage. The solution must prevent accidental or malicious deletion of logs. Which combination of configurations meets ALL these requirements?
  • A. Deliver logs to S3 with Object Lock (Governance mode), query with Athena for 90 days, and transition to S3 Glacier after 90 days
  • B. Deliver logs to S3 with Object Lock (Compliance mode), use CloudTrail Lake for 90-day queries, and configure S3 Glacier Deep Archive lifecycle rule after 90 days
  • C. Deliver logs to S3, enable versioning and MFA Delete, use Athena for queries, and configure S3 Intelligent-Tiering after 90 days, integrating natively with the rest of the pipeline
  • D. Use CloudTrail Lake with 7-year retention for all events and disable S3 delivery with native S3 integration and optimized data transfer, handling the described workload reliably at scale
Correct Answer: B
Object Lock Compliance mode prevents deletion by siapapun including root account during retention period, memenuhi persyaratan anti-deletion. CloudTrail Lake provides capabilities SQL query that easy during 90 days pertama. Lifecycle rule to Glacier Deep Archive setelah 90 days memenuhi persyaratan cold storage with cost most low for 7 years.

Option A: INCORRECT. Can in-bypass by user with permission s3:BypassGovernanceRetention, not sekuat Compliance mode.
Option B: CORRECT.
Option C: INCORRECT. Only melindungi from deletion without MFA but root account still can deletes.
Option D: INCORRECT. Very expensive for storage jangka panjang — although its description sounds convincing, in a fundamental still not appropriate for requirements this.

A data engineer is troubleshooting an issue where certain S3 PutObject events are not appearing in CloudTrail logs despite data events being enabled for the bucket. The trail is configured with basic event selectors. Which is the MOST likely cause of the missing events?
  • A. CloudTrail does not log PutObject events for objects smaller than 1 KB with readWriteType set
  • B. The S3 bucket is in a different region than the trail and the trail is not configured as a multi-region trail
  • C. The trail has reached the maximum number of events per hour and is throttling
  • D. The basic event selector is configured with readWriteType set to ReadOnly, filtering out PutObject write events
Correct Answer: D
Basic event selectors has parameter readWriteType that can is configured to ReadOnly, WriteOnly, or All. If is configured to ReadOnly, only operasi baca (GetObject) that is logged and operasi tulis (PutObject) will difilter. Ini is penyebab umum missing events.

Option A: INCORRECT. Salah because CloudTrail logs all S3 data events without pembatasan size objek — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Kurang correct — data events is logged in region tempat operasi occurs, but if trail multi-region already active (default for organization trails), region should not jadi problem.
Option C: INCORRECT. Salah because CloudTrail not has throttling limit per hour for event logging.
Option D: CORRECT.
