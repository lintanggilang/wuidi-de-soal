Skill 4.4.1: Use AWS CloudTrail to Track API Calls

CloudTrail configuration and management for comprehensive API activity auditing

12345 678910
1
A company operates a data lake on Amazon S3 containing sensitive financial records. The security team requires visibility into every GetObject and PutObject API call made against the data lake buckets to satisfy regulatory auditing requirements. The solution must capture the identity of the caller, the time of the call, and the specific objects accessed. Which CloudTrail configuration meets these requirements?
  • A. Create a trail that logs management events and enable log file integrity validation
  • B. Create a trail with S3 data events enabled for the specific data lake buckets
  • C. Enable CloudTrail Insights on the existing trail to detect unusual S3 access patterns
  • D. Configure S3 server access logging on the data lake buckets and export to CloudTrail
Jawaban Benar: B
S3 data events di CloudTrail mencatat operasi pada level objek seperti GetObject, PutObject, dan DeleteObject. Data events menyertakan identitas pemanggil (IAM principal), waktu, dan ARN objek spesifik yang diakses. Opsi A (management events) hanya mencatat operasi control plane seperti CreateBucket atau PutBucketPolicy, bukan akses data. Opsi C (CloudTrail Insights) mendeteksi anomali volume API calls tapi tidak mencatat detail individual object access. Opsi D salah karena S3 server access logs tidak bisa diekspor ke CloudTrail — keduanya sistem terpisah.
2
A multinational corporation with 50 AWS accounts under AWS Organizations needs a unified audit trail across all accounts and regions. The security team must ensure that individual account administrators cannot disable or modify the logging configuration. Which approach provides the MOST comprehensive and tamper-resistant solution?
  • A. Create individual trails in each account and aggregate logs to a central S3 bucket using cross-account access
  • B. Create an organization trail from the management account that logs events for all member accounts
  • C. Use AWS Config rules to monitor CloudTrail status in each account and auto-remediate if disabled
  • D. Deploy CloudTrail trails using AWS CloudFormation StackSets with termination protection enabled
Jawaban Benar: B
Organization trails yang dibuat dari management account secara otomatis diterapkan ke semua akun anggota di seluruh region. Member accounts tidak dapat memodifikasi atau menghapus organization trail — hanya management account yang memiliki kontrol penuh. Ini memberikan audit trail terpusat dan tamper-resistant. Opsi A memerlukan konfigurasi manual di setiap akun dan administrator lokal bisa menonaktifkannya. Opsi C bersifat reaktif dan ada delay antara disabling dan remediation. Opsi D (StackSets) bisa di-override oleh admin lokal yang memiliki permission untuk menghapus stack.
3
A data engineering team uses AWS Lambda functions to process sensitive data from Amazon DynamoDB. The compliance team requires an audit trail that captures every Lambda function invocation including the specific DynamoDB tables accessed. The team wants to use CloudTrail Lake to query these events using SQL. Which combination of steps should the data engineer implement? (Choose the MOST complete answer.)
  • A. Enable Lambda data events on the trail, create a CloudTrail Lake event data store, and run SQL queries filtering by eventSource and eventName
  • B. Enable management events on the trail, export logs to S3, and query with Amazon Athena using SQL
  • C. Enable Lambda data events, stream logs to CloudWatch Logs, and use CloudWatch Logs Insights for SQL queries
  • D. Enable CloudTrail Insights for Lambda, create a CloudTrail Lake event data store, and query anomalous invocations
Jawaban Benar: A
Lambda data events mencatat setiap invokasi fungsi (Invoke API call). CloudTrail Lake memungkinkan pembuatan event data store yang menyimpan events dan mendukung SQL queries langsung tanpa perlu ekspor ke S3 atau konfigurasi Athena. Query bisa memfilter berdasarkan eventSource (lambda.amazonaws.com) dan eventName (Invoke). Opsi B menggunakan management events yang tidak mencatat invocations individual. Opsi C (CloudWatch Logs Insights) bukan SQL standard dan tidak terintegrasi langsung dengan CloudTrail events. Opsi D (Insights) hanya mendeteksi anomali, bukan mencatat setiap invokasi individual.
4
A security engineer discovers that CloudTrail log files stored in S3 may have been tampered with during a security incident investigation. The engineer needs to verify the integrity of all log files delivered over the past 30 days. Which CloudTrail feature enables this verification, and how does it work?
  • A. CloudTrail log file integrity validation, which creates SHA-256 hash digest files delivered hourly to the same S3 bucket
  • B. CloudTrail encryption with AWS KMS, which prevents any modification to delivered log files
  • C. S3 Object Lock in Governance mode, which prevents deletion of CloudTrail log files
  • D. CloudTrail log file integrity validation, which uses digital signatures with a private key managed by AWS to create digest files
Jawaban Benar: D
CloudTrail log file integrity validation menggunakan SHA-256 hashing untuk setiap log file dan menandatangani digest files secara digital menggunakan private key yang dikelola AWS. Digest files dikirim setiap jam dan berisi hash dari semua log files yang dikirim dalam periode tersebut. Validasi menggunakan AWS CLI command `aws cloudtrail validate-logs`. Opsi A sebagian benar tapi melewatkan aspek digital signatures yang krusial — tanpa signatures, digest files sendiri bisa ditamper. Opsi B (KMS encryption) mencegah pembacaan tanpa key tapi tidak memvalidasi integritas post-delivery. Opsi C (Object Lock) mencegah deletion tapi bukan modifikasi konten jika governance mode di-bypass.
5
A data platform team needs to monitor API activity across their data pipeline infrastructure. They want to log all S3 data events but ONLY for buckets prefixed with "data-pipeline-" to control costs. They also need all DynamoDB data events for tables used by the pipeline. Which event selector configuration is MOST appropriate?
  • A. Use basic event selectors with readWriteType set to All for S3 and DynamoDB resources
  • B. Use advanced event selectors with field selectors filtering resources.ARN with StartsWith for the S3 bucket prefix and Equals for specific DynamoDB table ARNs
  • C. Create two separate trails — one for S3 data events with a resource prefix filter and another for DynamoDB data events
  • D. Use basic event selectors specifying individual S3 bucket ARNs and all DynamoDB tables
Jawaban Benar: B
Advanced event selectors memberikan granularitas filtering yang lebih tinggi dibanding basic event selectors. Field selector resources.ARN dengan operator StartsWith memungkinkan filtering berdasarkan prefix (arn:aws:s3:::data-pipeline-*), dan operator Equals untuk tabel DynamoDB spesifik. Ini mencapai kedua kebutuhan dalam satu trail. Opsi A (basic event selectors) tidak mendukung prefix matching pada ARN — hanya bisa memilih semua buckets atau bucket spesifik. Opsi C membuat dua trails yang tidak perlu dan meningkatkan biaya. Opsi D (basic selectors) harus mendaftar setiap bucket individu, tidak bisa menggunakan prefix pattern.
6
A healthcare organization needs to integrate CloudTrail logs with their existing on-premises SIEM (Security Information and Event Management) system for real-time security monitoring. The SIEM requires events to be delivered within 5 minutes of occurrence. Which architecture provides the LOWEST latency delivery of CloudTrail events to the SIEM?
  • A. Configure CloudTrail to deliver logs to S3, then use S3 event notifications to trigger Lambda that forwards events to the SIEM
  • B. Configure CloudTrail to deliver logs to CloudWatch Logs, create a subscription filter to Amazon Kinesis Data Streams, and use a consumer to forward to the SIEM
  • C. Configure S3 replication on the CloudTrail bucket to replicate logs to a bucket monitored by the SIEM agent
  • D. Use Amazon EventBridge to capture CloudTrail events and route them directly to an API destination connected to the SIEM
Jawaban Benar: D
Amazon EventBridge menerima CloudTrail events dalam near real-time (biasanya dalam hitungan detik) tanpa perlu menunggu log file delivery ke S3 (yang bisa memakan waktu hingga 15 menit). EventBridge API destinations memungkinkan routing langsung ke SIEM endpoint via HTTPS. Opsi A bergantung pada S3 delivery yang memiliki latensi 5-15 menit. Opsi B (CloudWatch Logs) menambahkan latency karena CloudTrail harus menulis ke log group terlebih dahulu. Opsi C (S3 replication) menambahkan latensi di atas S3 delivery time. EventBridge memberikan latensi terendah karena langsung menerima events dari CloudTrail.
7
A company has enabled an organization trail that captures management events across 30 accounts. The data engineering team notices that the monthly CloudTrail costs have significantly increased. Upon investigation, they find that most costs come from S3 and Lambda data events from development accounts. Which approach BEST optimizes costs while maintaining audit compliance for production accounts?
  • A. Disable the organization trail and create individual trails only in production accounts
  • B. Use advanced event selectors to exclude data events from development account resources while keeping all events for production accounts
  • C. Reduce the CloudTrail log retention period from 90 days to 30 days for all accounts
  • D. Switch from an organization trail to CloudTrail Lake with a shorter retention period
Jawaban Benar: B
Advanced event selectors memungkinkan filtering data events berdasarkan resource ARN, termasuk filtering berbasis account ID dalam ARN. Dengan mengecualikan data events dari development accounts (atau hanya meng-include production account resources), biaya data events berkurang signifikan tanpa mengorbankan audit compliance untuk production. Opsi A menghilangkan visibility ke management events di development accounts yang masih diperlukan. Opsi C (retention) mengacu pada S3 lifecycle, bukan fitur CloudTrail — dan mengurangi retention bisa melanggar compliance. Opsi D (CloudTrail Lake) memiliki pricing berbeda yang bisa lebih mahal tergantung volume query.
8
A data engineer is configuring CloudTrail for a new AWS account that will host a data analytics platform. The platform uses Amazon Redshift, AWS Glue, Amazon EMR, and Amazon Athena. The engineer needs to ensure that both control plane operations (like CreateCluster, StartJobRun) and data plane operations (like Redshift query execution) are logged. Which statement about CloudTrail event types is CORRECT?
  • A. Management events capture both control plane and data plane operations for all AWS services
  • B. Data events must be enabled separately and are available for S3, Lambda, DynamoDB, and other supported services, but not all services support data events
  • C. CloudTrail automatically logs all API calls including data plane operations without additional configuration
  • D. Management events are free and data events are always charged, regardless of the number of trails
Jawaban Benar: B
Data events harus diaktifkan secara terpisah dan hanya tersedia untuk layanan tertentu yang didukung (S3, Lambda, DynamoDB, EBS, S3 Object Lambda, dll). Tidak semua layanan AWS mendukung data events — misalnya Redshift query execution tidak dicatat sebagai data events di CloudTrail. Opsi A salah karena management events hanya mencatat control plane operations. Opsi C salah karena data events memerlukan konfigurasi eksplisit. Opsi D sebagian salah — management events gratis untuk satu copy pertama tapi charged untuk copies tambahan, dan pricing data events memang dikenakan biaya per event.
9
A financial institution requires that CloudTrail logs be retained for 7 years to comply with regulatory requirements. The logs must be queryable for the first 90 days and then moved to cold storage. The solution must prevent accidental or malicious deletion of logs. Which combination of configurations meets ALL these requirements?
  • A. Deliver logs to S3 with Object Lock (Compliance mode), use CloudTrail Lake for 90-day queries, and configure S3 Glacier Deep Archive lifecycle rule after 90 days
  • B. Deliver logs to S3, enable versioning and MFA Delete, use Athena for queries, and configure S3 Intelligent-Tiering after 90 days
  • C. Use CloudTrail Lake with 7-year retention for all events and disable S3 delivery
  • D. Deliver logs to S3 with Object Lock (Governance mode), query with Athena for 90 days, and transition to S3 Glacier after 90 days
Jawaban Benar: A
Object Lock Compliance mode mencegah penghapusan oleh siapapun termasuk root account selama retention period, memenuhi persyaratan anti-deletion. CloudTrail Lake menyediakan kemampuan SQL query yang mudah selama 90 hari pertama. Lifecycle rule ke Glacier Deep Archive setelah 90 hari memenuhi persyaratan cold storage dengan biaya paling rendah untuk 7 tahun. Opsi B (MFA Delete) hanya melindungi dari deletion tanpa MFA tapi root account masih bisa menghapus. Opsi C (CloudTrail Lake 7 tahun) sangat mahal untuk penyimpanan jangka panjang. Opsi D (Governance mode) bisa di-bypass oleh user dengan permission s3:BypassGovernanceRetention, tidak sekuat Compliance mode.
10
A data engineer is troubleshooting an issue where certain S3 PutObject events are not appearing in CloudTrail logs despite data events being enabled for the bucket. The trail is configured with basic event selectors. Which is the MOST likely cause of the missing events?
  • A. The trail has reached the maximum number of events per hour and is throttling
  • B. The basic event selector is configured with readWriteType set to ReadOnly, filtering out PutObject write events
  • C. The S3 bucket is in a different region than the trail and the trail is not configured as a multi-region trail
  • D. CloudTrail does not log PutObject events for objects smaller than 1 KB
Jawaban Benar: B
Basic event selectors memiliki parameter readWriteType yang bisa diatur ke ReadOnly, WriteOnly, atau All. Jika diatur ke ReadOnly, hanya operasi baca (GetObject) yang dicatat dan operasi tulis (PutObject) akan difilter. Ini adalah penyebab umum missing events. Opsi A salah karena CloudTrail tidak memiliki throttling limit per hour untuk event logging. Opsi C kurang tepat — data events dicatat di region tempat operasi terjadi, tapi jika trail multi-region sudah aktif (default untuk organization trails), region seharusnya tidak jadi masalah. Opsi D salah karena CloudTrail mencatat semua S3 data events tanpa pembatasan ukuran objek.
