1
A data engineer stores Amazon RDS PostgreSQL credentials in AWS Secrets Manager with automatic rotation enabled every 30 days. After a rotation occurs, an AWS Glue ETL job fails to connect to the database with "authentication failed" errors, but recovers after being restarted. What is the MOST likely cause of this issue?
  • A. The Glue job caches the database credentials at startup and does not refresh them when rotation occurs during a long-running job
  • B. The rotation Lambda function failed to update the password in the RDS database
  • C. The Glue job's IAM role does not have permission to access the rotated secret version
  • D. Secrets Manager requires a manual approval step after rotation before the new credentials become active
Jawaban Benar: A
Glue jobs yang long-running mengambil credentials saat startup dan menyimpannya di memory. Jika rotasi terjadi selama job berjalan, job masih menggunakan credentials lama yang sudah tidak valid. Setelah restart, job mengambil credentials baru dan berhasil. Solusinya adalah implement credential refresh logic dalam job atau menggunakan connection yang mengambil dari Secrets Manager secara periodik. Opsi B (rotation Lambda gagal) kurang kemungkinan karena job berhasil setelah restart — berarti credentials baru valid. Opsi C (IAM permission) — permission berlaku untuk semua secret versions. Opsi D salah — Secrets Manager tidak memerlukan manual approval, rotasi otomatis langsung aktif.
2
A company has multiple data pipelines (Glue jobs, Lambda functions, EMR applications) that all connect to a shared Amazon Aurora MySQL cluster. The security team mandates credential rotation every 7 days without any application downtime. Which Secrets Manager rotation strategy should the data engineer implement?
  • A. Single-user rotation strategy where the existing user's password is directly updated
  • B. Multi-user alternating rotation strategy that alternates between two database users
  • C. Create a new database user on each rotation and delete the old one after 24 hours
  • D. Use IAM database authentication instead of Secrets Manager to eliminate password rotation entirely
Jawaban Benar: B
Multi-user alternating rotation strategy menggunakan dua database users yang bergantian. Saat rotasi: user aktif (AWSCURRENT) tetap valid sementara user cadangan (AWSPREVIOUS) mendapat password baru. Setelah selesai, label ditukar. Ini memastikan zero downtime karena credentials lama tetap valid sampai rotasi berikutnya. Opsi A (single-user) memiliki window singkat dimana connections dengan password lama akan gagal selama rotation process — berisiko downtime. Opsi C (user baru setiap rotasi) memerlukan update permissions pada setiap user baru dan sangat sulit di-maintain. Opsi D (IAM auth) bagus tapi memiliki connection limit (256 connections/detik) yang mungkin tidak cukup untuk multiple pipelines.
3
A data engineer needs to store credentials for an on-premises Oracle database that is accessed by AWS Glue jobs. The credential includes hostname, port, username, password, and SID. The engineer evaluates AWS Secrets Manager versus AWS Systems Manager Parameter Store (SecureString). Which factor is the PRIMARY reason to choose Secrets Manager over Parameter Store for this use case?
  • A. Secrets Manager supports encryption with KMS keys while Parameter Store does not
  • B. Secrets Manager provides built-in automatic rotation with Lambda integration, which Parameter Store does not natively support
  • C. Secrets Manager can store larger values (up to 64 KB) compared to Parameter Store (4 KB limit)
  • D. Secrets Manager supports cross-region replication while Parameter Store is single-region only
Jawaban Benar: B
Keunggulan utama Secrets Manager dibanding Parameter Store adalah built-in automatic rotation capability dengan Lambda rotation functions. Secrets Manager menyediakan rotation templates untuk berbagai databases dan custom rotation Lambda functions untuk credential lainnya. Parameter Store SecureString bisa menyimpan credentials dengan enkripsi KMS tetapi tidak memiliki native rotation mechanism. Opsi A salah — Parameter Store SecureString juga menggunakan KMS encryption. Opsi C salah — Parameter Store Advanced tier mendukung hingga 8 KB, dan 4 KB cukup untuk credentials. Opsi D — meskipun Secrets Manager mendukung cross-region replication, ini bukan alasan PRIMARY untuk credential management use case.
4
A data engineer configures automatic rotation for an Amazon Redshift cluster password stored in AWS Secrets Manager. The rotation Lambda function needs network access to both the Secrets Manager API and the Redshift cluster in a private VPC subnet. How should the engineer configure the rotation Lambda function's network access?
  • A. Deploy the Lambda function in the VPC with a Secrets Manager VPC Interface Endpoint and ensure the security group allows outbound HTTPS to the endpoint and port 5439 to Redshift
  • B. Deploy the Lambda function outside the VPC with a Redshift public endpoint enabled
  • C. Deploy the Lambda function in the VPC with a NAT Gateway for Secrets Manager API access and direct VPC connectivity to Redshift
  • D. Deploy the Lambda function outside the VPC and use VPC peering to reach the Redshift cluster
Jawaban Benar: A
Lambda rotation function harus di-deploy dalam VPC yang sama dengan Redshift (untuk direct network access ke port 5439). Untuk mengakses Secrets Manager API (yang merupakan public service), diperlukan VPC Interface Endpoint untuk Secrets Manager (secretsmanager.region.amazonaws.com). Ini memungkinkan Lambda mengakses Secrets Manager API tanpa internet access. Opsi B (Lambda di luar VPC) tidak bisa mengakses Redshift di private subnet. Opsi C (NAT Gateway) berfungsi tetapi menambah biaya dan memerlukan internet gateway — kurang secure dibanding VPC endpoint. Opsi D (VPC peering dari luar VPC) tidak possible — Lambda di luar VPC tidak memiliki VPC attachment untuk peering.
5
A data engineer implements credential rotation for a database used by multiple microservices. After rotation, some services get the new password (AWSCURRENT) while others still use the cached old password. The engineer wants to understand the secret versioning mechanism. During the rotation process, which version stages exist and what is their purpose?
  • A. AWSCURRENT (active credentials), AWSPENDING (new credentials being tested), and AWSPREVIOUS (last known good credentials)
  • B. AWSCURRENT (active credentials), AWSNEXT (scheduled future credentials), and AWSARCHIVED (historical credentials)
  • C. PRIMARY (active credentials), SECONDARY (backup credentials), and TERTIARY (historical credentials)
  • D. AWSCURRENT (active credentials) and AWSBACKUP (rollback credentials) only
Jawaban Benar: A
Secrets Manager menggunakan tiga version stages selama rotation: (1) AWSCURRENT — credentials yang aktif saat ini, dikembalikan secara default saat GetSecretValue dipanggil. (2) AWSPENDING — credentials baru yang sedang dibuat dan ditest oleh rotation Lambda selama rotation process. (3) AWSPREVIOUS — credentials sebelumnya yang masih valid, berguna untuk services yang masih menggunakan credentials lama. Rotation Lambda melewati 4 steps: createSecret (buat AWSPENDING), setSecret (set di database), testSecret (validasi AWSPENDING works), finishSecret (promosikan AWSPENDING menjadi AWSCURRENT). Opsi lain menggunakan label yang tidak exist di Secrets Manager.
6
A data team in Account A needs to access a database credential stored in AWS Secrets Manager in Account B. The Glue jobs in Account A must retrieve the secret at runtime. Which configuration enables this cross-account secret access?
  • A. In Account B: Add a resource-based policy on the secret allowing Account A's Glue role to perform secretsmanager:GetSecretValue. In Account A: Grant the Glue role permission to call secretsmanager:GetSecretValue on the Account B secret ARN.
  • B. Replicate the secret from Account B to Account A using Secrets Manager cross-region replication
  • C. Create an IAM user in Account B with access to the secret, and store those access keys in Account A's Secrets Manager
  • D. Share the secret through AWS Resource Access Manager (RAM) to Account A
Jawaban Benar: A
Cross-account secret access memerlukan konfigurasi di kedua akun: (1) Account B (resource owner): Resource-based policy pada secret yang mengizinkan Account A's role ARN untuk GetSecretValue. Jika secret encrypted dengan CMK, KMS key policy juga harus allow Account A. (2) Account A (requester): IAM policy pada Glue role yang mengizinkan secretsmanager:GetSecretValue pada ARN secret di Account B. Opsi B (cross-region replication) bukan cross-account — ini untuk DR antar regions. Opsi C (IAM user + access keys) melanggar best practice dan menimbulkan credential management recursion. Opsi D (RAM) tidak mendukung sharing Secrets Manager secrets.
7
A data engineer needs to configure automatic rotation for Amazon Redshift cluster credentials stored in Secrets Manager. AWS provides native integration for Redshift rotation. Which statement about Secrets Manager's native Redshift rotation is CORRECT?
  • A. Native Redshift rotation uses a Secrets Manager-managed Lambda function that directly connects to Redshift to change the master user password without requiring custom code
  • B. Native Redshift rotation requires the engineer to write a custom Lambda function that uses the Redshift Data API to change the password
  • C. Native Redshift rotation is only available for Redshift Serverless, not provisioned Redshift clusters
  • D. Native Redshift rotation changes the password in Secrets Manager but requires manual execution of ALTER USER on the Redshift cluster
Jawaban Benar: A
AWS Secrets Manager menyediakan managed rotation untuk Amazon Redshift (baik provisioned maupun Serverless). Saat native rotation dikonfigurasi, Secrets Manager membuat dan mengelola Lambda function yang secara otomatis: (1) Generates password baru. (2) Connects ke Redshift cluster. (3) Menjalankan ALTER USER untuk mengubah password. (4) Updates secret value. Tidak perlu custom code — cukup konfigurasi rotation schedule dan network access (Lambda harus bisa reach Redshift dan Secrets Manager). Opsi B salah — custom Lambda tidak diperlukan untuk database yang supported. Opsi C salah — tersedia untuk keduanya. Opsi D salah — rotation mengubah password di Redshift dan Secrets Manager secara otomatis.
8
A data engineer has a Lambda function that retrieves database credentials from Secrets Manager on every invocation. The function is invoked 10,000 times per minute. The engineer is concerned about Secrets Manager API throttling and cost. What is the MOST cost-effective approach to reduce API calls while maintaining security?
  • A. Cache the secret value in a DynamoDB table and read from DynamoDB instead
  • B. Use the AWS Secrets Manager caching library (client-side caching) with a configurable TTL in the Lambda function
  • C. Store the credentials in Lambda environment variables encrypted with KMS
  • D. Use Parameter Store instead of Secrets Manager as it has higher API rate limits
Jawaban Benar: B
AWS menyediakan Secrets Manager Caching Library (tersedia untuk Python, Java, .NET, Go) yang melakukan client-side caching dengan configurable TTL. Library ini menyimpan secret value di memory Lambda execution environment dan hanya memanggil Secrets Manager API saat cache expired. Ini secara drastis mengurangi API calls (dari 10,000/menit menjadi beberapa calls per cache TTL period). Opsi A (DynamoDB cache) menambahkan service dependency dan risiko keamanan — credentials tersimpan di persistent store. Opsi C (environment variables) tidak mendukung automatic rotation — harus redeploy Lambda setiap kali password berubah. Opsi D (Parameter Store) memiliki throughput limit yang sama dan tidak menyelesaikan masalah caching.
9
A company's compliance policy requires that all database credentials must be rotated every 14 days. A data engineer configures Secrets Manager rotation for an RDS MySQL database. Two weeks after initial setup, the rotation fails. CloudWatch Logs from the rotation Lambda show "Access denied connecting to RDS instance." The rotation was working initially. What is the MOST likely cause?
  • A. The rotation Lambda function's security group was modified, removing access to the RDS instance on port 3306
  • B. The RDS instance was moved to a different subnet since initial configuration
  • C. The Secrets Manager VPC endpoint was deleted, preventing the Lambda function from communicating with Secrets Manager API
  • D. The master user credentials stored in a separate admin secret (used by the rotation function) have expired or been manually changed outside of Secrets Manager
Jawaban Benar: D
Untuk multi-user rotation strategy, rotation Lambda memerlukan "master secret" — credentials admin/master user yang digunakan untuk membuat dan mengubah password user lain. Jika master credentials diubah secara manual (di luar Secrets Manager) atau expired, rotation Lambda tidak bisa login ke database untuk melakukan perubahan password, menghasilkan "Access denied connecting to RDS." Error ini spesifik menunjukkan masalah database authentication, bukan network. Opsi A (security group) akan menghasilkan "connection timeout," bukan "access denied." Opsi B (subnet change) juga menghasilkan connectivity error, bukan auth error. Opsi C (VPC endpoint deleted) akan menghasilkan error pada Secrets Manager API calls, bukan RDS connection.
10
A data engineer manages an EMR cluster that runs multiple Spark jobs requiring credentials to connect to various data sources (RDS, Redshift, third-party API). The credentials are stored in AWS Secrets Manager. What is the RECOMMENDED way for Spark jobs on EMR to retrieve secrets from Secrets Manager?
  • A. Store all credentials in EMR cluster configuration properties at launch time and reference them as Spark configuration parameters
  • B. Use the AWS SDK (boto3) within the Spark job code to call Secrets Manager GetSecretValue at runtime, with the EMR EC2 instance profile role providing access
  • C. Create a bootstrap action that writes all secrets to a file on the master node, then distribute the file to all workers via HDFS
  • D. Use EMR's native Secrets Manager integration to automatically inject secrets as environment variables on all nodes
Jawaban Benar: B
Best practice adalah menggunakan AWS SDK (boto3 untuk Python) di dalam Spark job code untuk memanggil Secrets Manager GetSecretValue API saat runtime. EMR EC2 instances menggunakan instance profile role yang harus memiliki permission secretsmanager:GetSecretValue. Credentials diambil saat dibutuhkan dan tidak disimpan secara persistent. Opsi A (cluster config at launch) — credentials menjadi visible di EMR configuration dan tidak mendukung rotation setelah cluster launch. Opsi C (bootstrap + HDFS) sangat tidak aman — credentials tersimpan plaintext di filesystem yang accessible oleh semua users. Opsi D salah — EMR tidak memiliki native integration untuk auto-inject Secrets Manager secrets sebagai environment variables.
