Skill 1.2.2: Connect to Different Data Sources (JDBC, ODBC)

Configuring JDBC/ODBC connections in AWS Glue, EMR, Redshift, and other services for data extraction and loading

1
A data engineer is configuring an AWS Glue ETL job to read from an on-premises SQL Server database using JDBC. The database is accessible via AWS Site-to-Site VPN. The Glue connection test succeeds, but the ETL job fails with "Unable to connect" errors. What is the MOST likely cause?
  • A. The Glue connection's security group does not have a self-referencing inbound rule allowing all TCP traffic from itself
  • B. The JDBC URL format is incorrect
  • C. The SQL Server does not support JDBC connections
  • D. The Glue job timeout is too short
Jawaban Benar: A
AWS Glue requires a self-referencing inbound rule on the connection's security group. This allows Glue workers (which share the same security group) to communicate with each other. Without this, the Glue job fails even if the connection test (which uses a single ENI) succeeds. Opsi B tidak cocok karena connection test sudah berhasil. Opsi C salah — SQL Server mendukung JDBC. Opsi D (timeout) menyebabkan error berbeda.
2
A data engineer needs to connect Amazon Redshift to an external PostgreSQL database for federated queries. The PostgreSQL database is in a different VPC. Which feature and configuration enables this cross-VPC connection?
  • A. Create a Redshift external schema using CREATE EXTERNAL SCHEMA with JDBC connection string, with VPC peering between the Redshift VPC and the PostgreSQL VPC
  • B. Use Redshift Spectrum to query PostgreSQL directly
  • C. Create a Glue JDBC connection and use it from Redshift
  • D. Export PostgreSQL data to S3 and query with Redshift
Jawaban Benar: A
Redshift Federated Query mendukung koneksi langsung ke PostgreSQL (dan MySQL) via JDBC. CREATE EXTERNAL SCHEMA dengan CONNECTION mendefinisikan koneksi. VPC peering memungkinkan network connectivity antar VPCs. Opsi B (Spectrum) hanya untuk S3 data, bukan database. Opsi C (Glue connection) tidak bisa digunakan dari Redshift SQL secara langsung. Opsi D mengubah arsitektur dan menghilangkan real-time access.
3
An AWS Glue ETL job connects to an Amazon RDS MySQL database via JDBC. The job runs for 4 hours and processes data from 20 tables in parallel. The RDS instance reaches its max_connections limit (150) and starts rejecting connections. Which Glue JDBC configuration prevents this?
  • A. Set the numPartitions parameter to a value lower than max_connections and use connection pooling in the JDBC URL
  • B. Increase the RDS instance class to get more max_connections
  • C. Process tables sequentially instead of in parallel
  • D. Use Glue job bookmarks to reduce the amount of data read
Jawaban Benar: A
numPartitions (atau hashpartitions dalam Glue) menentukan jumlah concurrent connections yang Glue membuka ke database. Menetapkan ini di bawah max_connections (misalnya 50) mencegah connection exhaustion. Connection pooling di JDBC URL mengurangi connection churn. Opsi B (upgrade instance) mahal dan hanya sementara. Opsi C (sequential) sangat lambat. Opsi D (bookmarks) mengurangi data volume tapi tidak connection count per se.
4
A data engineer needs to extract data from an Oracle database using AWS Glue. The Oracle database uses a custom JDBC driver not included in the Glue environment. How should the engineer provide the custom JDBC driver to Glue?
  • A. Upload the JDBC driver JAR file to S3 and specify its path in the Glue connection's "JDBC driver - custom path" or in the job's extra jars parameter
  • B. Install the JDBC driver on the Glue worker nodes via SSH
  • C. Submit a support ticket to AWS to add the driver to the Glue environment
  • D. Use ODBC connection instead, which doesn't require a driver
Jawaban Benar: A
AWS Glue mendukung custom JDBC drivers. Driver JAR di-upload ke S3 dan direferensikan di Glue connection (class name dan S3 path) atau via --extra-jars job parameter. Glue otomatis mendownload dan memuat driver saat job dimulai. Opsi B — Glue managed service tanpa SSH access ke workers. Opsi C bukan cara yang feasible. Opsi D — ODBC juga memerlukan driver dan Glue primarily menggunakan JDBC.
5
A data engineer configures an Amazon EMR Spark application to read from a MySQL database using JDBC. The table has 500 million rows. The read operation is slow because Spark uses a single partition. Which Spark JDBC options enable parallel reads?
  • A. Specify partitionColumn, lowerBound, upperBound, and numPartitions in the JDBC read options
  • B. Increase the Spark executor memory
  • C. Use spark.sql.shuffle.partitions configuration
  • D. Enable Spark Adaptive Query Execution (AQE)
Jawaban Benar: A
Spark JDBC parallel read membutuhkan: partitionColumn (numeric column untuk split), lowerBound/upperBound (range values), dan numPartitions (jumlah parallel connections). Spark membuat numPartitions queries dengan WHERE clauses yang membagi range. Opsi B (memory) tidak mengaktifkan parallelism. Opsi C (shuffle.partitions) untuk shuffle operations, bukan JDBC reads. Opsi D (AQE) mengoptimalkan shuffle tapi tidak affect JDBC source parallelism.
6
A company wants Amazon Athena to query data from an on-premises Teradata database without moving the data to AWS. Which Athena feature and connection method enables this?
  • A. Use Athena Federated Query with a custom data source connector (Lambda-based) that connects to Teradata via JDBC through a VPN connection
  • B. Use Athena directly with a JDBC connection string in the FROM clause
  • C. Create a Glue connection to Teradata and Athena will use it automatically
  • D. Use Redshift Spectrum to proxy the query to Teradata
Jawaban Benar: A
Athena Federated Query menggunakan Lambda-based data source connectors untuk query external data sources. Connector untuk Teradata tersedia (dari AWS atau custom) yang menggunakan JDBC internally. Lambda runs in VPC dengan VPN access ke on-premises. Opsi B — Athena tidak menerima JDBC connection strings langsung di queries. Opsi C — Athena tidak otomatis menggunakan Glue JDBC connections untuk query. Opsi D — Redshift Spectrum hanya untuk S3 data.
7
A data engineer is troubleshooting an AWS Glue JDBC connection to an Amazon Aurora PostgreSQL cluster. The connection test passes, but the ETL job intermittently fails with "Connection reset" errors after running for 30 minutes. What is the MOST likely cause?
  • A. The Aurora cluster's idle connection timeout is closing inactive JDBC connections; configure connection validation/keep-alive in the JDBC URL parameters
  • B. The Glue job has insufficient DPUs
  • C. The Aurora cluster needs to be rebooted
  • D. The JDBC driver version is incompatible with Aurora
Jawaban Benar: A
Aurora (PostgreSQL) memiliki idle_in_transaction_session_timeout dan tcp_keepalives_idle parameters yang menutup koneksi idle. Untuk job yang berjalan lama, beberapa koneksi bisa menjadi idle dan di-close. Solusinya adalah menambahkan parameter keepalive dan validasi koneksi di JDBC URL (misalnya tcpKeepAlive=true, connectTimeout, socketTimeout). Opsi B (DPUs) menyebabkan OOM bukan connection reset. Opsi C (reboot) bukan solusi berkelanjutan. Opsi D (driver) akan gagal dari awal bukan intermittent.
8
A data engineer needs to set up Amazon Redshift to connect to an external MySQL database for federated queries. The credentials for the MySQL database must be stored securely. Which approach correctly configures the credentials?
  • A. Store MySQL credentials in AWS Secrets Manager and reference the secret ARN in the CREATE EXTERNAL SCHEMA command using SECRET_ARN parameter
  • B. Hard-code the credentials directly in the CREATE EXTERNAL SCHEMA SQL statement
  • C. Store credentials in an S3 file and reference it in the schema definition
  • D. Use IAM authentication for the external MySQL database
Jawaban Benar: A
Redshift Federated Query mendukung AWS Secrets Manager untuk credential management. CREATE EXTERNAL SCHEMA ... FROM MYSQL/POSTGRES ... SECRET_ARN 'arn:aws:secretsmanager:...' mengambil credentials secara secure dari Secrets Manager. Opsi B (hardcoded) adalah security risk dan visible di system tables. Opsi C (S3 file) tidak supported oleh Redshift schema definition. Opsi D (IAM auth) mungkin tidak available pada semua external databases, terutama non-AWS MySQL.
9
A company uses Amazon EMR to run Hive queries that join data from an S3 data lake with reference data in an Amazon RDS SQL Server database. The Hive queries need JDBC connectivity to SQL Server. Which EMR component enables this?
  • A. Configure a Hive JDBC storage handler and create an external table pointing to the SQL Server database with the JDBC URL and credentials
  • B. Install SQL Server client tools on the EMR master node
  • C. Use EMR's built-in SQL Server connector in the cluster configuration
  • D. Export SQL Server data to S3 first, then join in Hive
Jawaban Benar: A
Hive mendukung JDBC storage handler (org.apache.hive.storage.jdbc.JdbcStorageHandler) yang memungkinkan membuat external table yang backed by JDBC source. CREATE EXTERNAL TABLE ... STORED BY 'org.apache.hive.storage.jdbc.JdbcStorageHandler' WITH SERDEPROPERTIES ("hive.sql.jdbc.url"=...). Opsi B (client tools) tidak mengintegrasikan dengan Hive query engine. Opsi C — tidak ada built-in SQL Server connector di EMR configuration. Opsi D mengubah arsitektur dan menghilangkan real-time reference data.
10
A data engineer needs to ensure secure JDBC connections between AWS Glue and an Amazon RDS database. The company security policy requires encryption in transit for all database connections. How should this be configured?
  • A. Enable SSL/TLS on the RDS instance and add SSL parameters to the JDBC connection URL (e.g., useSSL=true, requireSSL=true, and specify the RDS CA certificate)
  • B. Enable encryption at rest on the RDS instance
  • C. Use a VPC endpoint for RDS to encrypt traffic
  • D. Configure the Glue security group to only allow encrypted connections
Jawaban Benar: A
Encryption in transit untuk JDBC connections membutuhkan SSL/TLS. RDS mendukung SSL dan menyediakan CA certificates. JDBC URL dikonfigurasi dengan SSL parameters: useSSL=true, requireSSL=true untuk MySQL; ssl=true, sslmode=require untuk PostgreSQL. Glue menggunakan URL ini untuk encrypted connections. Opsi B (at rest) melindungi data di storage, bukan in transit. Opsi C (VPC endpoint) — RDS Interface Endpoints tidak otomatis encrypt JDBC traffic. Opsi D (security group) tidak bisa enforce encryption level.
