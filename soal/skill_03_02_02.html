Skill 3.2.2: Verify and Clean Data

Lambda, Athena, QuickSight, Jupyter Notebooks, Amazon SageMaker Data Wrangler for data verification and cleaning

1
A data engineer has a daily ETL pipeline that loads customer records from multiple sources into an Amazon S3 data lake. Before downstream analytics consumes this data, the engineer needs to automatically verify that no critical fields (customer_id, email, transaction_date) contain NULL values, and that transaction_amount falls within the range of $0.01 to $1,000,000. Which AWS service provides the MOST integrated and declarative approach for these checks?
  • A. Write an Amazon Athena query that counts NULLs and out-of-range values, triggered by a Lambda function
  • B. Use AWS Glue Data Quality rules defined in the Glue Data Catalog with automatic evaluation during ETL jobs
  • C. Create a DataBrew recipe with validation steps and run it before the analytics pipeline
  • D. Deploy a SageMaker Data Wrangler flow with data quality checks as processing steps
Jawaban Benar: B
AWS Glue Data Quality memungkinkan definisi rules secara deklaratif menggunakan Data Quality Definition Language (DQDL). Rules dapat dievaluasi secara otomatis selama ETL job execution dan terintegrasi langsung dengan Glue Data Catalog. Rules seperti Completeness, ColumnValues range check bisa didefinisikan tanpa coding. Opsi A memerlukan kode custom dan orchestration terpisah. Opsi C (DataBrew) lebih cocok untuk transformasi visual daripada automated quality gates. Opsi D (Data Wrangler) dirancang untuk ML data preparation, bukan pipeline data quality automation.
2
A company has a data lake with historical transaction records in Amazon S3. A data analyst suspects that some records have duplicate transaction_id values due to a bug in the upstream system. The analyst needs to quickly identify the scale of the duplication problem and find specific duplicate records. Which approach provides the FASTEST investigation with minimal setup?
  • A. Load data into Amazon Redshift and run GROUP BY with HAVING COUNT(*) > 1
  • B. Use Amazon Athena to run a SQL query with GROUP BY transaction_id HAVING COUNT(*) > 1 directly on S3
  • C. Create an AWS Glue ETL job that uses FindMatches ML transform to identify duplicates
  • D. Use Amazon QuickSight to create a visual showing transaction_id distribution
Jawaban Benar: B
Amazon Athena adalah solusi serverless yang bisa langsung query data di S3 tanpa loading atau provisioning. Query GROUP BY dengan HAVING COUNT > 1 akan segera menunjukkan skala duplikasi dan record spesifik. Ini paling cepat karena zero setup. Opsi A memerlukan loading data ke Redshift (waktu dan biaya). Opsi C (FindMatches) untuk fuzzy matching, bukan exact duplicate yang sudah bisa dideteksi dengan GROUP BY sederhana. Opsi D (QuickSight) tidak memberikan detail granular per record yang diperlukan untuk investigasi.
3
A streaming data pipeline ingests IoT sensor data into Amazon Kinesis Data Streams. Some sensors occasionally send malformed JSON or values outside physically possible ranges (e.g., temperature > 1000°C for room sensors). The data engineer needs to validate and filter these records in real-time before they reach the data lake. Which solution BEST addresses this requirement?
  • A. Use an AWS Lambda function as a Kinesis consumer to validate JSON structure and value ranges, routing valid records to the data lake and invalid records to a dead-letter queue
  • B. Use Amazon Kinesis Data Analytics (Apache Flink) with in-application stream to filter anomalous values
  • C. Configure Amazon Data Firehose with a transformation Lambda that validates and cleans records
  • D. Write validation rules in AWS Glue streaming ETL to discard invalid records
Jawaban Benar: C
Amazon Data Firehose dengan transformation Lambda adalah solusi paling terintegrasi untuk validasi real-time sebelum data masuk ke data lake (S3). Lambda melakukan validasi JSON dan range check, mengembalikan status Ok untuk valid records dan ProcessingFailed untuk invalid records. Firehose secara otomatis memisahkan failed records ke error prefix. Opsi A memerlukan manajemen consumer dan DLQ terpisah. Opsi B (Flink) terlalu kompleks untuk simple validation. Opsi D (Glue streaming) memiliki startup time lebih lama dan kurang cocok untuk simple filtering.
4
A data scientist is exploring a new dataset on Amazon EMR using Jupyter Notebooks. The dataset contains customer addresses from multiple countries with inconsistent formatting (varying date formats, phone number formats, and address structures). The scientist needs to interactively explore different cleaning strategies before committing to a production pipeline. Which tool provides the BEST interactive data cleaning experience for this scenario?
  • A. Amazon SageMaker Data Wrangler with its visual interface for data transformations
  • B. AWS Glue DataBrew with custom recipe steps for address standardization
  • C. Jupyter Notebooks on EMR using PySpark with pandas UDFs for iterative exploration
  • D. Amazon Athena with CTAS (CREATE TABLE AS SELECT) queries applying regex transformations
Jawaban Benar: C
Jupyter Notebooks pada EMR memberikan fleksibilitas penuh untuk eksplorasi interaktif menggunakan PySpark dan pandas. Data scientist bisa mencoba berbagai strategi cleaning secara iteratif, menulis custom parsing logic, dan langsung melihat hasilnya. Ini paling cocok untuk kompleksitas format yang memerlukan logic custom. Opsi A (Data Wrangler) bagus untuk visual transformation tapi terbatas untuk complex custom logic. Opsi B (DataBrew) memiliki built-in transforms tapi kurang fleksibel untuk format internasional yang sangat bervariasi. Opsi D (Athena) kurang interaktif dan regex di SQL terbatas untuk multi-step cleaning.
5
A data engineer needs to build an automated data quality pipeline that runs after each nightly batch load. The pipeline must check: (1) referential integrity between orders and customers tables, (2) freshness - data should not be older than 24 hours, and (3) uniqueness of primary keys. Failed checks should halt downstream processing and send alerts. Which architecture is MOST appropriate?
  • A. AWS Glue Data Quality rules with EvaluateDataQuality transform in Glue workflow, configured to fail the job on rule violations, with CloudWatch alarms for notification
  • B. Step Functions orchestrating multiple Athena queries for each check, with conditional branching based on results
  • C. DataBrew profile job scheduled after each load, with Lambda reading profile results and halting pipeline if thresholds exceeded
  • D. Custom Python script on EMR that performs all validation checks and writes results to DynamoDB
Jawaban Benar: A
AWS Glue Data Quality dengan EvaluateDataQuality transform memungkinkan definisi rules deklaratif untuk referential integrity (ReferentialIntegrity), freshness (DataFreshness), dan uniqueness (Uniqueness). Rules dievaluasi inline dalam Glue workflow dan bisa dikonfigurasi untuk menghentikan job jika gagal. Integrasi dengan CloudWatch memungkinkan alerting otomatis. Opsi B memerlukan orchestration custom yang kompleks. Opsi C (DataBrew) tidak dirancang untuk referential integrity checks lintas tabel. Opsi D memerlukan maintenance kode custom.
6
A data engineer discovers that a dataset loaded into Amazon S3 has approximately 15% of records with inconsistent date formats (mix of YYYY-MM-DD, DD/MM/YYYY, and MM-DD-YYYY). The dataset has 200 million records. The engineer needs to standardize all dates to ISO 8601 format (YYYY-MM-DD) before the data is used by downstream Athena queries. What is the MOST cost-effective approach?
  • A. Use AWS Glue ETL with a custom PySpark transformation to parse and standardize date formats
  • B. Use Amazon SageMaker Data Wrangler to define date parsing transformations and export as a processing job
  • C. Use Athena CTAS with CASE statements and date_parse functions to create a cleaned table
  • D. Use AWS Glue DataBrew with built-in date format transformations in a recipe job
Jawaban Benar: C
Athena CTAS (CREATE TABLE AS SELECT) adalah pendekatan paling cost-effective karena serverless dan Anda hanya membayar per data yang di-scan. Dengan fungsi date_parse dan CASE statements, Anda bisa mendeteksi format dan mengkonversi ke standar. Hasilnya langsung tersedia sebagai tabel baru di Glue Data Catalog. Opsi A (Glue ETL) berfungsi tapi lebih mahal dengan DPU costs untuk job sederhana ini. Opsi B (Data Wrangler) dirancang untuk ML workflows dan overkill. Opsi D (DataBrew) memiliki biaya per-node yang lebih tinggi dibanding Athena untuk transformasi sederhana pada 200M records.
7
A data team uses Amazon SageMaker Data Wrangler to prepare features for a machine learning model. During the data cleaning phase, they notice that a numeric column (annual_income) has outliers where values exceed $10 million, which represent data entry errors. They want to cap these values at the 99th percentile and also impute missing values with the median. Which Data Wrangler capability should they use?
  • A. Use the Handle Outliers transform with the Winsorization method and Handle Missing Values with Impute option
  • B. Write custom PySpark code in the Data Wrangler custom transform step
  • C. Use the Featurize transform with normalization to automatically handle outliers and missing values
  • D. Export the dataset to a Jupyter notebook and handle cleaning with pandas
Jawaban Benar: A
SageMaker Data Wrangler menyediakan built-in transforms untuk Handle Outliers (termasuk Winsorization yang caps values pada percentile tertentu) dan Handle Missing Values (termasuk imputation dengan median, mean, atau custom value). Kedua operasi ini tersedia sebagai visual transforms tanpa coding. Opsi B (custom code) tidak perlu karena built-in transforms sudah tersedia. Opsi C (Featurize) untuk feature engineering seperti one-hot encoding, bukan outlier handling. Opsi D kehilangan integrasi dengan Data Wrangler pipeline.
8
A data engineer is building a data quality monitoring system for a multi-source data lake. The system needs to track data quality metrics over time, detect quality degradation trends, and provide a visual dashboard showing quality scores per source system. Quality rules are already defined in AWS Glue Data Quality. How should the engineer implement the monitoring dashboard?
  • A. Export Glue Data Quality evaluation results to S3, catalog with Glue, and visualize trends in Amazon QuickSight
  • B. Use CloudWatch custom metrics to publish quality scores and create CloudWatch dashboards
  • C. Store quality results in DynamoDB and build a custom web dashboard using API Gateway and Lambda
  • D. Use AWS Glue DataBrew profile job statistics as the quality monitoring dashboard
Jawaban Benar: A
AWS Glue Data Quality evaluation results dapat di-export ke S3 dalam format yang bisa di-catalog oleh Glue Crawler. Dengan data historis di S3, QuickSight bisa membuat dashboard interaktif yang menampilkan tren quality scores per source, trend degradation, dan drill-down ke specific rules. Ini memberikan visualisasi paling kaya dan interaktif. Opsi B (CloudWatch) memiliki keterbatasan visualization dan retention. Opsi C memerlukan custom development. Opsi D (DataBrew) hanya memberikan snapshot profiling, bukan time-series quality monitoring.
9
An e-commerce company receives product catalog data from 50 different suppliers via daily CSV uploads to Amazon S3. Each supplier uses slightly different column names and formats for the same information (e.g., "product_name", "item_title", "prod_desc" all represent the product title). The data engineer needs to standardize these into a unified schema. Which approach is MOST maintainable as new suppliers are added?
  • A. Create 50 separate AWS Glue ETL jobs, each with hardcoded column mappings for its supplier
  • B. Use AWS Glue DataBrew with a parameterized recipe that applies column mapping rules from a configuration table
  • C. Use AWS Glue ETL with a DynamicFrame and apply ApplyMapping transforms driven by a mapping configuration stored in DynamoDB
  • D. Use Amazon Athena views with COALESCE across all possible column names for each logical field
Jawaban Benar: C
Menggunakan Glue ETL dengan konfigurasi mapping di DynamoDB adalah pendekatan paling maintainable. Ketika supplier baru ditambahkan, cukup menambahkan entry di tabel konfigurasi tanpa mengubah kode ETL. DynamicFrame dengan ApplyMapping mendukung schema yang fleksibel. Opsi A (50 jobs) tidak scalable dan maintenance nightmare. Opsi B (DataBrew) memiliki keterbatasan parameterisasi dibanding Glue ETL. Opsi D (Athena COALESCE) menjadi sangat kompleks dengan 50+ supplier dan tidak bisa menangani transformasi format yang berbeda.
10
A data engineer needs to verify data consistency between a source Amazon RDS MySQL database and a target Amazon Redshift data warehouse after an initial full load migration. The tables contain 500 million rows each. The verification must confirm that row counts match, aggregate values (SUM, AVG) for numeric columns are identical, and there are no missing records. What is the MOST efficient verification approach?
  • A. Use AWS DMS data validation feature which automatically compares source and target data during migration tasks
  • B. Export both datasets to S3 and use a Glue ETL job to perform a full outer join to identify mismatches
  • C. Use Amazon Redshift federated queries to directly compare Redshift tables with RDS source tables
  • D. Write Python scripts to compute checksums on both databases and compare results
Jawaban Benar: A
AWS DMS memiliki fitur data validation bawaan yang secara otomatis membandingkan data antara source dan target selama migration task. Fitur ini melakukan row-by-row comparison, memeriksa row count, dan melaporkan mismatches. Ini paling efisien karena terintegrasi langsung dengan proses migrasi. Opsi B (full outer join) sangat resource-intensive untuk 500M rows. Opsi C (federated query) menambah load ke RDS production dan network transfer besar. Opsi D (custom script) memerlukan pengembangan dan tidak scalable untuk volume ini.
