1
A data engineer is building an ETL pipeline using AWS Glue to process semi-structured JSON data from Amazon S3. The source data contains nested arrays and fields with inconsistent data types across records. The engineer needs to resolve these schema inconsistencies before writing to a relational target. Which AWS Glue feature is MOST appropriate for handling this scenario?
  • A. Use AWS Glue DataBrew to manually define transformations for each nested field with the Relationalize transform and handle schema variations
  • B. Convert to a Spark DataFrame immediately and use explicit schema casting on all columns
  • C. Use Glue DynamicFrames with the Relationalize transform to flatten nested structures and handle schema variations
  • D. Create a Glue crawler to infer the schema and use the resulting table definition to force a fixed schema
Jawaban Benar: C
AWS Glue DynamicFrames dirancang khusus untuk menangani data semi-structured dengan schema yang tidak konsisten. DynamicFrame memiliki fitur "choice type" yang mendeteksi ketika field memiliki tipe data berbeda di record yang berbeda, dan transform Relationalize secara otomatis memecah nested arrays menjadi tabel relasional terpisah.

Opsi A: SALAH. Cocok untuk data preparation visual tetapi bukan solusi optimal untuk ETL pipeline otomatis dengan nested structures kompleks — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Akan gagal jika ada type mismatch karena memerlukan schema tetap.
Opsi C: BENAR.
Opsi D: SALAH. Hanya menginfer schema tetapi tidak menangani inkonsistensi saat processing.
2
A company runs large-scale data processing on Amazon EMR using a mix of On-Demand and Spot Instances. During peak processing hours, Spot Instance interruptions cause task failures and slow down the overall job. The team wants to improve resilience while maintaining cost optimization. Which EMR feature should the data engineer configure?
  • A. Use uniform instance groups with a single large instance type and increase the On-Demand percentage to 100%
  • B. Use EMR instance fleets with allocation strategy set to capacity-optimized and configure multiple instance types
  • C. Configure a single instance fleet with one Spot Instance type and enable automatic failover to On-Demand
  • D. Enable EMR managed scaling with only On-Demand instances in the core node group and configure multiple instance types
Jawaban Benar: B
EMR instance fleets dengan allocation strategy "capacity-optimized" memilih instance types dari Spot capacity pools yang paling tersedia, mengurangi kemungkinan interruption. Dengan mengonfigurasi multiple instance types, EMR memiliki lebih banyak opsi untuk mendapatkan kapasitas Spot yang stabil.

Opsi A: SALAH. Menghilangkan cost optimization sepenuhnya.
Opsi B: BENAR.
Opsi C: SALAH. Justru meningkatkan risiko interruption karena bergantung pada satu capacity pool saja.
Opsi D: SALAH. Juga menghilangkan keuntungan Spot pricing — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
3
A retail analytics team uses Amazon Redshift as their data warehouse. They have complex ETL transformations that aggregate sales data hourly from staging tables into summary tables. The transformations involve multiple JOINs and window functions. The team wants to simplify their ETL pipeline while keeping the summary data automatically refreshed. Which Redshift feature is BEST suited for this requirement?
  • A. Create materialized views with AUTO REFRESH enabled on the summary queries
  • B. Use Redshift stored procedures scheduled with Amazon EventBridge to rebuild summary tables
  • C. Create standard views and schedule a Lambda function to run REFRESH queries hourly
  • D. Implement external ETL using AWS Glue to perform the aggregations and write back to Redshift
Jawaban Benar: A
Materialized views di Amazon Redshift menyimpan hasil query yang sudah di-precompute dan mendukung AUTO REFRESH yang secara otomatis memperbarui data ketika tabel base berubah. Ini menyederhanakan ETL karena tidak memerlukan orchestration eksternal.

Opsi A: BENAR.
Opsi B: SALAH. Bekerja tetapi lebih kompleks dan tidak otomatis merespons perubahan data.
Opsi C: SALAH. Menambah kompleksitas dengan komponen eksternal dan standard views tidak menyimpan hasil.
Opsi D: SALAH. Menambah latensi dan biaya dengan memindahkan data keluar dan masuk kembali ke Redshift.
4
A data engineering team has hundreds of data sources in Amazon S3 with varying file formats (CSV, JSON, Parquet) and evolving schemas. They need to automatically discover and catalog these data sources so that downstream consumers can query them using Amazon Athena. The solution must detect schema changes without manual intervention. Which approach is MOST effective?
  • A. Write a Lambda function triggered by S3 events to parse file headers and update the Glue Data Catalog using the AWS SDK
  • B. Use Amazon Athena CREATE TABLE statements with explicit schemas for each data source
  • C. Deploy an AWS Glue ETL job that reads each source and writes schema metadata to a DynamoDB table for lookup with a schedule
  • D. Configure AWS Glue crawlers with a schedule and enable schema change detection with the "Update the table definition in the Data Catalog" option
Jawaban Benar: D
AWS Glue crawlers dirancang untuk otomatisasi schema discovery. Dengan jadwal crawl dan opsi "Update the table definition in the Data Catalog", crawler akan mendeteksi perubahan schema (kolom baru, tipe data berubah) dan memperbarui Data Catalog secara otomatis. Ini mendukung berbagai format file dan tidak memerlukan kode kustom.

Opsi A: SALAH. Memerlukan maintenance kode parsing untuk setiap format.
Opsi B: SALAH. Memerlukan update manual setiap kali schema berubah.
Opsi C: SALAH. Terlalu kompleks dan tidak terintegrasi langsung dengan Athena — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
5
A data engineer has an Amazon EMR cluster running batch processing jobs that complete within 2-3 hours each day. The cluster currently stays running 24/7, resulting in unnecessary costs. The engineer wants to optimize costs while ensuring jobs complete reliably without data loss. Which EMR feature should be implemented?
  • A. Convert all nodes to Spot Instances with a maximum bid price of 50% of On-Demand price
  • B. Use EMR on EKS to run jobs on a shared Kubernetes cluster configured for optimal performance and minimal operational overhead
  • C. Enable EMR auto-termination policy to automatically shut down the cluster after a specified idle period
  • D. Schedule manual cluster termination using a CloudWatch alarm based on CPU utilization
Jawaban Benar: C
EMR auto-termination policy secara otomatis menghentikan cluster setelah tidak ada pekerjaan yang berjalan selama periode idle yang ditentukan. Ini memastikan cluster hanya aktif saat diperlukan tanpa risiko kehilangan data karena termination hanya terjadi saat idle.

Opsi A: SALAH. Tidak mengatasi masalah cluster berjalan 24/7 dan bisa menyebabkan interruption saat job berjalan.
Opsi B: SALAH. Memerlukan redesign arsitektur yang signifikan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Bisa salah mentrigger termination saat CPU rendah tapi job masih berjalan (misalnya I/O intensive).
6
A financial institution needs to implement a complex ELT workflow in Amazon Redshift that involves loading raw transaction data, applying business rules for fraud detection, updating multiple dimension tables, and generating audit trails. The logic must be executed as a single atomic unit within Redshift. Which approach is MOST appropriate?
  • A. Use Amazon Redshift stored procedures with explicit transaction control (BEGIN/COMMIT/ROLLBACK)
  • B. Use Amazon Redshift materialized views with cascading refresh to implement the transformation chain
  • C. Execute individual SQL statements from an external AWS Glue Python shell job with error handling
  • D. Create a Step Functions workflow that executes each SQL statement via the Redshift Data API sequentially
Jawaban Benar: A
Redshift stored procedures mendukung procedural logic (IF/ELSE, loops, variables) dengan transaction control penuh (BEGIN/COMMIT/ROLLBACK), memungkinkan seluruh ELT workflow dieksekusi sebagai atomic unit di dalam Redshift. Ini ideal untuk business logic kompleks yang memerlukan konsistensi.

Opsi A: BENAR.
Opsi B: SALAH. Tidak mendukung update/insert ke dimension tables atau audit trail.
Opsi C: SALAH. Mengeksekusi dari luar Redshift, menambah latensi network dan tidak menjamin atomicity jika koneksi putus.
Opsi D: SALAH. Bersifat asynchronous dan tidak berjalan dalam single transaction.
7
A data engineer is developing and testing a new AWS Glue ETL script that processes complex transformations on a large dataset. The engineer needs an interactive development environment to iteratively test code, inspect intermediate DataFrames, and debug issues without waiting for full job deployments. Which AWS Glue feature provides the MOST efficient development experience?
  • A. Deploy the Glue job with a small subset of data and review CloudWatch Logs for output and inspect data at each step
  • B. Use AWS Glue interactive sessions to run code snippets with immediate feedback and inspect data at each step
  • C. Use a local development endpoint with a Zeppelin notebook connected to a long-running Glue dev environment
  • D. Write unit tests for each transformation and run them in a CI/CD pipeline before deployment
Jawaban Benar: B
AWS Glue interactive sessions menyediakan environment serverless on-demand untuk development interaktif. Engineer dapat menjalankan code snippets, melihat hasil intermediate, dan melakukan iterasi cepat tanpa provisioning infrastructure. Sessions dimulai dalam hitungan detik dan hanya dikenakan biaya saat digunakan.

Opsi A: SALAH. Memerlukan cycle deploy-run-check yang lambat — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Sudah deprecated dan mahal karena berjalan terus.
Opsi D: SALAH. Penting untuk production tetapi tidak menyediakan interactive debugging capability.
8
A media streaming company needs to run Apache Spark jobs to process viewing analytics data. The workloads are unpredictable — some days require processing terabytes of data while other days have minimal load. The company wants to avoid cluster management overhead and only pay for actual compute time used. Which AWS service is BEST suited for this requirement?
  • A. Amazon EMR on EKS with Kubernetes Cluster Autoscaler with fully managed infrastructure and automatic scaling
  • B. AWS Glue ETL jobs with auto-scaling DPUs configured at maximum capacity
  • C. Amazon EMR on EC2 with managed scaling enabled and minimum node count set to zero
  • D. Amazon EMR Serverless for on-demand Spark job execution without cluster provisioning
Jawaban Benar: D
Amazon EMR Serverless menghilangkan kebutuhan provisioning dan pengelolaan cluster sepenuhnya. Job berjalan on-demand dengan auto-scaling otomatis, dan perusahaan hanya membayar untuk compute resources yang digunakan selama job execution. Ini ideal untuk workloads yang tidak terprediksi.

Opsi A: SALAH. Masih memerlukan pengelolaan Kubernetes cluster yang menambah overhead operasional — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Memiliki batasan pada custom Spark configurations dan libraries.
Opsi C: SALAH. Tidak bisa scale to zero — minimum satu master node harus berjalan.
Opsi D: BENAR.
9
A data engineer is migrating an ETL pipeline from Apache Spark to AWS Glue. The existing pipeline uses Spark DataFrames extensively with complex operations like custom UDFs, broadcast joins, and window functions. Some of these operations are not natively supported by Glue DynamicFrames. What is the RECOMMENDED approach to handle this migration?
  • A. Use AWS Glue DataBrew instead, which supports all Spark DataFrame operations natively for complex operations
  • B. Run the existing Spark code on Amazon EMR instead of migrating to AWS Glue
  • C. Rewrite all transformations using only DynamicFrame APIs and avoid Spark DataFrame operations entirely
  • D. Convert DynamicFrames to Spark DataFrames for complex operations using .toDF(), then convert back to DynamicFrames using fromDF() when needed for Glue-specific features
Jawaban Benar: D
AWS Glue mendukung interoperabilitas antara DynamicFrames dan Spark DataFrames. Menggunakan .toDF() untuk konversi ke DataFrame memungkinkan penggunaan seluruh Spark API (UDFs, broadcast joins, window functions), sementara fromDF() memungkinkan konversi kembali ke DynamicFrame untuk memanfaatkan fitur Glue seperti bookmarks dan error handling.

Opsi A: SALAH. Salah karena DataBrew adalah tool visual yang tidak mendukung Spark operations — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Menghindari migrasi sepenuhnya tanpa mendapatkan keuntungan Glue (serverless, bookmarks, catalog integration).
Opsi C: SALAH. Membatasi fungsionalitas karena DynamicFrame API lebih terbatas.
Opsi D: BENAR.
10
A healthcare company uses Amazon Redshift to analyze patient visit data. They need to implement an ELT workflow where raw data is loaded into staging tables, then transformed using complex SQL with multiple CTEs, temporary tables, and conditional logic. The workflow must handle errors gracefully and provide detailed logging. The team prefers keeping all processing within Redshift. Which combination of Redshift features provides the MOST complete solution?
  • A. Redshift Spectrum external tables combined with Lambda functions for error handling configured for optimal performance and minimal operational overhead
  • B. Scheduled queries with SNS notifications combined with Redshift audit logging
  • C. Stored procedures with exception handling (BEGIN...EXCEPTION...END) combined with system tables (STL_LOAD_ERRORS, SVL_QLOG) for logging
  • D. Materialized views with AUTO REFRESH combined with Amazon CloudWatch alarms for error detection
Jawaban Benar: C
Redshift stored procedures mendukung exception handling (BEGIN...EXCEPTION...END blocks), conditional logic (IF/ELSE), loops, variabel, CTEs, dan temporary tables — semua dalam satu procedural unit. System tables seperti STL_LOAD_ERRORS dan SVL_QLOG menyediakan detailed logging native di Redshift. Ini memenuhi semua kebutuhan tanpa keluar dari Redshift.

Opsi A: SALAH. Membawa processing ke luar Redshift — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Tidak memiliki exception handling atau conditional logic yang diperlukan.
Opsi C: BENAR.
Opsi D: SALAH. Tidak mendukung procedural logic atau error handling.
