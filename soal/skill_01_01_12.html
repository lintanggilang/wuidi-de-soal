A data engineer is building a real-time pipeline that calculates a running average of sensor readings over a 5-minute window. Each new reading must be combined with previous readings to compute the average. Which type of processing does this represent?
  • A. Stateful processing — the pipeline must maintain state (accumulated values and count) across multiple events to compute the running average
  • B. Stateless processing with external lookup configured for optimal performance and minimal operational overhead, satisfying all of the stated requirements with minimal effort
  • C. Batch processing — the data must be collected before processing, satisfying all of the stated requirements with minimal effort
  • D. Stateless processing — each record is processed independently, making the data queryable within seconds of arrival and minimizing end-to-end processing latency
Jawaban Benar: A
Running average membutuhkan akumulasi nilai dari multiple events sebelumnya (sum dan count). State ini harus dipertahankan antar pemrosesan event. Ini adalah definisi klasik stateful processing — output bergantung pada input saat ini DAN state dari input sebelumnya.

Opsi A: BENAR.
Opsi B: SALAH. Contradictory — external lookup bisa stateful — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Bisa stateless tapi pertanyaannya tentang real-time pipeline.
Opsi D: SALAH. Salah karena setiap event tidak bisa diproses tanpa context dari event sebelumnya.

#Lambda#Kinesis#DynamoDB
A Lambda function processes events from a Kinesis stream. Each event contains a user's location coordinates. The function converts coordinates to an address using a geocoding API and writes the enriched record to DynamoDB. Is this processing stateful or stateless, and why?
  • A. Stateless — each event is processed independently; the function does not need to remember any information from previous events
  • B. Stateless — because Lambda functions are inherently stateless, transforming records into the required target format and reducing day-to-day operational effort
  • C. Stateful — the function calls an external API, creating a dependency, validating and cleansing each record before delivery
  • D. Stateful — the function writes to DynamoDB configured for optimal performance and minimal operational overhead, applying schema conversion and enrichment inline
Jawaban Benar: A
Processing ini stateless karena setiap event diproses secara independen — output (enriched record) hanya bergantung pada input saat ini (coordinates), bukan pada event sebelumnya. External API call dan DynamoDB write tidak membuat processing stateful; mereka adalah side effects. Stateful berarti output bergantung pada accumulated state dari multiple events.

Opsi A: BENAR.
Opsi B: SALAH. Alasannya tidak tepat — Lambda bisa melakukan stateful processing jika menggunakan external state store.
Opsi C: SALAH. Salah — external dependency bukan definisi stateful.
Opsi D: SALAH. Salah — writing output bukan state — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

#Lambda#Kinesis#Firehose#DynamoDB
A fraud detection system processes financial transactions in real-time. It needs to flag a transaction as suspicious if a user makes more than 5 transactions in different countries within 1 hour. Which approach correctly implements this stateful detection?
  • A. Use a stateless filter in Amazon Data Firehose transformation with keyed state and a 1-hour event-time window grouped by user_id
  • B. Use Kinesis Data Analytics SQL with a simple SELECT query, making the data queryable within seconds of arrival
  • C. Use Apache Flink (Amazon Managed Service for Apache Flink) with keyed state and a 1-hour event-time window grouped by user_id
  • D. Use a Lambda function that queries DynamoDB for the user's recent transaction count each time, minimizing end-to-end processing latency
Jawaban Benar: C
Apache Flink excels at stateful stream processing. Keyed state (grouped by user_id) memungkinkan Flink melacak jumlah transaksi per user dalam windowed time frame. Event-time processing menangani late-arriving events. Flink mengelola state secara internal dengan checkpointing untuk fault tolerance.

Opsi A: SALAH. Hanya untuk transformasi record-by-record stateless — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Tidak memiliki state management yang robust.
Opsi C: BENAR.
Opsi D: SALAH. Bisa bekerja tapi menambah latency DynamoDB lookup setiap transaction dan race conditions.

A data engineer needs to choose between stateful and stateless processing for a data pipeline. Which scenario is BEST suited for stateless processing?
  • A. Detecting sequences of failed login attempts across multiple events, satisfying strict compliance and audit requirements
  • B. Computing a customer's lifetime value from all their purchase history
  • C. Converting each JSON record's date field from US format to ISO 8601 format
  • D. Counting unique visitors per website session configured for optimal performance
Jawaban Benar: C
Konversi format tanggal adalah operasi per-record yang hanya membutuhkan data dalam record itu sendiri. Tidak perlu context dari record lain — ini stateless.

Opsi A: SALAH. Membutuhkan tracking sequence events sebelumnya (state).
Opsi B: SALAH. Membutuhkan akumulasi dari semua purchases (state).
Opsi C: BENAR.
Opsi D: SALAH. Membutuhkan tracking unique users (state) — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

#Lambda#Kinesis
A streaming pipeline uses AWS Lambda to process Kinesis records with tumbling window aggregation (5-minute windows). The Lambda function accumulates state across invocations within the window. What happens to the in-progress state if the Lambda function is scaled up (new execution environments added)?
  • A. Each execution environment starts with fresh state regardless of previous invocations, handling peak volume without any manual intervention and meeting the latency and throughput goals of the design
  • B. State is shared across all execution environments using shared memory with partition-level ordering and dedicated throughput, handling peak volume without any manual intervention and reducing day-to-day operational effort
  • C. Lambda Kinesis tumbling windows maintain state per shard; new execution environments for the SAME shard receive the accumulated state from previous invocations via the event's state field
  • D. State is lost when new execution environments are created, scaling horizontally as ingestion throughput keeps growing and scaling elastically to millions of events per second
Jawaban Benar: C
Lambda tumbling windows mengelola state per shard secara internal. Setiap invocation menerima state sebelumnya via event payload (field 'state') dan mengembalikan state yang diperbarui di response. Lambda service mengelola penyimpanan state antar invocations. State ini per-shard sehingga tidak terpengaruh scaling.

Opsi A: SALAH. Salah — state diteruskan melalui event.
Opsi B: SALAH. Tidak ada — state per-shard — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Salah karena Lambda service menyimpan state di antara invocations.

#S3
A data engineer is designing a pipeline where the processing logic must survive failures without data loss. The pipeline calculates running totals. In the context of stateful processing, which mechanism ensures state is not lost during a failure?
  • A. Increasing the number of processing nodes for redundancy, satisfying all of the stated requirements with minimal effort and providing exactly-once processing semantics
  • B. Using in-memory caching for faster state access configured for optimal performance and minimal operational overhead, handling the described workload reliably at scale
  • C. Implementing retry logic in the producer to resend failed records, handling the described workload reliably at scale and minimizing end-to-end processing latency
  • D. Checkpointing — periodically saving the current state to durable storage so processing can resume from the last checkpoint after failure
Jawaban Benar: D
Checkpointing adalah mekanisme utama untuk fault-tolerant stateful processing. Framework seperti Apache Flink melakukan periodic checkpoints yang menyimpan state ke durable storage (S3). Setelah failure, processing resume dari checkpoint terakhir dengan state yang intact.

Opsi A: SALAH. Tidak menjamin state preservation.
Opsi B: SALAH. Hilang saat failure — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Mengirim ulang records tapi state yang terakumulasi tetap hilang tanpa checkpoint.
Opsi D: BENAR.

#Glue#Redshift#Kinesis#S3
A company has two data pipelines. Pipeline A uses AWS Glue to read files from S3, transform each record (type casting, field renaming), and write to Redshift. Pipeline B uses Apache Flink to compute session-based user metrics from a Kinesis stream using event-time windows. Which statement correctly characterizes these pipelines?
  • A. Both pipelines are stateless because they use managed services, meeting the latency and throughput goals of the design
  • B. Pipeline A is primarily stateless (record-level transformations), while Pipeline B is stateful (requires maintaining session state across events)
  • C. Both pipelines are stateful because they write to persistent storage configured for optimal performance and minimal operational overhead
  • D. Pipeline A is stateful because Glue maintains job bookmarks, Pipeline B is stateless, validating and cleansing each record before delivery
Jawaban Benar: B
Pipeline A melakukan transformasi per-record (type casting, rename) — setiap record diproses independen dari yang lain = stateless processing. Pipeline B menghitung session metrics yang membutuhkan tracking events per user session over time = stateful processing.

Opsi A: SALAH. Salah — managed services bisa stateful.
Opsi B: BENAR.
Opsi C: SALAH. Salah — writing to storage adalah output, bukan definisi stateful processing — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Salah — job bookmarks adalah metadata tracking untuk incremental processing, bukan processing state dalam konteks stateful transactions.

#Kinesis
A data engineer needs to implement exactly-once semantics for a stateful streaming pipeline that processes payment transactions. The pipeline uses Apache Flink on Amazon Managed Service for Apache Flink. Which combination of Flink features provides exactly-once guarantees?
  • A. Use at-least-once checkpointing with deduplication in the sink, handling the described workload reliably at scale
  • B. Enable checkpointing with exactly-once mode and use two-phase commit sink connectors for external systems
  • C. Disable checkpointing and rely on Kinesis exactly-once delivery, requiring no servers to manage or scale manually
  • D. Set parallelism to 1 to process one record at a time with exactly-once mode and use two-phase commit sink connectors
Jawaban Benar: B
Flink's exactly-once semantics membutuhkan: (1) Checkpointing dalam exactly-once mode yang menjamin state consistency, (2) Two-phase commit (2PC) sink connectors yang mengoordinasikan commit ke external systems dengan Flink checkpoints. Kombinasi ini memastikan setiap record diproses dan output tepat satu kali.

Opsi A: SALAH. Bekerja tapi bukan exactly-once native.
Opsi B: BENAR.
Opsi C: SALAH. Tanpa checkpointing, Flink tidak bisa recover state.
Opsi D: SALAH. Tidak menjamin exactly-once tanpa checkpointing — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

#DynamoDB
An application uses DynamoDB with transactions to transfer funds between accounts. The operation debits one account and credits another in a single transaction. If the transaction fails midway, both operations are rolled back. This is an example of which concept?
  • A. Eventually consistent transaction — both accounts will eventually be correct, satisfying all of the stated requirements with minimal effort
  • B. Stateless transaction — each account update is independent, integrating natively with the rest of the pipeline
  • C. Idempotent operation — the transfer can be retried safely with ACID properties — atomicity ensures both operations succeed or both fail
  • D. Stateful transaction with ACID properties — atomicity ensures both operations succeed or both fail, maintaining consistent state
Jawaban Benar: D
Transfer antar akun adalah stateful transaction — state (account balances) harus berubah secara atomik. DynamoDB TransactWriteItems menjamin atomicity: semua operasi dalam transaksi sukses atau semua dibatalkan. Ini ACID (Atomic, Consistent, Isolated, Durable).

Opsi A: SALAH. Bisa menyebabkan temporary inconsistency yang tidak acceptable untuk transfers.
Opsi B: SALAH. Salah — kedua operasi saling bergantung (bukan independent).
Opsi C: SALAH. Adalah property terpisah dari transactional semantics — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.

A data engineer is deciding between AWS Lambda and Apache Flink for a streaming use case. The use case requires maintaining a count of events per user over the last 30 minutes, with the count updated on every new event. Why is Flink more suitable than Lambda for this scenario?
  • A. Flink is always faster than Lambda for any streaming workload with RocksDB backend), handling the described workload reliably at scale and providing exactly-once processing semantics
  • B. Flink natively manages state (per-key state with RocksDB backend), supports event-time windows, and provides consistent state checkpointing; Lambda requires external state stores adding latency and complexity
  • C. Lambda cannot process streaming data from Kinesis, satisfying all of the stated requirements with minimal effort and meeting the latency and throughput goals of the design
  • D. Lambda is limited to stateless processing and cannot maintain any form of state, satisfying all of the stated requirements with minimal effort and minimizing end-to-end processing latency
Jawaban Benar: B
Apache Flink dirancang untuk stateful stream processing. State per-key disimpan locally (RocksDB) di memory/disk worker, memberikan low-latency access. Checkpointing menjamin durability. Window operators (sliding 30-min window) built-in. Lambda BISA melakukan stateful processing (tumbling windows) tapi terbatas — hanya tumbling bukan sliding windows, membutuhkan external state store (DynamoDB) untuk custom state, yang menambah latency pada setiap event.

Opsi A: SALAH. Over-generalization — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Salah — Lambda bisa consume Kinesis.
Opsi D: SALAH. Salah — Lambda mendukung tumbling window state.
