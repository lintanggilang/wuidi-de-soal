A company stores daily sales reports as CSV files in an Amazon S3 bucket with the prefix `sales/year=2024/month=01/day=01/`. The data engineering team needs to read these files into a data lake and make them queryable via Amazon Athena. The schema changes occasionally. Which approach BEST handles this scenario?
  • A. Use an AWS Glue crawler to catalog the data and define the table schema automatically
  • B. Copy the data to DynamoDB and create a secondary index for queries and define the table schema automatically
  • C. Use Amazon Redshift Spectrum to query the S3 data directly
  • D. Manually create an Athena table with a fixed schema pointing to the S3 prefix
Jawaban Benar: A
AWS Glue crawler secara otomatis mendeteksi schema dari data di S3 dan membuat/memperbarui tabel di Glue Data Catalog. Ketika schema berubah, crawler akan mendeteksi perubahan tersebut.

Opsi A: BENAR.
Opsi B: SALAH. Bukan solusi untuk analitik batch data — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Membutuhkan Redshift cluster yang mahal untuk use case ini.
Opsi D: SALAH. Tidak menangani perubahan schema.
2
A data engineer needs to ingest data from a Salesforce CRM system into Amazon S3 on a scheduled basis. The data should be incrementally loaded based on the last modified timestamp. The solution must require minimal custom code. Which AWS service is MOST appropriate?
  • A. AWS Lambda with a custom Python script calling Salesforce REST API
  • B. AWS Glue with a custom PySpark script using Salesforce JDBC connector
  • C. AWS DMS with Salesforce as a source endpoint and incremental transfer
  • D. Amazon AppFlow with a scheduled flow and incremental transfer
Jawaban Benar: D
Amazon AppFlow dirancang khusus untuk integrasi data dari SaaS applications seperti Salesforce ke AWS services. AppFlow mendukung scheduled flows dan incremental data transfer berdasarkan field filter (seperti last modified date), tanpa kode custom.

Opsi A: SALAH. Membutuhkan banyak custom code untuk pagination, error handling, dll.
Opsi B: SALAH. Membutuhkan custom code dan konfigurasi JDBC.
Opsi C: SALAH. Tidak mendukung Salesforce sebagai source natively — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
3
An organization has a 50 TB Oracle data warehouse on-premises. They want to perform a one-time full load migration to Amazon Redshift, followed by ongoing CDC (Change Data Capture) replication. Which service combination provides the MOST complete solution?
  • A. AWS DataSync for full load and AWS DMS for ongoing CDC
  • B. AWS Glue for full load ETL and Amazon AppFlow for ongoing changes
  • C. AWS DMS for full load and CDC, with AWS SCT for schema conversion
  • D. Amazon EMR with Sqoop for full load and custom Spark streaming for CDC
Jawaban Benar: C
AWS DMS mendukung full load dan ongoing replication (CDC) dari Oracle ke Redshift. AWS SCT (Schema Conversion Tool) mengkonversi schema Oracle ke format yang kompatibel dengan Redshift. Kombinasi ini adalah solusi paling lengkap.

Opsi A: SALAH. Hanya untuk file transfer, bukan database migration.
Opsi B: SALAH. Tidak mendukung CDC dari Oracle.
Opsi C: BENAR.
Opsi D: SALAH. Terlalu kompleks.
4
A data engineer needs to process 500 GB of JSON files stored in Amazon S3. The files need to be read, filtered, and aggregated before being loaded into a Redshift table. The processing job runs once daily and must complete within 2 hours. Cost optimization is a priority. Which approach is MOST cost-effective?
  • A. Amazon EMR cluster with Spot Instances running Apache Spark
  • B. AWS Glue ETL job with auto-scaling enabled
  • C. AWS Lambda functions processing files in parallel
  • D. Amazon Redshift COPY command to load raw JSON, then transform with SQL
Jawaban Benar: A
Amazon EMR dengan Spot Instances memberikan harga hingga 90% lebih murah dari On-Demand untuk workload yang toleran terhadap interupsi. Untuk job harian 500 GB yang harus selesai dalam 2 jam, EMR Spark dengan Spot sangat cost-effective.

Opsi A: BENAR.
Opsi B: SALAH. Memiliki biaya DPU per jam yang lebih tinggi.
Opsi C: SALAH. Memiliki batas memory 10 GB dan timeout 15 menit, tidak cocok untuk 500 GB data.
Opsi D: SALAH. Memuat semua data mentah ke Redshift dulu yang tidak efisien dan menambah biaya storage.
5
A company uses Amazon Redshift as their data warehouse. A data engineer needs to regularly load large datasets from S3 into Redshift. The data files are in Parquet format and are organized with Hive-style partitioning. Which loading method provides the BEST performance?
  • A. Use INSERT INTO...SELECT from an external table using Redshift Spectrum
  • B. Use AWS Glue to read from S3 and write to Redshift using a JDBC connection
  • C. Use the COPY command with a manifest file specifying the exact files to load
  • D. Use the Redshift Data API to execute batch INSERT statements with a manifest file
Jawaban Benar: C
COPY command adalah metode paling efisien untuk loading data ke Redshift dari S3. Dengan manifest file, Anda dapat mengontrol file mana yang dimuat, mencegah duplikasi, dan memastikan semua file yang diperlukan ada. COPY membaca Parquet natively dan melakukan parallel loading dari semua file.

Opsi A: SALAH. Bagus untuk query tapi INSERT INTO dari external table lebih lambat dari COPY langsung.
Opsi B: SALAH. Jauh lebih lambat karena single-connection writing.
Opsi C: BENAR.
Opsi D: SALAH. Adalah metode paling lambat — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
6
A data engineer needs to read data from an Amazon RDS MySQL database and load it into an S3 data lake. The table contains 200 million rows. The engineer wants to parallelize the read operation to minimize extraction time without impacting the production database. Which approach is BEST?
  • A. Use AWS Glue with a JDBC connection and configure hashexpression or hashfield for parallel reads from a read replica
  • B. Use AWS DMS full load task pointing to the primary instance with a JDBC connection for parallel reads from a read replica
  • C. Use mysqldump to export the data and upload to S3
  • D. Use Amazon EMR with a single Spark executor reading via JDBC
Jawaban Benar: A
AWS Glue mendukung parallel reads dari JDBC sources menggunakan hashexpression atau hashfield, yang membagi tabel menjadi beberapa partisi yang dibaca secara paralel. Menggunakan read replica memastikan produksi tidak terganggu.

Opsi A: BENAR.
Opsi B: SALAH. Membebani instance produksi — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Adalah single-threaded dan mempengaruhi database.
Opsi D: SALAH. Tidak memanfaatkan paralelisme.
7
A retail company receives product catalog updates from 50 suppliers daily via different file formats (CSV, JSON, XML) dropped into separate S3 prefixes. The data engineer needs to create a unified pipeline that reads all formats and loads them into a single normalized table. Which service provides the MOST efficient solution?
  • A. AWS Lambda functions triggered by S3 events for each prefix
  • B. Amazon EMR with custom Spark code for each file format and a unified ETL job with dynamic frames
  • C. Amazon Athena CTAS queries for each format
  • D. AWS Glue ETL with multiple crawlers for each format and a unified ETL job with dynamic frames
Jawaban Benar: D
AWS Glue crawler mendeteksi schema berbagai format (CSV, JSON, dll.) dan membuat tabel di Glue Data Catalog. Glue ETL dengan DynamicFrames dapat membaca dari berbagai format, menerapkan mapping dan transformasi, lalu menulis ke output yang terstandarisasi. Ini solusi paling efisien karena fully managed.

Opsi A: SALAH. Sulit untuk handling XML parsing dan normalisasi kompleks dalam batas 15 menit.
Opsi B: SALAH. Membutuhkan banyak custom code — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Tidak mendukung XML natively.
Opsi D: BENAR.
8
A data engineer is using AWS Lambda to read batch files from Amazon S3 for processing. The Lambda function times out when processing files larger than 500 MB. The engineer cannot change the overall architecture. What modification should be made to handle large files?
  • A. Mount an Amazon EFS volume to Lambda and stream the file to EFS first
  • B. Use S3 byte-range fetches to process the file in chunks within Lambda
  • C. Configure Lambda with 10 GB memory and use multi-threaded processing
  • D. Increase Lambda timeout to the maximum of 15 minutes and use S3 Select to read only required columns
Jawaban Benar: B
S3 byte-range fetches memungkinkan Lambda membaca file secara bertahap (chunk by chunk) tanpa memuat seluruh file ke memory. Ini menghindari timeout karena setiap invocation memproses sebagian data.

Opsi A: SALAH. Menambah latency dan tidak menyelesaikan timeout.
Opsi B: BENAR.
Opsi C: SALAH. Tidak menyelesaikan masalah timeout karena membaca file besar dari S3 tetap memakan waktu lama.
Opsi D: SALAH. Berguna tapi hanya jika yang dibutuhkan filtering kolom, bukan masalah ukuran file keseluruhan.
9
A company needs to batch-ingest data from a third-party PostgreSQL database hosted outside of AWS. The database is only accessible through a private VPN connection. The data must be loaded into an S3 data lake daily. Which solution correctly handles the network connectivity requirement?
  • A. AWS DMS with a replication instance in a public subnet configured for optimal performance and minimal operational overhead
  • B. AWS Glue ETL job with a Glue connection configured to use a VPC with VPN connectivity to the on-premises network
  • C. Amazon AppFlow with a custom connector for the PostgreSQL database
  • D. AWS Lambda in a VPC with NAT Gateway connecting through AWS Site-to-Site VPN
Jawaban Benar: B
AWS Glue connections dapat dikonfigurasi untuk berjalan dalam VPC yang memiliki koneksi VPN ke jaringan on-premises/third-party. Glue ETL job akan menggunakan ENI di subnet VPC tersebut dan bisa mengakses database melalui VPN tunnel.

Opsi A: SALAH. Tidak bisa mengakses database private tanpa VPN connectivity yang tepat — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Tidak mendukung koneksi ke PostgreSQL on-premises melalui VPN.
Opsi D: SALAH. Bisa bekerja tapi memiliki batas timeout 15 menit untuk data besar.
10
A media company stores video metadata in Amazon S3 across multiple AWS accounts. A central data engineering team needs to read data from S3 buckets in 10 different accounts and consolidate it into a single data lake account. What is the MOST scalable approach to manage cross-account S3 access?
  • A. Use AWS Organizations with Service Control Policies to grant blanket access
  • B. Configure S3 bucket policies in each account granting access to an IAM role in the central account, and use AWS Glue with an assumed role
  • C. Create IAM users with access keys in each account and store credentials in Secrets Manager
  • D. Copy all data to the central account using S3 Replication rules with an assumed role and use AWS Glue with an assumed role
Jawaban Benar: B
Cross-account S3 access paling scalable menggunakan bucket policies yang mengizinkan IAM role dari central account. AWS Glue dapat assume role ini untuk membaca data langsung dari bucket di akun lain tanpa copying data.

Opsi A: SALAH. Hanya untuk membatasi/deny permissions, bukan grant access.
Opsi B: BENAR.
Opsi C: SALAH. Tidak scalable dan merupakan anti-pattern keamanan.
Opsi D: SALAH. Menduplikasi data dan menambah biaya storage — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
