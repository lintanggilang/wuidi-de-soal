A company stores daily sales reports as CSV files in an Amazon S3 bucket with the prefix `sales/year=2024/month=01/day=01/`. The data engineering team needs to read these files into a data lake and make them queryable via Amazon Athena. The schema changes occasionally. Which approach BEST handles this scenario?
  • A. Use an AWS Glue crawler to catalog the data and define the table schema automatically
  • B. Manually create an Athena table with a fixed schema pointing to the S3 prefix
  • C. Use Amazon Redshift Spectrum to query the S3 data directly
  • D. Copy the data to DynamoDB and create a secondary index for queries
Jawaban Benar: A
AWS Glue crawler secara otomatis mendeteksi schema dari data di S3 dan membuat/memperbarui tabel di Glue Data Catalog. Ketika schema berubah, crawler akan mendeteksi perubahan tersebut. Opsi B tidak menangani perubahan schema. Opsi C (Redshift Spectrum) membutuhkan Redshift cluster yang mahal untuk use case ini. Opsi D (DynamoDB) bukan solusi untuk analitik batch data.
2
A data engineer needs to ingest data from a Salesforce CRM system into Amazon S3 on a scheduled basis. The data should be incrementally loaded based on the last modified timestamp. The solution must require minimal custom code. Which AWS service is MOST appropriate?
  • A. Amazon AppFlow with a scheduled flow and incremental transfer
  • B. AWS Glue with a custom PySpark script using Salesforce JDBC connector
  • C. AWS Lambda with a custom Python script calling Salesforce REST API
  • D. AWS DMS with Salesforce as a source endpoint
Jawaban Benar: A
Amazon AppFlow dirancang khusus untuk integrasi data dari SaaS applications seperti Salesforce ke AWS services. AppFlow mendukung scheduled flows dan incremental data transfer berdasarkan field filter (seperti last modified date), tanpa kode custom. Opsi B membutuhkan custom code dan konfigurasi JDBC. Opsi C membutuhkan banyak custom code untuk pagination, error handling, dll. Opsi D (DMS) tidak mendukung Salesforce sebagai source natively.
3
An organization has a 50 TB Oracle data warehouse on-premises. They want to perform a one-time full load migration to Amazon Redshift, followed by ongoing CDC (Change Data Capture) replication. Which service combination provides the MOST complete solution?
  • A. AWS DMS for full load and CDC, with AWS SCT for schema conversion
  • B. AWS Glue for full load ETL and Amazon AppFlow for ongoing changes
  • C. Amazon EMR with Sqoop for full load and custom Spark streaming for CDC
  • D. AWS DataSync for full load and AWS DMS for ongoing CDC
Jawaban Benar: A
AWS DMS mendukung full load dan ongoing replication (CDC) dari Oracle ke Redshift. AWS SCT (Schema Conversion Tool) mengkonversi schema Oracle ke format yang kompatibel dengan Redshift. Kombinasi ini adalah solusi paling lengkap. Opsi B tidak mendukung CDC dari Oracle. Opsi C terlalu kompleks. Opsi D (DataSync) hanya untuk file transfer, bukan database migration.
4
A data engineer needs to process 500 GB of JSON files stored in Amazon S3. The files need to be read, filtered, and aggregated before being loaded into a Redshift table. The processing job runs once daily and must complete within 2 hours. Cost optimization is a priority. Which approach is MOST cost-effective?
  • A. AWS Glue ETL job with auto-scaling enabled
  • B. Amazon EMR cluster with Spot Instances running Apache Spark
  • C. AWS Lambda functions processing files in parallel
  • D. Amazon Redshift COPY command to load raw JSON, then transform with SQL
Jawaban Benar: B
Amazon EMR dengan Spot Instances memberikan harga hingga 90% lebih murah dari On-Demand untuk workload yang toleran terhadap interupsi. Untuk job harian 500 GB yang harus selesai dalam 2 jam, EMR Spark dengan Spot sangat cost-effective. Opsi A (Glue) memiliki biaya DPU per jam yang lebih tinggi. Opsi C (Lambda) memiliki batas memory 10 GB dan timeout 15 menit, tidak cocok untuk 500 GB data. Opsi D memuat semua data mentah ke Redshift dulu yang tidak efisien dan menambah biaya storage.
5
A company uses Amazon Redshift as their data warehouse. A data engineer needs to regularly load large datasets from S3 into Redshift. The data files are in Parquet format and are organized with Hive-style partitioning. Which loading method provides the BEST performance?
  • A. Use the COPY command with a manifest file specifying the exact files to load
  • B. Use INSERT INTO...SELECT from an external table using Redshift Spectrum
  • C. Use AWS Glue to read from S3 and write to Redshift using a JDBC connection
  • D. Use the Redshift Data API to execute batch INSERT statements
Jawaban Benar: A
COPY command adalah metode paling efisien untuk loading data ke Redshift dari S3. Dengan manifest file, Anda dapat mengontrol file mana yang dimuat, mencegah duplikasi, dan memastikan semua file yang diperlukan ada. COPY membaca Parquet natively dan melakukan parallel loading dari semua file. Opsi B (Spectrum) bagus untuk query tapi INSERT INTO dari external table lebih lambat dari COPY langsung. Opsi C (Glue JDBC) jauh lebih lambat karena single-connection writing. Opsi D (INSERT statements) adalah metode paling lambat.
6
A data engineer needs to read data from an Amazon RDS MySQL database and load it into an S3 data lake. The table contains 200 million rows. The engineer wants to parallelize the read operation to minimize extraction time without impacting the production database. Which approach is BEST?
  • A. Use AWS Glue with a JDBC connection and configure hashexpression or hashfield for parallel reads from a read replica
  • B. Use mysqldump to export the data and upload to S3
  • C. Use AWS DMS full load task pointing to the primary instance
  • D. Use Amazon EMR with a single Spark executor reading via JDBC
Jawaban Benar: A
AWS Glue mendukung parallel reads dari JDBC sources menggunakan hashexpression atau hashfield, yang membagi tabel menjadi beberapa partisi yang dibaca secara paralel. Menggunakan read replica memastikan produksi tidak terganggu. Opsi B (mysqldump) adalah single-threaded dan mempengaruhi database. Opsi C (DMS ke primary) membebani instance produksi. Opsi D (single executor) tidak memanfaatkan paralelisme.
7
A retail company receives product catalog updates from 50 suppliers daily via different file formats (CSV, JSON, XML) dropped into separate S3 prefixes. The data engineer needs to create a unified pipeline that reads all formats and loads them into a single normalized table. Which service provides the MOST efficient solution?
  • A. AWS Glue ETL with multiple crawlers for each format and a unified ETL job with dynamic frames
  • B. Amazon EMR with custom Spark code for each file format
  • C. AWS Lambda functions triggered by S3 events for each prefix
  • D. Amazon Athena CTAS queries for each format
Jawaban Benar: A
AWS Glue crawler mendeteksi schema berbagai format (CSV, JSON, dll.) dan membuat tabel di Glue Data Catalog. Glue ETL dengan DynamicFrames dapat membaca dari berbagai format, menerapkan mapping dan transformasi, lalu menulis ke output yang terstandarisasi. Ini solusi paling efisien karena fully managed. Opsi B membutuhkan banyak custom code. Opsi C (Lambda) sulit untuk handling XML parsing dan normalisasi kompleks dalam batas 15 menit. Opsi D (Athena CTAS) tidak mendukung XML natively.
8
A data engineer is using AWS Lambda to read batch files from Amazon S3 for processing. The Lambda function times out when processing files larger than 500 MB. The engineer cannot change the overall architecture. What modification should be made to handle large files?
  • A. Increase Lambda timeout to the maximum of 15 minutes and use S3 Select to read only required columns
  • B. Mount an Amazon EFS volume to Lambda and stream the file to EFS first
  • C. Configure Lambda with 10 GB memory and use multi-threaded processing
  • D. Use S3 byte-range fetches to process the file in chunks within Lambda
Jawaban Benar: D
S3 byte-range fetches memungkinkan Lambda membaca file secara bertahap (chunk by chunk) tanpa memuat seluruh file ke memory. Ini menghindari timeout karena setiap invocation memproses sebagian data. Opsi A (S3 Select) berguna tapi hanya jika yang dibutuhkan filtering kolom, bukan masalah ukuran file keseluruhan. Opsi B (EFS) menambah latency dan tidak menyelesaikan timeout. Opsi C (10 GB memory) tidak menyelesaikan masalah timeout karena membaca file besar dari S3 tetap memakan waktu lama.
9
A company needs to batch-ingest data from a third-party PostgreSQL database hosted outside of AWS. The database is only accessible through a private VPN connection. The data must be loaded into an S3 data lake daily. Which solution correctly handles the network connectivity requirement?
  • A. AWS Glue ETL job with a Glue connection configured to use a VPC with VPN connectivity to the on-premises network
  • B. Amazon AppFlow with a custom connector for the PostgreSQL database
  • C. AWS Lambda in a VPC with NAT Gateway connecting through AWS Site-to-Site VPN
  • D. AWS DMS with a replication instance in a public subnet
Jawaban Benar: A
AWS Glue connections dapat dikonfigurasi untuk berjalan dalam VPC yang memiliki koneksi VPN ke jaringan on-premises/third-party. Glue ETL job akan menggunakan ENI di subnet VPC tersebut dan bisa mengakses database melalui VPN tunnel. Opsi B (AppFlow) tidak mendukung koneksi ke PostgreSQL on-premises melalui VPN. Opsi C (Lambda) bisa bekerja tapi memiliki batas timeout 15 menit untuk data besar. Opsi D (DMS public subnet) tidak bisa mengakses database private tanpa VPN connectivity yang tepat.
10
A media company stores video metadata in Amazon S3 across multiple AWS accounts. A central data engineering team needs to read data from S3 buckets in 10 different accounts and consolidate it into a single data lake account. What is the MOST scalable approach to manage cross-account S3 access?
  • A. Configure S3 bucket policies in each account granting access to an IAM role in the central account, and use AWS Glue with an assumed role
  • B. Copy all data to the central account using S3 Replication rules
  • C. Use AWS Organizations with Service Control Policies to grant blanket access
  • D. Create IAM users with access keys in each account and store credentials in Secrets Manager
Jawaban Benar: A
Cross-account S3 access paling scalable menggunakan bucket policies yang mengizinkan IAM role dari central account. AWS Glue dapat assume role ini untuk membaca data langsung dari bucket di akun lain tanpa copying data. Opsi B (S3 Replication) menduplikasi data dan menambah biaya storage. Opsi C (SCPs) hanya untuk membatasi/deny permissions, bukan grant access. Opsi D (IAM users + access keys) tidak scalable dan merupakan anti-pattern keamanan.
