A data engineering team runs Apache Spark jobs on Amazon EKS for daily ETL processing. The jobs experience unpredictable memory usage spikes that cause OOMKilled errors. The team wants to handle these spikes without over-provisioning memory for all pods. Which EKS configuration BEST addresses this?
  • A. Use Horizontal Pod Autoscaler (HPA) to add more pods when memory is high, scaling horizontally as ingestion throughput keeps growing
  • B. Enable Kubernetes memory overcommit by setting requests to 0, absorbing sudden traffic spikes without throttling and applying schema conversion and enrichment inline
  • C. Set memory requests equal to limits for all Spark executor pods and limits based on historical usage patterns
  • D. Configure Vertical Pod Autoscaler (VPA) in "Auto" mode to adjust pod memory requests and limits based on historical usage patterns
Correct Answer: D
VPA menganalisis historical resource usage and automatically adjusts memory requests/limits for pods. In "Auto" mode, VPA will evict pods and restart mereka with right-sized resources. This is ideal for workloads with variable memory patterns.

Option A: INCORRECT. Adds pods but each pod still can OOM.
Option B: INCORRECT. Not secure and can menyebabkan node-level OOM.
Option C: INCORRECT. Mencegah bursting but memaksa over-provisioning — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: CORRECT.

A company runs data transformation tasks on Amazon ECS with Fargate. Each task processes a batch of files and the processing time varies from 5 minutes to 2 hours depending on file size. The company wants to minimize cost while maintaining performance. Which Fargate configuration strategy is MOST cost-effective?
  • A. Run all tasks on EC2 launch type with Reserved Instances for fault-tolerant batch tasks with retry logic
  • B. Use the maximum vCPU and memory configuration for all tasks to ensure they complete quickly
  • C. Configure a single large task definition to process all files sequentially, validating and cleansing each record before delivery
  • D. Use Fargate Spot for fault-tolerant batch tasks with retry logic, reserving Fargate On-Demand for time-critical tasks only
Correct Answer: D
Fargate Spot menawarkan diskon up to 70% dibanding On-Demand for workloads that toleran against interruption. Batch ETL tasks that has retry logic can memanfaatkan this. Tasks that time-critical still gunakan On-Demand.

Option A: INCORRECT. Adds operational overhead and not suitable for variable workloads — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Membuang resources and cost.
Option C: INCORRECT. Very slow and not memanfaatkan parallelism.
Option D: CORRECT.

A company uses Amazon ECS to run a containerized data processing application that reads from Amazon Kinesis. The application uses the Kinesis Client Library (KCL). There are 10 Kinesis shards. The ECS service needs to ensure exactly one KCL worker per shard for optimal processing. How should the service be configured?
  • A. Set desired count to 1 task with 10 threads inside the container, handling the described workload reliably at scale
  • B. Set desired count to 20 tasks for redundancy with one KCL worker per task, handling the described workload reliably at scale
  • C. Set the ECS service desired count to 10 tasks, matching the number of shards, with one KCL worker per task
  • D. Use ECS Service Auto Scaling based on CPU utilization, handling the described workload reliably at scale and keeping steady-state operating costs low
Correct Answer: C
KCL distributes shard leases among workers. By 10 shards, 10 tasks (workers) ensures each task processes correct 1 shard — beban terdistribusi merata. If satu task fails, KCL will redistribusi shard to remaining workers.

Option A: INCORRECT. Single point of failure, if task dies all processing stops.
Option B: INCORRECT. 10 tasks will idle because only ada 10 shards, membuang resources — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option C: CORRECT.
Option D: INCORRECT. Not tahu about shard count.
