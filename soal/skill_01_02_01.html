A data engineering team runs Apache Spark jobs on Amazon EKS for daily ETL processing. The jobs experience unpredictable memory usage spikes that cause OOMKilled errors. The team wants to handle these spikes without over-provisioning memory for all pods. Which EKS configuration BEST addresses this?
  • A. Configure Vertical Pod Autoscaler (VPA) in "Auto" mode to adjust pod memory requests and limits based on historical usage patterns
  • B. Set memory requests equal to limits for all Spark executor pods
  • C. Use Horizontal Pod Autoscaler (HPA) to add more pods when memory is high
  • D. Enable Kubernetes memory overcommit by setting requests to 0
Jawaban Benar: A
VPA menganalisis historical resource usage dan secara otomatis menyesuaikan memory requests/limits untuk pods. Dalam "Auto" mode, VPA akan evict pods dan restart mereka dengan right-sized resources. Ini ideal untuk workloads dengan variable memory patterns. Opsi B (requests=limits) mencegah bursting tapi memaksa over-provisioning. Opsi C (HPA) menambah pods tapi setiap pod tetap bisa OOM. Opsi D (requests=0) tidak aman dan bisa menyebabkan node-level OOM.
2
A company runs data transformation tasks on Amazon ECS with Fargate. Each task processes a batch of files and the processing time varies from 5 minutes to 2 hours depending on file size. The company wants to minimize cost while maintaining performance. Which Fargate configuration strategy is MOST cost-effective?
  • A. Use Fargate Spot for fault-tolerant batch tasks with retry logic, reserving Fargate On-Demand for time-critical tasks only
  • B. Use the maximum vCPU and memory configuration for all tasks to ensure they complete quickly
  • C. Run all tasks on EC2 launch type with Reserved Instances
  • D. Configure a single large task definition to process all files sequentially
Jawaban Benar: A
Fargate Spot menawarkan diskon hingga 70% dibanding On-Demand untuk workloads yang toleran terhadap interruption. Batch ETL tasks yang memiliki retry logic bisa memanfaatkan ini. Tasks yang time-critical tetap gunakan On-Demand. Opsi B (maximum config) membuang resources dan biaya. Opsi C (EC2 Reserved) menambah operational overhead dan tidak cocok untuk variable workloads. Opsi D (sequential processing) sangat lambat dan tidak memanfaatkan parallelism.
3
A data engineering team uses Amazon EKS to run Apache Flink stream processing. The Flink cluster has 10 TaskManager pods that need to communicate with each other for data shuffling. The team notices high network latency between pods. Which optimization reduces inter-pod network latency?
  • A. Use pod anti-affinity rules to spread pods across different Availability Zones for high availability
  • B. Configure pod affinity rules to co-locate TaskManager pods on the same node or within the same placement group
  • C. Increase the EKS cluster's VPC CIDR block for more IP addresses
  • D. Enable service mesh (Istio) for all pod-to-pod communication
Jawaban Benar: B
Pod affinity rules memastikan pods di-schedule pada node yang sama atau dekat secara fisik (same AZ, placement group). Ini mengurangi network latency untuk inter-pod communication yang heavy (seperti Flink data shuffling). Opsi A (anti-affinity) justru menyebarkan pods lebih jauh, meningkatkan latency. Opsi C (CIDR block) tidak mempengaruhi latency. Opsi D (service mesh) menambah overhead networking layer yang meningkatkan latency.
4
A company uses Amazon ECS with EC2 launch type for data processing. They need to run GPU-accelerated ML inference as part of their data pipeline. The GPU tasks run intermittently (2-3 hours per day). Which configuration minimizes cost while providing GPU when needed?
  • A. Create a separate ECS capacity provider with GPU instances using Auto Scaling that scales to 0 when no GPU tasks are pending
  • B. Keep GPU instances running 24/7 in the ECS cluster
  • C. Use Fargate with GPU task definitions
  • D. Run GPU workloads on a separate EKS cluster with always-on GPU nodes
Jawaban Benar: A
ECS capacity providers dengan managed scaling memungkinkan cluster auto-scale GPU instances berdasarkan pending tasks. Dengan scale-to-zero, GPU instances hanya berjalan saat ada tasks yang membutuhkan GPU (2-3 jam/hari), menghemat biaya signifikan. Opsi B (24/7) membuang biaya 21-22 jam per hari. Opsi C (Fargate) — Fargate tidak mendukung GPU instances. Opsi D (EKS 24/7) juga membuang biaya jika nodes selalu on.
5
A data pipeline on Amazon EKS processes large CSV files (10 GB each) that need to be read from Amazon S3, transformed, and written back to S3. The pods frequently experience disk pressure because the default ephemeral storage is insufficient. What is the MOST appropriate solution?
  • A. Attach Amazon EBS volumes as PersistentVolumes to the data processing pods for temporary storage during processing
  • B. Increase the node instance type to get more ephemeral storage
  • C. Stream data directly from S3 without writing to local disk
  • D. Mount Amazon EFS as shared storage for all pods
Jawaban Benar: A
EBS volumes sebagai PersistentVolumes memberikan storage yang bisa dikonfigurasi sesuai kebutuhan (size, IOPS). Untuk file 10GB yang perlu processing lokal, EBS memberikan performa I/O yang baik. Opsi B (larger instance) over-provisioning compute untuk masalah storage. Opsi C (streaming) tidak selalu feasible untuk transformasi yang membutuhkan random access ke seluruh file. Opsi D (EFS) memiliki latency lebih tinggi dari EBS dan mahal untuk temporary processing storage.

A data engineer is containerizing a Python-based ETL application that processes data using pandas. The application requires 8 GB of memory and 4 vCPUs during peak processing. The engineer needs to choose between ECS Fargate and ECS with EC2. The workload runs continuously 24/7. Which option is MORE cost-effective for this scenario?
  • A. ECS with EC2 launch type using Compute Savings Plans or Reserved Instances for the continuous workload
  • B. ECS Fargate with Compute Savings Plans
  • C. ECS Fargate Spot for cost savings
  • D. ECS with EC2 On-Demand instances
Jawaban Benar: A
Untuk workloads 24/7 yang continuous, EC2 dengan Savings Plans atau Reserved Instances memberikan diskon signifikan (hingga 72%) dibanding On-Demand. Dengan known fixed resource requirements, EC2 lebih murah dari Fargate pada sustained usage. Opsi B (Fargate + Savings) masih lebih mahal dari EC2 RI untuk 24/7. Opsi C (Fargate Spot) bisa terinterrupsi — tidak cocok untuk continuous processing. Opsi D (On-Demand) tanpa discount paling mahal.
7
A data engineering team deploys multiple Spark applications on Amazon EKS. They use the Spark Operator for job management. During peak hours, jobs queue because there aren't enough cluster resources. Which EKS scaling strategy provides the FASTEST response to resource demands?
  • A. Configure Karpenter as the node provisioner for rapid node scaling with diverse instance type selection
  • B. Use Cluster Autoscaler with a single node group
  • C. Pre-provision a fixed number of large nodes
  • D. Use Horizontal Pod Autoscaler to scale Spark executors
Jawaban Benar: A
Karpenter provisions nodes dalam hitungan detik (vs minutes untuk Cluster Autoscaler) dan secara otomatis memilih instance types optimal berdasarkan pending pod requirements. Karpenter juga support mixed instance types dan consolidation. Opsi B (Cluster Autoscaler) lebih lambat karena harus scale node groups yang sudah didefinisikan. Opsi C (pre-provision) membuang biaya saat idle. Opsi D (HPA) scale pods bukan nodes — pods tetap pending jika node resources habis.
8
A company uses Amazon ECS to run a containerized data processing application that reads from Amazon Kinesis. The application uses the Kinesis Client Library (KCL). There are 10 Kinesis shards. The ECS service needs to ensure exactly one KCL worker per shard for optimal processing. How should the service be configured?
  • A. Set the ECS service desired count to 10 tasks, matching the number of shards, with one KCL worker per task
  • B. Set desired count to 1 task with 10 threads inside the container
  • C. Set desired count to 20 tasks for redundancy
  • D. Use ECS Service Auto Scaling based on CPU utilization
Jawaban Benar: A
KCL distributes shard leases among workers. Dengan 10 shards, 10 tasks (workers) memastikan setiap task memproses tepat 1 shard — beban terdistribusi merata. Jika satu task fails, KCL akan redistribusi shard ke remaining workers. Opsi B (1 task 10 threads) — single point of failure, jika task dies semua processing berhenti. Opsi C (20 tasks) — 10 tasks akan idle karena hanya ada 10 shards, membuang resources. Opsi D (CPU-based) tidak tahu tentang shard count.

A data engineer is building a container image for an ETL application that will run on ECS Fargate. The application requires Python, pandas, numpy, and scikit-learn. The initial image size is 2.5 GB, causing slow task startup times. How can the image be optimized for faster start?
  • A. Use a multi-stage build with a slim Python base image (python:3.11-slim), install only production dependencies, and remove cache files
  • B. Use the full python:3.11 image for compatibility
  • C. Install all dependencies at runtime using an entrypoint script
  • D. Use Amazon Linux 2 base image and compile Python from source
Jawaban Benar: A
Multi-stage build mengurangi image size dengan memisahkan build stage (compile dependencies) dari runtime stage (hanya binary/packages yang diperlukan). python:3.11-slim jauh lebih kecil dari full image. Menghapus pip cache dan unnecessary files mengurangi ukuran lebih lanjut. Smaller image = faster pull = faster task startup. Opsi B (full image) 2.5GB tetap besar. Opsi C (runtime install) memperlambat setiap task start. Opsi D (compile Python) menambah complexity tanpa benefit signifikan.

A company runs an EKS-based data pipeline that processes customer data. Compliance requires that data processing containers cannot communicate with the internet. The containers only need access to S3, DynamoDB, and the Kubernetes API server. Which network configuration enforces this?
  • A. Deploy pods in private subnets without NAT Gateway, create VPC endpoints for S3 and DynamoDB, and use EKS private endpoint access
  • B. Use Kubernetes NetworkPolicy to block egress to 0.0.0.0/0
  • C. Configure security groups to deny all outbound traffic
  • D. Remove the Internet Gateway from the VPC
Jawaban Benar: A
Private subnets tanpa NAT Gateway memastikan tidak ada internet access. VPC endpoints (Gateway endpoint untuk S3/DynamoDB) memungkinkan akses ke AWS services tanpa internet. EKS private endpoint memungkinkan kubelet/pods berkomunikasi dengan control plane secara private. Opsi B (NetworkPolicy) bergantung pada CNI plugin dan bisa di-bypass. Opsi C (deny all outbound SG) memblokir semua termasuk VPC endpoints. Opsi D (remove IGW) mempengaruhi seluruh VPC termasuk resources yang butuh internet.
