1
A data engineering team stores daily ETL output files in an S3 bucket with versioning enabled. Over time, storage costs have increased significantly due to accumulated noncurrent object versions. The team wants to reduce costs while retaining the ability to recover accidentally overwritten files for 30 days. Which solution BEST meets these requirements?
  • A. Suspend versioning on the bucket and delete all noncurrent versions manually
  • B. Create a lifecycle rule to expire noncurrent versions after 30 days and transition them to S3 Glacier after 7 days
  • C. Create a lifecycle rule to permanently delete noncurrent versions after 30 days
  • D. Disable versioning and enable S3 Cross-Region Replication for data protection
Jawaban Benar: C
Lifecycle rule untuk menghapus noncurrent versions setelah 30 hari memungkinkan pemulihan file yang tertimpa dalam waktu 30 hari sambil secara otomatis membersihkan versi lama untuk mengontrol biaya. Opsi A (suspend versioning) tidak menghapus versi yang ada dan menghilangkan proteksi ke depan. Opsi B salah karena transition ke Glacier terjadi sebelum expiration, tapi lifecycle rule untuk noncurrent versions harus menggunakan NoncurrentVersionExpiration, bukan Expiration. Opsi D (disable versioning) tidak mungkin — versioning hanya bisa di-suspend, tidak di-disable, dan CRR membutuhkan versioning enabled.
2
A company has a DynamoDB table storing user session data. Each session record includes a "lastActivity" attribute (Unix epoch timestamp). The team wants sessions to automatically expire 24 hours after the last activity. Which configuration correctly implements this requirement?
  • A. Enable TTL on the table using the "lastActivity" attribute and set the TTL value to 86400
  • B. Enable TTL on the table using a dedicated "expirationTime" attribute that stores lastActivity + 86400 seconds
  • C. Create a DynamoDB Stream that triggers a Lambda function to delete expired items every 24 hours
  • D. Enable TTL on the table using the "lastActivity" attribute and configure the TTL offset to 86400 seconds in the DynamoDB console
Jawaban Benar: B
DynamoDB TTL membandingkan nilai atribut TTL (Unix epoch timestamp) dengan waktu saat ini. Item dihapus ketika current time > TTL value. Tidak ada "offset" yang bisa dikonfigurasi — atribut TTL harus berisi waktu ekspirasi absolut. Oleh karena itu, atribut terpisah "expirationTime" yang berisi lastActivity + 86400 (24 jam dalam detik) adalah implementasi yang benar. Opsi A salah karena menggunakan lastActivity langsung berarti item langsung expired. Opsi C menambah kompleksitas yang tidak perlu. Opsi D tidak ada — DynamoDB tidak memiliki fitur TTL offset.
3
A financial institution requires that specific compliance-critical objects in their S3 bucket cannot be permanently deleted, even by the root account user, without multi-factor authentication. Which feature should the data engineer enable?
  • A. S3 Object Lock in Compliance mode
  • B. S3 Versioning with MFA Delete enabled
  • C. S3 Bucket Policy denying s3:DeleteObject for all principals
  • D. S3 Versioning with a lifecycle rule preventing deletion
Jawaban Benar: B
MFA Delete mengharuskan autentikasi multi-faktor untuk menghapus versi objek secara permanen atau mengubah status versioning bucket. Ini mencegah penghapusan permanen tanpa MFA, bahkan oleh root account. Opsi A (Object Lock Compliance) mencegah penghapusan selama retention period tapi tidak memerlukan MFA — ia memblokir semua penghapusan termasuk root. Opsi C (Bucket Policy) bisa di-bypass oleh root account yang bisa mengubah policy. Opsi D (lifecycle rule) tidak mencegah penghapusan manual. Pertanyaan spesifik menyebut "tanpa multi-factor authentication" yang langsung mengarah ke MFA Delete.
4
A data engineer has an S3 bucket with versioning enabled. They need to retrieve a specific previous version of a data file that was accidentally overwritten yesterday. The engineer knows the object key but not the version ID. Which approach should they use?
  • A. Use the S3 console to view object versions, identify the correct version ID, then use GetObject with the versionId parameter
  • B. Use S3 Inventory to find the version ID and then restore using S3 Batch Operations
  • C. Use S3 Replication Time Control to restore the previous version
  • D. Use aws s3 cp with the --restore flag to retrieve the previous version
Jawaban Benar: A
Untuk mengambil versi spesifik, gunakan ListObjectVersions API atau S3 console untuk melihat semua versi objek beserta version ID-nya, kemudian gunakan GetObject dengan parameter versionId untuk mengunduh versi yang diinginkan. Opsi B (S3 Inventory) tidak real-time dan membutuhkan waktu untuk generate report. Opsi C (Replication Time Control) untuk mengontrol SLA replikasi, bukan untuk restore. Opsi D (--restore flag) digunakan untuk restore dari Glacier, bukan untuk mengakses versi sebelumnya.
5
A company uses DynamoDB to store IoT sensor readings. They enable TTL to automatically delete readings older than 90 days. The team also needs to archive expired items to S3 for long-term analytics. Which architecture achieves this with MINIMAL operational overhead?
  • A. Schedule a Lambda function to scan the table hourly and move items older than 90 days to S3 before they expire
  • B. Enable DynamoDB Streams on the table, filter for TTL-deleted events (REMOVE with userIdentity.type = "Service"), and use Lambda to write to S3
  • C. Use DynamoDB Export to S3 feature daily to export the full table, then let TTL handle deletion
  • D. Create a Global Secondary Index on the TTL attribute and periodically query items near expiration to copy to S3
Jawaban Benar: B
DynamoDB Streams menangkap TTL deletions sebagai event REMOVE dengan userIdentity.type = "Service" dan userIdentity.principalId = "dynamodb.amazonaws.com". Lambda consumer dapat memfilter event ini dan menulis data ke S3 untuk archival. Ini fully event-driven dan minimal overhead. Opsi A memerlukan scan yang mahal dan berisiko race condition dengan TTL. Opsi C (full export) sangat mahal untuk tabel besar dan menghasilkan data duplikat. Opsi D tidak efisien — GSI tidak bisa digunakan untuk query items berdasarkan waktu mendekati TTL secara efektif.
6
A data engineer suspends versioning on an S3 bucket that previously had versioning enabled. What happens when a new object is uploaded with the same key as an existing versioned object?
  • A. The upload fails because the bucket previously had versioning enabled
  • B. A new version with a null version ID is created, and all previous versions are retained
  • C. The new object overwrites the current version and all previous versions are permanently deleted
  • D. A new version with a null version ID is created, and the previous null version ID object (if any) is overwritten
Jawaban Benar: D
Ketika versioning di-suspend, objek baru yang diupload mendapat null version ID. Jika sudah ada objek dengan null version ID, objek tersebut ditimpa. Versi-versi sebelumnya yang memiliki version ID non-null tetap dipertahankan. Opsi A salah — upload tetap berhasil. Opsi B hampir benar tapi tidak menyebutkan bahwa null version ID sebelumnya ditimpa. Opsi C salah — versi sebelumnya tidak dihapus otomatis. Ini penting dipahami: suspend versioning TIDAK menghapus versi yang sudah ada.
7
A company stores machine learning model artifacts in a versioned S3 bucket. The bucket has accumulated thousands of noncurrent versions over two years. The team wants to keep only the 3 most recent noncurrent versions and delete older ones. Which S3 feature should the data engineer use?
  • A. S3 Lifecycle rule with NoncurrentVersionExpiration and NewerNoncurrentVersions set to 3
  • B. S3 Intelligent-Tiering with version management enabled
  • C. S3 Lifecycle rule with AbortIncompleteMultipartUpload set to 3 versions
  • D. S3 Batch Operations to delete all but the 3 most recent versions per object
Jawaban Benar: A
S3 Lifecycle rules mendukung NoncurrentVersionExpiration dengan parameter NewerNoncurrentVersions yang memungkinkan menyimpan sejumlah N versi noncurrent terbaru dan menghapus yang lebih lama. Ini adalah solusi native S3 yang paling efisien. Opsi B (Intelligent-Tiering) mengelola storage class bukan jumlah versi. Opsi C (AbortIncompleteMultipartUpload) untuk multipart upload yang tidak selesai, bukan versi. Opsi D (Batch Operations) bisa dilakukan tapi membutuhkan pengelolaan manual dan tidak otomatis.
8
A data engineer observes that DynamoDB TTL is not deleting expired items immediately at the specified expiration time. Some items remain in the table for several hours after their TTL timestamp has passed. The application queries are returning stale data. What is the MOST appropriate solution?
  • A. Increase the table's write capacity units to speed up TTL deletions
  • B. Add a filter expression in application queries to exclude items where the TTL attribute is less than the current time
  • C. Disable and re-enable TTL to reset the background deletion process
  • D. Contact AWS Support to increase the TTL deletion throughput for the table
Jawaban Benar: B
DynamoDB TTL tidak menjamin penghapusan instan — item biasanya dihapus dalam waktu 48 jam setelah expiration (umumnya dalam beberapa jam). Ini by design dan tidak bisa dipercepat. Solusi yang benar adalah menambahkan filter expression di query aplikasi untuk mengecualikan item yang sudah expired (TTL < current_time). Opsi A salah — TTL deletion menggunakan background proses yang terpisah dari WCU provisioned. Opsi C tidak akan mempercepat proses. Opsi D tidak ada mekanisme untuk meningkatkan TTL throughput secara manual.
9
A healthcare company stores patient records in a versioned S3 bucket. Due to a regulatory requirement, they must ensure that once an object version is deleted, it cannot be recovered. Currently, when users delete objects, only delete markers are created. What must the data engineer do to permanently remove specific object versions?
  • A. Disable versioning on the bucket, then delete the objects
  • B. Issue DeleteObject requests specifying the exact version ID for each version to be permanently deleted
  • C. Create a lifecycle rule with an Expiration action targeting the specific objects
  • D. Use S3 Batch Operations with the DeleteObject operation without specifying version IDs
Jawaban Benar: B
Untuk menghapus versi objek secara permanen di bucket dengan versioning enabled, Anda harus mengirim DeleteObject request dengan version ID spesifik. Tanpa version ID, S3 hanya membuat delete marker. Opsi A salah — versioning tidak bisa di-disable, hanya di-suspend, dan itu tidak menghapus versi yang ada. Opsi C (lifecycle rule) tidak bisa menargetkan objek spesifik berdasarkan key. Opsi D tanpa version ID hanya akan membuat delete markers, bukan penghapusan permanen.
10
A company has a DynamoDB table with TTL enabled for automatic session cleanup. They want to understand the cost implications of TTL deletions. Which statement about DynamoDB TTL cost is CORRECT?
  • A. TTL deletions consume write capacity units (WCU) from the table's provisioned capacity
  • B. TTL deletions are free of charge and do not consume any write capacity units
  • C. TTL deletions are charged at 50% of the normal write cost per item deleted
  • D. TTL deletions are free but incur additional charges for DynamoDB Streams if enabled
Jawaban Benar: B
DynamoDB TTL deletions sepenuhnya gratis — tidak mengonsumsi write capacity units dan tidak dikenakan biaya. Ini menjadikan TTL cara yang paling cost-effective untuk menghapus data yang sudah expired secara otomatis. Opsi A salah — TTL menggunakan background proses terpisah yang tidak mempengaruhi WCU. Opsi C tidak ada skema biaya seperti ini. Opsi D salah — TTL deletions yang tercatat di DynamoDB Streams juga tidak menimbulkan biaya tambahan di luar biaya normal Streams (biaya read dari stream tetap berlaku jika ada consumer).
