1
A company runs an AWS Glue-based ETL pipeline that processes data from multiple sources. The compliance team requires that all ETL job logs be retained for exactly 5 years and must be encrypted at rest with a customer-managed KMS key. The data engineering team wants to organize logs by environment (production, staging, development). Which CloudWatch Logs configuration meets ALL these requirements?
  • A. Create log groups named /aws/glue/{environment}/{job-name}, set retention to 1827 days, and associate a customer-managed KMS key with each log group
  • B. Create log groups per job with AWS-managed KMS encryption, set retention to 5 years, and use log group tags for environment identification
  • C. Create log groups per environment, set no retention policy, export to S3 with KMS encryption, and delete log groups after export
  • D. Use a single log group /aws/glue/all-jobs with log streams per environment, set retention to Never Expire, and enable default SSE-S3 encryption
Correct Answer: A
Naming convention /aws/glue/{environment}/{job-name} provides organisasi hierarkis that jelas. Retention 1827 days (≈5 years) memenuhi compliance requirement in a correct. CloudWatch Logs supports asosiasi customer-managed KMS key per log group uses API associate-kms-key.

Option A: CORRECT.
Option B: INCORRECT. Menyebut AWS-managed KMS that not memenuhi syarat customer-managed key.
Option C: INCORRECT. Deletes log groups setelah export that berisiko kehilangan data if export fails and not enables query real-time.
Option D: INCORRECT. Uses satu log group that difficult is managed and SSE-S3 not customer-managed KMS.
2
A data platform team needs to export CloudWatch Logs to Amazon S3 for long-term archival and compliance. The logs must be exported daily and stored in a specific S3 bucket with a structured prefix. The solution must be automated and require minimal operational overhead. Which approach is MOST appropriate?
  • A. Configure CloudWatch Logs automatic export feature in the log group settings to export to S3 daily
  • B. Use AWS DataSync to synchronize CloudWatch Logs storage to S3 on a daily schedule with real-time processing and low-latency data delivery
  • C. Create a CloudWatch Logs subscription filter that streams all logs to Amazon Data Firehose, which delivers to S3
  • D. Use CloudWatch Logs CreateExportTask API called by a daily EventBridge scheduled rule triggering a Lambda function
Correct Answer: C
Subscription filter to Firehose provides near real-time streaming to S3 with prefiks terstruktur automatically, minimal operational overhead, and not requires scheduled jobs. Firehose supports dynamic partitioning based on time.

Option A: INCORRECT. Not ada feature automatic export bawaan in CloudWatch Logs — export must is performed manually or via API.
Option B: INCORRECT. Not supports CloudWatch Logs sebagai source — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option C: CORRECT.
Option D: INCORRECT. Berfungsi but has limitations: only satu export task per log group on satu time, requires maintenance Lambda, and ada delay.
3
A multinational company has AWS accounts in multiple regions. The security team requires that application logs from all regions be accessible from a central account for audit purposes. Individual account teams should still be able to read their own logs but cannot modify the cross-account sharing configuration. Which solution provides centralized log access with these constraints?
  • A. Export logs from each account to a shared S3 bucket using cross-account bucket policies with a monitoring account as sink and source accounts as links, managed
  • B. Use CloudWatch Logs cross-account subscription filters in each source account to stream logs to the central account's log groups
  • C. Use CloudWatch cross-account observability with a monitoring account as sink and source accounts as links, managed via AWS Organizations
  • D. Create a CloudWatch Logs resource policy in the central account that grants PutLogEvents from source accounts, and configure source accounts to send logs directly
Correct Answer: C
CloudWatch cross-account observability enables monitoring account (sink) for melihat logs from source accounts (links) without menyalin data. When is managed via Organizations, configuration is applied in a terpusat and member accounts cannot memodifikasi sharing configuration. Source accounts still has access baca to logs mereka itself.

Option A: INCORRECT. Not real-time and not provides capabilities query directly from CloudWatch console — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Requires configuration subscription filter in each source account that can is changed admin local.
Option C: CORRECT.
Option D: INCORRECT. Requires configuration in source accounts and not prevents modifikasi by admin local.

A data engineer needs to implement real-time alerting on error patterns in application logs stored in CloudWatch Logs. When specific error patterns are detected (such as "DataCorruptionException"), the events must be forwarded to a dedicated Kinesis Data Stream for downstream processing by a fraud detection system. Which CloudWatch Logs feature should be used?
  • A. CloudWatch Logs metric filters with CloudWatch Alarms forwarding to Kinesis
  • B. CloudWatch Logs subscription filters with Kinesis Data Streams as the destination
  • C. CloudWatch Logs Insights scheduled queries with results exported to Kinesis
  • D. CloudWatch Anomaly Detection on log metrics with SNS notification to trigger Kinesis ingestion
Correct Answer: B
Subscription filters enables streaming real-time log events that suitable with pattern filter certain (such as "DataCorruptionException") directly to Kinesis Data Streams. Ini provides full log event data to downstream system.

Option A: INCORRECT. Only produces numeric metrics and alarm notifications — not meneruskan actual log event content to Kinesis.
Option B: CORRECT.
Option C: INCORRECT. Bersifat batch and has delay, not real-time.
Option D: INCORRECT. Mendeteksi deviasi from baseline metrics, not pattern matching on log content, and not meneruskan log events.

A company has a data pipeline generating 500 GB of logs daily. The logs are currently stored in CloudWatch Logs with Standard log class. Only 10% of these logs are queried regularly — the rest are kept purely for compliance retention. The team wants to reduce costs significantly without losing any data. Which approach provides the MOST cost-effective solution?
  • A. Export all logs to S3 using Firehose and delete from CloudWatch Logs after 1 day, keeping steady-state operating costs low
  • B. Compress logs before sending to CloudWatch Logs to reduce storage volume and compliance-only logs in Infrequent Access class
  • C. Move all log groups to Infrequent Access log class to reduce storage and ingestion costs, optimizing cost for the described workload
  • D. Separate logs into two log groups — frequently queried logs in Standard class and compliance-only logs in Infrequent Access class
Correct Answer: D
Memisahkan logs based on pattern access to dua log classes is approach most cost-effective. Infrequent Access class has cost ingestion lower (~50% cheaper) but not supports all feature (for example subscription filters, Live Tail is limited). Logs that often in-query still in Standard class for fungsionalitas full.

Option A: INCORRECT. Adds complexity and eliminates capabilities CloudWatch Logs Insights query.
Option B: INCORRECT. Salah because CloudWatch Logs already performs compression internal — user cannot sends data pre-compressed — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option C: INCORRECT. Menempatkan all in Infrequent Access, that limits capabilities query for 10% logs that often diakses.
Option D: CORRECT.

A security team needs to ensure that no one in the organization can delete specific CloudWatch Logs log groups that contain audit trail data, even if they have administrator permissions in their respective accounts. Which mechanism provides the STRONGEST protection against log group deletion?
  • A. Use an AWS Organizations Service Control Policy (SCP) that denies logs:DeleteLogGroup for the audit log groups
  • B. Configure IAM policies in each account that deny logs:DeleteLogGroup for all users and roles
  • C. Enable CloudWatch Logs data protection to prevent deletion of log groups with sensitive data
  • D. Apply a CloudWatch Logs resource policy that denies logs:DeleteLogGroup action for all principals
Correct Answer: A
Service Control Policies (SCPs) provides perlindungan terkuat because is applied in level Organizations and cannot in-override by administrator in member accounts, including that has AdministratorAccess policy. SCP can uses kondisi on resource ARN for menargetkan log groups specific.

Option A: CORRECT.
Option B: INCORRECT. Can is changed by administrator in akun the said.
Option C: INCORRECT. Berfungsi for masking sensitive data in logs, not for prevents deletion log groups.
Option D: INCORRECT. Can dimodifikasi by siapapun with permission logs:PutResourcePolicy.
7
A data engineer is configuring CloudWatch Logs for an Amazon EMR cluster that runs Spark jobs processing sensitive healthcare data. The logs must be encrypted with a specific KMS key, and only the data engineering team and the compliance team should have access to decrypt and read the logs. How should the KMS key policy be configured?
  • A. Grant kms:Encrypt to the CloudWatch Logs service principal (logs.amazonaws.com) and kms:Decrypt to the data engineering and compliance team IAM roles
  • B. Grant full KMS permissions to CloudWatch Logs service and use log group-level IAM policies for access control
  • C. Grant kms:GenerateDataKey and kms:Decrypt to the CloudWatch Logs service principal, and kms:Decrypt to the authorized IAM roles
  • D. Grant kms:Encrypt and kms:Decrypt to CloudWatch Logs service principal, and use KMS key grants for the data engineering and compliance team roles
Correct Answer: C
CloudWatch Logs uses envelope encryption. Service principal requires kms:GenerateDataKey* for creates data encryption key saat writes logs, and kms:Decrypt for reads returns (for feature such as filter patterns). IAM roles that needs reads logs requires kms:Decrypt for mendekripsi log data.

Option A: INCORRECT. Salah because CloudWatch Logs requires GenerateDataKey, not Encrypt directly.
Option B: INCORRECT. Terlalu permissive and not limits decrypt access.
Option C: CORRECT.
Option D: INCORRECT. Provides Encrypt that not is required — CloudWatch Logs uses GenerateDataKey for envelope encryption, not Encrypt.

A company operates a multi-tenant SaaS application where each tenant's data processing logs must be isolated. Tenants should only see logs related to their own data processing. The platform team needs a view of all logs. Currently, all logs go to a single log group with tenant_id in the log message. Which redesign provides the BEST log isolation?
  • A. Create separate log streams per tenant within one log group and use stream-level IAM permissions, handling the described workload reliably at scale
  • B. Create separate log groups per tenant (/app/tenant/{tenant_id}) and use IAM policies with conditions on the log group ARN to restrict tenant access
  • C. Use subscription filters per tenant to copy relevant logs to tenant-specific log groups with conditions on the log group ARN
  • D. Keep a single log group and use CloudWatch Logs Insights queries filtered by tenant_id for each tenant's access, providing exactly-once processing semantics
Correct Answer: B
Log groups separate per tenant enables IAM policies that limits access based on log group ARN (arn:aws:logs:region:account:log-group:/app/tenant/{tenant_id}:*). Ini provides isolasi that kuat and auditable. Platform team can has access to all log groups.

Option A: INCORRECT. Salah because IAM permissions CloudWatch Logs not supports granularitas level log stream — permissions applies in level log group.
Option B: CORRECT.
Option C: INCORRECT. Adds complexity and cost (double ingestion) and subscription filters has limit per log group — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option D: INCORRECT. Not provides isolasi nyata — tenant with permission FilterLogEvents can melihat all logs in log group.

A data engineering team discovers that their CloudWatch Logs ingestion costs have doubled in the past month. After investigation, they find that verbose DEBUG-level logs from development Lambda functions are being sent to CloudWatch. The team wants to retain ERROR and WARN logs but discard DEBUG logs before they reach CloudWatch Logs. Which approach MOST effectively reduces ingestion costs?
  • A. Set the log group retention to 1 day to minimize storage costs for DEBUG logs configured for optimal performance and minimal operational overhead
  • B. Configure CloudWatch Logs metric filters to count only ERROR and WARN events, ignoring DEBUG, avoiding charges for idle provisioned capacity
  • C. Create a subscription filter that only forwards ERROR and WARN logs to a separate log group
  • D. Set the Lambda function's log level configuration to WARN to prevent DEBUG logs from being emitted to CloudWatch
Correct Answer: D
AWS Lambda Advanced Logging Controls enables configuration log level in level function (DEBUG, INFO, WARN, ERROR). Mengatur to WARN will prevents DEBUG and INFO logs is sent to CloudWatch Logs same sekali, reduces ingestion costs directly in source.

Option A: INCORRECT. Reduces storage costs but not ingestion costs — cost terbesar usually ada in ingestion — although its description sounds convincing, in a fundamental still not appropriate for requirements this.
Option B: INCORRECT. Tetap mengingestion all logs — metric filters only processes data that already in-ingest.
Option C: INCORRECT. Also not reduces ingestion because logs already enters to log group pertama before difilter.
Option D: CORRECT.
10
A compliance auditor requires that the company prove no log data was modified or deleted from CloudWatch Logs during a specific investigation period. The logs are stored in CloudWatch Logs and also exported to S3. Which combination of controls provides the STRONGEST evidence of log immutability for the auditor?
  • A. Show S3 versioning on the export bucket and present CloudWatch Logs subscription filter configuration proving all events are copied in real-time
  • B. Demonstrate that IAM policies prevent all users from calling DeleteLogGroup and show CloudWatch Logs are encrypted with KMS, satisfying strict compliance and audit requirements
  • C. Show CloudWatch Logs retention policy is set to Never Expire and present CloudTrail logs showing no DeleteLogGroup or DeleteLogStream API calls during the period
  • D. Present the S3 exported logs with S3 Object Lock (Compliance mode) enabled and provide CloudTrail evidence that no PutLogEvents overwrote existing data
Correct Answer: D
S3 Object Lock Compliance mode provides immutability that can dibuktikan in a technical — there is no user, including root, that can deletes or memodifikasi objek during retention period. Dikombinasikan with CloudTrail evidence that menunjukkan there is no PutLogEvents that overwrote data, this provides bukti terkuat.

Option A: INCORRECT. Mempertahankan versi but not prevents deletion — delete markers can is added.
Option B: INCORRECT. Can is changed when saja and not provides bukti retroaktif.
Option C: INCORRECT. Not prevents manual deletion by administrator, only prevents auto-deletion.
Option D: CORRECT.
