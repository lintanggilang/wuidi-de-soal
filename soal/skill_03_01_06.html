1
A data analyst team receives daily CSV files from an external vendor containing customer transaction data. The files have inconsistent date formats (MM/DD/YYYY, YYYY-MM-DD, DD-Mon-YY), null values represented as "N/A", "null", and empty strings, and phone numbers in varying formats. The team needs a repeatable, no-code solution to standardize this data before loading into the data warehouse. Which AWS service is MOST appropriate?
  • A. AWS Glue DataBrew with a recipe containing steps for date parsing, null standardization, and phone number formatting
  • B. AWS Glue ETL job with custom PySpark code for each transformation rule
  • C. Amazon Athena CTAS query with CASE statements to handle each format variation
  • D. AWS Lambda function with pandas library to parse and clean the data
Jawaban Benar: A
AWS Glue DataBrew menyediakan visual interface no-code untuk data preparation dengan 250+ built-in transformations. Recipes dapat dibuat sekali dan dijalankan berulang kali (repeatable) untuk setiap batch file baru. DataBrew memiliki built-in functions untuk date parsing multi-format, null handling, dan string formatting. Opsi B (Glue ETL PySpark) memerlukan coding yang tidak cocok untuk requirement "no-code". Opsi C (Athena CTAS) memerlukan SQL yang kompleks untuk semua variasi format. Opsi D (Lambda + pandas) memerlukan coding dan memiliki batas memory/timeout untuk file besar.
2
A data quality team needs to establish automated data quality rules for incoming datasets. They need to verify that: email columns match a regex pattern, age values fall within 0-150 range, no more than 5% of required fields are null, and all dates are within the last 5 years. Which AWS Glue DataBrew feature addresses this requirement?
  • A. DataBrew data quality rules (rulesets) applied to a DataBrew profile job that validates data against defined conditions
  • B. DataBrew recipe steps that filter out rows not meeting the criteria
  • C. DataBrew dataset-level configuration that rejects files failing validation
  • D. DataBrew custom SQL transforms that check constraints during processing
Jawaban Benar: A
DataBrew data quality rules (rulesets) memungkinkan definisi aturan validasi (regex patterns, range checks, null thresholds, date ranges) yang diaplikasikan melalui profile jobs. Hasilnya menunjukkan persentase data yang pass/fail setiap rule, memberikan visibility ke data quality tanpa mengubah data. Opsi B (recipe steps) mengubah data tetapi tidak melaporkan kualitas. Opsi C tidak ada fitur dataset-level rejection di DataBrew. Opsi D (custom SQL) tidak tersedia di DataBrew — DataBrew menggunakan visual transforms, bukan SQL.
3
A machine learning team needs to prepare training data from a 500 GB dataset stored in Amazon S3. The preparation involves feature engineering, handling missing values with statistical imputation, one-hot encoding categorical variables, and normalizing numeric features. They need visual exploration capabilities and the ability to export the preparation steps as a pipeline. Which tool is MOST suitable?
  • A. Amazon SageMaker Data Wrangler for visual ML data preparation with built-in transformations and export to SageMaker Pipeline
  • B. AWS Glue DataBrew for data cleaning with export to Glue ETL job
  • C. Amazon EMR with Jupyter Notebook for interactive Spark-based feature engineering
  • D. Amazon Athena with CTAS for creating transformed feature tables
Jawaban Benar: A
Amazon SageMaker Data Wrangler dirancang khusus untuk ML data preparation. Ia menyediakan visual interface untuk feature engineering (one-hot encoding, normalization, imputation), data exploration dengan built-in visualizations, dan kemampuan export ke SageMaker Pipeline untuk production. Ini mencakup semua kebutuhan: visual exploration, ML-specific transforms, dan pipeline export. Opsi B (DataBrew) bagus untuk data cleaning umum tetapi kurang optimal untuk ML-specific feature engineering seperti statistical imputation dan normalization. Opsi C (EMR Jupyter) memerlukan coding. Opsi D (Athena) terbatas pada SQL transforms tanpa ML capabilities.
4
A data engineer has created a DataBrew recipe with 15 transformation steps during an interactive session on a sample dataset. The recipe needs to be applied to the full production dataset (2 TB) on a daily schedule. Which approach correctly operationalizes this DataBrew recipe?
  • A. Create a DataBrew recipe job linked to the recipe, configure the output destination (S3), and schedule it using the DataBrew built-in scheduler or Amazon EventBridge
  • B. Export the recipe as a Python script and run it in an AWS Glue ETL job
  • C. Manually run the recipe in the DataBrew console each day on the full dataset
  • D. Convert the recipe to SQL statements and execute them in Amazon Athena
Jawaban Benar: A
DataBrew recipe jobs adalah mekanisme production-ready untuk menjalankan recipes pada full datasets. Recipe jobs dapat dikonfigurasi dengan output ke S3 (berbagai format: CSV, Parquet, JSON), dan dijadwalkan menggunakan built-in scheduler atau EventBridge untuk automasi harian. DataBrew secara otomatis menangani scaling untuk dataset besar. Opsi B (export Python) tidak didukung — DataBrew recipes tidak dapat diekspor sebagai executable code. Opsi C (manual run) tidak scalable dan memerlukan human intervention. Opsi D (convert to SQL) tidak praktis dan kehilangan DataBrew-specific transformations.
5
A data engineering team is evaluating whether to use AWS Glue DataBrew or AWS Glue ETL for a new data preparation pipeline. The pipeline involves: reading from 50+ source tables, applying complex conditional logic based on business rules, joining multiple tables with different keys, and writing to a partitioned data lake. Which factors should influence the choice toward AWS Glue ETL over DataBrew?
  • A. Complex multi-table joins, conditional business logic requiring programming constructs (if/else, loops), and partitioned output with custom partitioning schemes
  • B. Need for visual data profiling and column-level statistics before transformation
  • C. Requirement for non-technical users to modify transformation rules without coding
  • D. Need to validate data quality with predefined rule sets before processing
Jawaban Benar: A
AWS Glue ETL lebih cocok untuk complex multi-table joins, conditional business logic yang memerlukan programming constructs (PySpark/Scala), dan custom partitioning schemes. Glue ETL memberikan full control atas Spark processing yang diperlukan untuk skenario kompleks ini. Opsi B (visual profiling) dan Opsi D (quality rules) justru merupakan kekuatan DataBrew. Opsi C (non-technical users) juga merupakan use case DataBrew. DataBrew dirancang untuk data cleaning dan preparation yang lebih straightforward, sedangkan Glue ETL untuk transformasi yang memerlukan kode dan logika kompleks.
6
A retail company receives product catalog data from suppliers in various character encodings (UTF-8, ISO-8859-1, Windows-1252) and with inconsistent text formatting (mixed case product names, extra whitespace, special characters in descriptions). The data team needs to prepare this data before loading into their search index. Which DataBrew transformation approach handles these encoding and formatting issues?
  • A. Use DataBrew's string transformation steps: TRIM for whitespace, UPPER/LOWER for case standardization, and character encoding detection with conversion to UTF-8 during dataset import configuration
  • B. Pre-process all files with a Lambda function to convert encoding before importing into DataBrew
  • C. Use DataBrew's regex-based REPLACE_PATTERN to remove all non-ASCII characters
  • D. Configure the S3 bucket to automatically convert file encodings upon upload
Jawaban Benar: A
DataBrew menyediakan built-in string transformations (TRIM, UPPER, LOWER, PROPER_CASE) untuk standarisasi format teks, dan mendukung konfigurasi character encoding saat import dataset sehingga dapat menangani berbagai encoding source. Kombinasi ini menyelesaikan kedua masalah (encoding + formatting) dalam satu tool. Opsi B (Lambda pre-processing) menambah komponen ekstra yang tidak perlu. Opsi C (remove non-ASCII) akan menghapus karakter valid seperti aksen dan simbol mata uang. Opsi D (S3 auto-convert) tidak ada fitur auto-convert encoding di S3.
7
A data scientist needs to understand the quality and distribution of a new 100 GB dataset before deciding on transformation strategies. They need column-level statistics (mean, median, standard deviation, percentiles), data type detection, correlation analysis between columns, and identification of outliers. The analysis should complete within minutes without writing code. Which approach is MOST efficient?
  • A. Run a DataBrew profile job on the dataset to generate comprehensive column statistics, data quality metrics, and correlation analysis automatically
  • B. Load the data into Amazon Redshift and run manual SQL queries for each statistical measure
  • C. Use Amazon Athena to run aggregate queries (AVG, STDDEV, PERCENTILE) on each column
  • D. Create a QuickSight analysis connected to the S3 dataset for visual exploration
Jawaban Benar: A
DataBrew profile jobs secara otomatis menghasilkan comprehensive statistics untuk setiap kolom: data types, unique values, missing values, distributions, percentiles, correlations, dan outlier detection — tanpa menulis kode apapun. Profile berjalan sebagai managed job yang scale otomatis. Opsi B (Redshift) memerlukan loading data terlebih dahulu dan menulis SQL queries manual. Opsi C (Athena) memerlukan SQL manual untuk setiap metrik dan tidak menyediakan correlation atau outlier detection built-in. Opsi D (QuickSight) untuk visualization, bukan statistical profiling komprehensif.
8
A healthcare data team is preparing patient records for analytics. The dataset contains duplicate records due to multiple system integrations. Duplicates need to be identified based on a combination of patient name (with fuzzy matching for typos), date of birth, and insurance ID. Which DataBrew approach is MOST effective for deduplication?
  • A. Use DataBrew's duplicate removal transformation with grouping by exact match on date of birth and insurance ID, combined with a pre-step to standardize name formatting (UPPER, TRIM) for improved matching
  • B. Use DataBrew's built-in ML-based fuzzy matching algorithm that automatically detects duplicates across all fields
  • C. Export data to AWS Entity Resolution for probabilistic matching and feed results back to DataBrew
  • D. Create a DataBrew recipe that sorts records and removes consecutive rows with identical values in all columns
Jawaban Benar: A
DataBrew mendukung duplicate removal berdasarkan grouping columns. Dengan pre-standardisasi nama (UPPER, TRIM untuk menghapus variasi formatting), exact match pada nama yang sudah distandardisasi bersama date of birth dan insurance ID memberikan deduplication yang efektif. Opsi B salah karena DataBrew tidak memiliki ML-based fuzzy matching built-in. Opsi C (Entity Resolution) adalah solusi valid untuk fuzzy matching tetapi menambah kompleksitas pipeline yang tidak diperlukan jika standardisasi nama sudah cukup. Opsi D (consecutive removal) hanya bekerja jika duplicates berdekatan dan identik di semua kolom.
9
A data engineer needs to prepare IoT sensor data for time-series analysis. The raw data has: missing readings that need forward-fill interpolation, timestamps in different timezones that need UTC normalization, and numeric values stored as strings with comma decimal separators (European format, e.g., "23,5" instead of "23.5"). Which sequence of DataBrew recipe steps correctly handles this preparation?
  • A. 1) Replace comma with dot in numeric columns, 2) Cast to numeric data type, 3) Convert timestamps to UTC, 4) Fill missing values using forward-fill (FILL with FORWARD method)
  • B. 1) Fill missing values first, 2) Convert data types, 3) Replace commas, 4) Normalize timezones
  • C. 1) Cast all columns to string, 2) Use regex to fix formatting, 3) Cast back to appropriate types, 4) Sort by timestamp
  • D. 1) Remove all rows with missing values, 2) Parse timestamps with auto-detection, 3) Convert European numbers using locale settings
Jawaban Benar: A
Urutan yang benar adalah: (1) Fix format terlebih dahulu (comma → dot) agar string bisa diparse, (2) Cast ke numeric agar operasi numerik bisa dilakukan, (3) Normalize timestamps ke UTC untuk konsistensi temporal, (4) Forward-fill missing values yang memerlukan data sudah dalam tipe yang benar dan urutan temporal yang benar. Opsi B salah karena forward-fill pada data yang belum di-cast ke numeric tidak akan bekerja dengan benar. Opsi C terlalu berbelit-belit. Opsi D menghapus missing values (bukan interpolasi) yang kehilangan data penting untuk time-series analysis.
10
A company wants to implement data preparation governance where data stewards can review and approve transformation recipes before they are applied to production data. They also need version history of recipe changes. Which approach provides this governance capability with DataBrew?
  • A. Use DataBrew's published recipe versions to create immutable snapshots, combined with IAM policies that restrict recipe job execution to approved roles, and CloudTrail for audit trail of recipe changes
  • B. Store recipes in a Git repository and use pull request workflows for approval
  • C. Create a Lambda function that validates recipes against a whitelist before allowing execution
  • D. Use AWS Config rules to detect non-compliant recipe configurations and auto-remediate
Jawaban Benar: A
DataBrew recipes mendukung versioning — setiap publish membuat versi baru yang immutable. IAM policies dapat mengontrol siapa yang boleh publish recipes (data stewards) vs siapa yang boleh menjalankan recipe jobs. CloudTrail mencatat semua API calls termasuk recipe modifications untuk audit trail lengkap. Kombinasi ini memberikan governance built-in tanpa tools eksternal. Opsi B (Git) tidak terintegrasi langsung dengan DataBrew execution. Opsi C (Lambda validation) memerlukan custom development. Opsi D (AWS Config) tidak memiliki managed rules untuk DataBrew recipes.
