1
A data engineer configures an AWS Lambda function as a consumer for an Amazon Kinesis Data Stream with 10 shards. The Lambda function processes each batch in 30 seconds on average. The engineer notices that processing throughput is lower than expected. Which configuration change will MOST improve throughput without adding shards?
  • A. Increase the ParallelizationFactor in the event source mapping to process multiple batches per shard concurrently
  • B. Decrease the Lambda function timeout to force faster processing
  • C. Enable Enhanced Fan-Out on the Kinesis stream with parallel processing and horizontal scaling capabilities
  • D. Increase the batch size to process more records per invocation
Jawaban Benar: A
ParallelizationFactor (default 1, max 10) memungkinkan Lambda memproses multiple batches dari satu shard secara bersamaan. Dengan 10 shards dan parallelization factor 10, bisa ada hingga 100 Lambda invocations concurrent. Ini meningkatkan throughput secara signifikan.

Opsi A: BENAR.
Opsi B: SALAH. Bisa menyebabkan failures.
Opsi C: SALAH. Untuk dedicated throughput per consumer app, bukan untuk meningkatkan Lambda processing speed — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Menambah records per invocation tapi tidak menambah concurrency.
2
A Lambda function consuming from a Kinesis stream encounters a processing error on one record in a batch of 100 records. The default behavior causes the entire batch to be retried, blocking the shard. How should the data engineer configure the event source mapping to handle this scenario efficiently?
  • A. Reduce batch size to 1 so only one record fails at a time
  • B. Implement try-catch in the Lambda function to suppress all errors
  • C. Set MaximumRetryAttempts to 0 to skip all failures immediately with an on-failure destination
  • D. Enable BisectBatchOnFunctionError to split failed batches and configure a MaximumRetryAttempts limit with an on-failure destination
Jawaban Benar: D
BisectBatchOnFunctionError membagi batch menjadi dua bagian dan mencoba masing-masing secara terpisah, secara rekursif mengidentifikasi record yang bermasalah. MaximumRetryAttempts membatasi jumlah retry sebelum mengirim ke on-failure destination (SQS/SNS) untuk investigasi.

Opsi A: SALAH. Mengurangi throughput secara drastis.
Opsi B: SALAH. Menyembunyikan errors dan bisa menyebabkan data loss silently.
Opsi C: SALAH. Kehilangan data karena langsung skip — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
3
A data engineer is setting up a Lambda event source mapping for a Kinesis stream. The business requirement is that the Lambda function should wait until there are at least 500 records OR 60 seconds have passed before being invoked, whichever comes first. Which configuration achieves this?
  • A. Set BatchSize to 500 only; Lambda will automatically wait for the batch to fill
  • B. Set MaximumBatchingWindowInSeconds to 60 only; batch size will be unlimited
  • C. Set BatchSize to 500 and MaximumBatchingWindowInSeconds to 60
  • D. Set BatchSize to 500 and use a CloudWatch timer to delay invocation
Jawaban Benar: C
BatchSize menentukan jumlah maksimum records per batch. MaximumBatchingWindowInSeconds menentukan berapa lama menunggu untuk mengumpulkan records sebelum invocation. Lambda akan dipanggil ketika salah satu kondisi terpenuhi lebih dahulu (500 records atau 60 detik).

Opsi A: SALAH. Salah karena tanpa batching window, Lambda dipanggil segera setelah ada records.
Opsi B: SALAH. Tidak ada batch size limit default yang sesuai.
Opsi C: BENAR.
Opsi D: SALAH. Tidak valid karena CloudWatch timer tidak bisa delay Lambda invocation dari event source mapping.
4
A Lambda function processes records from a Kinesis stream and writes results to DynamoDB. After a deployment, the data engineer realizes that the Lambda function has a bug that corrupts data. They need to reprocess all records from the last 24 hours. What is the MOST effective way to replay these records?
  • A. Delete and recreate the event source mapping with TRIM_HORIZON as the starting position
  • B. Increase the Kinesis stream retention period and wait for automatic reprocessing with the timestamp from 24 hours ago
  • C. Update the event source mapping's StartingPosition to AT_TIMESTAMP with the timestamp from 24 hours ago
  • D. Use the Kinesis GetShardIterator API with AT_TIMESTAMP in a separate Lambda function
Jawaban Benar: C
Mengupdate event source mapping dengan StartingPosition AT_TIMESTAMP memungkinkan Lambda mulai membaca dari posisi waktu tertentu. Ini adalah cara paling langsung untuk replay records dari titik waktu spesifik.

Opsi A: SALAH. Memproses semua records dari awal retention period, bukan hanya 24 jam terakhir.
Opsi B: SALAH. Tidak menyebabkan reprocessing otomatis — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Membutuhkan custom consumer terpisah yang lebih kompleks.
5
A data engineer is troubleshooting a Lambda function consuming from Kinesis. The function's IteratorAge metric is increasing steadily, indicating the consumer is falling behind. The function's duration is 5 seconds per batch with a batch size of 100 records. What is the MOST effective first step to reduce the iterator age?
  • A. Reduce the batch size to process fewer records per invocation with parallel processing
  • B. Increase the ParallelizationFactor to allow concurrent processing within each shard
  • C. Add more shards to the Kinesis stream using UpdateShardCount
  • D. Increase the Lambda function memory to get more CPU and reduce execution time
Jawaban Benar: B
ParallelizationFactor langsung meningkatkan throughput dengan memproses multiple batches per shard secara bersamaan tanpa perubahan kode atau infrastruktur. Ini adalah first step paling efektif.

Opsi A: SALAH. Bisa meningkatkan invocation rate tapi setiap invocation masih overhead — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Lebih mahal dan memerlukan resharding time, sebaiknya dilakukan setelah tuning options lain.
Opsi D: SALAH. Bisa membantu jika function CPU-bound tapi tidak dijamin signifikan.
6
A data engineer needs to process Kinesis records where each record must be transformed and then sent to different SQS queues based on the record content. Some records require enrichment from a DynamoDB table. The Lambda function must handle records that fail enrichment differently from records that fail SQS delivery. How should error handling be implemented?
  • A. Use BisectBatchOnFunctionError for all error types
  • B. Implement item-level error handling using ReportBatchItemFailures in the Lambda response, returning only failed record sequence numbers
  • C. Catch all exceptions in a single try-catch and write to a dead-letter S3 bucket
  • D. Configure two separate event source mappings for the same stream configured for optimal performance and minimal operational overhead
Jawaban Benar: B
ReportBatchItemFailures (FunctionResponseTypes) memungkinkan Lambda melaporkan hanya records yang gagal diproses. Lambda mengembalikan batchItemFailures dengan sequence numbers dari records yang perlu diretry. Records yang berhasil tidak diproses ulang. Ini memberikan granular error handling per record.

Opsi A: SALAH. Hanya splits batch tanpa granular per-record control.
Opsi B: BENAR.
Opsi C: SALAH. Kehilangan kemampuan retry.
Opsi D: SALAH. Tidak supported - hanya satu event source mapping per stream-function pair — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
7
A company processes IoT sensor data via Kinesis and Lambda. The Lambda function applies a tumbling window aggregation (e.g., average temperature per device per 5 minutes). Which Lambda Kinesis feature supports stateful processing for this use case?
  • A. Configure Tumbling Windows on the event source mapping with a window size of 300 seconds and use the state parameter in the function response
  • B. Set MaximumBatchingWindowInSeconds to 300 to batch 5 minutes of records with a window size of 300 seconds and use the state parameter in the function response
  • C. Store intermediate state in DynamoDB and aggregate manually in the Lambda function
  • D. Use Kinesis Data Analytics (Apache Flink) instead of Lambda for windowed aggregation
Jawaban Benar: A
Lambda event source mappings mendukung Tumbling Windows (hingga 900 detik) yang memungkinkan stateful processing. Fungsi menerima state dari invocation sebelumnya dan mengembalikan state yang diperbarui. Pada akhir window, fungsi menerima isFinalInvokeForWindow=true untuk emit hasil akhir.

Opsi A: BENAR.
Opsi B: SALAH. Bukan sama dengan tumbling window - tidak menyimpan state antar batches — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Membutuhkan custom code dan DynamoDB costs.
Opsi D: SALAH. Bisa bekerja tapi over-engineering jika hanya perlu aggregasi sederhana.
8
A Lambda function processes events from a Kinesis stream with 5 shards. The event source mapping is configured with ParallelizationFactor = 5. During peak hours, the data engineer notices that some Lambda invocations are being throttled. What is the maximum number of concurrent Lambda executions possible with this configuration?
  • A. 50 concurrent executions (5 shards × 10 maximum parallelization)
  • B. 5 concurrent executions (one per shard) with parallel processing
  • C. 10 concurrent executions (5 shards × 2 default parallelization)
  • D. 25 concurrent executions (5 shards × 5 parallelization factor)
Jawaban Benar: D
Maximum concurrent executions = jumlah shards × ParallelizationFactor. Dengan 5 shards dan ParallelizationFactor 5, maximum adalah 5 × 5 = 25 concurrent Lambda invocations. Jika account-level concurrency limit atau reserved concurrency kurang dari 25, throttling terjadi.

Opsi A: SALAH. Salah karena parallelization factor dikonfigurasi sebagai 5, bukan 10.
Opsi B: SALAH. Adalah tanpa parallelization (factor=1) — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Bukan default behavior.
Opsi D: BENAR.
9
A data engineer needs to filter Kinesis records before they reach the Lambda function to reduce unnecessary invocations. Only records where the "eventType" field equals "PURCHASE" should be processed. Which approach filters records at the event source mapping level?
  • A. Configure event filtering criteria on the Lambda event source mapping with a filter pattern matching {"data": {"eventType": ["PURCHASE"]}}
  • B. Use Kinesis Data Analytics to filter records before they reach Lambda
  • C. Configure the Kinesis producer to only send PURCHASE events to a dedicated stream with a filter pattern matching {"data": {"eventType": ["PURCHASE"]}}
  • D. Add an if-statement at the beginning of the Lambda function to skip non-PURCHASE records
Jawaban Benar: A
Lambda event source mapping mendukung event filtering (filter criteria) yang memfilter records sebelum invocation. Records yang tidak cocok dengan filter tidak memicu Lambda, menghemat biaya invocation. Filter pattern mengevaluasi record data setelah base64 decode.

Opsi A: BENAR.
Opsi B: SALAH. Menambah service dan complexity.
Opsi C: SALAH. Membutuhkan perubahan di producer side yang mungkin tidak feasible — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Memfilter di dalam Lambda sehingga invocation tetap terjadi (biaya tetap ada).
10
A data engineer configured a Lambda function with a Kinesis event source mapping. The stream has a retention period of 24 hours. The Lambda function was disabled for maintenance for 30 hours. When the function is re-enabled, what happens to the records that are older than the retention period?
  • A. Lambda automatically replays all 30 hours of records from a backup configured for optimal performance and minimal operational overhead
  • B. Records older than 24 hours are permanently lost; Lambda resumes from the oldest available record (TRIM_HORIZON of current data)
  • C. The event source mapping fails with an error and must be recreated
  • D. Lambda resumes from where it left off using the last checkpoint, including expired records from DynamoDB backup
Jawaban Benar: B
Kinesis records yang melewati retention period (24 jam) dihapus secara permanen dari stream. Ketika Lambda di-enable kembali setelah 30 jam, iterator lama sudah expired. Lambda akan mendapatkan error iterator dan otomatis meresolve dengan membaca dari TRIM_HORIZON (data tertua yang masih tersedia). Records dari 6 jam terakhir (30-24) sudah hilang.

Opsi A: SALAH. Tidak ada mekanisme backup otomatis di Kinesis — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Tetap valid dan tidak perlu dibuat ulang.
Opsi D: SALAH. Tidak akurat karena Kinesis tidak backup ke DynamoDB.
