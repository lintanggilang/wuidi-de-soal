1
A data engineer deployed a new DAG to their Amazon MWAA environment by uploading the Python file to the S3 DAGs folder. After 10 minutes, the DAG still does not appear in the Airflow UI. The engineer verified the file is in the correct S3 path. What is the MOST likely cause?
  • A. The MWAA environment needs to be restarted after adding new DAGs
  • B. The DAG file has a Python syntax error or an import error that prevents the scheduler from parsing it
  • C. The DAG file exceeds the maximum file size limit of 1 MB configured for optimal performance and minimal operational overhead
  • D. The S3 bucket does not have versioning enabled, which is required for MWAA
Jawaban Benar: B
Ketika DAG tidak muncul di Airflow UI, penyebab paling umum adalah syntax error atau import error dalam file DAG. Airflow scheduler mem-parse semua DAG files secara periodik, dan jika ada error saat parsing, DAG tidak akan di-register. Error ini terlihat di scheduler logs di CloudWatch.

Opsi A: SALAH. Salah — MWAA tidak perlu restart, scheduler secara otomatis mendeteksi file baru di S3.
Opsi B: BENAR.
Opsi C: SALAH. Salah — tidak ada hard limit 1 MB untuk DAG files — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Salah — S3 versioning diperlukan tapi ini akan menyebabkan error saat setup environment, bukan saat adding DAGs.
2
An MWAA environment running Apache Airflow has tasks that intermittently fail with the error "Task received SIGTERM signal" even though the task logic executed correctly. The environment uses the mw1.small environment class with 5 workers. CloudWatch metrics show worker CPU usage frequently exceeds 90%. What is the MOST appropriate resolution?
  • A. Switch from CeleryExecutor to LocalExecutor to reduce overhead
  • B. Increase the task timeout setting in the DAG configuration configured for optimal performance and minimal operational overhead
  • C. Upgrade the MWAA environment class to mw1.medium or mw1.large to provide more resources per worker
  • D. Add more tasks per worker by increasing worker_concurrency in Airflow configuration overrides
Jawaban Benar: C
SIGTERM signals ketika worker CPU secara konsisten tinggi (>90%) menunjukkan resource exhaustion — workers kehabisan resources dan Airflow/system mengirim SIGTERM untuk membunuh task processes yang melebihi limits. Upgrade environment class (mw1.small → mw1.medium/large) meningkatkan CPU dan memory per worker.

Opsi A: SALAH. Tidak berlaku — MWAA selalu menggunakan CeleryExecutor dan tidak bisa diubah ke LocalExecutor.
Opsi B: SALAH. Tidak menyelesaikan resource exhaustion — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Justru memperburuk masalah dengan menambah load pada workers yang sudah overloaded.
3
A data engineer's MWAA DAG uses a custom Python library that is installed via requirements.txt. After updating requirements.txt with a new package version, the environment update fails and enters an "UPDATE_FAILED" state. The previous version was working correctly. What should the engineer do FIRST to diagnose the issue?
  • A. Open an AWS Support ticket as UPDATE_FAILED indicates an AWS service issue
  • B. Check the MWAA environment's CloudWatch Log group for the requirements installation logs to identify dependency conflicts
  • C. Revert to the previous requirements.txt version immediately without investigation
  • D. Delete and recreate the MWAA environment with the new requirements configured for optimal performance and minimal operational overhead
Jawaban Benar: B
MWAA menyimpan log instalasi requirements di CloudWatch Logs. Langkah pertama adalah memeriksa log tersebut untuk mengidentifikasi error spesifik — biasanya dependency conflicts, package incompatibilities, atau package yang tidak tersedia. Ini memberikan informasi untuk fix yang tepat.

Opsi A: SALAH. Salah — UPDATE_FAILED biasanya karena user's requirements/plugins, bukan AWS service issue.
Opsi B: BENAR.
Opsi C: SALAH. Tidak membantu memahami masalah untuk fix di masa depan.
Opsi D: SALAH. Sangat disruptive dan tidak diperlukan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
4
A company's MWAA environment suddenly cannot access their Amazon RDS PostgreSQL database that is used as a data source in multiple DAGs. Tasks fail with connection timeout errors. The MWAA environment and RDS instance are in the same VPC but different subnets. The RDS instance is confirmed to be running and accessible from an EC2 instance in the same VPC. What should be checked FIRST?
  • A. The RDS instance's security group inbound rules to verify it allows traffic from the MWAA environment's security group
  • B. The MWAA Airflow connection configuration for correct hostname and port
  • C. The RDS instance's parameter group to check max_connections setting
  • D. The MWAA execution role to verify it has permissions to access RDS configured for optimal performance and minimal operational overhead
Jawaban Benar: A
Connection timeout (bukan authentication failure atau connection refused) antara resources di VPC yang berbeda subnet paling sering disebabkan oleh security group rules. MWAA workers berjalan di VPC menggunakan security group tertentu, dan RDS security group harus explicitly allow inbound traffic dari MWAA security group pada port database (3306/5432).

Opsi A: BENAR.
Opsi B: SALAH. Jika sebelumnya berfungsi dan konfigurasi tidak berubah, ini bukan penyebab.
Opsi C: SALAH. Akan menyebabkan "too many connections" error, bukan timeout.
Opsi D: SALAH. RDS PostgreSQL connection menggunakan username/password melalui network, bukan IAM roles (kecuali IAM auth di-enable) — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
5
A data engineer observes that their MWAA environment's DAG processing time has significantly increased. Previously, DAGs were parsed in under 30 seconds, but now parsing takes over 5 minutes. The DAGs folder contains 150 DAG files. Several DAGs use top-level code that queries AWS services (S3, DynamoDB) during import. What is the MOST likely cause and solution?
  • A. The scheduler needs more memory; upgrade to a larger environment class configured for optimal performance and minimal operational overhead
  • B. 150 DAG files exceeds the MWAA maximum; consolidate DAGs into fewer files
  • C. Top-level code that makes API calls during DAG parsing is blocking the scheduler; move API calls inside task callables
  • D. The S3 bucket hosting DAGs has throttling; enable S3 Transfer Acceleration
Jawaban Benar: C
Airflow scheduler mem-parse setiap DAG file secara periodik (default setiap 30 detik). Kode di top-level (di luar task functions) dieksekusi setiap kali scheduler parse file. Jika top-level code membuat API calls ke S3/DynamoDB, ini menambah latency signifikan yang dimultiplikasi dengan jumlah DAG files (150 × API call latency). Solusinya adalah memindahkan semua API calls ke dalam task callables yang hanya dieksekusi saat task running.

Opsi A: SALAH. Bisa membantu sedikit tapi tidak menyelesaikan root cause — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Salah — 150 DAGs masih dalam batas wajar.
Opsi C: BENAR.
Opsi D: SALAH. Tidak relevan dengan DAG parsing time.
6
An MWAA environment becomes inaccessible — the Airflow webserver returns HTTP 503 errors and no one can access the UI. Scheduled DAGs are still running according to CloudWatch Logs from the scheduler. What should the data engineer investigate?
  • A. The MWAA environment's network configuration — verify NAT Gateway or VPC endpoints are functioning for the webserver subnet
  • B. The scheduler is overloaded and needs more resources, causing the webserver to become unresponsive
  • C. The S3 DAGs bucket has been deleted, causing the webserver to fail
  • D. All workers have failed and the webserver cannot display task status for the webserver subnet
Jawaban Benar: A
MWAA webserver memerlukan network connectivity yang proper. HTTP 503 menunjukkan webserver tidak bisa melayani requests, yang sering disebabkan oleh networking issues — NAT Gateway unhealthy, VPC endpoint misconfiguration, atau network ACL blocking traffic. Fakta bahwa scheduler masih berjalan (DAGs running) menunjukkan masalah spesifik pada webserver networking, bukan general environment failure.

Opsi A: BENAR.
Opsi B: SALAH. Salah — scheduler dan webserver adalah komponen terpisah; scheduler overload tidak menyebabkan webserver 503.
Opsi C: SALAH. Salah — jika DAGs bucket dihapus, scheduler juga akan berhenti.
Opsi D: SALAH. Salah — worker failure tidak membuat webserver inaccessible — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
7
A data engineer's MWAA DAG includes a PythonOperator task that processes large CSV files (2 GB) downloaded from S3. The task consistently fails with "OSError: [Errno 28] No space left on device" after running for about 20 minutes. The worker's local storage is filling up. What is the MOST appropriate solution?
  • A. Mount an EFS volume to the MWAA workers for additional storage
  • B. Process the file in chunks using streaming reads instead of downloading the entire file to local disk, or use /tmp with cleanup logic
  • C. Upgrade to the largest MWAA environment class for more local storage
  • D. Increase the worker count to distribute the load across more workers with cleanup logic
Jawaban Benar: B
MWAA workers memiliki limited local storage. Solusi terbaik adalah mengubah approach — gunakan streaming reads (misalnya boto3 S3 streaming atau pandas chunked reading) untuk memproses file tanpa menyimpan seluruhnya di disk lokal. Jika perlu temp storage, gunakan /tmp dengan explicit cleanup setelah selesai.

Opsi A: SALAH. MWAA tidak mendukung mounting EFS ke workers secara native.
Opsi B: BENAR.
Opsi C: SALAH. Environment class upgrade memberikan sedikit lebih banyak storage tapi mungkin masih tidak cukup untuk 2 GB files + intermediate data.
Opsi D: SALAH. Tidak membantu jika setiap worker masih harus process file 2 GB secara lokal — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
8
A data team notices that tasks in their MWAA DAG stay in "queued" state for extended periods (30+ minutes) before being picked up by workers. The environment has min_workers=2 and max_workers=10. During peak hours, there are 50 tasks waiting in the queue. What is the MOST likely cause?
  • A. The Celery broker (SQS) has a message delivery delay configured and current workers are at maximum capacity
  • B. The scheduler is processing DAGs too slowly to dispatch tasks to workers
  • C. The worker_concurrency setting is too low, limiting how many tasks each worker can execute simultaneously
  • D. The MWAA autoscaling is too slow to scale up workers, and current workers are at maximum capacity
Jawaban Benar: D
MWAA auto-scaling memerlukan waktu untuk menambah workers (provisioning new containers). Jika ada burst 50 tasks tiba-tiba dengan hanya 2 min workers, scaling ke 10 workers membutuhkan waktu. Selama scaling period, tasks menunggu di queue. Solusinya adalah meningkatkan min_workers agar ada cukup workers ready untuk peak demand.

Opsi A: SALAH. MWAA manages Celery broker configuration, users tidak bisa set message delay — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Scheduler queuing dan task execution are separate; scheduler sudah queued tasks (mereka sudah di "queued" state).
Opsi C: SALAH. Jika ini masalahnya, tasks akan stuck bukan karena kurang workers tapi karena limit per worker, tapi ini biasanya terlihat saat workers idle yang tidak sesuai scenario ini.
Opsi D: BENAR.
9
After adding a custom Airflow plugin to the plugins.zip file in the MWAA S3 bucket, the environment update completes successfully but the plugin's custom operator is not available — DAGs importing it fail with "ModuleNotFoundError". What is the MOST likely issue?
  • A. The plugins.zip file was not uploaded to the correct S3 path specified in the MWAA environment configuration
  • B. The MWAA execution role lacks S3 permissions to read the plugins.zip file configured for optimal performance and minimal operational overhead
  • C. Custom plugins are not supported in Amazon MWAA; only built-in Airflow operators are available
  • D. The directory structure inside plugins.zip is incorrect — the plugin module must be at the root level of the zip or follow Airflow's expected plugin directory structure
Jawaban Benar: D
MWAA mengekstrak plugins.zip ke folder plugins/ Airflow. Jika directory structure di dalam zip salah (misalnya ada extra parent directory seperti plugins/my-plugin/ bukannya langsung file di root), module path tidak sesuai dan import gagal. Structure yang benar: zip root harus langsung berisi __init__.py dan module files yang bisa di-import.

Opsi A: SALAH. Jika path salah, environment update seharusnya gagal atau warning muncul, bukan silent failure.
Opsi B: SALAH. Jika permission issue, environment update akan gagal karena MWAA perlu membaca plugins — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.zip saat update.
Opsi C: SALAH. Salah — MWAA fully mendukung custom plugins.
Opsi D: BENAR.
10
A data engineering team's MWAA environment shows "Scheduler Heartbeat" failures in the CloudWatch metrics dashboard. DAGs are not being scheduled on time and some tasks are being marked as "zombie" tasks. The scheduler log group shows the scheduler process is being killed and restarted frequently. What is the root cause and resolution?
  • A. The scheduler is running out of memory due to too many DAGs or complex DAG structures; reduce DAG count or simplify DAGs and consider upgrading environment class
  • B. CloudWatch Logs subscription filters are blocking scheduler log delivery
  • C. The MWAA environment's IAM role has expired credentials and consider upgrading environment class
  • D. The VPC's DNS resolution is failing, causing scheduler connectivity issues
Jawaban Benar: A
Scheduler heartbeat failures dan frequent process kills/restarts adalah classic symptoms of scheduler resource exhaustion (OOM — Out of Memory). Ketika scheduler kehabisan memory (karena parsing terlalu banyak DAGs, DAGs yang sangat complex, atau banyak running task instances), process di-kill oleh OS dan di-restart oleh supervisor. Zombie tasks terjadi karena scheduler tidak bisa send heartbeats saat dead. Solusi: kurangi jumlah/complexity DAGs, atau upgrade environment class untuk lebih banyak scheduler memory.

Opsi A: BENAR.
Opsi B: SALAH. Tidak mempengaruhi scheduler operation.
Opsi C: SALAH. MWAA manages credential rotation otomatis — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Akan menyebabkan connectivity errors, bukan OOM kills.
