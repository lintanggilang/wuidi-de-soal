A data engineer needs to schedule an AWS Glue ETL job to run every weekday at 6:00 AM UTC. The schedule must NOT trigger on weekends. Which scheduling approach is MOST appropriate?
  • A. Create an Amazon EventBridge rule with a cron expression: cron(0 6 ? * MON-FRI *)
  • B. Use the AWS Glue built-in scheduler with a rate expression: rate(1 day)
  • C. Create a CloudWatch Events rule with rate(24 hours) and a Lambda to check the day
  • D. Use Amazon MWAA (Airflow) with a DAG that runs daily and has a Python operator to skip weekends
Jawaban Benar: A
EventBridge (penerus CloudWatch Events) mendukung cron expressions yang dapat menentukan hari dalam minggu. cron(0 6 ? * MON-FRI *) berjalan pada pukul 6:00 UTC hanya pada hari Senin hingga Jumat. Ini solusi paling sederhana dan native. Opsi B (rate expression) tidak bisa mengecualikan hari tertentu. Opsi C menambah kompleksitas tidak perlu dengan Lambda filter. Opsi D (MWAA) berlebihan untuk scheduling sederhana satu job.
2
A company has a complex data pipeline with 15 AWS Glue jobs that have dependencies between them. Job B and Job C depend on Job A completing successfully. Job D depends on both Job B and Job C completing. Which scheduling solution BEST manages these dependencies?
  • A. Amazon MWAA (Apache Airflow) with a DAG defining task dependencies
  • B. AWS Glue Workflows with triggers and job dependencies
  • C. EventBridge rules chained with Glue job state change events
  • D. AWS Step Functions with Glue StartJobRun tasks
Jawaban Benar: B
AWS Glue Workflows dirancang khusus untuk mengorkestrasikan multiple Glue jobs dengan dependensi. Workflows mendukung triggers conditional (on job success/failure) dan fan-out/fan-in patterns. Untuk pipeline yang sepenuhnya menggunakan Glue jobs, ini adalah solusi paling terintegrasi. Opsi A (MWAA) adalah pilihan valid tapi menambah overhead operasional (cluster management). Opsi C (EventBridge chaining) sulit untuk fan-in (menunggu multiple jobs selesai). Opsi D (Step Functions) bisa bekerja tapi lebih generik dan membutuhkan lebih banyak konfigurasi.
3
A data engineering team manages 50+ data pipelines with cross-system dependencies spanning AWS Glue, Amazon EMR, Amazon Redshift, and external APIs. They need a centralized scheduler with DAG visualization, retry policies, SLA monitoring, and alerting. Which solution is MOST appropriate?
  • A. Amazon MWAA (Managed Workflows for Apache Airflow)
  • B. AWS Step Functions with CloudWatch alarms
  • C. AWS Glue Workflows with EventBridge notifications
  • D. Amazon EventBridge Scheduler with Lambda orchestration
Jawaban Benar: A
Amazon MWAA (Apache Airflow) adalah satu-satunya solusi yang menyediakan semua fitur: DAG visualization, cross-system orchestration (Glue, EMR, Redshift, APIs), retry policies, SLA monitoring, dan alerting built-in. Ini dirancang untuk pipeline orchestration berskala enterprise. Opsi B (Step Functions) tidak memiliki DAG visualization dan SLA monitoring bawaan. Opsi C (Glue Workflows) hanya untuk Glue jobs. Opsi D (EventBridge + Lambda) tidak memiliki UI visualization dan SLA features.
4
A data engineer configured an AWS Glue crawler to run on a schedule every hour to detect new partitions in an S3 data lake. However, the crawler runs even when no new data has arrived, consuming unnecessary DPU hours. How can the engineer optimize this?
  • A. Replace the scheduled crawler with an S3 event notification that triggers a Lambda function calling the MSCK REPAIR TABLE command in Athena
  • B. Configure the crawler with "Crawl new folders only" and reduce schedule to once daily
  • C. Use an EventBridge rule triggered by S3:PutObject to start the crawler only when new files arrive
  • D. Increase the crawler's recrawl policy to "Crawl everything" to process faster
Jawaban Benar: C
Menggunakan EventBridge untuk mendeteksi S3:PutObject events dan memicu crawler hanya ketika data baru tiba menghilangkan run yang tidak perlu. Crawler hanya berjalan saat ada data baru. Opsi A (MSCK REPAIR TABLE) hanya menambahkan partisi Hive-style yang sudah ada, tidak mendeteksi schema changes. Opsi B mengurangi frekuensi tapi masih bisa berjalan tanpa data baru. Opsi D (Crawl everything) justru lebih boros karena memproses semua data setiap kali.
5
A company uses Amazon MWAA to orchestrate their data pipelines. They need to schedule a DAG that runs at 8:00 AM local time in the US/Eastern timezone, properly handling daylight saving time transitions. How should this be configured in the Airflow DAG?
  • A. Set schedule_interval with a cron expression and specify start_date with timezone: pendulum.timezone('US/Eastern')
  • B. Use schedule_interval='0 8 * * *' with default UTC timezone and manually adjust for DST
  • C. Create two DAGs — one for EST and one for EDT — and enable/disable them manually during transitions
  • D. Use a Lambda function triggered by EventBridge to start the DAG at the correct local time
Jawaban Benar: A
Apache Airflow mendukung timezone-aware scheduling menggunakan library pendulum. Dengan menentukan timezone di start_date, Airflow secara otomatis menangani transisi DST. DAG akan selalu berjalan pada 8:00 AM Eastern terlepas dari apakah EST atau EDT berlaku. Opsi B (UTC tanpa timezone) menyebabkan DAG berjalan pada jam yang salah saat DST berubah. Opsi C sangat manual dan error-prone. Opsi D menambah kompleksitas yang tidak perlu.
6
A data engineer needs to schedule a data pipeline that must complete before 9:00 AM every morning. If the pipeline fails, it should automatically retry up to 3 times with 10-minute intervals. If all retries fail, the on-call engineer must be notified. Which combination of services provides this functionality?
  • A. EventBridge Scheduler to trigger the pipeline, Step Functions for retry logic, and SNS for notification
  • B. EventBridge Scheduler with built-in retry policy (3 retries) and a dead-letter queue connected to SNS
  • C. AWS Glue trigger with time-based schedule, built-in Glue job retry, and CloudWatch alarm for failures
  • D. Amazon MWAA DAG with retries=3, retry_delay=timedelta(minutes=10), and email on_failure_callback
Jawaban Benar: D
MWAA (Airflow) menyediakan built-in support untuk retries, retry_delay, dan callbacks (on_failure_callback) dalam satu konfigurasi DAG. Ini mencakup semua requirements: scheduling, retry logic, interval, dan notification. Opsi A bekerja tapi membutuhkan integrasi 3 service. Opsi B (EventBridge retry) memiliki retry interval yang sangat pendek (hingga 185 detik) bukan 10 menit. Opsi C (Glue retry) bisa retry tapi CloudWatch alarm harus dikonfigurasi terpisah dan retry interval tidak bisa dikustomisasi per Glue.

A data engineer is using Amazon EventBridge Scheduler to trigger an AWS Glue job every 15 minutes. The Glue job occasionally takes longer than 15 minutes to complete, causing overlapping runs. How should the engineer prevent concurrent executions?
  • A. Configure the Glue job with maximum concurrency set to 1 (MaxConcurrentRuns = 1)
  • B. Add a Lambda function before the Glue job to check if a previous run is still active
  • C. Increase the EventBridge schedule to every 30 minutes
  • D. Enable Glue job bookmarks to prevent duplicate processing
Jawaban Benar: A
MaxConcurrentRuns = 1 pada Glue job memastikan hanya satu instance job yang berjalan pada satu waktu. Jika schedule memicu run baru sementara run sebelumnya masih berjalan, run baru akan diskip atau queued. Opsi B menambah kompleksitas yang tidak perlu. Opsi C tidak menyelesaikan masalah karena job masih bisa exceed 30 menit. Opsi D (bookmarks) mencegah pemrosesan ulang data tapi tidak mencegah concurrent executions.

A data engineering team is migrating from a self-managed Apache Airflow on EC2 to Amazon MWAA. Their existing DAGs use custom Python packages and operators. What must they do to ensure the DAGs work on MWAA?
  • A. Package custom dependencies in a requirements.txt file and upload DAGs and plugins to the designated S3 bucket
  • B. Install custom packages directly on the MWAA worker nodes via SSH
  • C. Use only Airflow providers available in the MWAA managed image without custom packages
  • D. Deploy custom operators as Lambda functions and call them from the DAG
Jawaban Benar: A
MWAA menggunakan S3 bucket untuk DAGs (dags/ folder), plugins (plugins.zip), dan dependencies (requirements.txt). Custom Python packages didaftarkan di requirements.txt dan diinstall otomatis saat environment update. Plugins (custom operators) dipaket dalam plugins.zip. Opsi B tidak mungkin karena MWAA adalah managed service tanpa akses SSH. Opsi C membatasi fungsionalitas. Opsi D mengubah arsitektur operator yang sudah ada secara tidak perlu.
9
A company wants to schedule an AWS Glue crawler to run immediately after a Glue ETL job completes successfully. If the ETL job fails, the crawler should NOT run. Which is the MOST straightforward way to implement this?
  • A. Create a Glue Workflow with a conditional trigger that starts the crawler on job SUCCEEDED state
  • B. Use EventBridge rule matching Glue job state change to SUCCEEDED, targeting StartCrawler API
  • C. Add a post-processing step in the Glue job script to programmatically start the crawler via boto3
  • D. Use Step Functions with a Choice state after the Glue job to decide whether to start the crawler
Jawaban Benar: A
Glue Workflow dengan conditional trigger adalah cara paling native dan straightforward untuk menjalankan crawler setelah job sukses. Trigger "SUCCEEDED" hanya memicu crawler ketika job selesai dengan sukses. Opsi B (EventBridge) bekerja tapi membutuhkan konfigurasi di luar Glue. Opsi C (boto3 di script) mixing orchestration logic dengan ETL logic yang bukan best practice. Opsi D (Step Functions) overkill untuk dua step sederhana.
10
A data engineer uses Amazon EventBridge Scheduler to trigger multiple Lambda functions and Glue jobs at different intervals. The engineer needs to temporarily pause all scheduled tasks during a planned maintenance window without deleting any schedules. What is the MOST efficient approach?
  • A. Use a schedule group and disable the entire group during maintenance
  • B. Delete all schedules before maintenance and recreate them after
  • C. Change each schedule's state to DISABLED individually
  • D. Set each schedule's end date to the maintenance start time
Jawaban Benar: A
EventBridge Scheduler mendukung schedule groups. Dengan menempatkan semua related schedules dalam satu group, Anda bisa men-disable (atau delete) seluruh group sekaligus. Ini paling efisien untuk batch operations. Opsi B (delete + recreate) berisiko kehilangan konfigurasi. Opsi C (disable satu per satu) tidak efisien untuk banyak schedules. Opsi D (end date) membutuhkan update setiap schedule dan perlu di-reset setelah maintenance.
