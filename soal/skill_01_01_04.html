Skill 1.1.4: Consume Data APIs

Consuming REST APIs, GraphQL APIs, and integrating external data sources via API calls in data pipelines

A data engineer needs to consume a third-party weather REST API that returns paginated JSON responses. The API has a rate limit of 100 requests per minute. The engineer must ingest 50,000 records and store them in Amazon S3. Which AWS service and approach is MOST suitable for this requirement?
  • A. AWS Lambda with a Step Functions state machine implementing pagination and rate limiting with Wait states
  • B. Amazon AppFlow with a custom connector to the weather API
  • C. AWS Glue Python Shell job with retry logic and sleep intervals
  • D. Amazon API Gateway with a direct integration to S3
Jawaban Benar: A
Step Functions dengan Lambda ideal untuk workflow yang membutuhkan pagination (Map state) dan rate limiting (Wait state). Lambda menangani setiap API call, Step Functions mengorkestrasikan loop pagination dan mengatur jeda antar batch. Ini serverless dan cost-effective. Opsi B (AppFlow) hanya mendukung SaaS connectors yang sudah ada, bukan custom REST APIs generik. Opsi C (Glue Python Shell) bisa timeout untuk 50,000 records dengan rate limit. Opsi D (API Gateway) untuk menerima API calls, bukan consuming external APIs.
2
A company uses Amazon API Gateway to expose a data API that returns customer analytics. The data engineer needs to ensure the API can handle burst traffic of 10,000 requests per second while maintaining data freshness within 5 minutes. The underlying data is stored in Amazon Redshift. Which architecture provides OPTIMAL performance?
  • A. API Gateway → Lambda → Redshift Data API with API Gateway caching enabled (TTL 5 minutes)
  • B. API Gateway → Lambda → Direct Redshift JDBC connection
  • C. API Gateway → Lambda → ElastiCache (pre-populated from Redshift every 5 minutes)
  • D. API Gateway → Direct integration with Redshift Data API
Jawaban Benar: A
API Gateway caching menangani burst traffic tanpa membebani backend. Dengan TTL 5 menit, data tetap fresh sesuai requirement. Redshift Data API menghindari masalah connection pooling. Opsi B (direct JDBC) tidak bisa scale ke 10K rps karena connection limit. Opsi C (ElastiCache) menambah kompleksitas operasional untuk pre-populating cache. Opsi D tidak mendukung direct integration tanpa Lambda dan tidak bisa handle caching di layer API Gateway tanpa Lambda proxy.

A data engineer is building a pipeline that consumes data from an external partner's API. The API uses OAuth 2.0 authentication with token refresh. The access token expires every hour. Where should the data engineer securely store and manage the OAuth credentials?
  • A. AWS Secrets Manager with automatic rotation configured using a Lambda rotation function
  • B. AWS Systems Manager Parameter Store as a SecureString parameter
  • C. Hard-coded in the Lambda function environment variables encrypted with KMS
  • D. Amazon DynamoDB table with encryption at rest enabled
Jawaban Benar: A
AWS Secrets Manager dirancang khusus untuk mengelola credentials dengan fitur automatic rotation. Lambda rotation function dapat secara otomatis merefresh OAuth token sebelum expired. Opsi B (Parameter Store) bisa menyimpan credentials tapi tidak memiliki built-in rotation mechanism. Opsi C (environment variables) tidak aman untuk credentials yang berubah dan sulit di-rotate. Opsi D (DynamoDB) bukan tempat yang tepat untuk credential management.
4
A media company needs to consume a video metadata API that returns large responses (up to 50 MB per request). The data must be processed and stored in S3. AWS Lambda has a payload size limit. Which approach handles this large API response scenario?
  • A. Use Lambda to call the API with streaming response, write directly to S3 using multipart upload
  • B. Use an ECS Fargate task to call the API, process the response, and write to S3
  • C. Use API Gateway with a 50 MB payload limit configuration
  • D. Use Lambda with /tmp storage (10 GB) to buffer the response before uploading to S3
Jawaban Benar: D
Lambda /tmp storage mendukung hingga 10 GB (jauh lebih besar dari 50 MB response). Lambda bisa streaming API response ke /tmp lalu upload ke S3. Ini adalah solusi serverless yang paling sederhana. Opsi A salah karena Lambda invocation payload limit adalah 6 MB (synchronous), bukan soal streaming. Opsi B bisa bekerja tapi lebih kompleks untuk dikelola. Opsi C (API Gateway) memiliki batas payload 10 MB dan bukan untuk consuming external API. Opsi D paling tepat karena /tmp storage cukup untuk 50 MB.
5
A data engineering team needs to ingest data from multiple SaaS applications (Salesforce, ServiceNow, and Zendesk) into a centralized S3 data lake. Each source has different API protocols. Which approach provides the MOST unified and manageable solution?
  • A. Amazon AppFlow with pre-built connectors for each SaaS application
  • B. Separate Lambda functions for each API with custom integration code
  • C. AWS Glue ETL jobs with marketplace connectors for each SaaS
  • D. Amazon EventBridge with partner event sources for each application
Jawaban Benar: A
Amazon AppFlow memiliki pre-built connectors untuk Salesforce, ServiceNow, Zendesk, dan banyak SaaS lainnya. Ini memberikan unified interface untuk mengonfigurasi flows dari semua sources ke S3, dengan features seperti scheduling, data transformation, dan error handling built-in. Opsi B membutuhkan custom code untuk setiap source. Opsi C (Glue) tidak memiliki native connectors untuk semua SaaS ini. Opsi D (EventBridge) hanya untuk events, bukan data ingestion bulk.
6
A data engineer needs to call the Amazon Redshift Data API asynchronously from a Lambda function to execute a long-running query. The query takes 10 minutes to complete. How should the engineer implement this to get the results?
  • A. Call ExecuteStatement, then use EventBridge to trigger another Lambda when the query completes via Redshift Data API state change events
  • B. Call ExecuteStatement and use a while loop with DescribeStatement to poll until completion
  • C. Call ExecuteStatement with synchronous mode enabled and wait for the result
  • D. Call BatchExecuteStatement and retrieve results immediately
Jawaban Benar: A
Redshift Data API adalah asynchronous. ExecuteStatement mengembalikan query ID segera. EventBridge menangkap event ketika statement berubah status ke FINISHED, lalu memicu Lambda kedua yang mengambil hasil. Ini event-driven dan efisien. Opsi B (polling) akan timeout karena Lambda memiliki batas 15 menit dan query memakan 10 menit. Opsi C tidak ada mode synchronous di Redshift Data API. Opsi D (BatchExecuteStatement) tetap asynchronous dan tidak mengembalikan hasil langsung.
7
An e-commerce company exposes product data through a GraphQL API built on AWS AppSync. A partner company needs to consume this API to sync product catalogs daily. The partner processes data in batches of 1,000 items. Which approach allows the partner to efficiently consume the GraphQL API for batch data retrieval?
  • A. Use GraphQL queries with pagination (cursor-based) and request only needed fields to minimize payload
  • B. Use GraphQL subscriptions to receive all product updates in real-time
  • C. Directly query the underlying DynamoDB table using the AWS SDK
  • D. Use AppSync pipeline resolvers to batch all results in a single response
Jawaban Benar: A
GraphQL dengan cursor-based pagination memungkinkan pengambilan data dalam batch (1,000 items per page). Pemilihan field (query projection) mengurangi ukuran response. Ini adalah pola standar untuk batch consumption dari GraphQL API. Opsi B (subscriptions) untuk real-time streaming, bukan batch retrieval. Opsi C melewati API layer yang melanggar security boundaries. Opsi D (pipeline resolvers) untuk composing multiple data sources server-side, bukan batch response.
8
A data engineer is consuming a financial data API that occasionally returns HTTP 429 (Too Many Requests) errors. The pipeline must be resilient and eventually process all data. Which implementation pattern is MOST appropriate?
  • A. Implement exponential backoff with jitter and a maximum retry count with dead letter queue for failed requests
  • B. Immediately retry failed requests with no delay
  • C. Skip the failed requests and log them for manual retry later
  • D. Increase the concurrency of API calls to compensate for failed requests
Jawaban Benar: A
Exponential backoff with jitter adalah best practice untuk handling rate limiting (429 errors). Jitter mencegah thundering herd problem dimana semua retry terjadi bersamaan. Maximum retry count mencegah infinite loops. Dead letter queue menangkap requests yang gagal setelah semua retry untuk investigasi. Opsi B (immediate retry) memperburuk rate limiting. Opsi C kehilangan data. Opsi D (increase concurrency) justru menyebabkan lebih banyak 429 errors.
9
A data engineer needs to consume data from Amazon DynamoDB using the DynamoDB API for a batch export. The table has 100 GB of data. The engineer wants to minimize the impact on the table's read capacity. Which API operation is MOST appropriate?
  • A. Use DynamoDB Export to S3 feature which reads from the table's backup without consuming read capacity
  • B. Use Scan operation with parallel scan and a rate limiter
  • C. Use Query operation on each partition key sequentially
  • D. Use BatchGetItem with consistent reads enabled
Jawaban Benar: A
DynamoDB Export to S3 membaca dari point-in-time recovery (PITR) backup dan tidak mengonsumsi read capacity units pada tabel. Ini ideal untuk batch export tanpa impacting production. Opsi B (parallel Scan) mengonsumsi banyak RCU. Opsi C (sequential Query) lambat dan masih consume RCU. Opsi D (BatchGetItem) membutuhkan mengetahui semua keys terlebih dahulu dan juga consume RCU.

A healthcare company needs to consume a FHIR (Fast Healthcare Interoperability Resources) API from a hospital system. The API requires mutual TLS (mTLS) authentication. The data pipeline runs on AWS Lambda. How should the data engineer configure the client certificate for mTLS?
  • A. Store the client certificate and private key in AWS Secrets Manager, retrieve them in Lambda, and configure the HTTPS client
  • B. Attach the client certificate to the Lambda function's execution role
  • C. Use AWS Certificate Manager (ACM) to generate the client certificate and associate it with Lambda
  • D. Store the certificate in the Lambda deployment package as a static file
Jawaban Benar: A
AWS Secrets Manager adalah tempat aman untuk menyimpan client certificates dan private keys. Lambda mengambil secret saat runtime dan mengonfigurasi HTTPS client (misalnya requests library di Python) dengan mTLS. Ini memungkinkan rotation tanpa redeploy. Opsi B (IAM role) tidak mendukung client certificates. Opsi C (ACM) hanya untuk server certificates di AWS services, bukan client certificates di Lambda outbound calls. Opsi D (static file) tidak aman karena private key terexpose di deployment package dan sulit di-rotate.
