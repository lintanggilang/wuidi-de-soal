Skill 3.3.1: Extract Logs for Audits

Extracting and preparing log data from various AWS services for compliance auditing

1
A financial services company must provide auditors with a complete record of all API calls made to their data lake infrastructure over the past 12 months. The audit team requires the ability to query specific events by user, service, and time range. The logs must be stored cost-effectively while supporting SQL-based analysis. Which solution meets these requirements?
  • A. Enable AWS CloudTrail and deliver logs to Amazon Redshift using Amazon Data Firehose. Query logs using Redshift SQL, satisfying all of the stated requirements with minimal effort
  • B. Enable AWS CloudTrail and deliver logs to an S3 bucket with a 12-month retention lifecycle policy. Use Amazon Athena with partition projection to query logs.
  • C. Enable AWS CloudTrail and stream logs to Amazon CloudWatch Logs. Use CloudWatch Logs Insights to query events, satisfying strict compliance and audit requirements
  • D. Enable AWS CloudTrail and store logs in Amazon DynamoDB with a TTL of 365 days. Use PartiQL to query events, with native S3 integration and optimized data transfer
Jawaban Benar: B
CloudTrail logs delivered to S3 with Athena queries is the most cost-effective solution for long-term audit log storage and SQL-based analysis. Partition projection enables efficient querying by date without running MSCK REPAIR TABLE. Option B: CloudWatch Logs is more expensive for 12-month retention and Logs Insights has query limitations for large volumes. Option C: Redshift is over-engineered and expensive for infrequent audit queries. Option D: DynamoDB is not optimized for complex analytical queries on log data and would be prohibitively expensive at scale.

Opsi A: SALAH.
Opsi B: BENAR.
Opsi C: SALAH.
Opsi D: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
2
A healthcare organization stores sensitive patient data in Amazon S3. For HIPAA compliance, the security team needs to audit all object-level access (GetObject, PutObject, DeleteObject) to specific S3 buckets containing Protected Health Information (PHI). Which CloudTrail configuration is required?
  • A. Configure S3 Event Notifications to send all access events to CloudTrail via SNS.
  • B. Enable management events in CloudTrail; S3 object-level access is captured by default.
  • C. Enable data events for S3 in the CloudTrail trail and specify the target bucket ARNs.
  • D. Enable S3 server access logging on the PHI buckets and export to CloudTrail.
Jawaban Benar: C
CloudTrail data events must be explicitly enabled to capture S3 object-level operations (GetObject, PutObject, DeleteObject). You can scope data events to specific bucket ARNs to control costs. Option A is incorrect because management events only capture bucket-level operations (CreateBucket, DeleteBucket), not object-level access. Option C: S3 server access logging is separate from CloudTrail and cannot export to CloudTrail. Option D: S3 Event Notifications are for triggering workflows, not for sending to CloudTrail.

Opsi A: SALAH.
Opsi B: SALAH.
Opsi C: BENAR.
Opsi D: SALAH.
3
A data engineering team operates an Amazon Redshift cluster that processes financial transactions. Auditors require a report showing all user connections, disconnections, and authentication failures over the past quarter. The report must include the database user, source IP, and timestamp. Which Redshift audit logging feature should be used?
  • A. Enable Redshift audit logging and analyze the user activity log delivered to S3.
  • B. Enable enhanced VPC flow logs for the Redshift subnet and filter by port 5439.
  • C. Enable Redshift audit logging and analyze the connection log delivered to S3.
  • D. Query the STL_CONNECTION_LOG system table directly in Redshift, enforcing encryption and fine-grained access control
Jawaban Benar: C
Redshift audit logging includes connection logs that record authentication attempts, connections, and disconnections with user identity, IP address, and timestamps. Delivering to S3 provides durable, long-term storage for quarterly audits. Option B: The user activity log captures SQL statements executed, not connection/authentication events. Option C: STL_CONNECTION_LOG is stored on the cluster and has limited retention (2-5 days depending on cluster size), making it unsuitable for quarterly audits. Option D: VPC Flow Logs capture network traffic metadata but not database-level authentication details like username or auth failures.

Opsi A: SALAH.
Opsi B: SALAH.
Opsi C: BENAR.
Opsi D: SALAH.
4
A company needs to extract VPC Flow Logs for a network security audit of their data pipeline infrastructure. The audit requires analysis of traffic patterns between their EMR cluster and external data sources over the last 30 days. The analysis must support ad-hoc SQL queries with sub-minute granularity. Which approach provides the MOST efficient solution?
  • A. Publish VPC Flow Logs to S3 in Parquet format with Hive-compatible prefixes. Query using Athena with partition projection on date.
  • B. Publish VPC Flow Logs to S3 in default text format. Load into Amazon Redshift using COPY command for analysis.
  • C. Publish VPC Flow Logs to CloudWatch Logs. Use CloudWatch Logs Insights for all queries, with Hive-compatible prefixes
  • D. Publish VPC Flow Logs to CloudWatch Logs. Export the log group to S3, then query with Athena.
Jawaban Benar: A
VPC Flow Logs can be published directly to S3 in Parquet format with Hive-compatible partition prefixes (per-hour). This is the most efficient for Athena queries because Parquet enables columnar scanning and partition projection eliminates the need for partition maintenance. Option B adds unnecessary complexity with CloudWatch as an intermediary. Option C: Loading into Redshift is expensive for periodic audit queries. Option D: CloudWatch Logs Insights has a 10,000 result limit per query and is less cost-effective for large-volume analysis compared to S3 + Athena.

Opsi A: BENAR.
Opsi B: SALAH.
Opsi C: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi D: SALAH.
5
An enterprise runs multiple data pipelines across 15 AWS accounts. The compliance team requires a centralized audit log repository where all CloudTrail events from all accounts are aggregated into a single S3 bucket in the security account. Which CloudTrail configuration achieves this?
  • A. Use AWS Config to aggregate CloudTrail events from all accounts into the security account, with the target S3 bucket in the security account
  • B. Create an EventBridge rule in each account to forward CloudTrail events to the security account's S3 bucket.
  • C. Create individual trails in each account and configure S3 cross-region replication to the security account bucket.
  • D. Create an organization trail in the AWS Organizations management account with the target S3 bucket in the security account.
Jawaban Benar: D
An organization trail in AWS Organizations automatically captures events from all member accounts and delivers them to a centralized S3 bucket. This is the simplest, most scalable solution for multi-account centralized audit logging. Option B: Cross-region replication is for S3 buckets across regions, not for aggregating trails from multiple accounts (and adds management overhead). Option C: AWS Config tracks resource configuration changes, not CloudTrail API events. Option D: While technically possible, this requires maintaining EventBridge rules in every account and doesn't capture all event types reliably.

Opsi A: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi B: SALAH.
Opsi C: SALAH.
Opsi D: BENAR.
6
A data engineer needs to extract S3 access logs to identify which IAM principals accessed specific objects in a data lake during a security investigation. The access logs are stored in a dedicated logging bucket with millions of log files. Querying individual files is impractical. Which approach allows efficient extraction of relevant audit events?
  • A. Use S3 Select to filter individual log files for the target object key, then aggregate results, handling the described workload reliably at scale
  • B. Create an Athena table over the S3 access log bucket using a regex SerDe, then query by object key and requester.
  • C. Use Amazon Macie to scan the access log bucket and identify access patterns. and requester, absorbing sudden traffic spikes without throttling
  • D. Configure S3 Inventory to report on object access patterns for the target objects, meeting the latency and throughput goals of the design
Jawaban Benar: B
Amazon Athena with a regex SerDe can parse S3 server access log format efficiently, enabling SQL queries to filter by object key, requester (IAM principal), operation type, and time range across millions of log files. This is the standard approach for large-scale S3 access log analysis. Option A: S3 Select works on individual files and would require processing millions of files sequentially, which is impractical. Option C: Macie is for discovering sensitive data (PII), not for analyzing access patterns. Option D: S3 Inventory reports on object metadata (size, storage class), not access patterns.

Opsi A: SALAH.
Opsi B: BENAR.
Opsi C: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi D: SALAH.
7
A regulated company must retain all data pipeline audit logs for 7 years to comply with financial regulations. After the first 90 days, logs are rarely accessed but must remain queryable within 12 hours if requested by regulators. Which S3 storage strategy minimizes costs while meeting these requirements?
  • A. Store logs in S3 Standard. Transition to S3 Glacier Deep Archive after 90 days. Delete after 7 years.
  • B. Store logs in S3 Intelligent-Tiering for the entire 7-year period, with native S3 integration and optimized data transfer
  • C. Store logs in S3 Standard. Transition to S3 Glacier Flexible Retrieval after 90 days. Delete after 7 years.
  • D. Store logs in S3 Standard. Transition to S3 Standard-IA after 90 days. Delete after 7 years.
Jawaban Benar: C
S3 Glacier Flexible Retrieval provides the best cost optimization for logs that are rarely accessed but must be retrievable within 12 hours (standard retrieval is 3-5 hours, which satisfies the 12-hour requirement). Option B: Standard-IA is more expensive than Glacier for 7-year retention with rare access. Option C: Glacier Deep Archive has a minimum retrieval time of 12 hours (standard) and can take up to 48 hours, which may not reliably meet the 12-hour SLA. Option D: Intelligent-Tiering has monitoring fees per object that add up at scale, and the archive tiers require configuration that doesn't guarantee the 12-hour retrieval SLA.

Opsi A: SALAH.
Opsi B: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi C: BENAR.
Opsi D: SALAH.

A data engineer needs to extract Redshift user activity logs to identify all SQL queries that accessed a specific sensitive table during a data breach investigation. The user activity logs are delivered to S3. The logs contain thousands of SQL statements per hour. Which approach efficiently filters the relevant audit events?
  • A. Create an Athena table over the Redshift user activity log files in S3 and use SQL to filter by table name in the query text.
  • B. Use Amazon Redshift Spectrum to query the audit log files directly from Redshift, handling the described workload reliably at scale and satisfying strict compliance and audit requirements
  • C. Download the user activity log files and use grep to search for the table name. and use SQL to filter by table name in the query text
  • D. Query the SVL_STATEMENTTEXT system view in Redshift filtered by the table name, enforcing encryption and fine-grained access control and integrating natively with the rest of the pipeline
Jawaban Benar: A
Creating an Athena table over the Redshift user activity logs in S3 enables efficient SQL-based filtering across large volumes of log data. You can use WHERE clauses with LIKE to filter by table name in the query text. Option A: Manual grep is not scalable and not suitable for production audit workflows. Option C: SVL_STATEMENTTEXT has limited retention on the cluster (typically 2-5 days) and may not cover the investigation timeframe. Option D: While Redshift Spectrum could work, it requires the Redshift cluster to be running and available, adding unnecessary cost for a one-time investigation that Athena handles serverlessly.

Opsi A: BENAR.
Opsi B: SALAH.
Opsi C: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi D: SALAH.
9
A company uses Amazon Kinesis Data Streams in their real-time data pipeline. During an audit, they need to demonstrate that no unauthorized applications consumed data from a specific stream during a 2-week period. Which log source provides the necessary evidence?
  • A. CloudTrail data events for Kinesis, filtering for GetRecords and GetShardIterator API calls on the target stream.
  • B. Kinesis Data Streams enhanced monitoring metrics showing consumer application names, satisfying strict compliance and audit requirements
  • C. CloudTrail management events, filtering for Kinesis DescribeStream calls. and GetShardIterator API calls on the target stream
  • D. VPC Flow Logs for the subnet where the Kinesis endpoint resides, satisfying strict compliance and audit requirements
Jawaban Benar: A
CloudTrail data events for Kinesis capture GetRecords and GetShardIterator API calls, which show exactly which IAM principal consumed data from a specific stream and when. This provides definitive evidence of who accessed the data. Option B: Enhanced monitoring shows metrics like IteratorAge but doesn't provide IAM identity of consumers. Option C: Management events capture control-plane operations (CreateStream, DescribeStream) but not data-plane operations (GetRecords). Option D: VPC Flow Logs show network connections but not the identity of the API caller or which stream was accessed.

Opsi A: BENAR.
Opsi B: SALAH.
Opsi C: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi D: SALAH.
10
An organization's compliance framework requires that all audit logs from data pipelines must be tamper-proof and verifiable for integrity. An auditor needs to confirm that CloudTrail log files have not been modified or deleted since creation. Which CloudTrail feature provides this assurance?
  • A. Enable S3 Object Lock in governance mode on the CloudTrail log bucket.
  • B. Enable CloudTrail Insights to detect unusual log deletion patterns, with hash values for verification for verification
  • C. Enable S3 versioning on the CloudTrail log bucket to track all modifications.
  • D. Enable CloudTrail log file integrity validation to generate digest files with hash values for verification.
Jawaban Benar: D
CloudTrail log file integrity validation generates SHA-256 hash digest files every hour. These digest files are signed and can be used to programmatically verify that no log files have been modified, deleted, or forged after delivery. This is the purpose-built feature for log integrity verification. Option B: S3 Object Lock prevents deletion but doesn't provide cryptographic verification of integrity. Option C: S3 versioning preserves old versions but doesn't prove logs haven't been tampered with. Option D: CloudTrail Insights detects unusual API activity patterns, not log file tampering.

Opsi A: SALAH.
Opsi B: SALAH. Meskipun terdengar meyakinkan, tetap tidak tepat untuk skenario ini.
Opsi C: SALAH.
Opsi D: BENAR.
