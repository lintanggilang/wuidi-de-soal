#Lambda#APIGateway
A data engineering team manages a REST API deployed on Amazon API Gateway that serves analytics data to multiple internal consumer teams. They need to release a new version of the API with breaking schema changes while allowing existing consumers to continue using the current version during a 3-month migration window. Which API Gateway versioning strategy provides the LEAST operational overhead?
  • A. Use custom domain name with base path mappings to route /v1 and /v2 to different API stages
  • B. Create a completely separate API Gateway REST API for v2 with a new endpoint URL
  • C. Use API Gateway stage variables to route requests to different Lambda function versions based on the deployment stage (v1, v2)
  • D. Implement versioning through request headers and use a single Lambda function with conditional logic
Jawaban Benar: A
Custom domain names dengan base path mappings memungkinkan routing path-based (/v1, /v2) ke API stages yang berbeda di bawah satu domain. Ini memberikan URL yang bersih untuk consumers (api.company.com/v1/data, api.company.com/v2/data) dan memisahkan deployment secara penuh tanpa overhead mengelola dua API terpisah.

Opsi A: BENAR.
Opsi B: SALAH. Menambah overhead manajemen dua API terpisah.
Opsi C: SALAH. Baik untuk konfigurasi tetapi stage variables tidak mendukung routing ke versi API yang benar-benar berbeda secara struktural.
Opsi D: SALAH. Mencampur logika versi dalam satu fungsi yang sulit di-maintain.

A company exposes a data API that is consumed by 15 different microservices across the organization. The API team plans to deprecate an endpoint in 6 months. They need to communicate this deprecation to all consumers proactively and track which consumers have migrated. Which combination of approaches is MOST effective?
  • A. Add a "Deprecation" and "Sunset" HTTP response header to the deprecated endpoint, enable API Gateway access logging to track consumer usage by API key
  • B. Return HTTP 301 redirects immediately to force consumers to use the new endpoint configured for optimal performance and minimal operational overhead
  • C. Send an email notification to all teams and remove the endpoint after 6 months, meeting the latency and throughput goals of the design
  • D. Add deprecation notices to the API documentation and create a CloudWatch dashboard to monitor total request counts, integrating natively with the rest of the pipeline
Jawaban Benar: A
Menggunakan HTTP headers "Deprecation" (RFC 8594) dan "Sunset" memberikan machine-readable notice yang dapat dideteksi oleh consumer applications secara otomatis. API Gateway access logging dengan API keys memungkinkan tracking granular tentang consumer mana yang masih menggunakan endpoint deprecated. Ini menggabungkan komunikasi proaktif dengan monitoring.

Opsi A: BENAR.
Opsi B: SALAH. Akan langsung memecah consumer yang tidak siap — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Tidak memberikan tracking dan mudah terlewat.
Opsi D: SALAH. Tidak mengidentifikasi consumer individual yang belum migrasi.

#conceptual
A data engineer needs to add a new optional field "processing_timestamp" to an existing API response without breaking any current consumers. The API is documented using OpenAPI specification and consumed by multiple teams. Which change is considered backward compatible?
  • A. Rename an existing field from "timestamp" to "processing_timestamp" to better describe its purpose, integrating natively with the rest of the pipeline
  • B. Add the new field as a required field in the response with a default value configured for optimal performance
  • C. Add the new optional field to the response body — consumers that don't need it can simply ignore it
  • D. Change the data type of the existing "timestamp" field from string to integer (Unix epoch), providing exactly-once processing semantics
Jawaban Benar: C
Menambahkan field opsional baru ke response body adalah backward-compatible change karena consumer yang sudah ada mengabaikan field yang tidak mereka kenal (sesuai dengan Postel's Law / Robustness Principle).

Opsi A: SALAH. Adalah breaking change karena consumer yang membaca field lama tidak akan menemukan data mereka.
Opsi B: SALAH. Bisa jadi masalah jika consumer melakukan strict schema validation — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Adalah breaking change yang akan menyebabkan parsing errors pada consumer yang mengharapkan string.

#APIGateway
A data platform team provides a high-volume analytics API that receives 10,000 requests per second during peak hours. They notice that some consumers are sending excessive requests that degrade performance for other users. The team needs to implement fair usage controls. Which API Gateway configuration provides the MOST granular control?
  • A. Set a single account-level throttle limit on the API Gateway stage with API keys and monthly quota limits for each consumer team
  • B. Configure usage plans with API keys, setting per-key throttle rates and monthly quota limits for each consumer team
  • C. Use AWS WAF rate-based rules to block IP addresses that exceed a request threshold, absorbing sudden traffic spikes without throttling
  • D. Implement client-side rate limiting in the SDK distributed to consumers, scaling horizontally as ingestion throughput keeps growing
Jawaban Benar: B
API Gateway usage plans dengan API keys memberikan kontrol granular per consumer — throttle rate (requests per second) dan quota (total requests per period) dapat dikonfigurasi secara independen untuk setiap team. Ini memastikan fair usage tanpa mempengaruhi consumer lain.

Opsi A: SALAH. Membatasi semua consumer secara sama tanpa diferensiasi — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Bekerja per IP yang tidak cocok untuk internal consumers yang mungkin share IP.
Opsi D: SALAH. Tidak enforceable karena consumer bisa bypass atau mengubah implementasi.

#CloudWatch#APIGateway
A data engineering team maintains a data API that has experienced several outages in the past month. Management requires comprehensive monitoring to detect and alert on API issues before they impact consumers. Which combination of Amazon CloudWatch features provides the MOST comprehensive API monitoring solution?
  • A. CloudWatch metrics for API Gateway (4XXError, 5XXError, Latency, Count) with composite alarms, combined with CloudWatch Logs for detailed request/response logging
  • B. CloudWatch Logs Insights queries running on a daily schedule to identify error patterns, meeting the latency and throughput goals of the design
  • C. CloudWatch Synthetics canaries that test API endpoints every 5 minutes with composite alarms for API Gateway (4XXError
  • D. AWS X-Ray tracing enabled on all API requests to track latency distributions, handling the described workload reliably at scale
Jawaban Benar: A
CloudWatch metrics untuk API Gateway (4XXError, 5XXError, Latency, Count) memberikan real-time visibility ke kesehatan API. Composite alarms menggabungkan multiple conditions (misalnya, error rate > 5% DAN latency > 2s) untuk alerting yang lebih akurat. Detailed logging memberikan data untuk troubleshooting.

Opsi A: BENAR.
Opsi B: SALAH. Terlalu lambat untuk mendeteksi masalah sebelum impact.
Opsi C: SALAH. Berguna sebagai tambahan tetapi hanya menguji dari perspektif sintetis, bukan traffic aktual — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Bagus untuk tracing tetapi tidak menyediakan alerting atau error rate monitoring secara langsung.

A company is deploying a new version of their data API using Amazon API Gateway. They want to gradually shift traffic from the current version to the new version, starting with 10% of traffic, and automatically roll back if the error rate exceeds 2%. Which deployment strategy achieves this with MINIMAL custom development?
  • A. Use Route 53 weighted routing between two API Gateway endpoints with health checks, meeting the latency and throughput goals of the design
  • B. Deploy both versions as separate stages and use a Lambda@Edge function to distribute traffic, meeting the latency and throughput goals of the design
  • C. Use AWS CodeDeploy with a Lambda deployment preference of Linear10PercentEvery1Minute and configure CloudWatch alarms to trigger automatic rollback, reducing day-to-day operational effort
  • D. Use API Gateway canary deployment on the production stage with a 10% canary percentage and configure CloudWatch alarms to trigger automatic rollback
Jawaban Benar: D
API Gateway mendukung canary deployments secara native pada stage level. Traffic dapat dialokasikan ke canary (misalnya 10%) sementara sisanya tetap di deployment saat ini. Dengan CloudWatch alarms pada canary metrics, rollback otomatis dapat dicapai melalui API Gateway deployment rollback. Ini built-in tanpa kode kustom.

Opsi A: SALAH. Memerlukan dua endpoints terpisah dan tidak terintegrasi untuk rollback otomatis.
Opsi B: SALAH. Memerlukan development kustom yang signifikan.
Opsi C: SALAH. Untuk Lambda functions, bukan API Gateway stage deployments — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.

A data platform team needs to maintain two major versions of their API simultaneously (v1 and v2) for at least 12 months. Each version has different request/response schemas, different business logic, and independent deployment cycles. The team wants to minimize code duplication while keeping versions independently deployable. Which architecture is MOST appropriate?
  • A. Use API Gateway request/response mapping templates to transform v1 requests into v2 format before forwarding to a single backend, reducing day-to-day operational effort
  • B. Use separate Lambda functions for v1 and v2 behind a single API Gateway with base path mappings, sharing common logic through Lambda layers
  • C. Use a single Lambda function with version-based conditional logic handling both v1 and v2 requests configured for optimal performance and minimal operational overhead
  • D. Deploy two completely independent API Gateway APIs with no shared components, meeting the latency and throughput goals of the design and reducing day-to-day operational effort
Jawaban Benar: B
Separate Lambda functions untuk setiap versi memungkinkan independent deployment cycles dan isolasi logika bisnis. Lambda layers sharing common code (utility functions, data access layer) mengurangi duplikasi. Base path mappings pada custom domain menyediakan clean URL routing.

Opsi A: SALAH. Hanya bekerja jika perbedaan versi minimal dan superficial, tidak cocok untuk different business logic.
Opsi B: BENAR.
Opsi C: SALAH. Mencampur logika kedua versi, membuat testing dan deployment lebih kompleks dan berisiko — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Memaksimalkan duplikasi kode.

When a new team wants to consume the API, they often struggle with integration because the documentation is outdated. Which approach ensures API documentation stays synchronized with the actual implementation?
  • A. Generate documentation from the deployed API Gateway using the export feature and publish it to a developer portal, satisfying all of the stated requirements with minimal effort and reducing day-to-day operational effort
  • B. Use AWS AppSync with a GraphQL schema that auto-generates documentation from the type definitions configured for optimal performance and minimal operational overhead, satisfying all of the stated requirements with minimal effort
  • C. Import the OpenAPI specification directly into API Gateway and use it as the single source of truth — any API changes must first update the spec, then deploy through the spec

API Gateway mendukung import OpenAPI spec yang mendefinisikan endpoints, request/response models, dan validasi. CI/CD pipeline memastikan perubahan selalu dimulai dari spec update.

Opsi A: SALAH. Bersifat reactive — dokumentasi diupdate setelah perubahan, bisa ada gap.

  • A. Remove the field immediately and notify consumers through an email blast after the change, satisfying all of the stated requirements with minimal effort and handling the described workload reliably at scale
  • B. Implement a phased approach: announce via developer portal and API response headers (Sunset header with date), track usage of deprecated field through custom CloudWatch metrics, contact remaining consumers directly before removal
  • C. Make the field return null values for 30 days before removing it completely with date), requiring no servers to manage or scale manually and satisfying all of the stated requirements with minimal effort
  • D. Create a new API version and redirect all v1 traffic to v2 immediately, removing the need to provision or patch any infrastructure and meeting the latency and throughput goals of the design

Ini memaksimalkan awareness dan minimalisir disruption.

Opsi A: SALAH. Akan langsung memecah consumers.

Opsi C: SALAH. Bisa menyebabkan NullPointerException pada consumers yang menggunakan field tersebut — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

#SQS#APIGateway
A data platform team has an API Gateway REST API that occasionally experiences sudden traffic spikes causing 429 (Too Many Requests) responses for legitimate consumers. The team needs to protect the backend while ensuring critical consumers always have access. Which configuration approach provides the BEST balance between protection and availability?
  • A. Increase the account-level throttle limit to accommodate the maximum expected traffic spike, integrating natively with the rest of the pipeline and scaling horizontally as ingestion throughput keeps growing
  • B. Place Amazon CloudFront in front of API Gateway to cache all responses and reduce backend load, durably storing every event with built-in fault tolerance and providing exactly-once processing semantics
  • C. Implement an SQS queue between API Gateway and the backend to buffer requests during spikes with higher throttle/burst limits for critical consumers, providing exactly-once processing semantics
  • D. Create tiered usage plans — premium plan with higher throttle/burst limits for critical consumers, standard plan with lower limits for others, combined with method-level throttling for expensive endpoints
Jawaban Benar: D
Tiered usage plans memungkinkan diferensiasi service level antar consumer groups. Critical consumers mendapat throttle/burst limits lebih tinggi sehingga tetap bisa mengakses API saat traffic spike. Method-level throttling melindungi endpoint yang mahal secara komputasi.

Opsi A: SALAH. Tidak memberikan prioritas dan bisa overload backend.
Opsi B: SALAH. Hanya efektif untuk data yang jarang berubah, tidak cocok untuk real-time analytics API.
Opsi C: SALAH. Mengubah API dari synchronous ke asynchronous yang memecah consumer expectations — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
