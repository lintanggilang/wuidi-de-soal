1
A security team at a large enterprise needs to investigate a potential data breach that occurred across multiple AWS accounts over the past 6 months. They need to run SQL queries to identify all IAM users who accessed specific S3 buckets containing PII data. The team currently stores CloudTrail logs in S3. Which approach provides the FASTEST time to investigation with the LEAST operational setup?
  • A. Create a CloudTrail Lake organization event data store, wait for events to be ingested, and run SQL queries directly
  • B. Set up Amazon Athena tables pointing to the CloudTrail S3 logs and run SQL queries using partition projection
  • C. Import existing CloudTrail logs from S3 into a CloudTrail Lake event data store and query immediately after import completes
  • D. Deploy Amazon OpenSearch Service, ingest the 6 months of CloudTrail logs, and use OpenSearch SQL for investigation
Jawaban Benar: C
CloudTrail Lake mendukung import of existing CloudTrail logs dari S3 ke event data store. Setelah import selesai, tim bisa langsung menjalankan SQL queries pada data historis tersebut. Ini memberikan fastest time-to-investigation karena tidak perlu menunggu events baru terkumpul dan tidak perlu setup infrastructure. Opsi A hanya akan menangkap events baru setelah pembuatan, bukan data historis 6 bulan. Opsi B (Athena) memerlukan setup: membuat tabel, konfigurasi partition projection, dan memahami format log — lebih banyak operational setup. Opsi D (OpenSearch) memerlukan provisioning cluster, konfigurasi ingestion, dan waktu indexing — paling banyak setup.
2
A company with 100 AWS accounts under AWS Organizations wants to centrally query CloudTrail events using SQL. They need to capture both management events and S3 data events across all accounts. The solution must retain events for 2555 days (7 years) for compliance. Which CloudTrail Lake configuration is MOST appropriate?
  • A. Create one organization event data store with both management and data events enabled, set retention to 2555 days with one-year extendable pricing
  • B. Create separate event data stores for management events (7-year retention) and data events (1-year retention) to optimize costs
  • C. Create individual event data stores in each account and query them separately from the management account
  • D. Create one organization event data store for management events with 2555-day retention using seven-year extendable pricing, and a separate one for S3 data events
Jawaban Benar: D
Memisahkan management events dan data events ke event data stores yang berbeda adalah best practice karena: (1) data events biasanya menghasilkan volume jauh lebih tinggi dengan biaya yang signifikan, (2) retention requirements mungkin berbeda, (3) seven-year extendable pricing lebih cost-effective untuk retention 2555 hari dibanding one-year extendable pricing. Organization event data store secara otomatis mengumpulkan events dari semua member accounts. Opsi A menggabungkan semuanya yang kurang optimal dari segi biaya dan management. Opsi B memiliki retention terlalu pendek untuk data events jika compliance memerlukan 7 tahun. Opsi C (individual per account) tidak scalable untuk 100 accounts dan tidak bisa cross-account query.
3
A data engineer needs to write a CloudTrail Lake SQL query to find all IAM role assumption events (AssumeRole) that originated from outside the company's known IP ranges (10.0.0.0/8 and 172.16.0.0/12) in the past 24 hours. Which query is CORRECT?
  • A. SELECT eventTime, userIdentity.arn, sourceIPAddress FROM event_data_store_id WHERE eventName = 'AssumeRole' AND sourceIPAddress NOT LIKE '10.%' AND sourceIPAddress NOT LIKE '172.16.%' AND eventTime > date_add('hour', -24, now())
  • B. SELECT eventTime, userIdentity.arn, sourceIPAddress FROM $EDS_ID WHERE eventName = 'AssumeRole' AND sourceIPAddress NOT LIKE '10.%' AND sourceIPAddress NOT LIKE '172.16.%' AND eventTime > dateadd('hour', -24, current_timestamp)
  • C. SELECT eventTime, userIdentity, sourceIPAddress FROM event_data_store WHERE eventName = 'AssumeRole' AND eventTime BETWEEN now() - INTERVAL '24' HOUR AND now()
  • D. SELECT eventTime, element_at(userIdentity, 'arn') as user_arn, sourceIPAddress FROM $EDS_ID WHERE eventName = 'AssumeRole' AND sourceIPAddress NOT LIKE '10.%' AND sourceIPAddress NOT LIKE '172.16.%' AND eventTime > '2024-01-01'
Jawaban Benar: A
CloudTrail Lake menggunakan SQL syntax di mana event data store direferensikan oleh ID-nya. Field userIdentity.arn mengakses nested field menggunakan dot notation. Fungsi date_add dan now() digunakan untuk time-based filtering. NOT LIKE digunakan untuk filtering IP ranges. Opsi B menggunakan $EDS_ID yang bukan syntax valid — CloudTrail Lake menggunakan event data store ID langsung. Opsi C tidak memfilter IP addresses sesuai requirement dan INTERVAL syntax tidak didukung di CloudTrail Lake. Opsi D menggunakan element_at yang merupakan fungsi Athena/Presto, bukan CloudTrail Lake SQL, dan memiliki hardcoded date bukan relative time.
4
A company is deciding between using CloudTrail Lake and Amazon Athena to query their CloudTrail logs. They have the following requirements: (1) query frequency is approximately 5 queries per day, (2) they need to retain logs for 3 years, (3) they prefer no infrastructure management, (4) query results must be available within seconds. Which analysis correctly compares the two options?
  • A. CloudTrail Lake is more cost-effective because it charges per query and has built-in retention, while Athena requires separate S3 storage management
  • B. Athena is more cost-effective because it only charges for data scanned per query, while CloudTrail Lake charges for both ingestion and retention regardless of query volume
  • C. CloudTrail Lake and Athena have identical pricing models — the choice should be based on query syntax preference only
  • D. Athena is preferred because it supports federated queries across multiple data sources, while CloudTrail Lake only queries CloudTrail events
Jawaban Benar: B
Untuk low query frequency (5/day), Athena lebih cost-effective karena biaya hanya berdasarkan data yang di-scan per query ($5/TB scanned). CloudTrail Lake memiliki biaya ingestion ($2.50 per 100K events ingested) dan retention storage charges yang berlaku terus-menerus terlepas dari apakah data di-query atau tidak. Untuk 3 tahun retention dengan volume tinggi events, biaya CloudTrail Lake bisa sangat signifikan. Athena + S3 dengan lifecycle rules ke Glacier memberikan storage costs yang jauh lebih rendah. Opsi A salah karena CloudTrail Lake tidak charge per query — biaya utamanya adalah ingestion dan retention. Opsi C salah karena pricing models sangat berbeda. Opsi D benar tentang Athena federated queries tapi bukan faktor utama untuk use case ini.
5
A security analyst creates a CloudTrail Lake dashboard to monitor suspicious activity across the organization. They want to display: (1) top 10 IAM users by number of denied API calls in the past week, (2) hourly trend of ConsoleLogin events, and (3) geographic distribution of API calls by source country. Which dashboard configuration is achievable with CloudTrail Lake?
  • A. All three visualizations can be created using CloudTrail Lake dashboard widgets with SQL queries
  • B. Only items 1 and 2 are achievable — CloudTrail Lake does not store geographic/country information in the event record
  • C. Only item 1 is achievable — CloudTrail Lake dashboards do not support time-series visualizations or geographic data
  • D. All three require exporting CloudTrail Lake results to Amazon QuickSight for visualization — CloudTrail Lake does not have native dashboards
Jawaban Benar: B
CloudTrail Lake mendukung dashboards yang dibuat dari saved queries dan dapat menampilkan widgets berupa bar charts, line charts, dan tables. Item 1 (top denied calls) bisa dicapai dengan query filtering errorCode = 'AccessDenied' dan GROUP BY userIdentity. Item 2 (hourly trend) bisa dicapai dengan time-series grouping. Namun item 3 tidak achievable karena CloudTrail events menyimpan sourceIPAddress tapi TIDAK menyimpan informasi negara/geografi — konversi IP ke negara memerlukan GeoIP database eksternal yang tidak tersedia di CloudTrail Lake SQL. Opsi A salah karena geographic data tidak tersedia. Opsi C salah karena time-series didukung. Opsi D salah karena CloudTrail Lake memiliki native dashboards.
6
A company creates a CloudTrail Lake event data store configured to collect management events from their organization. After 30 days, they realize they also need to capture S3 data events for compliance. What is the correct approach to add S3 data events to their existing setup?
  • A. Update the existing event data store to add S3 data events using advanced event selectors
  • B. Delete the existing event data store and create a new one that includes both management and S3 data events
  • C. Create a new separate event data store configured for S3 data events, keeping the existing one for management events
  • D. Add S3 data events to the existing organization trail — they will automatically appear in the event data store
Jawaban Benar: C
Best practice adalah membuat event data stores terpisah untuk management events dan data events karena mereka memiliki volume, cost profiles, dan potentially different retention periods. Event data store configuration (event types) tidak bisa diubah setelah creation untuk beberapa settings. Membuat event data store terpisah juga memungkinkan query yang lebih targeted dan cost management yang lebih baik. Opsi A - beberapa konfigurasi event data store bisa diupdate tapi memisahkan tetap best practice. Opsi B menghapus 30 hari data yang sudah ada. Opsi D salah karena trail dan event data store adalah entities terpisah — menambahkan data events ke trail tidak otomatis memasukkannya ke existing event data store.

During a security incident investigation, a data engineer needs to determine which IAM principal deleted a critical DynamoDB table 3 months ago. The company has CloudTrail Lake with a management event data store. Which SQL query will identify the responsible principal?
  • A. SELECT eventTime, userIdentity.principalId, userIdentity.arn, sourceIPAddress, requestParameters FROM eds_id WHERE eventName = 'DeleteTable' AND eventSource = 'dynamodb.amazonaws.com' AND eventTime > date_add('day', -90, now())
  • B. SELECT eventTime, userIdentity.userName, requestParameters FROM eds_id WHERE eventName = 'DropTable' AND eventSource = 'dynamodb.amazonaws.com' AND eventTime > date_add('month', -3, now())
  • C. SELECT * FROM eds_id WHERE resourceType = 'AWS::DynamoDB::Table' AND eventCategory = 'Delete' AND eventTime > date_add('day', -90, now())
  • D. SELECT eventTime, userIdentity.arn FROM eds_id WHERE eventName = 'DeleteTable' AND resources.type = 'AWS::DynamoDB::Table' AND eventTime BETWEEN date_add('month', -4, now()) AND date_add('month', -2, now())
Jawaban Benar: A
Query yang benar menggunakan eventName = 'DeleteTable' (nama API DynamoDB yang tepat), eventSource = 'dynamodb.amazonaws.com', dan mengambil userIdentity fields yang mengidentifikasi principal. sourceIPAddress membantu investigasi asal request. requestParameters berisi nama tabel yang dihapus. Opsi B menggunakan 'DropTable' yang bukan nama API DynamoDB yang benar (itu SQL terminology). Opsi C menggunakan field eventCategory = 'Delete' yang bukan field valid di CloudTrail events — eventCategory hanya berisi 'Management' atau 'Data'. Opsi D menggunakan resources.type yang bukan standard filtering approach dan time range terlalu spesifik jika tanggal persis tidak diketahui.
8
A company is evaluating CloudTrail Lake pricing for their organization with 50 accounts. They estimate 500 million management events and 2 billion data events per month. They need 7-year retention. Which pricing consideration is MOST critical for their cost estimation?
  • A. CloudTrail Lake charges per query executed, so the number of analysts running queries will be the primary cost driver
  • B. CloudTrail Lake charges for ingestion and retention — with 2 billion data events monthly at 7-year retention, the cumulative storage cost will be the primary cost driver
  • C. The first copy of management events is free in CloudTrail Lake, so only the 2 billion data events incur ingestion charges
  • D. CloudTrail Lake has a flat monthly fee per organization regardless of event volume, making it predictable for budgeting
Jawaban Benar: B
CloudTrail Lake pricing memiliki dua komponen utama: ingestion (per event) dan retention (per GB stored per month). Dengan 2 billion data events per bulan yang diakumulasi selama 7 tahun, total stored data akan sangat besar dan biaya retention menjadi primary cost driver. Ini bisa mencapai puluhan ribu dollar per bulan. Opsi A salah karena CloudTrail Lake tidak charge per query — queries included tanpa biaya tambahan. Opsi C salah karena "first copy free" berlaku untuk CloudTrail trail delivery ke S3, bukan untuk CloudTrail Lake ingestion — Lake memiliki pricing terpisah. Opsi D salah karena tidak ada flat fee — pricing sepenuhnya usage-based.
9
A security operations team uses CloudTrail Lake for daily security monitoring. They have saved queries that run every morning to check for: unauthorized access attempts, privilege escalation patterns, and resource deletion in production. They want to automate these daily checks and receive notifications when anomalies are found. Which approach integrates BEST with CloudTrail Lake?
  • A. Schedule CloudTrail Lake queries using Amazon EventBridge Scheduler to run StartQuery API, then use Lambda to check results and send SNS notifications
  • B. Use CloudTrail Lake's built-in scheduled query feature with automatic email notifications
  • C. Export CloudTrail Lake data to S3 and use Athena scheduled queries with SNS notifications
  • D. Use CloudTrail Insights instead, which automatically detects anomalies without requiring custom queries
Jawaban Benar: A
CloudTrail Lake menyediakan StartQuery API yang bisa dipanggil secara programmatic. Menggunakan EventBridge Scheduler untuk memicu Lambda yang menjalankan StartQuery, kemudian GetQueryResults untuk mengecek hasilnya, dan SNS untuk notifikasi jika ditemukan anomali, adalah pendekatan yang paling terintegrasi dan flexible. Opsi B salah karena CloudTrail Lake tidak memiliki built-in scheduled query feature dengan email notifications pada saat ini. Opsi C menambah kompleksitas dan biaya yang tidak perlu. Opsi D (CloudTrail Insights) hanya mendeteksi anomali volume API calls, bukan pattern matching kustom seperti privilege escalation patterns yang memerlukan query spesifik.
10
A company wants to use CloudTrail Lake to query events from both AWS services AND custom applications. Their custom application generates security audit events (user login, permission changes, data export) that need to be queryable alongside CloudTrail events. Which CloudTrail Lake feature enables this?
  • A. Create a custom event data store that accepts events via the PutAuditEvents API from the custom application through a CloudTrail Lake channel
  • B. Write custom application events to CloudWatch Logs and configure a subscription filter to CloudTrail Lake
  • C. Send custom application events to Amazon EventBridge which automatically routes them to CloudTrail Lake
  • D. Format custom application events as CloudTrail-compatible JSON and write them directly to the CloudTrail S3 bucket
Jawaban Benar: A
CloudTrail Lake mendukung integrations yang memungkinkan ingestion events dari sumber di luar AWS melalui channels. Aplikasi kustom dapat mengirim events menggunakan PutAuditEvents API ke channel yang terkait dengan event data store. Events ini kemudian queryable menggunakan SQL sama seperti CloudTrail events native. Opsi B salah karena tidak ada subscription filter dari CloudWatch Logs ke CloudTrail Lake. Opsi C salah karena EventBridge tidak memiliki routing otomatis ke CloudTrail Lake. Opsi D salah karena menulis ke S3 bucket CloudTrail tidak membuat events muncul di CloudTrail Lake — Lake memiliki storage terpisah dari S3 trail delivery.
