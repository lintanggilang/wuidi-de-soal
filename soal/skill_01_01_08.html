Skill 1.1.8: Create Allowlists for IP Addresses

Configuring security groups, NACLs, and network access controls to allow connections to data sources

1
A data engineer needs to configure an AWS Glue connection to access an Amazon RDS PostgreSQL database in a private subnet. The Glue job fails with a connection timeout. The RDS security group currently only allows connections from the application's EC2 instances. What must be configured to allow Glue to connect?
  • A. Add a self-referencing inbound rule to the Glue connection's security group, and add the Glue security group as an allowed source in the RDS security group
  • B. Add the AWS Glue service IP range to the RDS security group inbound rules
  • C. Configure a VPC endpoint for Glue and whitelist the endpoint IP
  • D. Move the RDS instance to a public subnet and allow all inbound traffic
Jawaban Benar: A
AWS Glue connections menggunakan ENI (Elastic Network Interface) di VPC dengan security group yang ditetapkan. Glue membutuhkan self-referencing rule (inbound dari security group sendiri) untuk komunikasi antar worker nodes. RDS security group harus mengizinkan inbound dari Glue security group. Opsi B salah karena Glue menggunakan ENI di VPC, bukan IP range service. Opsi C (VPC endpoint) untuk akses ke Glue API, bukan untuk Glue mengakses resources di VPC. Opsi D melanggar security best practices.
2
A company's data pipeline uses AWS DMS to replicate data from an on-premises Oracle database to Amazon S3. The on-premises firewall requires specific IP addresses to be allowlisted for outbound database connections. The DMS replication instance is in a VPC. How should the data engineer determine which IP to allowlist on the on-premises firewall?
  • A. Assign an Elastic IP (EIP) to the DMS replication instance in a public subnet, and allowlist that EIP on the on-premises firewall
  • B. Use the VPC's NAT Gateway public IP address as the allowlisted IP
  • C. Allowlist the entire AWS IP range for the region
  • D. Use the DMS replication instance's private IP address
Jawaban Benar: A
Untuk koneksi dari DMS ke sumber on-premises melalui internet, DMS replication instance harus berada di public subnet dengan Elastic IP. EIP ini statis dan dapat di-allowlist di firewall on-premises. Opsi B (NAT Gateway) bisa bekerja jika replication instance di private subnet tapi EIP di replication instance lebih direct. Opsi C (seluruh AWS IP range) terlalu luas dan insecure. Opsi D (private IP) tidak routable melalui internet ke on-premises.
3
A data engineer is setting up Amazon Redshift in a VPC to receive data from a partner company's application over the internet. The partner provides their static IP addresses for allowlisting. Which VPC component should be configured to restrict access to only the partner's IPs?
  • A. Update the Redshift cluster's security group inbound rules to allow TCP port 5439 only from the partner's IP addresses
  • B. Configure a Network ACL (NACL) on the VPC to deny all traffic except from partner IPs
  • C. Create an S3 bucket policy with IP condition restricting access
  • D. Configure AWS WAF with an IP set rule for the partner's addresses
Jawaban Benar: A
Security group pada Redshift cluster adalah mekanisme yang tepat untuk membatasi akses network ke IP tertentu. Dengan menambahkan inbound rule untuk TCP 5439 (Redshift port) dari CIDR partner's IP, hanya partner yang bisa connect. Opsi B (NACL) terlalu broad dan bisa mempengaruhi resources lain di subnet. Opsi C (S3 bucket policy) tidak relevan untuk Redshift connection. Opsi D (WAF) tidak applicable untuk Redshift — WAF untuk HTTP/HTTPS di ALB, CloudFront, atau API Gateway.
4
An AWS Glue ETL job in a VPC needs to access both an S3 bucket and an on-premises database through a VPN connection. The job currently cannot reach S3. The subnet has no internet access. What is the MOST secure solution to allow S3 access?
  • A. Create a VPC Gateway Endpoint for S3 and update the route table of the Glue subnet
  • B. Add a NAT Gateway and route internet traffic through it
  • C. Allowlist S3 public IP ranges in the security group outbound rules
  • D. Move the Glue connection to a public subnet with an Internet Gateway
Jawaban Benar: A
VPC Gateway Endpoint untuk S3 memungkinkan akses ke S3 tanpa internet, menjaga traffic di dalam AWS network. Route table di-update untuk mengarahkan traffic S3 melalui endpoint. Ini paling secure karena traffic tidak pernah meninggalkan AWS network. Opsi B (NAT Gateway) memungkinkan internet access yang lebih luas dari yang diperlukan. Opsi C (security group) — security groups are stateful dan allow all outbound by default; masalahnya routing bukan security group. Opsi D (public subnet) menambah attack surface.
5
A company's data pipeline connects to a third-party SaaS API that rotates its IP addresses frequently. The data engineer needs to allowlist these IPs in the VPC security group, but manual updates are not feasible. Which approach automates IP allowlist management?
  • A. Use AWS Lambda triggered by DNS resolution changes (via Route 53 health checks) to automatically update security group rules with current IPs
  • B. Use a prefix list that automatically resolves domain names to IPs
  • C. Configure the security group with the domain name instead of IP addresses
  • D. Use AWS Network Firewall with domain-based filtering rules instead of IP-based security groups
Jawaban Benar: D
AWS Network Firewall mendukung domain name filtering (stateful rule groups) yang secara otomatis resolve domain ke IP saat evaluasi. Ini ideal ketika IPs berubah sering karena rules berdasarkan domain name, bukan static IPs. Opsi A bisa bekerja tapi sangat custom dan fragile. Opsi B (prefix list) tidak resolve DNS - hanya berisi static CIDR blocks. Opsi C tidak supported - security groups hanya menerima IP/CIDR, bukan domain names.
6
A data engineer needs to allow an Amazon EMR cluster in a private subnet to access a partner's SFTP server on the internet. The partner requires the company to provide static IP addresses for their firewall allowlist. How should this be architected?
  • A. Place the EMR cluster in a private subnet with a NAT Gateway in the public subnet; provide the NAT Gateway's Elastic IP to the partner
  • B. Assign Elastic IPs to all EMR cluster nodes and provide those to the partner
  • C. Use AWS PrivateLink to establish a private connection to the partner's SFTP server
  • D. Configure a VPN connection to the partner and use the VPN endpoint IP
Jawaban Benar: A
NAT Gateway memiliki Elastic IP yang statis. Semua outbound traffic dari private subnet ke internet melewati NAT Gateway, sehingga partner akan selalu melihat koneksi dari NAT Gateway's EIP. Ini memberikan satu static IP untuk allowlisting. Opsi B tidak feasible karena EMR nodes bisa auto-scale dan private subnet nodes tidak bisa punya public IP. Opsi C (PrivateLink) membutuhkan partner juga di AWS dan mengekspos NLB. Opsi D (VPN) over-engineering untuk SFTP access.
7
A data engineer is configuring an Amazon Redshift cluster to be publicly accessible for a BI tool that runs outside AWS. The company security policy requires that only specific CIDR ranges from the corporate network can connect. The engineer also needs to log all connection attempts. Which combination of configurations is correct?
  • A. Enable publicly accessible on the Redshift cluster, configure the security group to allow port 5439 from corporate CIDR ranges only, and enable audit logging
  • B. Use a VPN connection for all BI tool access and remove public accessibility
  • C. Configure NACL rules to allow the corporate CIDR and deny all else, with VPC Flow Logs for logging
  • D. Place Redshift behind an Application Load Balancer with WAF rules for IP filtering
Jawaban Benar: A
Redshift publicly accessible + security group IP restriction adalah cara standar untuk memberikan akses dari corporate network. Security group membatasi akses ke CIDR yang ditentukan. Redshift audit logging mencatat semua connection attempts dan queries. Opsi B mengubah requirement (harus publicly accessible untuk BI tool). Opsi C (NACL + Flow Logs) kurang granular dan Flow Logs tidak capture application-level info. Opsi D (ALB + WAF) tidak applicable karena Redshift menggunakan PostgreSQL protocol, bukan HTTP.
8
A data pipeline uses AWS Lambda in a VPC to connect to an on-premises database through AWS Direct Connect. The on-premises team reports that they see connections from many different IP addresses and cannot create a stable allowlist. What causes this issue and how should it be resolved?
  • A. Lambda functions use multiple ENIs with different private IPs; configure a NAT Gateway in the VPC so all Lambda traffic egresses from a single private IP over Direct Connect
  • B. Assign static IP addresses to Lambda functions directly
  • C. Use Lambda reserved concurrency to limit the number of ENIs
  • D. Configure the on-premises firewall to allow the entire VPC CIDR range
Jawaban Benar: D
Lambda functions di VPC menggunakan Hyperplane ENIs dengan IPs dari subnet CIDR. Karena Lambda bisa membuat banyak ENIs dengan IPs berbeda (tergantung concurrency), solusi paling praktis adalah mengizinkan seluruh VPC CIDR range (yang biasanya adalah private IP range tertentu) di firewall on-premises. Opsi A (NAT Gateway) — untuk Direct Connect traffic, NAT Gateway tidak digunakan karena traffic sudah private-to-private. Opsi B tidak mungkin — Lambda tidak mendukung static IP assignment. Opsi C (reserved concurrency) membatasi performa.

A data engineer is configuring cross-region data ingestion. A Kinesis Data Stream in us-east-1 needs to be accessed by a consumer application in eu-west-1. The company policy requires that only specific VPC CIDR ranges can access the Kinesis stream. Which approach enforces this IP-based access control?
  • A. Use a VPC Interface Endpoint for Kinesis with an endpoint policy that restricts access, combined with a Kinesis resource policy with aws:SourceVpce condition
  • B. Configure a security group on the Kinesis stream to restrict source IPs
  • C. Use IAM policy with aws:SourceIp condition to restrict access to specific CIDR ranges
  • D. Configure Kinesis VPC allowlist in the stream settings
Jawaban Benar: C
IAM policy dengan aws:SourceIp condition membatasi akses API ke Kinesis berdasarkan source IP address. Ini bisa diterapkan pada IAM role/user yang digunakan consumer application. Untuk cross-region access, ini adalah mekanisme yang efektif karena Kinesis adalah service managed yang tidak memiliki security group sendiri. Opsi A valid untuk same-region VPC endpoint tapi cross-region endpoint membutuhkan setup tambahan. Opsi B salah — Kinesis tidak memiliki security group. Opsi D — fitur ini tidak ada di Kinesis.
10
A data engineer manages an Amazon RDS MySQL instance that must accept connections from multiple AWS services: AWS Glue, Lambda, and an EC2-based application. Each service runs in different security groups within the same VPC. What is the MOST maintainable way to configure the RDS security group?
  • A. Add three inbound rules referencing each service's security group ID as the source (Glue SG, Lambda SG, EC2 SG) on port 3306
  • B. Add one inbound rule allowing the entire VPC CIDR range on port 3306
  • C. Add individual IP addresses of each Glue ENI, Lambda ENI, and EC2 instance
  • D. Use a managed prefix list containing all service IP ranges
Jawaban Benar: A
Security group references (SG-to-SG rules) adalah best practice karena rules tetap valid bahkan ketika IP addresses berubah. Setiap resource yang menggunakan SG yang di-reference secara otomatis mendapat akses. Ini paling maintainable karena tidak perlu update ketika instances berubah. Opsi B (VPC CIDR) terlalu luas dan melanggar least privilege. Opsi C (individual IPs) tidak maintainable karena ENI IPs berubah. Opsi D (prefix list) untuk static CIDR ranges, bukan dynamic service IPs.
