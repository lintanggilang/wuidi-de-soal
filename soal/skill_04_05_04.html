Skill 4.5.4: Viewing Configuration Changes That Have Occurred in an Account

AWS Config for tracking and auditing resource configuration changes

1
A data engineering team suspects that someone changed the encryption settings on their production S3 bucket two weeks ago, which caused an ETL pipeline failure. They need to determine: WHO made the change, WHEN it happened, and WHAT the previous encryption configuration was. Which combination of AWS services provides all three pieces of information?
  • A. AWS Trusted Advisor provides the change history with user attribution for S3 security changes
  • B. AWS Config configuration timeline shows the previous and current encryption settings with timestamps; CloudTrail shows who made the PutBucketEncryption API call
  • C. AWS Config alone provides who, when, and what — it records the IAM identity, timestamp, and configuration diff with timestamps; CloudTrail shows who made the PutBucketEncryption API call
  • D. CloudTrail alone provides all information since it logs the API call with user identity, timestamp, and request parameters
Jawaban Benar: B
AWS Config dan CloudTrail memberikan informasi komplementer: Config menyimpan configuration timeline (state history) — menunjukkan konfigurasi SEBELUM dan SESUDAH perubahan beserta timestamp, memungkinkan Anda melihat persis apa encryption setting lama. CloudTrail merekam API calls termasuk identity of caller (WHO — IAM user/role ARN, source IP). Kombinasi keduanya memberikan complete audit trail.

Opsi A: SALAH. Trusted Advisor memberikan recommendations, bukan change history.
Opsi B: BENAR.
Opsi C: SALAH. Config TIDAK merekam identitas siapa yang membuat perubahan; Config hanya merekam state changes — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. CloudTrail merekam API request parameters tapi tidak selalu menyimpan PREVIOUS state; juga request parameters tidak selalu menunjukkan full previous configuration.
2
A company operates 15 AWS accounts in their organization and needs a centralized view of all resource configurations across all accounts and regions. The security team wants to query configuration data using SQL-like syntax to identify non-compliant resources. Which AWS Config feature enables this centralized multi-account, multi-region view?
  • A. Use AWS Organizations APIs to collect configuration details from all member accounts configured for optimal performance and minimal operational overhead
  • B. Deploy AWS Config rules in each account and aggregate findings to Security Hub
  • C. Export Config snapshots from all accounts to a central S3 bucket and query with Athena
  • D. Create an AWS Config Aggregator in a central account that collects configuration data from all source accounts, then use AWS Config advanced queries to run SQL queries across aggregated data
Jawaban Benar: D
AWS Config Aggregator mengumpulkan configuration dan compliance data dari multiple accounts dan regions ke satu central view. Dikombinasi dengan Config advanced queries (yang menggunakan SQL-like syntax), security team bisa menjalankan queries seperti "SELECT resourceId, configuration WHERE resourceType = 'AWS::S3::Bucket' AND configuration.serverSideEncryptionConfiguration IS NULL" across semua 15 accounts. Aggregator bisa di-setup melalui AWS Organizations (automatic enrollment) atau individual account authorization.

Opsi A: SALAH. Organizations API tidak menyediakan resource configuration details — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Security Hub aggregasi untuk security findings, bukan full configuration data.
Opsi C: SALAH. Bisa bekerja tapi memerlukan additional infrastructure (Athena, Glue catalog) dan data tidak real-time.
Opsi D: BENAR.
3
A data platform team uses Amazon Redshift, AWS Glue, and Amazon S3 for their data pipeline. They want AWS Config to record configuration changes for these specific data services only, not all AWS resources in the account. This is to reduce Config costs and noise. How should they configure AWS Config recording?
  • A. Enable Config recording with tag-based filtering — only resources tagged with "data-pipeline=true" will be recorded
  • B. Configure AWS Config to record specific resource types only: AWS::Redshift::Cluster, AWS::Glue::Job, AWS::Glue::Crawler, AWS::Glue::Database, AWS::S3::Bucket
  • C. Enable Config with "Record all resources" and create a filter to display only data service resources
  • D. Use AWS Config's service-linked recording that automatically detects and records only data-related services with native S3 integration and optimized data transfer
Jawaban Benar: B
AWS Config mendukung selective recording — Anda bisa memilih resource types yang ingin direkam daripada merekam semua resources. Dengan memilih spesifik types (Redshift clusters, Glue jobs/crawlers/databases, S3 buckets), hanya perubahan pada resource types tersebut yang direkam. Ini mengurangi jumlah configuration items yang disimpan dan biaya.

Opsi A: SALAH. Config tidak mendukung tag-based recording selection; tag-based filtering hanya tersedia untuk Config rules evaluation scope, bukan recording.
Opsi B: BENAR.
Opsi C: SALAH. "Record all resources" merekam SEMUA resource types di account yang menambah cost; filtering hanya di display level, recording tetap terjadi.
Opsi D: SALAH. Tidak ada fitur "service-linked recording" yang auto-detect data services di Config — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
4
A compliance team needs to ensure all S3 buckets in their data lake have: (1) server-side encryption enabled, (2) versioning enabled, (3) public access blocked, and (4) access logging enabled. They want to deploy all four checks as a package and ensure any new account added to the organization automatically gets these rules. Which Config feature achieves this?
  • A. Deploy an AWS Config Conformance Pack containing all four rules, deployed through AWS Organizations for automatic enforcement on new accounts
  • B. Use AWS Security Hub standards that include S3 security checks for automatic enforcement on new accounts
  • C. Create four individual Config rules and deploy them using CloudFormation StackSets across the organization
  • D. Create a single custom Config rule using Lambda that checks all four conditions simultaneously
Jawaban Benar: A
Config Conformance Packs adalah collection of Config rules dan remediation actions yang can be deployed as a single entity. Ketika deployed melalui AWS Organizations, conformance packs otomatis diterapkan ke semua member accounts termasuk accounts baru yang bergabung. Conformance pack bisa berisi managed rules (s3-bucket-server-side-encryption-enabled, s3-bucket-versioning-enabled, s3-bucket-public-read-prohibited, s3-bucket-logging-enabled) dalam satu template YAML.

Opsi A: BENAR.
Opsi B: SALAH. Security Hub memiliki S3 checks tapi ini terpisah dari Config rules dan tidak memberikan Config-specific compliance reporting — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. CloudFormation StackSets bisa deploy rules tapi memerlukan manual update saat menambah rules; juga kurang terintegrasi dengan Config's compliance view.
Opsi D: SALAH. Single custom rule kurang maintainable dan tidak mengikuti best practice separation of concerns.
5
An AWS Config rule detects that an S3 bucket has public read access enabled, which violates company policy. The security team wants automatic remediation — when the rule evaluates as NON_COMPLIANT, the public access should be automatically blocked. Which Config remediation configuration achieves this?
  • A. Create an EventBridge rule triggered by Config compliance change events and invoke a Lambda function to block public access
  • B. Use AWS Config auto-remediation with a custom Lambda function that calls S3 PutPublicAccessBlock API
  • C. Configure the Config rule with automatic remediation using the SSM Automation document AWS-DisableS3BucketPublicReadWrite, with automatic remediation retries set to 5
  • D. Configure the Config rule with manual remediation and wait for security team approval with native S3 integration and optimized data transfer
Jawaban Benar: C
AWS Config remediation actions menggunakan AWS Systems Manager Automation documents. AWS menyediakan pre-built SSM Automation documents untuk common remediations termasuk AWS-DisableS3BucketPublicReadWrite. Dengan mengonfigurasi automatic remediation pada Config rule, setiap kali rule evaluates sebagai NON_COMPLIANT, SSM Automation document otomatis dieksekusi. Retry mechanism memastikan remediation dicoba beberapa kali jika gagal.

Opsi A: SALAH. EventBridge + Lambda bisa bekerja tapi ini bypass Config's built-in remediation feature; kurang integrated dan tidak memanfaatkan retry/tracking built-in.
Opsi B: SALAH. Config auto-remediation menggunakan SSM documents bukan direct Lambda invocation; untuk custom remediation, Anda membuat custom SSM document yang could call Lambda, tapi pre-built document sudah tersedia.
Opsi C: BENAR.
Opsi D: SALAH. Manual remediation tidak memenuhi requirement "automatic — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.".
6
A data engineer needs to write a custom AWS Config rule that evaluates whether Glue jobs use a specific security configuration (encryption and CloudWatch logging enabled). The managed Config rules do not cover Glue job configurations. Which approach correctly implements this custom rule?
  • A. Create a Lambda function that receives the configuration item from Config, checks if the Glue job has the required SecurityConfiguration property and CloudWatch logging, then returns COMPLIANT or NON_COMPLIANT using the Config PutEvaluations API
  • B. Write an AWS Config custom policy rule using Guard policy language to check Glue job properties declaratively configured for optimal performance and minimal operational overhead
  • C. Create a CloudWatch Events rule that monitors Glue job creations and updates, triggering a Lambda that reports compliance to Config
  • D. Use AWS Config advanced queries to periodically search for non-compliant Glue jobs and flag them manually
Jawaban Benar: A
Custom Config rules menggunakan Lambda functions yang di-trigger oleh Config saat configuration changes terdeteksi atau secara periodic. Lambda function menerima event berisi configuration item (resource details), mengevaluasi compliance (apakah SecurityConfiguration ada dan mereferensikan config yang benar, apakah logging enabled), lalu memanggil PutEvaluations API dengan hasil COMPLIANT atau NON_COMPLIANT.

Opsi A: BENAR.
Opsi B: SALAH. Config custom policy rules (Guard/Proactive rules) tersedia tapi tidak semua resource types didukung oleh Guard; untuk Glue jobs, Lambda-based rule lebih reliable — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. CloudWatch Events bukan mekanisme delivery untuk custom Config rules; Config harus trigger Lambda langsung.
Opsi D: SALAH. Advanced queries hanya menampilkan current state, bukan continuous compliance evaluation dengan tracking history.
7
A security audit requires the team to understand exactly what changed in an Amazon Redshift cluster's configuration over the past 30 days. They need to see a day-by-day timeline of all configuration modifications including parameter group changes, VPC security group modifications, and encryption status changes. Which AWS Config feature provides this detailed historical view?
  • A. Check the Redshift cluster's maintenance history in the Redshift console with diff comparisons for the specific Redshift cluster
  • B. Query CloudTrail event history with filter for Redshift API calls in the last 30 days
  • C. Use the AWS Config console's Resource Timeline view for the specific Redshift cluster, which shows all configuration changes in chronological order with diff comparisons
  • D. Use AWS Config configuration snapshots delivered to S3 and compare daily snapshots
Jawaban Benar: C
AWS Config Resource Timeline (juga disebut Configuration Timeline) adalah fitur yang menampilkan complete history of configuration changes untuk specific resource. Untuk Redshift cluster, timeline menunjukkan: setiap perubahan configuration (parameter group, VPC security groups, encryption, node type, dll), timestamp perubahan, dan kemampuan untuk compare configurations antar dua titik waktu (diff view). Ini adalah cara paling langsung dan detail untuk melihat apa yang berubah.

Opsi A: SALAH. Redshift maintenance history hanya mencakup maintenance events (patches, upgrades), bukan user-initiated configuration changes — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. CloudTrail menunjukkan API calls (SIAPA melakukan APA) tapi tidak menampilkan full configuration state before/after; juga parameter group detail mungkin tidak lengkap di event.
Opsi C: BENAR.
Opsi D: SALAH. Configuration snapshots ke S3 bisa di-compare tapi manual dan tidak se-user-friendly timeline view.
8
A company wants to detect when any Amazon RDS instance in their data pipeline accounts is created without encryption enabled. When detected, they want to receive an SNS notification within minutes. They also need this detection to work for RDS instances across 20 accounts. Which approach provides near real-time detection across all accounts?
  • A. Deploy Config rule rds-storage-encrypted via Organization conformance pack, configure EventBridge rule in each account to forward compliance change events to a central event bus, which triggers SNS
  • B. Create the managed Config rule rds-storage-encrypted in each account with a Config Aggregator in central account, and configure SNS notification from the aggregator when NON_COMPLIANT
  • C. Use CloudTrail organizational trail to detect CreateDBInstance API calls and filter for unencrypted configurations via CloudWatch Logs Insights configured for optimal performance and minimal operational overhead
  • D. Deploy a periodic Lambda function that calls DescribeDBInstances across all accounts every 5 minutes and checks encryption status
Jawaban Benar: A
Organization conformance pack deploys Config rules ke semua member accounts secara otomatis. EventBridge rules di setiap account forward compliance change events ke central event bus saat Config rule evaluates NON_COMPLIANT. Central EventBridge rule kemudian triggers SNS notification. Ini memberikan near real-time notification (Config evaluates saat resource creation detected, EventBridge forwards immediately).

Opsi A: BENAR.
Opsi B: SALAH. Config Aggregator mengumpulkan compliance data tapi tidak memiliki native built-in notification mechanism yang langsung trigger SNS dari compliance changes; aggregation bisa delay.
Opsi C: SALAH. CloudTrail bisa mendeteksi API calls tapi parsing CreateDBInstance parameters untuk encryption memerlukan complex filtering dan mungkin miss encrypt-after-create scenarios — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Polling setiap 5 menit bukan near real-time dan creates significant API overhead across 20 accounts.

A data engineer is comparing AWS Config and AWS CloudTrail for their audit requirements. They need to answer: "What was the security group configuration of my Redshift cluster at 3:00 PM last Tuesday?" Which service answers this question and why?
  • A. Both services together — CloudTrail for the API call history and Config for the relationship mapping between Redshift and security groups
  • B. AWS Config — because it records point-in-time configuration snapshots (configuration items) that capture the complete resource configuration state, allowing you to look up the exact configuration at any past timestamp
  • C. VPC Flow Logs — because they record network-level security group usage at specific timestamps
  • D. CloudTrail — because it logs all security group modification API calls with timestamps and full request/response parameters configured for optimal performance and minimal operational overhead
Jawaban Benar: B
Pertanyaan ini tentang STATE pada titik waktu tertentu, bukan EVENTS. AWS Config merekam configuration items — snapshot lengkap dari konfigurasi resource pada setiap perubahan. Dengan Config, Anda bisa melihat "pada timestamp X, resource Y memiliki configuration Z." Ini termasuk security groups yang attached ke Redshift cluster pada waktu tertentu. CloudTrail merekam EVENTS (API calls) — untuk menjawab pertanyaan state, Anda harus replay semua events dari awal yang complex dan error-prone.

Opsi A: SALAH. Meskipun kombinasi berguna, Config alone cukup untuk pertanyaan tentang state.
Opsi B: BENAR.
Opsi C: SALAH. VPC Flow Logs mencatat network traffic, bukan security group configuration.
Opsi D: SALAH. CloudTrail mencatat modification events tapi tidak menyimpan resulting state secara langsung; Anda harus merekonstruksi state dari sequence of events — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.

A data platform team wants to use AWS Config to detect when their data pipeline resources drift from the approved baseline configuration. Specifically, they need to detect: (1) Glue jobs that have been modified to remove encryption, (2) S3 buckets where lifecycle policies have been deleted, and (3) Redshift clusters where audit logging has been disabled. They want one unified compliance view. What is the MOST efficient approach?
  • A. Use AWS Config advanced queries running on a schedule via EventBridge to check all three conditions and publish results to a custom dashboard
  • B. Create a single custom Config rule with a Lambda function that evaluates all three resource types based on the configuration item's resourceType field
  • C. Create three separate custom Lambda-based Config rules, one for each resource type, and view compliance in the Config dashboard with fully managed infrastructure and automatic scaling
  • D. Use a combination of managed rules where available (s3-bucket-level-public-access-prohibited for S3, redshift-audit-logging-enabled for Redshift) and one custom rule for Glue, grouped in a conformance pack for unified view
Jawaban Benar: D
Best practice adalah menggunakan managed rules saat tersedia (AWS maintains dan updates them) dan custom rules hanya ketika diperlukan. AWS sudah menyediakan managed rules untuk Redshift audit logging (redshift-audit-logging-enabled) dan berbagai S3 checks. Untuk S3 lifecycle, bisa digunakan custom rule atau managed rule yang sesuai. Untuk Glue job encryption, custom rule diperlukan karena tidak ada managed rule. Semua rules dikelompokkan dalam conformance pack untuk unified compliance view dan single deployment unit.

Opsi A: SALAH. Advanced queries bukan compliance evaluation mechanism; mereka snapshot current state tanpa tracking history atau compliance status.
Opsi B: SALAH. Single Lambda handling multiple resource types melanggar single responsibility principle dan sulit di-maintain.
Opsi C: SALAH. Tiga custom rules menambah maintenance burden untuk checks yang sudah ada sebagai managed rules — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
