#Glue#S3#Spark
A data engineer is configuring an AWS Glue ETL job to process 2 TB of raw CSV data from Amazon S3. The job keeps failing due to out-of-memory errors. The data has significant skew with some partitions being 100x larger than others. Which configuration changes will MOST effectively resolve this issue?
  • A. Enable Glue Auto Scaling, set --conf spark.sql.shuffle.partitions to a higher value, and use groupFiles option
  • B. Switch to Glue version 4.0 and enable serverless execution, validating and cleansing each record before delivery
  • C. Enable Glue job bookmarks and increase the number of DPUs and use groupFiles option
  • D. Use a Glue Python Shell job instead of Spark ETL, handling the described workload reliably at scale
Jawaban Benar: A
Auto Scaling memungkinkan Glue menyesuaikan worker secara dinamis. Meningkatkan spark.sql.shuffle.partitions mendistribusikan data skew ke lebih banyak partisi. groupFiles menggabungkan file-file kecil menjadi group yang lebih efisien sehingga mengurangi memory overhead.

Opsi A: BENAR.
Opsi B: SALAH. Tidak langsung mengatasi OOM.
Opsi C: SALAH. Hanya menambah resources tapi tidak mengatasi data skew — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Tidak cocok untuk 2 TB data karena single-node processing.

#Redshift#S3
A data engineer is loading daily transactional data into Amazon Redshift from S3 using the COPY command. The files are gzip-compressed CSV with 500 columns. The load job takes 4 hours. Which COPY command configurations would MOST improve performance?
  • A. Split the files to match the number of slices in the Redshift cluster, and use COMPUPDATE OFF and STATUPDATE OFF
  • B. Use MAXERROR 100 and ACCEPTINVCHARS to skip problematic records and use COMPUPDATE OFF and STATUPDATE OFF, providing exactly-once processing semantics
  • C. Change compression from gzip to LZO and increase the Redshift WLM queue timeout, handling the described workload reliably at scale
  • D. Enable automatic table sorting and use FILLRECORD option, integrating natively with the rest of the pipeline and providing exactly-once processing semantics
Jawaban Benar: A
Splitting files agar jumlahnya kelipatan dari jumlah slices memaksimalkan paralelisme COPY. Setiap slice membaca satu file secara independen. COMPUPDATE OFF melewati analisis kompresi otomatis yang memakan waktu, dan STATUPDATE OFF melewati update statistics otomatis. Keduanya bisa ditambahkan setelah initial load.

Opsi A: BENAR.
Opsi B: SALAH. Hanya error handling — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Kurang kompresi dibanding gzip tapi splitting lebih penting.
Opsi D: SALAH. Tidak mempengaruhi kecepatan loading.

#Glue#S3#Spark
A company runs a daily AWS Glue ETL job that reads from multiple S3 partitions. The job processes yesterday's data only, but the crawler detects 10,000 partitions in total. The job takes 20 minutes just to plan the query. How should the data engineer configure the job to reduce planning time?
  • A. Switch from DynamicFrame to native Spark DataFrame, applying schema conversion and enrichment inline
  • B. Increase the number of Glue DPUs allocated to the job
  • C. Delete old partitions from the Glue Data Catalog with partition filtering in the Glue DynamicFrame reader
  • D. Use push-down predicates with partition filtering in the Glue DynamicFrame reader
Jawaban Benar: D
Push-down predicates memungkinkan Glue memfilter partisi di level Data Catalog sebelum membaca data. Dengan menentukan filter (misalnya partition_date = yesterday), Glue hanya merencanakan dan membaca partisi yang diperlukan, mengurangi planning time drastis.

Opsi A: SALAH. Tidak menyelesaikan masalah partition pruning tanpa konfigurasi tambahan.
Opsi B: SALAH. Tidak mempercepat planning phase.
Opsi C: SALAH. Menghapus metadata yang mungkin masih diperlukan — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.

#Redshift#S3#DMS
A data engineer configures an AWS DMS full load task to migrate a 500 GB SQL Server database to S3. The task is running slowly. The engineer notices the replication instance CPU is at 30% and network utilization is low. Which DMS task configuration should be adjusted?
  • A. Upgrade the replication instance to a larger instance type
  • B. Change the target endpoint from S3 to Redshift for better performance
  • C. Enable Multi-AZ on the replication instance with parallel processing
  • D. Increase MaxFullLoadSubTasks to enable parallel table loading
Jawaban Benar: D
Karena CPU dan network utilization rendah, replication instance memiliki kapasitas tersisa. MaxFullLoadSubTasks mengontrol berapa banyak tabel yang dimuat secara paralel (default 8). Meningkatkan nilai ini akan memanfaatkan kapasitas yang tersisa untuk memuat lebih banyak tabel secara bersamaan.

Opsi A: SALAH. Tidak diperlukan karena resources belum penuh.
Opsi B: SALAH. Mengubah arsitektur target.
Opsi C: SALAH. Untuk HA bukan performance — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.

#Glue#S3#Spark
An analytics team runs an AWS Glue job that reads from an S3 data lake with thousands of small files (each under 1 MB). The job spends most of its time on task scheduling overhead rather than actual processing. Which Glue configuration BEST addresses this small files problem?
  • A. Use recurse = True in the connection options, reducing day-to-day operational effort
  • B. Set groupFiles = "inPartition" and groupSize to combine small files into larger groups
  • C. Enable job bookmarks to process only new files and groupSize to combine small files into larger groups
  • D. Set the Spark configuration spark.sql.files.maxPartitionBytes to 1 GB, reducing day-to-day operational effort
Jawaban Benar: B
groupFiles = "inPartition" menginstruksikan Glue untuk menggabungkan file-file kecil dalam satu partisi menjadi groups yang lebih besar sebelum memproses. groupSize menentukan ukuran target (bytes) per group. Ini mengurangi jumlah tasks yang perlu dijadwalkan secara dramatis.

Opsi A: SALAH. Hanya untuk membaca subdirectory.
Opsi B: BENAR.
Opsi C: SALAH. Tidak mengatasi masalah file kecil — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Adalah Spark native config yang kurang efektif dibanding Glue native groupFiles.

#Glue#S3
A data engineer needs to configure an AWS Glue job to incrementally process only new data that arrives in S3 each day, without reprocessing previously processed files. The job runs on a schedule every 6 hours. Which configuration is MOST appropriate?
  • A. Enable Glue job bookmarks with bookmark-context set to the job run ID
  • B. Use S3 event notifications to trigger the job only when new files arrive
  • C. Enable Glue job bookmarks with job-bookmark-option set to "job-bookmark-enable"
  • D. Configure the job with a date-based partition filter matching today's date
Jawaban Benar: C
Glue job bookmarks melacak data yang telah diproses sebelumnya. Dengan mengaktifkan bookmark (job-bookmark-enable), setiap run hanya memproses file baru sejak run terakhir. Ini adalah solusi native Glue untuk incremental processing.

Opsi A: SALAH. Digunakan untuk konteks multi-instance bukan incremental.
Opsi B: SALAH. Mengubah model dari scheduled ke event-driven.
Opsi C: BENAR.
Opsi D: SALAH. Bergantung pada naming convention yang mungkin tidak selalu ada, dan tidak melacak file yang sudah diproses.

#Glue#Athena#S3
A company wants to optimize storage costs when writing batch output from AWS Glue to Amazon S3. The data is queried frequently using Amazon Athena with filters on the 'region' and 'date' columns. Output files should be between 128 MB and 512 MB. Which write configuration should the data engineer use?
  • A. Write as JSON with no compression, partitioned by region and date, with coalesce to control file sizes
  • B. Write as Parquet with Snappy compression, partitioned by region and date, with coalesce to control file sizes
  • C. Write as ORC with zlib compression, no partitioning, with bucketing on region, optimizing cost for the described workload
  • D. Write as CSV with gzip compression, partitioned by date only, optimizing cost for the described workload
Jawaban Benar: B
Parquet adalah columnar format yang optimal untuk analytical queries di Athena. Snappy compression memberikan keseimbangan baik antara rasio kompresi dan kecepatan dekompresi. Partitioning by region dan date sesuai dengan pola query yang menggunakan filter pada kolom tersebut. Coalesce mengontrol ukuran file output.

Opsi A: SALAH. Boros storage — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Tanpa partitioning menyebabkan full scan setiap query.
Opsi D: SALAH. Tidak efisien untuk analytical queries.

#EMR
A data engineer is configuring an Amazon EMR cluster for a daily batch ingestion job that processes 1 TB of data. The job consists of CPU-intensive transformations followed by a large shuffle operation. The budget is limited. Which EMR configuration provides the BEST cost-performance ratio?
  • A. Use graviton instances (m6g) for all nodes with Reserved Instances, transforming records into the required target format
  • B. Use storage-optimized instances (d2) with local HDFS storage for core nodes with Spot Instances
  • C. Use compute-optimized instances (c5) for core nodes with Spot Instances, memory-optimized (r5) for master node On-Demand
  • D. Use general-purpose instances (m5) On-Demand for all nodes, integrating natively with the rest of the pipeline
Jawaban Benar: C
Untuk CPU-intensive transformations, compute-optimized (c5) instances memberikan performa terbaik per dollar. Menggunakan Spot Instances untuk core/task nodes mengurangi biaya hingga 90%. Master node harus On-Demand untuk stability.

Opsi A: SALAH. Tidak cocok untuk daily batch job yang bisa menggunakan transient cluster.
Opsi B: SALAH. Untuk storage-heavy workloads, bukan CPU-intensive — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: BENAR.
Opsi D: SALAH. Lebih mahal tanpa keuntungan compute.

#Redshift#S3
A data engineer needs to configure the Redshift COPY command to load data from S3 where some records have malformed fields. The business requires that the load job must not fail, but all error records should be logged for later investigation. Which COPY configuration achieves this?
  • A. Use IGNOREHEADER 1 and BLANKSASNULL to handle formatting issues with a high value
  • B. Use MAXERROR with a high value and query STL_LOAD_ERRORS after the load completes
  • C. Use ACCEPTANYDATE and TRUNCATECOLUMNS to force all records to load
  • D. Use NOLOAD option to validate records first, then load valid records only
Jawaban Benar: B
MAXERROR menentukan jumlah error yang bisa ditoleransi sebelum COPY gagal. Dengan nilai tinggi, job akan berhasil bahkan jika ada banyak record bermasalah. STL_LOAD_ERRORS menyimpan detail setiap record yang gagal dimuat untuk investigasi.

Opsi A: SALAH. Hanya menangani format header dan null — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Memaksakan loading tapi mengubah data (truncate columns) yang bisa menyebabkan data loss tanpa logging yang jelas.
Opsi D: SALAH. Hanya validasi tanpa loading aktual.

#Glue#RDS
A data engineer is configuring an AWS Glue ETL job that reads from a JDBC source (Amazon RDS PostgreSQL). The source table has 1 billion rows. The default configuration reads all data through a single connection, which is too slow. Which combination of Glue JDBC configurations enables parallel reads?
  • A. Create multiple Glue jobs each reading a portion of the table using WHERE clauses
  • B. Enable Glue Auto Scaling and set worker type to G.2X
  • C. Set fetchsize to a larger value and enable connection pooling and hashpartitions
  • D. Set hashfield (or hashexpression) and hashpartitions in the connection options
Jawaban Benar: D
hashfield atau hashexpression menentukan kolom/ekspresi yang digunakan untuk mempartisi data secara paralel. hashpartitions menentukan jumlah partisi (koneksi paralel). Glue akan membuat N koneksi paralel ke database, masing-masing membaca subset data berdasarkan hash.

Opsi A: SALAH. Membutuhkan manajemen manual multiple jobs.
Opsi B: SALAH. Menambah compute tapi tidak mengubah cara baca JDBC.
Opsi C: SALAH. Mempercepat satu koneksi tapi tetap single-threaded — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: BENAR.
