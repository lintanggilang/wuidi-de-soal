Managing VPC security groups for data pipeline network security

1
A data engineer needs to configure an AWS Glue connection to access an Amazon RDS PostgreSQL database in a private subnet. The Glue job fails with a connection timeout error. The RDS security group allows inbound traffic on port 5432 from the Glue connection's security group. What additional security group configuration is required to resolve this issue?
  • A. Add an outbound rule to the RDS security group allowing all traffic to the Glue security group
  • B. Add a self-referencing inbound rule to the Glue connection's security group allowing all TCP traffic from itself
  • C. Add an inbound rule to the Glue security group allowing traffic on port 5432 from the RDS security group
  • D. Add an outbound rule to the Glue security group allowing traffic only on port 5432 to the RDS subnet CIDR
Jawaban Benar: B
AWS Glue memerlukan self-referencing inbound rule pada security group yang digunakan oleh Glue connection. Ini diperlukan karena Glue ENIs (Elastic Network Interfaces) perlu berkomunikasi satu sama lain untuk koordinasi tugas dalam cluster. Tanpa self-referencing rule ini, Glue executors tidak dapat berkomunikasi dan job akan timeout. Opsi A tidak diperlukan karena security groups bersifat stateful — outbound response traffic otomatis diizinkan. Opsi C tidak diperlukan karena Glue yang melakukan koneksi ke RDS, bukan sebaliknya. Opsi D tidak cukup karena masalah utamanya adalah komunikasi antar Glue ENI.
2
A company has an Amazon Redshift cluster in a VPC that needs to be accessed by data analysts from the corporate network (10.0.0.0/8) and by AWS Glue ETL jobs. The data engineer needs to configure the Redshift cluster's security group. Which set of inbound rules provides the MOST secure configuration?
  • A. Allow port 5439 from 0.0.0.0/0
  • B. Allow port 5439 from 10.0.0.0/8 and allow port 5439 from the Glue connection's security group ID
  • C. Allow all TCP ports from 10.0.0.0/8 and allow all TCP ports from the Glue security group ID
  • D. Allow port 5439 from 10.0.0.0/8 and allow all traffic from the VPC CIDR range
Jawaban Benar: B
Konfigurasi paling aman adalah memberikan akses hanya pada port yang diperlukan (5439 untuk Redshift) dari sumber yang spesifik: CIDR corporate network untuk analysts dan security group ID untuk Glue. Security group referencing (SG-to-SG) lebih aman daripada CIDR karena hanya resource yang terhubung ke security group tersebut yang diizinkan. Opsi A (0.0.0.0/0) terlalu permissive dan membuka Redshift ke internet. Opsi C (semua TCP ports) melanggar prinsip least privilege. Opsi D (all traffic dari VPC CIDR) terlalu broad — semua resource di VPC akan bisa akses.
3
A data engineer deploys a Lambda function in a VPC to process data from an RDS MySQL instance. The Lambda function can successfully connect to RDS but cannot access Amazon S3 to write processed results. The VPC has no internet gateway or NAT gateway. Which solution allows the Lambda function to access S3 without exposing traffic to the public internet?
  • A. Add an outbound rule in the Lambda security group allowing HTTPS (port 443) to 0.0.0.0/0
  • B. Create a VPC Gateway Endpoint for S3 and update the route table associated with the Lambda subnet
  • C. Attach an elastic IP to the Lambda function's ENI for internet access
  • D. Create a VPC Interface Endpoint for S3 and modify the Lambda security group to allow outbound traffic to the endpoint
Jawaban Benar: B
VPC Gateway Endpoint untuk S3 memungkinkan akses ke S3 melalui AWS private network tanpa internet gateway atau NAT gateway. Gateway endpoint tidak memerlukan perubahan security group karena traffic di-route melalui route table. Ini gratis dan menyediakan akses private ke S3. Opsi A tidak akan berhasil karena tanpa internet gateway/NAT, tidak ada path ke internet meskipun security group mengizinkan. Opsi C tidak possible — Lambda ENI tidak bisa memiliki elastic IP secara langsung. Opsi D (Interface Endpoint) juga bisa berfungsi tetapi Gateway Endpoint untuk S3 lebih sederhana, lebih murah (gratis), dan direkomendasikan AWS.
4
An Amazon EMR cluster runs in a VPC private subnet and processes data from multiple sources. The cluster needs to communicate with Amazon S3, Amazon DynamoDB, and an external API on the internet. The data engineer needs to configure security groups for the EMR master and core nodes. Which security group configuration follows AWS best practices for EMR?
  • A. One security group for master with all ports open from core nodes SG, one for core nodes with all ports open from master SG, and a NAT gateway for internet access
  • B. A single shared security group for both master and core nodes allowing all internal traffic, with VPC endpoints for all services
  • C. Separate security groups for master and core nodes with required inter-node communication ports, VPC Gateway Endpoints for S3 and DynamoDB, and a NAT gateway for the external API
  • D. Default EMR-managed security groups with an internet gateway attached to the subnet for all external communications
Jawaban Benar: C
Best practice untuk EMR adalah: (1) Separate security groups untuk master dan core/task nodes dengan port-port spesifik yang diperlukan untuk inter-node communication (misalnya port 8443 untuk cluster management). (2) VPC Gateway Endpoints untuk S3 dan DynamoDB (gratis, traffic tetap di AWS network). (3) NAT gateway untuk akses ke external API yang memerlukan internet. Opsi A (all ports open) terlalu permissive meskipun antar SG sendiri. Opsi B (single shared SG) tidak memungkinkan granular control antara master dan core. Opsi D (internet gateway + public subnet) membuat nodes accessible dari internet — kurang aman untuk private subnet pattern.
5
A data engineer is troubleshooting connectivity between an AWS Glue job and an Amazon Redshift Serverless endpoint. Both are in the same VPC. The Glue job uses security group sg-glue and Redshift Serverless uses security group sg-redshift. The current configuration has: sg-redshift inbound allows port 5439 from sg-glue, and sg-glue has default outbound (all traffic allowed). The job still fails to connect. What should the engineer check FIRST?
  • A. Whether the Glue connection's security group (sg-glue) has a self-referencing inbound rule for all TCP traffic
  • B. Whether the Redshift Serverless workgroup is configured to be publicly accessible
  • C. Whether the VPC has DNS resolution and DNS hostnames enabled
  • D. Whether the subnet route table has a route to an internet gateway
Jawaban Benar: A
Masalah paling umum saat Glue connection gagal adalah tidak adanya self-referencing inbound rule pada security group Glue. AWS Glue membutuhkan ENI-nya untuk berkomunikasi satu sama lain (inter-node communication), yang memerlukan inbound rule dari security group itu sendiri (self-referencing). Ini adalah persyaratan spesifik Glue yang sering terlewat. Opsi B (publicly accessible) tidak relevan karena keduanya dalam VPC yang sama. Opsi C (DNS settings) penting tapi biasanya sudah enabled by default di VPC. Opsi D (internet gateway) tidak diperlukan untuk komunikasi intra-VPC.
6
A company has reached the limit of 60 inbound rules on a security group attached to their Amazon RDS instance. Multiple data processing services from different VPC CIDR blocks need access to the database. The engineer cannot increase the limit further. Which approach allows additional services to connect while maintaining security?
  • A. Replace individual CIDR-based rules with security group references, grouping multiple services under shared security groups
  • B. Create a second RDS instance with a different security group for the overflow connections
  • C. Use a Network ACL (NACL) to allow the additional IP ranges instead of security group rules
  • D. Create a managed prefix list containing all the CIDR blocks and reference it in a single security group rule
Jawaban Benar: D
AWS Managed Prefix Lists memungkinkan pengelompokan beberapa CIDR blocks ke dalam satu objek yang bisa direferensikan dalam satu security group rule. Ini secara efektif mengurangi jumlah rules yang diperlukan. Satu rule dengan prefix list bisa mencakup banyak CIDR ranges. Opsi A (SG references) bagus jika services berada di VPC yang sama, tapi tidak berfungsi untuk CIDR dari VPC berbeda atau on-premises. Opsi B (RDS kedua) mahal dan menambah kompleksitas manajemen data. Opsi C (NACL) bersifat stateless dan apply pada subnet level, kurang granular dibanding security groups, dan memiliki limit yang sama.
7
A data engineer needs to update the security group of a production Amazon Redshift cluster to add a new data pipeline's access without causing any downtime. The current security group has rules allowing access from 3 existing ETL services. Which statement about security group updates is CORRECT?
  • A. Security group changes require a cluster reboot to take effect, so maintenance window should be scheduled
  • B. Security group rule changes take effect immediately on all existing and new connections without requiring restart
  • C. New inbound rules take effect immediately, but removal of existing rules only affects new connections
  • D. Security group changes propagate within 60 seconds and temporarily block all traffic during propagation
Jawaban Benar: B
Perubahan security group rule di AWS take effect immediately tanpa restart, reboot, atau downtime. Ini berlaku untuk penambahan maupun penghapusan rules, dan mempengaruhi semua koneksi (existing dan new). Security groups bersifat stateful — jika aturan dihapus, koneksi yang sudah terestablish juga akan terputus karena return traffic tidak lagi diizinkan. Opsi A salah — tidak perlu reboot. Opsi C salah — penghapusan rule juga mempengaruhi existing connections. Opsi D salah — tidak ada blocking period selama propagation.
8
A data team has a multi-tier architecture where Lambda functions (tier 1) write to an RDS Aurora instance (tier 2), and a Glue job (tier 3) reads from the same Aurora instance. The security requirement states that tier 1 and tier 3 should not be able to communicate directly with each other. How should the security groups be configured?
  • A. Use one security group for all three tiers with rules restricting port-based access
  • B. Create three separate security groups. Aurora SG allows inbound 3306 from Lambda SG and Glue SG. Lambda SG and Glue SG have no rules referencing each other.
  • C. Create two security groups — one for Lambda and Glue, another for Aurora. Aurora SG allows inbound from the shared SG.
  • D. Use Network ACLs to block traffic between Lambda and Glue subnets, with a single security group for all services
Jawaban Benar: B
Tiga security groups terpisah memberikan isolasi yang diperlukan: Aurora SG mengizinkan port 3306 dari Lambda SG dan Glue SG secara terpisah. Lambda SG dan Glue SG tidak memiliki rules yang mereferensikan satu sama lain, sehingga tidak bisa berkomunikasi langsung. Opsi A (satu SG) tidak memungkinkan isolasi antar tier karena semua resource dalam SG yang sama bisa berkomunikasi. Opsi C (shared SG untuk Lambda dan Glue) membuat keduanya berada dalam security group yang sama — jika ada self-referencing rule, mereka bisa berkomunikasi. Opsi D (NACL) bisa bekerja tapi lebih sulit di-manage dan stateless.
9
A data engineer configures an Amazon EMR cluster with a custom security group. The EMR cluster needs to access an Amazon RDS MySQL database on port 3306. After launching the cluster, the EMR steps fail to connect to RDS. The engineer verifies that the RDS security group allows inbound port 3306 from the EMR security group. VPC flow logs show that outbound traffic from EMR to RDS is being rejected. What is the MOST likely cause?
  • A. The EMR security group's outbound rules have been modified to restrict traffic, preventing outbound connections to port 3306
  • B. EMR requires an additional managed security group that was not attached to the cluster
  • C. The RDS instance is in a different Availability Zone than the EMR cluster
  • D. The Network ACL on the EMR subnet is blocking outbound traffic to the RDS subnet
Jawaban Benar: A
Secara default, security groups mengizinkan semua outbound traffic. Namun, jika engineer menggunakan custom security group dan memodifikasi outbound rules (misalnya hanya mengizinkan port tertentu), koneksi outbound ke port 3306 bisa diblok. VPC flow logs mengkonfirmasi bahwa traffic outbound yang ditolak — ini menunjukkan masalah pada outbound rules di security group EMR atau NACL. Karena soal menyebutkan "outbound traffic from EMR is being rejected" dan security group memiliki custom rules, kemungkinan besar outbound rule EMR SG yang restrictive. Opsi B (managed SG) tidak menyebabkan outbound rejection. Opsi C (AZ berbeda) tidak mempengaruhi connectivity. Opsi D bisa jadi penyebab, tetapi custom SG outbound restriction adalah penyebab paling umum.
10
A company is deploying a data lake architecture where multiple AWS services need to access an Amazon Redshift cluster: AWS Glue for ETL, Amazon QuickSight for visualization, and Lambda functions for data validation. The security team requires that each service has its own security group and only port 5439 is allowed. The engineer wants to simplify security group management as new services are added. Which approach provides the MOST maintainable solution?
  • A. Create a single inbound rule on the Redshift security group using the VPC CIDR range on port 5439
  • B. Create individual inbound rules on the Redshift security group referencing each service's security group ID on port 5439
  • C. Create a common "data-access" security group, assign it as an additional security group to all services that need Redshift access, and add one inbound rule on Redshift SG referencing this common SG
  • D. Use AWS Resource Access Manager to share the Redshift security group with all service accounts
Jawaban Benar: C
Membuat common "data-access" security group dan menambahkannya sebagai additional SG ke setiap service adalah pendekatan paling maintainable. Redshift SG hanya memerlukan satu inbound rule (port 5439 dari data-access SG). Ketika service baru ditambahkan, cukup attach data-access SG ke service tersebut tanpa memodifikasi Redshift SG. Opsi A (VPC CIDR) terlalu broad — semua resource di VPC bisa akses. Opsi B (individual rules) berfungsi tapi memerlukan penambahan rule baru setiap kali ada service baru — kurang scalable dan bisa hit rule limit. Opsi D (RAM) bukan untuk sharing security groups antar services dalam account yang sama.
