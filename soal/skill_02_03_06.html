A global financial services company requires a DynamoDB-based trading platform to remain fully operational even if an entire AWS Region becomes unavailable. The solution must provide active-active read/write capabilities with sub-second replication between regions. Which DynamoDB feature meets these requirements?
  • A. DynamoDB Point-in-Time Recovery (PITR) with manual restore to another region
  • B. DynamoDB Global Tables with multi-region replication
  • C. DynamoDB on-demand backups with cross-region copy
  • D. DynamoDB Streams with Lambda to replicate items to another region's table
Jawaban Benar: B
DynamoDB Global Tables menyediakan active-active multi-region replication dengan sub-second replication. Setiap region bisa menerima read dan write, dan konflik diselesaikan dengan "last writer wins" reconciliation. Ini memastikan layanan tetap beroperasi penuh jika satu region down. Opsi A (PITR) adalah backup mechanism yang membutuhkan restore manual — tidak real-time dan bukan active-active. Opsi C (on-demand backup) juga memerlukan proses restore manual. Opsi D (Streams + Lambda) bisa dibuat tapi tidak memberikan active-active natively dan memiliki latensi lebih tinggi serta operational overhead.
2
A data engineer needs to implement disaster recovery for an Amazon Redshift data warehouse. The RPO requirement is 1 hour and the RTO requirement is 30 minutes. The primary cluster is in us-east-1. Which strategy BEST meets these requirements with minimal cost?
  • A. Enable cross-region snapshot copy to us-west-2 with snapshot frequency of 1 hour, and restore from snapshot during disaster
  • B. Maintain a running Redshift cluster in us-west-2 with continuous data sharing from us-east-1
  • C. Use Redshift Serverless in us-west-2 with automated data recovery from S3
  • D. Configure automated snapshots every 8 hours with manual copy to another region
Jawaban Benar: A
Cross-region snapshot copy dengan frequency 1 jam memenuhi RPO 1 jam. Redshift dapat restore cluster dari snapshot dalam waktu menit (tergantung ukuran), memenuhi RTO 30 menit dengan elastic resize. Ini cost-effective karena tidak perlu running cluster di region kedua selama normal operation. Opsi B (running cluster) memenuhi RTO tapi sangat mahal — membayar cluster penuh yang idle. Opsi C (Serverless) tidak memiliki automated DR dari S3 natively. Opsi D (8 jam) tidak memenuhi RPO 1 jam.
3
A company uses S3 Cross-Region Replication (CRR) to replicate their data lake from us-east-1 to eu-west-1 for disaster recovery. They notice that some objects are not being replicated. Which of the following is a common reason for CRR replication failure?
  • A. The destination bucket has versioning suspended
  • B. The objects were uploaded using multipart upload
  • C. The objects were created by a lifecycle rule (transition operations)
  • D. The source bucket has more than 1 billion objects
Jawaban Benar: A
S3 Cross-Region Replication memerlukan versioning enabled di KEDUA bucket (source dan destination). Jika destination bucket memiliki versioning suspended, replication akan gagal. Ini adalah persyaratan dasar CRR. Opsi B salah — multipart upload berfungsi normal dengan CRR. Opsi C salah — lifecycle transitions bukan objects baru, mereka mengubah storage class dan memang tidak direplikasi, tapi ini by design bukan "failure". Opsi D salah — tidak ada batas jumlah objek untuk CRR.

A data engineering team manages multiple data stores including RDS PostgreSQL, DynamoDB tables, EFS file systems, and S3 buckets. They need a centralized backup solution with consistent policies, compliance reporting, and cross-account backup capabilities. Which AWS service should they use?
  • A. Custom Lambda functions that create snapshots on a schedule for each service
  • B. AWS Backup with a backup plan covering all supported resources
  • C. Individual service-native backup features configured separately
  • D. AWS CloudFormation StackSets to deploy backup configurations across accounts
Jawaban Benar: B
AWS Backup adalah solusi terpusat yang mendukung backup untuk RDS, DynamoDB, EFS, S3, dan banyak layanan lainnya. AWS Backup menyediakan backup plans, lifecycle policies, cross-account backup, compliance reporting, dan audit capabilities dalam satu dashboard. Opsi A (Lambda custom) memerlukan banyak development dan maintenance. Opsi C (service-native) bekerja tapi tidak terpusat dan sulit untuk compliance reporting. Opsi D (CloudFormation) bisa deploy configuration tapi bukan backup solution itu sendiri.

A company stores critical analytics data in Amazon S3 Standard. They want to understand the durability guarantees of their data. A manager asks the data engineer about the risk of data loss in S3. Which statement about S3 durability is CORRECT?
  • A. S3 provides 99.99% durability, meaning approximately 1 in 10,000 objects could be lost per year
  • B. S3 Standard provides 99.999999999% (11 nines) durability, designed to sustain the concurrent loss of data in two facilities
  • C. S3 durability guarantees only apply when versioning is enabled
  • D. S3 provides 99.99% availability and 99.99% durability for all storage classes
Jawaban Benar: B
Amazon S3 Standard dirancang untuk 99.999999999% (11 nines) durability, menyimpan data di minimal 3 Availability Zones dan mampu menahan kehilangan data secara simultan di 2 fasilitas. Ini berarti jika menyimpan 10 juta objek, rata-rata akan kehilangan 1 objek sekali dalam 10.000 tahun. Opsi A mencampurkan availability (99.99%) dengan durability. Opsi C salah — durability berlaku terlepas dari versioning. Opsi D salah — availability S3 Standard adalah 99.99% tapi durability 11 nines, dan storage class lain memiliki availability berbeda.
6
A data engineer operates an RDS MySQL Multi-AZ deployment for a transactional data pipeline. During a planned maintenance window, the primary instance will be patched. What happens to the database availability during this maintenance?
  • A. The database becomes completely unavailable for 15-30 minutes during patching
  • B. RDS performs a failover to the standby instance, applies maintenance to the old primary, then fails back — resulting in brief downtime during failover only
  • C. Multi-AZ ensures zero downtime during all maintenance operations
  • D. The standby instance serves read traffic while the primary is being patched
Jawaban Benar: B
Untuk Multi-AZ deployments, RDS melakukan maintenance dengan: (1) apply patch ke standby terlebih dahulu, (2) failover ke standby yang sudah di-patch, (3) apply patch ke old primary (sekarang menjadi standby baru). Failover menyebabkan downtime singkat (biasanya 60-120 detik). Opsi A berlebihan — downtime hanya saat failover. Opsi C salah — ada brief downtime selama failover. Opsi D salah — Multi-AZ standby (bukan Read Replica) tidak melayani traffic baca dalam konfigurasi standar.
7
A data engineer needs to enable Point-in-Time Recovery (PITR) for a DynamoDB table that processes real-time financial transactions. The table experienced accidental data corruption 2 hours ago due to a buggy Lambda function. Which statement about DynamoDB PITR is CORRECT?
  • A. PITR can restore the table to any point in time within the last 35 days with per-second granularity
  • B. PITR restores data in-place to the existing table, overwriting current data
  • C. PITR must be enabled before the corruption occurs — it cannot recover data from before it was enabled
  • D. PITR restoration takes less than 1 minute regardless of table size
Jawaban Benar: C
DynamoDB PITR harus diaktifkan SEBELUM event yang ingin dipulihkan. Earliest restorable time adalah saat PITR diaktifkan (atau 35 hari yang lalu, mana yang lebih baru). Jika PITR tidak aktif saat corruption terjadi, data tidak bisa dipulihkan. Opsi A benar tentang 35 hari dan per-second granularity, tapi tidak menjawab inti pertanyaan. Opsi B salah — PITR melakukan restore ke TABLE BARU, bukan in-place. Opsi D salah — restore time tergantung ukuran tabel dan bisa memakan waktu beberapa jam untuk tabel besar.
8
A company runs their data warehouse on Amazon Redshift in us-east-1. They need to set up disaster recovery in eu-west-1 that allows them to resume operations within 4 hours (RTO) with no more than 1 hour of data loss (RPO). The Redshift cluster is 50 TB. Which approach meets the requirements MOST cost-effectively?
  • A. Enable automated snapshots every hour and configure cross-region snapshot copy to eu-west-1
  • B. Run a secondary Redshift cluster in eu-west-1 with Redshift data sharing for real-time synchronization
  • C. Use AWS DMS for continuous replication from us-east-1 Redshift to eu-west-1 Redshift
  • D. Export data to S3 every hour using UNLOAD and replicate with S3 CRR
Jawaban Benar: A
Automated snapshots setiap jam dengan cross-region copy memenuhi RPO 1 jam. Restore dari snapshot 50TB ke cluster baru bisa diselesaikan dalam beberapa jam menggunakan fast restore (data tersedia untuk query segera setelah restore dimulai, data di-stream dari S3). RTO 4 jam terpenuhi. Ini paling cost-effective karena tidak ada running cluster di DR region. Opsi B sangat mahal (cluster kedua aktif). Opsi C (DMS) tidak optimal untuk Redshift-to-Redshift dan menambah kompleksitas. Opsi D (UNLOAD) mahal untuk 50TB setiap jam dan tidak efisien.

A data engineer is configuring S3 Cross-Region Replication (CRR) for a versioned bucket containing processed analytics data. They want to minimize replication lag for compliance reasons. Which S3 feature helps monitor and ensure replication completes within a predictable timeframe?
  • A. S3 Transfer Acceleration
  • B. S3 Replication Time Control (S3 RTC) with replication metrics
  • C. S3 Intelligent-Tiering with async replication
  • D. S3 Event Notifications to trigger manual replication verification
Jawaban Benar: B
S3 Replication Time Control (RTC) memberikan SLA bahwa 99.99% objek direplikasi dalam 15 menit. RTC juga menyertakan replication metrics dan event notifications yang memungkinkan monitoring replication lag secara real-time. Ini ideal untuk compliance yang memerlukan predictable replication time. Opsi A (Transfer Acceleration) mempercepat upload ke S3, bukan replication. Opsi C (Intelligent-Tiering) mengelola storage class, bukan replication. Opsi D (Event Notifications) memerlukan custom logic dan tidak memberikan SLA.
10
A startup runs their entire data platform on AWS. They need to protect against accidental deletion of critical infrastructure including RDS instances, DynamoDB tables, and Redshift clusters. A junior engineer previously deleted a production DynamoDB table by mistake. Which combination of protections should the data engineer implement? (Choose the BEST answer)
  • A. Enable deletion protection on RDS and Redshift, enable DynamoDB deletion protection, and use IAM policies to restrict DeleteTable/DeleteCluster permissions
  • B. Use AWS Organizations SCPs to deny all delete operations across the account
  • C. Create CloudWatch Alarms that notify when delete API calls are detected
  • D. Enable AWS CloudTrail and review logs daily for unauthorized deletions
Jawaban Benar: A
Pendekatan defense-in-depth yang benar: (1) Enable deletion protection di level resource (RDS, Redshift, DynamoDB semua mendukung deletion protection), (2) Restrict IAM permissions untuk delete operations hanya ke role tertentu. Ini mencegah accidental deletion di dua layer. Opsi B (SCP deny all delete) terlalu restrictive — akan memblokir operasi normal seperti cleanup temporary resources. Opsi C (CloudWatch Alarms) hanya mendeteksi setelah terjadi, tidak mencegah. Opsi D (CloudTrail review) adalah post-incident investigation, bukan prevention.
