1
A company has a shared S3 data lake bucket accessed by three different teams: Analytics, Machine Learning, and Data Engineering. Each team needs access to different prefixes within the bucket. The bucket policy has become extremely complex with over 50 statements. Which solution simplifies access management while maintaining per-team isolation?
  • A. Split the data into three separate S3 buckets, one per team, and replicate shared data
  • B. Create S3 Access Points for each team, with each Access Point having its own policy that restricts access to the team's specific prefixes
  • C. Use IAM policies only and remove the bucket policy entirely
  • D. Create IAM groups per team with inline policies that restrict access to specific key prefixes using conditions
Jawaban Benar: B
S3 Access Points dirancang khusus untuk menyederhanakan access management pada shared buckets. Setiap Access Point memiliki hostname unik dan access point policy tersendiri yang bisa membatasi akses ke prefix tertentu. Tim Analytics mengakses melalui access-point-analytics, ML melalui access-point-ml, dll. Ini menggantikan satu bucket policy yang kompleks dengan multiple simple policies. Opsi A (split buckets) menambah biaya storage dan complexity sinkronisasi shared data. Opsi C (IAM only) tidak memungkinkan resource-based control dan sulit mengelola untuk banyak tim. Opsi D (IAM groups) hanya mengontrol dari sisi identity, tidak memberikan resource-level simplification yang sama.
2
A data engineer configures a VPC endpoint for Amazon S3 (Gateway type) and wants to restrict the endpoint so that it can only access two specific S3 buckets: a data lake bucket and a code artifacts bucket. Which policy should be applied?
  • A. Apply a VPC endpoint policy that allows s3:* only on the two specific bucket ARNs and their objects
  • B. Modify the S3 bucket policy to deny access from all VPC endpoints except the specific endpoint ID
  • C. Apply a security group on the VPC endpoint to restrict traffic to the S3 bucket IP ranges
  • D. Modify the VPC route table to only route traffic for the two bucket IP addresses through the endpoint
Jawaban Benar: A
VPC endpoint policies control API calls yang diperbolehkan melalui endpoint tersebut. Dengan membatasi resource ke ARN dua bucket spesifik (arn:aws:s3:::data-lake-bucket dan arn:aws:s3:::data-lake-bucket/*), semua request S3 melalui endpoint ini hanya bisa mengakses kedua bucket tersebut. Ini memberikan defense-in-depth tambahan. Opsi B (bucket policy) bisa jadi defense-in-depth tambahan tapi tidak membatasi endpoint itu sendiri — resources di VPC masih bisa mencoba akses bucket lain. Opsi C salah — Gateway endpoints tidak memiliki security groups (hanya Interface endpoints yang punya). Opsi D salah — S3 Gateway endpoint menggunakan prefix list di route table, bukan per-bucket IP routing.
3
A company needs to ensure that their S3 data lake bucket can ONLY be accessed from within their VPC — no access from the internet or other VPCs should be allowed, even if IAM policies permit it. Which approach enforces this network-level restriction?
  • A. Enable S3 Block Public Access at the account level
  • B. Add a bucket policy with a Deny statement using the condition "aws:SourceVpc" not equal to the company's VPC ID
  • C. Remove all IAM policies that allow access from outside the VPC
  • D. Configure the S3 bucket as a VPC endpoint target
Jawaban Benar: B
Bucket policy dengan explicit Deny menggunakan condition "aws:SourceVpc" memastikan bahwa SEMUA requests yang tidak berasal dari VPC yang ditentukan akan ditolak, terlepas dari IAM permissions yang ada. Statement: {"Effect": "Deny", "Principal": "*", "Action": "s3:*", "Resource": ["bucket-arn", "bucket-arn/*"], "Condition": {"StringNotEquals": {"aws:SourceVpc": "vpc-12345"}}}. Explicit Deny selalu override Allow. Opsi A (Block Public Access) hanya memblokir public access via ACLs/policies, bukan access dari other VPCs atau AWS accounts. Opsi C (remove IAM policies) tidak scalable dan tidak mencegah policies ditambahkan kembali. Opsi D bukan konsep yang valid — S3 bukan "target" endpoint.
4
A data engineer implements AWS PrivateLink to allow a data processing service in VPC-A to access a third-party SaaS data provider's API without traversing the public internet. The SaaS provider has set up a VPC endpoint service (NLB-backed). What must the data engineer configure in VPC-A to use this PrivateLink connection?
  • A. Create a VPC Interface Endpoint in VPC-A pointing to the SaaS provider's endpoint service name, and configure security groups on the endpoint to allow outbound traffic
  • B. Create a VPC peering connection between VPC-A and the SaaS provider's VPC
  • C. Create a Transit Gateway attachment to reach the SaaS provider's VPC
  • D. Create a VPN connection from VPC-A to the SaaS provider's on-premises endpoint
Jawaban Benar: A
AWS PrivateLink menggunakan Interface Endpoints (powered by ENIs) di consumer VPC yang terhubung ke provider's VPC Endpoint Service (backed by NLB). Engineer perlu: (1) Create Interface Endpoint di VPC-A dengan service name yang diberikan provider (com.amazonaws.vpce.region.vpce-svc-xxxxx). (2) Accept the connection (provider mungkin perlu approve). (3) Configure security group pada endpoint ENI untuk allow traffic dari data processing service. Data mengalir melalui AWS private network. Opsi B (VPC peering) memerlukan kooperasi provider dan membuka akses lebih luas. Opsi C (Transit Gateway) berlebihan untuk single service connection. Opsi D (VPN) menggunakan internet dan lebih lambat.
5
A data engineer needs to restrict access to an S3 bucket so that it can only be accessed by principals within the same AWS Organization (org-id: o-abc123def). The bucket contains shared datasets used by multiple accounts in the organization. Which bucket policy condition provides this restriction?
  • A. Condition: {"StringEquals": {"aws:PrincipalOrgID": "o-abc123def"}}
  • B. Condition: {"StringEquals": {"aws:SourceAccount": "o-abc123def"}}
  • C. Condition: {"StringEquals": {"aws:PrincipalAccount": "management-account-id"}}
  • D. Condition: {"ArnLike": {"aws:PrincipalArn": "arn:aws:organizations::*:organization/o-abc123def"}}
Jawaban Benar: A
aws:PrincipalOrgID adalah global condition key yang memeriksa apakah calling principal berasal dari AWS Organization tertentu. Dengan menambahkan Allow statement bersyarat pada aws:PrincipalOrgID, hanya principals dari accounts yang merupakan member organization o-abc123def yang mendapat akses. Ini sangat berguna untuk shared resources — saat account baru ditambahkan ke organization, mereka otomatis mendapat akses tanpa perlu mengupdate bucket policy. Opsi B salah — aws:SourceAccount hanya tersedia untuk service-to-service calls, bukan langsung applicable untuk org ID. Opsi C (PrincipalAccount) hanya memeriksa satu account, bukan seluruh organization. Opsi D menggunakan format ARN yang salah untuk org condition.
6
A data engineer is implementing a multi-layer security model for an S3 bucket. The bucket has: an IAM policy on the Glue role allowing s3:GetObject on the bucket, an S3 bucket policy allowing the Glue role, and a VPC endpoint policy that does NOT include this bucket. The Glue job runs in a VPC and accesses S3 through the VPC endpoint. What is the result when the Glue job tries to read from the bucket?
  • A. Access is allowed because the IAM policy and bucket policy both grant access
  • B. Access is denied because the VPC endpoint policy does not allow access to the bucket, and the endpoint policy acts as an additional filter
  • C. Access is allowed because VPC endpoint policies are advisory only and do not enforce restrictions
  • D. The request bypasses the VPC endpoint and goes directly to S3 over the internet when the endpoint policy denies access
Jawaban Benar: B
VPC endpoint policies berfungsi sebagai additional access control layer (filter). Request harus diizinkan oleh SEMUA policies yang relevan: IAM policy, resource policy (bucket policy), DAN VPC endpoint policy. Jika VPC endpoint policy tidak mengizinkan akses ke bucket tersebut, request akan ditolak meskipun IAM dan bucket policy mengizinkan. VPC endpoint policy bersifat intersectional — request hanya berhasil jika diizinkan oleh semua layer. Opsi A salah — endpoint policy juga harus allow. Opsi C salah — endpoint policies bersifat enforcing, bukan advisory. Opsi D salah — jika traffic diroute melalui endpoint (via route table), tidak ada fallback ke internet path; request akan fail.
7
A data engineer needs to grant cross-account access to an S3 bucket for a specific Lambda function in Account B (account 222222222222). The Lambda function's role ARN is arn:aws:iam::222222222222:role/DataProcessorRole. The engineer wants to use a resource-based policy. Which S3 bucket policy statement correctly grants this access?
  • A. {"Effect": "Allow", "Principal": {"AWS": "222222222222"}, "Action": "s3:GetObject", "Resource": "arn:aws:s3:::mybucket/*"}
  • B. {"Effect": "Allow", "Principal": {"AWS": "arn:aws:iam::222222222222:role/DataProcessorRole"}, "Action": "s3:GetObject", "Resource": "arn:aws:s3:::mybucket/*"}
  • C. {"Effect": "Allow", "Principal": {"Service": "lambda.amazonaws.com"}, "Action": "s3:GetObject", "Resource": "arn:aws:s3:::mybucket/*"}
  • D. {"Effect": "Allow", "Principal": "*", "Action": "s3:GetObject", "Resource": "arn:aws:s3:::mybucket/*", "Condition": {"StringEquals": {"aws:SourceAccount": "222222222222"}}}
Jawaban Benar: B
Untuk memberikan cross-account access ke specific role, gunakan role ARN sebagai Principal. Ini memberikan akses hanya ke DataProcessorRole di Account B, bukan semua entities di account tersebut. Ini adalah pendekatan paling restrictive dan mengikuti least privilege. Opsi A (account root) memberikan akses ke SEMUA principals di Account B yang memiliki IAM permission — kurang restrictive. Opsi C (lambda.amazonaws.com service) mengizinkan ALL Lambda functions dari semua accounts — sangat tidak aman. Opsi D (Principal *) dengan SourceAccount condition masih terlalu broad — mengizinkan semua principals di Account B, dan aws:SourceAccount condition tidak selalu tersedia untuk direct API calls.
8
A company's security policy requires that S3 buckets storing sensitive data must NEVER be publicly accessible, regardless of any bucket policy changes made by developers. The data engineer needs to implement a preventive control that enforces this across all S3 buckets in the account. Which approach provides the STRONGEST preventive control?
  • A. Enable S3 Block Public Access at the account level (s3:PutAccountPublicAccessBlock) to block all current and future public access configurations
  • B. Create an AWS Config rule to detect public S3 buckets and automatically remediate
  • C. Use Amazon Macie to scan for publicly exposed buckets and alert the security team
  • D. Add a Deny statement in every bucket policy preventing public access
Jawaban Benar: A
S3 Block Public Access di account level adalah preventive control paling kuat. Saat diaktifkan, ini secara otomatis memblokir semua konfigurasi public access pada SEMUA buckets di account — termasuk public bucket policies, public ACLs, dan new public bucket/access point policies. Bahkan jika developer menambahkan bucket policy dengan Principal "*", Block Public Access akan override dan tetap memblokir public access. Opsi B (AWS Config) adalah detective control (deteksi + remediate) — ada window dimana bucket sudah public sebelum remediation. Opsi C (Macie) hanya detection dan alerting, bukan prevention. Opsi D (per-bucket Deny) memerlukan penerapan di setiap bucket dan bisa dihapus oleh developer.
9
A data engineer sets up an S3 Access Point for the analytics team. The Access Point policy allows the team's IAM role to perform s3:GetObject and s3:ListBucket. However, the underlying bucket policy has a Deny statement that blocks the team's role from s3:GetObject. What happens when the analytics team accesses the bucket through the Access Point?
  • A. Access is allowed because the Access Point policy overrides the bucket policy
  • B. Access is denied because the bucket policy Deny still applies — Access Points cannot override explicit Deny statements in bucket policies
  • C. Only s3:ListBucket works (via Access Point policy) but s3:GetObject is denied (by bucket policy)
  • D. The Access Point becomes invalid because it conflicts with the bucket policy
Jawaban Benar: B
S3 Access Points tidak override bucket policies. Access dikontrol oleh INTERSECTION dari Access Point policy dan bucket policy (plus IAM policy). Explicit Deny di bucket policy selalu menang — ini adalah prinsip fundamental IAM policy evaluation. Access Points dimaksudkan untuk menyederhanakan policy management, bukan untuk bypass existing restrictions. Jika bucket policy explicitly deny akses dari role tertentu, Access Point tidak bisa memberikan akses tersebut. Opsi A salah — Access Points tidak override. Opsi C salah jika Deny diterapkan pada semua S3 actions (tergantung apa yang di-deny di bucket policy). Opsi D salah — Access Point tetap valid, hanya permissions yang terbatas.
10
A data engineer is implementing defense-in-depth for a data pipeline that processes sensitive financial data. The pipeline uses Lambda functions in a VPC accessing S3 through a Gateway Endpoint. The engineer wants to ensure that even if a Lambda function is compromised, it can only access designated S3 buckets and cannot exfiltrate data to external locations. Which combination of policies provides the MOST comprehensive data exfiltration protection?
  • A. IAM policy on Lambda role restricting S3 access to specific bucket ARNs only
  • B. IAM policy restricting to specific buckets + VPC endpoint policy limiting S3 access to those same buckets + S3 bucket policy with aws:SourceVpce condition allowing only the specific VPC endpoint
  • C. VPC endpoint policy restricting to specific buckets + Network ACLs blocking all outbound traffic except to S3 IP ranges
  • D. S3 bucket policy with aws:SourceIp condition restricting to the Lambda function's private IP addresses
Jawaban Benar: B
Defense-in-depth memerlukan multiple layers of control: (1) IAM policy — controls what the Lambda role can do (only specific buckets). (2) VPC endpoint policy — controls what can be accessed through the endpoint (only same specific buckets). Bahkan jika attacker mendapat credentials berbeda, endpoint hanya mengizinkan traffic ke designated buckets. (3) S3 bucket policy with aws:SourceVpce — ensures bucket hanya accessible dari VPC endpoint tertentu, mencegah akses dari lokasi lain. Ketiga layer bersama-sama membuat exfiltration sangat sulit. Opsi A (IAM only) — single layer, jika credentials compromised, bisa digunakan dari mana saja. Opsi C kurang IAM restriction dan NACLs tidak bisa distinguish antar S3 buckets. Opsi D — Lambda private IPs bersifat dynamic dan berubah setiap invocation.
