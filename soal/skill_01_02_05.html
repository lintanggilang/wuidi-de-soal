Skill 1.2.5: Implement Data Transformation Services Based on Requirements

Choosing between Amazon EMR, AWS Glue, Lambda, and Amazon Redshift for data transformation workloads

1
A company needs to transform 50 GB of JSON data daily from S3, performing deduplication, field mapping, and aggregation. The team has limited Spark experience and wants a no-code/low-code approach with visual authoring. They need the pipeline operational within one week. Which service is MOST appropriate?
  • A. AWS Glue Studio with visual ETL job editor
  • B. Amazon Redshift stored procedures with visual ETL
  • C. Amazon EMR with custom PySpark code
  • D. AWS Lambda with custom Python code
Jawaban Benar: A
AWS Glue Studio menyediakan visual drag-and-drop ETL editor yang tidak memerlukan coding. Transform nodes untuk dedup, mapping, dan aggregation tersedia out-of-the-box. 50 GB sesuai dengan Glue serverless capabilities. Team tanpa Spark experience bisa productive dalam days.

Opsi A: BENAR.
Opsi B: SALAH. Membutuhkan loading data terlebih dahulu — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Membutuhkan Spark expertise.
Opsi D: SALAH. Memiliki timeout/memory limits untuk 50 GB.
2
A data engineering team needs to process 10 TB of geospatial data with custom C++ libraries for coordinate transformations. The processing requires specialized libraries (GDAL, PROJ) not available in managed services. The job runs weekly. Which service provides the MOST flexibility?
  • A. AWS Glue with custom Python libraries configured for optimal performance and minimal operational overhead, integrating natively with the rest of the pipeline
  • B. AWS Lambda with Lambda layers containing the C++ libraries, requiring no servers to manage or scale manually and handling the described workload reliably at scale
  • C. Amazon EMR with custom bootstrap actions to install GDAL and PROJ, running a Spark job that calls native libraries via JNI or subprocess
  • D. Amazon Redshift with UDFs, applying schema conversion and enrichment inline and integrating natively with the rest of the pipeline and reducing day-to-day operational effort
Jawaban Benar: C
EMR memberikan full control atas environment melalui bootstrap actions yang bisa install any system-level packages (GDAL, PROJ, C++ libraries). Spark jobs bisa memanggil native libraries. 10 TB processing membutuhkan distributed computing yang EMR Spark sediakan.

Opsi A: SALAH. Mendukung Python libraries tapi sulit install system-level C++ dependencies — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Memiliki 250MB deployment limit dan 15 min timeout.
Opsi C: BENAR.
Opsi D: SALAH. Limited untuk geospatial processing scale ini.
3
A company needs to apply simple transformations to individual records in a data stream: parsing JSON, adding timestamps, and masking PII fields. Each record is processed independently. Volume is 1,000 records/second, each under 1 KB. Which transformation service is MOST cost-effective?
  • A. Amazon EMR Spark Structured Streaming for per-record transformation, applying schema conversion and enrichment inline
  • B. AWS Lambda triggered by the stream (Kinesis or MSK) for per-record transformation
  • C. Amazon Managed Service for Apache Flink, satisfying strict compliance and audit requirements
  • D. AWS Glue Streaming ETL, transforming records into the required target format
Jawaban Benar: B
Lambda adalah pilihan paling cost-effective untuk simple per-record transformations di volume moderat (1K records/sec). Pay-per-invocation model berarti Anda hanya membayar saat records diproses. Transformasi stateless sederhana (parse, add field, mask) ideal untuk Lambda.

Opsi A: SALAH. Membutuhkan cluster yang berjalan 24/7 — overkill — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: BENAR.
Opsi C: SALAH. Untuk complex stateful processing, terlalu mahal untuk simple transforms.
Opsi D: SALAH. Minimum charges DPU-hour.
4
A financial institution has existing complex SQL-based transformation logic (thousands of lines of SQL) running on an on-premises data warehouse. They want to migrate these transformations to AWS with minimal code changes. Which service provides the EASIEST migration path?
  • A. Amazon EMR — convert SQL to Hive queries with minimal syntax changes and scheduled queries with minimal syntax changes
  • B. AWS Lambda — rewrite transformations in Python, reducing day-to-day operational effort and applying schema conversion and enrichment inline
  • C. Amazon Redshift — migrate SQL transformations as stored procedures and scheduled queries with minimal syntax changes
  • D. AWS Glue — rewrite SQL logic in PySpark, removing the need to provision or patch any infrastructure
Jawaban Benar: C
Amazon Redshift menggunakan PostgreSQL-compatible SQL. Existing SQL transformations bisa dimigrasikan dengan perubahan minimal (AWS SCT membantu konversi syntax). Stored procedures, scheduled queries, dan materialized views tersedia. Ini memberikan migration path paling mudah untuk SQL-heavy workloads.

Opsi A: SALAH. SQL dialect berbeda dan limited features — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi B: SALAH. Complete rewrite dari SQL ke imperative code.
Opsi C: BENAR.
Opsi D: SALAH. Membutuhkan rewrite signifikan.
5
A data engineer needs to implement a real-time transformation pipeline that performs windowed aggregations, pattern detection, and stateful processing on a Kinesis stream. The stream has 100,000 events per second with complex event processing (CEP) requirements. Which service is BEST suited?
  • A. Amazon Managed Service for Apache Flink with custom Flink application for complex event processing
  • B. AWS Glue Streaming ETL with custom Flink application for complex event processing
  • C. AWS Lambda with Kinesis event source mapping, satisfying all of the stated requirements with minimal effort
  • D. Amazon Data Firehose with Lambda transformation, transforming records into the required target format
Jawaban Benar: A
Apache Flink excels at complex event processing: windowed aggregations (tumbling, sliding, session windows), pattern detection (FlinkCEP library), and stateful processing with exactly-once guarantees. 100K events/sec is well within Flink's throughput capabilities.

Opsi A: BENAR.
Opsi B: SALAH. Uses micro-batching (Spark Streaming) yang kurang real-time — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Tidak cocok untuk windowed aggregations dan stateful processing at scale.
Opsi D: SALAH. Untuk simple transforms, bukan CEP.
6
A startup processes 5 GB of data per batch, running 10 batches per day. The transformations are simple: flatten nested JSON, rename fields, and filter records. The team prioritizes minimal operational overhead. Which service requires the LEAST operational management?
  • A. Self-managed Apache Spark on Amazon EKS, integrating natively with the rest of the pipeline
  • B. AWS Glue ETL (serverless) — no infrastructure to manage, auto-scales, built-in scheduling
  • C. Amazon EMR on EC2 with auto-termination with fully managed infrastructure and automatic scaling
  • D. Amazon EMR Serverless, meeting the latency and throughput goals of the design
Jawaban Benar: B
AWS Glue adalah fully serverless — no servers, no cluster management, no capacity planning. Auto Scaling handles resources. Built-in scheduler (triggers) handles scheduling. For simple transforms (flatten, rename, filter), Glue DynamicFrames menyediakan native transforms. 5 GB per batch is ideal for Glue.

Opsi A: SALAH. Highest operational overhead.
Opsi B: BENAR.
Opsi C: SALAH. Membutuhkan cluster management — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Juga serverless tapi membutuhkan packaging Spark applications.
7
A data engineer needs to perform ELT (Extract-Load-Transform) where raw data is first loaded into Amazon Redshift and then transformed using SQL. The transformations include: creating denormalized tables, calculating running totals, and building slowly changing dimensions (SCD Type 2). Which Redshift feature is MOST appropriate for scheduling these SQL transformations?
  • A. Amazon MWAA (Airflow) with Redshift operator, validating and cleansing each record before delivery
  • B. AWS Step Functions calling Redshift Data API configured for optimal performance and minimal operational overhead
  • C. AWS Glue ETL job that runs SQL against Redshift via JDBC
  • D. Amazon Redshift stored procedures called by Amazon EventBridge Scheduler or Redshift scheduled queries
Jawaban Benar: D
Redshift stored procedures mengelompokkan SQL transformation logic, dan scheduled queries (atau EventBridge) menjalankannya pada jadwal. Ini solusi paling native untuk ELT dalam Redshift — logic dan execution dalam satu system. SCD Type 2, running totals, dan denormalization semuanya bisa diimplementasikan dalam SQL.

Opsi A: SALAH. Valid tapi overkill jika hanya scheduling Redshift queries.
Opsi B: SALAH. Valid tapi lebih complex untuk pure SQL transforms — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Menambah unnecessary layer.
Opsi D: BENAR.
8
A company needs to transform data as part of their streaming pipeline before delivery to S3. The transformation is lightweight: adding metadata fields and converting timestamp formats. The data source is already using Amazon Data Firehose. Which transformation approach requires the LEAST additional infrastructure?
  • A. Enable data transformation on the Firehose delivery stream using an inline Lambda function
  • B. Add a Kinesis Data Stream before Firehose and use a separate Lambda consumer
  • C. Replace Firehose with a Glue Streaming ETL job with real-time processing and low-latency data delivery
  • D. Deploy an Apache Flink application to perform the transformation, reducing day-to-day operational effort
Jawaban Benar: A
Amazon Data Firehose memiliki built-in data transformation feature yang memanggil Lambda function untuk memodifikasi records sebelum delivery ke destination. Tidak perlu infrastructure tambahan — hanya konfigurasi transformation Lambda pada Firehose stream yang sudah ada.

Opsi A: BENAR.
Opsi B: SALAH. Menambah Kinesis Data Stream dan Lambda terpisah.
Opsi C: SALAH. Mengganti Firehose dengan service lain — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi D: SALAH. Overkill untuk transformasi sederhana.
9
A company has a use case where data analysts need to explore and clean messy datasets (fixing data types, handling missing values, removing outliers) before formal ETL processing. They prefer a visual, interactive approach without writing code. Which AWS service is DESIGNED for this use case?
  • A. Amazon SageMaker Data Wrangler, handling the described workload reliably at scale and reducing day-to-day operational effort
  • B. Amazon QuickSight with data preparation, meeting the latency and throughput goals of the design
  • C. AWS Glue DataBrew — visual data preparation tool for cleaning and normalizing data without code
  • D. AWS Glue Studio visual editor and normalizing data without code for cleaning and normalizing data without code
Jawaban Benar: C
AWS Glue DataBrew adalah purpose-built untuk visual data preparation. Menyediakan 250+ built-in transformations (fix data types, handle nulls, remove outliers, standardize formats) dalam interface visual yang interaktif. Analysts bisa profile data dan apply cleaning recipes tanpa code.

Opsi A: SALAH. Untuk ML data preparation specifically.
Opsi B: SALAH. Untuk visualization bukan data cleaning.
Opsi C: BENAR.
Opsi D: SALAH. Untuk building ETL pipelines, bukan interactive data exploration — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
10
A data engineering team is deciding between AWS Glue and Amazon EMR for a new transformation workload. The workload processes 5 TB daily, requires Spark 3.4 with specific library versions, needs fine-grained cluster tuning (custom spark.conf, YARN settings), and the team has deep Spark expertise. Which service is MORE appropriate?
  • A. Amazon Redshift — for SQL-based transformations, applying schema conversion and enrichment inline and validating and cleansing each record before delivery
  • B. AWS Lambda — for serverless processing and allows custom spark-defaults, integrating natively with the rest of the pipeline
  • C. AWS Glue — handles all configuration automatically, applying schema conversion and enrichment inline and absorbing sudden traffic spikes without throttling
  • D. Amazon EMR — provides full control over Spark versions, cluster configuration, and allows custom spark-defaults.conf and YARN tuning
Jawaban Benar: D
EMR memberikan full control atas: Spark version selection, custom spark-defaults.conf, YARN resource manager configuration, instance types, dan library versions. Untuk team dengan deep Spark expertise yang membutuhkan fine-grained tuning, EMR memberikan flexibility yang tidak tersedia di Glue.

Opsi A: SALAH. SQL-only, bukan Spark.
Opsi B: SALAH. Untuk simple transforms, bukan 5 TB — meskipun deskripsinya terdengar meyakinkan, secara fundamental tetap tidak sesuai untuk kebutuhan ini.
Opsi C: SALAH. Abstracts infrastructure — tidak bisa tune YARN atau pilih exact Spark version.
Opsi D: BENAR.
