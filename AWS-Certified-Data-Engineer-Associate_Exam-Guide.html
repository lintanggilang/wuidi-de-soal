Panduan Ujian AWS Certified Data Engineer - Associate

Terjemahan Bahasa Indonesia dari panduan ujian resmi. Nama layanan dan istilah teknis AWS dipertahankan dalam bahasa asli.

Pendahuluan

Ujian AWS Certified Data Engineer - Associate (DEA-C01) memvalidasi kemampuan kandidat untuk mengimplementasikan data pipeline serta memantau, memecahkan masalah, dan mengoptimalkan isu biaya dan performa sesuai praktik terbaik.

Ujian ini juga memvalidasi kemampuan kandidat untuk menyelesaikan tugas berikut:

  • Melakukan ingesti dan transformasi data, serta mengorkestrasi data pipeline sambil menerapkan konsep pemrograman.
  • Memilih penyimpanan data yang optimal, merancang model data, mengatalogkan skema data, dan mengelola siklus hidup data.
  • Mengoperasikan, memelihara, dan memantau data pipeline. Menganalisis data dan memastikan kualitas data.
  • Menerapkan autentikasi, otorisasi, enkripsi data, privasi, dan tata kelola yang sesuai. Mengaktifkan logging.

Deskripsi Kandidat Sasaran

Kandidat sasaran sebaiknya memiliki pengalaman setara 2–3 tahun di bidang data engineering. Kandidat sasaran harus memahami efek volume, variasi, dan kecepatan (velocity) terhadap ingesti data, transformasi, pemodelan, keamanan, tata kelola, privasi, desain skema, dan desain penyimpanan data yang optimal. Selain itu, kandidat sasaran sebaiknya memiliki setidaknya 1–2 tahun pengalaman langsung (hands-on) dengan layanan AWS.

Pengetahuan TI Umum yang Direkomendasikan

  • Penyiapan dan pemeliharaan pipeline extract, transform, and load (ETL) dari ingesti hingga tujuan
  • Penerapan konsep pemrograman tingkat tinggi namun tidak bergantung bahasa tertentu, sesuai kebutuhan pipeline
  • Cara menggunakan perintah Git untuk kontrol sumber (source control)
  • Cara menggunakan data lake untuk menyimpan data
  • Konsep umum jaringan, penyimpanan, dan komputasi

Pengetahuan AWS yang Direkomendasikan

  • Cara menggunakan layanan AWS untuk menyelesaikan tugas yang tercantum di bagian Pendahuluan
  • Pemahaman tentang layanan AWS untuk enkripsi, tata kelola, perlindungan, dan logging seluruh data yang menjadi bagian data pipeline
  • Kemampuan membandingkan layanan AWS untuk memahami perbedaan biaya, performa, dan fungsi antar layanan
  • Cara menyusun kueri SQL dan cara menjalankan kueri SQL pada layanan AWS
  • Pemahaman cara menganalisis data, memverifikasi kualitas data, dan memastikan konsistensi data menggunakan layanan AWS

Tugas yang Berada di Luar Cakupan Kandidat Sasaran

Daftar berikut memuat tugas yang tidak diharapkan dapat dilakukan kandidat sasaran. Daftar ini tidak lengkap. Tugas-tugas ini di luar cakupan ujian:

  • Melakukan tugas artificial intelligence dan machine learning (AI/ML).
  • Menunjukkan pengetahuan sintaks spesifik bahasa pemrograman tertentu.
  • Menarik kesimpulan bisnis berdasarkan data.

Konten Ujian

Jenis Respons

Ada dua jenis soal pada ujian:

  • Pilihan ganda (multiple choice): Memiliki satu jawaban benar dan tiga jawaban salah (pengecoh/distractor)
  • Respons ganda (multiple response): Memiliki dua atau lebih jawaban benar dari lima atau lebih opsi jawaban

Pilih satu atau lebih respons yang paling melengkapi pernyataan atau menjawab pertanyaan. Pengecoh (distractor), atau jawaban salah, adalah opsi jawaban yang mungkin dipilih kandidat dengan pengetahuan atau keterampilan yang belum lengkap. Pengecoh umumnya adalah respons yang tampak masuk akal dan sesuai dengan area konten.

Soal yang tidak dijawab dinilai salah; tidak ada penalti untuk menebak. Ujian mencakup 50 soal yang memengaruhi skor Anda.

Konten Tidak Bernilai (Unscored)

Ujian mencakup 15 soal tidak bernilai yang tidak memengaruhi skor Anda. AWS mengumpulkan informasi performa pada soal tidak bernilai ini untuk mengevaluasinya sebagai soal bernilai di masa depan. Soal tidak bernilai ini tidak ditandai di dalam ujian.

Hasil Ujian

Ujian AWS Certified Data Engineer - Associate (DEA-C01) memiliki penilaian lulus atau tidak lulus. Ujian dinilai terhadap standar minimum yang ditetapkan oleh profesional AWS yang mengikuti praktik terbaik dan pedoman industri sertifikasi.

Hasil ujian Anda dilaporkan sebagai skor berskala 100–1.000. Skor kelulusan minimum adalah 720. Skor Anda menunjukkan performa Anda pada ujian secara keseluruhan dan apakah Anda lulus. Model skor berskala membantu menyetarakan skor di berbagai bentuk ujian yang mungkin memiliki tingkat kesulitan sedikit berbeda.

Laporan skor Anda bisa memuat tabel klasifikasi performa pada tiap tingkat bagian (section). Ujian menggunakan model penilaian kompensatoris, artinya Anda tidak perlu mencapai skor lulus pada tiap bagian. Anda hanya perlu lulus ujian secara keseluruhan.

Setiap bagian ujian memiliki bobot spesifik, sehingga beberapa bagian punya lebih banyak soal daripada bagian lain. Tabel klasifikasi memuat informasi umum yang menyoroti kekuatan dan kelemahan Anda. Berhati-hatilah saat menafsirkan umpan balik tingkat bagian.

Domain 1: Ingesti dan Transformasi Data

Pernyataan Tugas 1.1: Melakukan ingesti data.

Pengetahuan tentang:

  • Karakteristik throughput dan latensi untuk layanan AWS yang melakukan ingesti data
  • Pola ingesti data (misalnya frekuensi dan riwayat data)
  • Ingesti data streaming
  • Ingesti data batch (misalnya ingesti terjadwal, ingesti berbasis event)
  • Replayability (kemampuan memutar ulang) pipeline ingesti data
  • Transaksi data stateful dan stateless

Keterampilan dalam:

  • Membaca data dari sumber streaming (misalnya Amazon Kinesis, Amazon MSK, Amazon DynamoDB Streams, AWS DMS, AWS Glue, Amazon Redshift)
  • Membaca data dari sumber batch (misalnya Amazon S3, AWS Glue, Amazon EMR, AWS DMS, Amazon Redshift, AWS Lambda, Amazon AppFlow)
  • Mengimplementasikan opsi konfigurasi yang sesuai untuk ingesti batch
  • Mengonsumsi API data
  • Menyiapkan scheduler menggunakan Amazon EventBridge, Apache Airflow, atau jadwal berbasis waktu untuk job dan crawler
  • Menyiapkan pemicu event (misalnya Amazon S3 Event Notifications, EventBridge)
  • Memanggil fungsi Lambda dari Amazon Kinesis
  • Membuat allowlist untuk alamat IP agar koneksi ke sumber data diizinkan
  • Mengimplementasikan throttling dan mengatasi batas laju (rate limit) (misalnya DynamoDB, Amazon RDS, Kinesis)
  • Mengelola fan-in dan fan-out untuk distribusi data streaming

Pernyataan Tugas 1.2: Mentransformasi dan memproses data.

Pengetahuan tentang:

  • Pembuatan pipeline ETL berdasarkan kebutuhan bisnis
  • Volume, velocity, dan variety data (misalnya data terstruktur, data tidak terstruktur)
  • Komputasi cloud dan komputasi terdistribusi
  • Cara menggunakan Apache Spark untuk memproses data
  • Lokasi staging data perantara

Keterampilan dalam:

  • Mengoptimalkan penggunaan container untuk kebutuhan performa (misalnya Amazon EKS, Amazon ECS)
  • Menghubungkan ke berbagai sumber data (misalnya JDBC, ODBC)
  • Mengintegrasikan data dari banyak sumber
  • Mengoptimalkan biaya saat memproses data
  • Mengimplementasikan layanan transformasi data sesuai kebutuhan (misalnya Amazon EMR, AWS Glue, Lambda, Amazon Redshift)
  • Mentransformasi data antar format (misalnya dari .csv ke Apache Parquet)
  • Memecahkan dan men-debug kegagalan transformasi umum serta isu performa
  • Membuat API data untuk menyediakan data ke sistem lain menggunakan layanan AWS

Pernyataan Tugas 1.3: Mengorkestrasi data pipeline.

Pengetahuan tentang:

  • Cara mengintegrasikan berbagai layanan AWS untuk membuat pipeline ETL
  • Arsitektur berbasis event (event-driven)
  • Cara mengonfigurasi layanan AWS untuk data pipeline berdasarkan jadwal atau dependensi
  • Alur kerja serverless

Keterampilan dalam:

  • Menggunakan layanan orkestrasi untuk membangun alur kerja pipeline ETL data (misalnya Lambda, EventBridge, Amazon MWAA, AWS Step Functions, AWS Glue workflows)
  • Membangun data pipeline untuk performa, ketersediaan, skalabilitas, resiliensi, dan toleransi kesalahan
  • Mengimplementasikan dan memelihara alur kerja serverless
  • Menggunakan layanan notifikasi untuk mengirim peringatan (misalnya Amazon SNS, Amazon SQS)

Pernyataan Tugas 1.4: Menerapkan konsep pemrograman.

Pengetahuan tentang:

  • Continuous integration dan continuous delivery (CI/CD) (implementasi, pengujian, dan deployment data pipeline)
  • Kueri SQL (untuk kueri sumber data dan transformasi data)
  • Infrastructure as code (IaC) untuk deployment berulang (misalnya AWS CDK, AWS CloudFormation)
  • Komputasi terdistribusi
  • Struktur data dan algoritma (misalnya struktur data graph dan tree)
  • Optimasi kueri SQL

Keterampilan dalam:

  • Mengoptimalkan kode untuk mengurangi runtime ingesti dan transformasi data
  • Mengonfigurasi fungsi Lambda untuk memenuhi kebutuhan konkurensi dan performa
  • Menjalankan kueri SQL untuk mentransformasi data (misalnya stored procedure Amazon Redshift)
  • Menyusun kueri SQL untuk memenuhi kebutuhan data pipeline
  • Menggunakan perintah Git untuk membuat, memperbarui, meng-clone, dan mem-branch repositori
  • Menggunakan AWS SAM untuk mengemas dan men-deploy pipeline data serverless (misalnya fungsi Lambda, Step Functions, tabel DynamoDB)
  • Menggunakan dan me-mount volume penyimpanan dari dalam fungsi Lambda

Domain 2: Manajemen Penyimpanan Data

Pernyataan Tugas 2.1: Memilih penyimpanan data.

Pengetahuan tentang:

  • Platform penyimpanan dan karakteristiknya
  • Layanan dan konfigurasi penyimpanan untuk kebutuhan performa spesifik
  • Format penyimpanan data (misalnya .csv, .txt, Parquet)
  • Cara menyelaraskan penyimpanan data dengan kebutuhan migrasi data
  • Cara menentukan solusi penyimpanan yang sesuai untuk pola akses tertentu
  • Cara mengelola lock untuk mencegah akses ke data (misalnya Amazon Redshift, Amazon RDS)

Keterampilan dalam:

  • Mengimplementasikan layanan penyimpanan yang sesuai untuk kebutuhan biaya dan performa spesifik (misalnya Amazon Redshift, Amazon EMR, AWS Lake Formation, Amazon RDS, DynamoDB, Amazon Kinesis Data Streams, Amazon MSK)
  • Mengonfigurasi layanan penyimpanan yang sesuai untuk pola akses dan kebutuhan spesifik (misalnya Amazon Redshift, Amazon EMR, Lake Formation, Amazon RDS, DynamoDB)
  • Menerapkan layanan penyimpanan pada use case yang sesuai (misalnya Amazon S3)
  • Mengintegrasikan alat migrasi ke sistem pemrosesan data (misalnya AWS Transfer Family)
  • Mengimplementasikan metode migrasi data atau akses jarak jauh (misalnya federated query Amazon Redshift, materialized view Amazon Redshift, Amazon Redshift Spectrum)

Pernyataan Tugas 2.2: Memahami sistem katalog data.

Pengetahuan tentang:

  • Cara membuat katalog data
  • Klasifikasi data berdasarkan kebutuhan
  • Komponen metadata dan katalog data

Keterampilan dalam:

  • Menggunakan katalog data untuk mengonsumsi data dari sumbernya
  • Membangun dan merujuk katalog data (misalnya AWS Glue Data Catalog, Apache Hive metastore)
  • Menemukan skema dan menggunakan AWS Glue crawler untuk mengisi katalog data
  • Menyinkronkan partisi dengan katalog data
  • Membuat koneksi sumber atau target baru untuk katalogisasi (misalnya AWS Glue)

Pernyataan Tugas 2.3: Mengelola siklus hidup data.

Pengetahuan tentang:

  • Solusi penyimpanan yang sesuai untuk kebutuhan data panas (hot) dan dingin (cold)
  • Cara mengoptimalkan biaya penyimpanan berdasarkan siklus hidup data
  • Cara menghapus data untuk memenuhi kebutuhan bisnis dan hukum
  • Kebijakan retensi data dan strategi pengarsipan
  • Cara melindungi data dengan resiliensi dan ketersediaan yang sesuai

Keterampilan dalam:

  • Melakukan operasi load dan unload untuk memindahkan data antara Amazon S3 dan Amazon Redshift
  • Mengelola kebijakan S3 Lifecycle untuk mengubah tier penyimpanan data S3
  • Mengaturkan data kedaluwarsa saat mencapai usia tertentu menggunakan kebijakan S3 Lifecycle
  • Mengelola S3 versioning dan DynamoDB TTL

Pernyataan Tugas 2.4: Merancang model data dan evolusi skema.

Pengetahuan tentang:

  • Konsep pemodelan data
  • Cara memastikan akurasi dan keandalan data menggunakan data lineage
  • Praktik terbaik indexing, strategi partisi, kompresi, dan teknik optimasi data lainnya
  • Cara memodelkan data terstruktur, semi-terstruktur, dan tidak terstruktur
  • Teknik evolusi skema

Keterampilan dalam:

  • Merancang skema untuk Amazon Redshift, DynamoDB, dan Lake Formation
  • Menangani perubahan karakteristik data
  • Melakukan konversi skema (misalnya menggunakan AWS SCT dan AWS DMS Schema Conversion)
  • Membangun data lineage menggunakan alat AWS (misalnya Amazon SageMaker ML Lineage Tracking)

Domain 3: Operasi dan Dukungan Data

Pernyataan Tugas 3.1: Mengotomatiskan pemrosesan data menggunakan layanan AWS.

Pengetahuan tentang:

  • Cara memelihara dan memecahkan masalah pemrosesan data untuk hasil bisnis yang berulang
  • Panggilan API untuk pemrosesan data
  • Layanan mana yang menerima scripting (misalnya Amazon EMR, Amazon Redshift, AWS Glue)

Keterampilan dalam:

  • Mengorkestrasi data pipeline (misalnya Amazon MWAA, Step Functions)
  • Memecahkan masalah alur kerja terkelola Amazon
  • Memanggil SDK untuk mengakses fitur Amazon dari kode
  • Menggunakan fitur layanan AWS untuk memproses data (misalnya Amazon EMR, Amazon Redshift, AWS Glue)
  • Mengonsumsi dan memelihara API data
  • Menyiapkan transformasi data (misalnya AWS Glue DataBrew)
  • Mengkueri data (misalnya Amazon Athena)
  • Menggunakan Lambda untuk mengotomatiskan pemrosesan data
  • Mengelola event dan scheduler (misalnya EventBridge)

Pernyataan Tugas 3.2: Menganalisis data menggunakan layanan AWS.

Pengetahuan tentang:

  • Tradeoff antara layanan provisioned dan layanan serverless
  • Kueri SQL (misalnya pernyataan SELECT dengan banyak qualifier atau klausa JOIN)
  • Cara memvisualisasikan data untuk analisis
  • Kapan dan bagaimana menerapkan teknik pembersihan (cleansing)
  • Agregasi data, rolling average, grouping, dan pivoting

Keterampilan dalam:

  • Memvisualisasikan data menggunakan layanan dan alat AWS (misalnya AWS Glue DataBrew, Amazon QuickSight)
  • Memverifikasi dan membersihkan data (misalnya Lambda, Athena, QuickSight, Jupyter Notebooks, Amazon SageMaker Data Wrangler)
  • Menggunakan Athena untuk mengkueri data atau membuat view
  • Menggunakan Athena notebook yang memakai Apache Spark untuk mengeksplorasi data

Pernyataan Tugas 3.3: Memelihara dan memantau data pipeline.

Pengetahuan tentang:

  • Cara mencatat (log) data aplikasi
  • Praktik terbaik untuk performance tuning
  • Cara mencatat akses ke layanan AWS
  • Amazon Macie, AWS CloudTrail, dan Amazon CloudWatch

Keterampilan dalam:

  • Mengekstrak log untuk audit
  • Men-deploy solusi logging dan monitoring untuk memfasilitasi audit dan penelusuran (traceability)
  • Menggunakan notifikasi saat monitoring untuk mengirim peringatan
  • Memecahkan masalah performa
  • Menggunakan CloudTrail untuk melacak panggilan API
  • Memecahkan masalah dan memelihara pipeline (misalnya AWS Glue, Amazon EMR)
  • Menggunakan Amazon CloudWatch Logs untuk mencatat data aplikasi (fokus pada konfigurasi dan otomasi)
  • Menganalisis log dengan layanan AWS (misalnya Athena, Amazon EMR, Amazon OpenSearch Service, CloudWatch Logs Insights, log aplikasi big data)

Pernyataan Tugas 3.4: Memastikan kualitas data.

Pengetahuan tentang:

  • Teknik pengambilan sampel data
  • Cara mengimplementasikan mekanisme data skew
  • Validasi data (kelengkapan, konsistensi, akurasi, dan integritas data)
  • Data profiling

Keterampilan dalam:

  • Menjalankan pemeriksaan kualitas data saat memproses data (misalnya memeriksa field kosong)
  • Mendefinisikan aturan kualitas data (misalnya AWS Glue DataBrew)
  • Menyelidiki konsistensi data (misalnya AWS Glue DataBrew)

Domain 4: Keamanan dan Tata Kelola Data

Pernyataan Tugas 4.1: Menerapkan mekanisme autentikasi.

Pengetahuan tentang:

  • Konsep jaringan keamanan VPC
  • Perbedaan antara layanan terkelola (managed) dan tidak terkelola (unmanaged)
  • Metode autentikasi (berbasis password, berbasis sertifikat, dan berbasis role)
  • Perbedaan antara AWS managed policy dan customer managed policy

Keterampilan dalam:

  • Memperbarui security group VPC
  • Membuat dan memperbarui grup IAM, role, endpoint, dan layanan
  • Membuat dan merotasi kredensial untuk manajemen password (misalnya AWS Secrets Manager)
  • Menyiapkan IAM role untuk akses (misalnya Lambda, Amazon API Gateway, AWS CLI, CloudFormation)
  • Menerapkan IAM policy pada role, endpoint, dan layanan (misalnya S3 Access Points, AWS PrivateLink)

Pernyataan Tugas 4.2: Menerapkan mekanisme otorisasi.

Pengetahuan tentang:

  • Metode otorisasi (berbasis role, berbasis policy, berbasis tag, dan berbasis atribut)
  • Prinsip hak akses minimum (least privilege) yang berlaku pada keamanan AWS
  • Kontrol akses berbasis role dan pola akses yang diharapkan
  • Metode melindungi data dari akses tidak sah lintas layanan

Keterampilan dalam:

  • Membuat IAM policy kustom saat managed policy tidak memenuhi kebutuhan
  • Menyimpan kredensial aplikasi dan database (misalnya Secrets Manager, AWS Systems Manager Parameter Store)
  • Memberikan akses dan wewenang kepada pengguna, grup, dan role database (misalnya untuk Amazon Redshift)
  • Mengelola izin melalui Lake Formation (untuk Amazon Redshift, Amazon EMR, Athena, dan Amazon S3)

Pernyataan Tugas 4.3: Memastikan enkripsi dan masking data.

Pengetahuan tentang:

  • Opsi enkripsi data yang tersedia di layanan analitik AWS (misalnya Amazon Redshift, Amazon EMR, AWS Glue)
  • Perbedaan antara enkripsi sisi klien (client-side) dan sisi server (server-side)
  • Perlindungan data sensitif
  • Anonimisasi data, masking, dan key salting

Keterampilan dalam:

  • Menerapkan masking dan anonimisasi data sesuai hukum kepatuhan atau kebijakan perusahaan
  • Menggunakan kunci enkripsi untuk mengenkripsi atau mendekripsi data (misalnya AWS KMS)
  • Mengonfigurasi enkripsi lintas batas akun AWS
  • Mengaktifkan enkripsi in-transit untuk data

Pernyataan Tugas 4.4: Menyiapkan log untuk audit.

Pengetahuan tentang:

  • Cara mencatat data aplikasi
  • Cara mencatat akses ke layanan AWS
  • Log AWS terpusat

Keterampilan dalam:

  • Menggunakan CloudTrail untuk melacak panggilan API
  • Menggunakan CloudWatch Logs untuk menyimpan log aplikasi
  • Menggunakan AWS CloudTrail Lake untuk kueri logging terpusat
  • Menganalisis log menggunakan layanan AWS (misalnya Athena, CloudWatch Logs Insights, Amazon OpenSearch Service)
  • Mengintegrasikan berbagai layanan AWS untuk melakukan logging (misalnya Amazon EMR untuk volume data log besar)

Pernyataan Tugas 4.5: Memahami privasi dan tata kelola data.

Pengetahuan tentang:

  • Cara melindungi personally identifiable information (PII)
  • Kedaulatan data (data sovereignty)

Keterampilan dalam:

  • Memberikan izin untuk berbagi data (misalnya berbagi data untuk Amazon Redshift)
  • Mengimplementasikan identifikasi PII (misalnya Macie dengan Lake Formation)
  • Mengimplementasikan strategi privasi data untuk mencegah backup atau replikasi data ke AWS Region yang tidak diizinkan
  • Mengelola perubahan konfigurasi yang terjadi dalam akun (misalnya AWS Config)
